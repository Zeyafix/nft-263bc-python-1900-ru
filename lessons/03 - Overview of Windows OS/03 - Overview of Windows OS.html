02 / Зачем нужна операционная система

Определение

Операционная система

Операционная система (ОС) управляет устройствами и ресурсами компьютера и предоставляет программам общие способы работы с ними. Она помогает запускать программы, получать ввод с клавиатуры и мыши, хранить и открывать файлы. ОС сама по себе тоже считается программой.

Компоненты сами по себе не знают, что Вы хотите написать заметку. Программа «Блокнот» умеет работать с текстом, а ОС помогает ей получить память, прочитать файл и показать результат на экране. Благодаря этому разработчику Блокнота не нужно отдельно управлять каждой моделью SSD или клавиатуры.

Как ОС управляет ресурсами
РесурсЧто делает ОС
Время CPUРаспределяет время выполнения между работающими программами. Поэтому можно слушать музыку и печатать текст одновременно.
RAMВыделяет память программам и освобождает её, когда она больше не нужна. Память компьютера ограничена.
НакопительОрганизует чтение и запись файлов, проверяет доступ к ним.
УстройстваЧерез драйверы взаимодействует с графикой, клавиатурой, мышью и другими устройствами. Драйвер помогает ОС работать с конкретным оборудованием.

Windows 11 является одной из операционных систем. Есть и другие: Linux, macOS, Android, iOS. В этом уроке будем работать в Windows 11, но понятия файла, папки и программы встречаются и в других ОС.

В графическом интерфейсе Windows программы показывают содержимое в окнах. Окно можно переместить, свернуть, развернуть или закрыть. Свёрнутое окно исчезает с рабочего стола, но программа обычно продолжает работать. Папки помогают упорядочить файлы, а Проводник показывает их в своём окне. Окно и папка не одно и то же: закрыв окно Проводника, Вы не удалите папку.

На практике

Что происходит при открытии notes.txt?

Представим, что файл уже сохранён на SSD, а для расширения .txt выбран Блокнот. Это упрощённая последовательность:

  1. Вы дважды щёлкаете по notes.txt в Проводнике. Мышь передаёт действие компьютеру, Windows обрабатывает его.
  2. Windows определяет программу открытия для .txt и запускает Блокнот или передаёт файл уже работающему Блокноту.
  3. Блокнот обращается к ОС за содержимым файла. Данные читаются с SSD в RAM; если файл хранится на HDD, чтение идёт с HDD.
  4. CPU выполняет инструкции ОС и Блокнота. Блокнот подготавливает текст для показа, графическая подсистема с GPU помогает вывести окно на монитор.
  5. Когда Вы меняете текст, программа держит изменения в памяти. Команда «Сохранить» записывает их в файл на накопителе.

Материнская плата соединяет компоненты, блок питания снабжает их электричеством, а кулер CPU отводит тепло. Они поддерживают работу компьютера на всех этих шагах.

03 / Файлы, папки и Проводник

Проводник является программой для просмотра файлов и папок. Откройте его сочетанием Win + E или нажмите значок папки на панели задач. Клавиша Win обычно отмечена логотипом Windows.

Основные понятия файловой системы
ПонятиеОбъяснение и пример
ФайлДанные, сохранённые под именем: текст notes.txt, фотография photo.jpg или программа. У файла есть размер и место хранения.
ПапкаМесто для группировки файлов и других папок. Например, в папке Lesson03 лежат материалы одной пары.
ВложенностьПапка может находиться внутри другой папки. Lesson03 внутри Python Bootcamp является её вложенной папкой, а Python Bootcamp является родительской.
Корень дискаВерхний уровень файлов и папок на диске. Например, C:\. Выше корня в пределах этого диска подняться нельзя.
Обратите внимание

Буква диска не равна отдельному накопителю

В Проводнике Вы можете увидеть C: и D:. Они могут обозначать два раздела одного физического SSD или разные накопители. Букву также может получить флешка или подключённый сетевой ресурс. По числу букв нельзя определить число физических накопителей.

Адресная строка сверху показывает текущее расположение. Нажмите Ctrl + L, чтобы увидеть и выделить путь к обычной папке, ввести другой путь или скопировать адрес. «Главная» и «Этот компьютер» являются обзорными представлениями Проводника; у них нет обычного пути вида C:\папка.

04 / Имя, расширение и программа открытия

В имени notes.txt часть notes помогает человеку понять назначение файла, а .txt является расширением. Расширение обычно записывают после последней точки. Оно подсказывает предполагаемый тип файла и помогает Windows выбрать программу для открытия.

Имя, расширение и программа
Полное имяРасширениеЧто обычно внутриЧем работать
notes.txt.txtОбычный текстБлокнот или другой текстовый редактор
photo.jpg.jpgИзображение в формате JPEGФотографии или другой просмотрщик изображений
main.py.pyТекст программы на PythonРедактор для изменения кода; интерпретатор Python для выполнения
homework.zip.zipАрхив с файлами и папкамиПроводник или программа для архивов

Один тип файла могут поддерживать разные программы. Двойной щелчок использует назначенную программу, а пункт «Открыть с помощью» в контекстном меню позволяет выбрать другую. Для main.py действие зависит от установленного ПО и настроек. Переименование файла в .py само по себе не устанавливает Python.

  1. Откройте Проводник.
  2. На верхней панели выберите «Просмотреть» → «Показать» → «Расширения имён файлов» (в английском интерфейсе View → Show → File name extensions).
  3. Убедитесь, что теперь видно полное имя, например notes.txt. Оставьте расширения включёнными для следующих заданий.
Обратите внимание

Новое имя не меняет содержимое

Если переименовать notes.txt в notes.jpg, внутри останется тот же текст. Просмотрщик изображений может сообщить об ошибке, потому что ожидает данные JPEG. Для смены формата нужна программа, которая действительно преобразует и сохраняет данные в другом формате.

Обратите внимание

Почему получилось main.py.txt?

Если расширения скрыты, файл main.py.txt может отображаться как main.py. Его последнее расширение всё ещё .txt. Такое бывает, когда текстовый редактор добавляет расширение автоматически или при переименовании меняют только видимую часть имени.

Сначала включите расширения. Если внутри действительно текст программы Python и файл должен называться main.py, нажмите F2 и удалите конечное .txt. Подтверждайте предупреждение Windows только после проверки имени. Здесь мы исправляем имя текстового файла с кодом; текст в изображение от этого не превратится.

Справка Microsoft: Расширения имён файлов.

05 / Абсолютные и относительные пути

Путь описывает, как найти файл или папку. В Windows части обычного пути разделяют обратной косой чертой \. Во всех примерах ниже используем одну структуру папок. Student является учебным именем пользователя; на Вашем компьютере имя и расположение «Документов» могут отличаться, например из-за OneDrive.

Учебная структура папок (не команда)
C:\Users\Student\Documents\Python Bootcamp\
├── Lesson03\
│   ├── notes.txt
│   └── Drafts\
├── Images\
│   └── photo.jpg
└── Lesson04\
Определение

Абсолютный путь

Полный адрес начинается от корня, например C:\Users\Student\Documents\Python Bootcamp\Lesson03\notes.txt. Такой путь указывает на этот файл независимо от текущей папки. Здесь C:\ является корнем, затем перечислены папки и имя файла.

Определение

Относительный путь

Это маршрут от текущей папки. Если текущая папка Python Bootcamp, до заметок ведёт Lesson03\notes.txt. Если текущая папка уже Lesson03, достаточно notes.txt. Без начальной папки относительный путь нельзя истолковать однозначно.

. означает текущую папку, а .. означает родительскую. Поэтому .\notes.txt явно говорит «файл notes.txt здесь», а ..\notes.txt говорит «поднимись на один уровень и найди notes.txt». Две точки сами по себе не означают возврат к предыдущей посещённой папке.

Python BootcampLesson03\notes.txtВойти в Lesson03
Lesson03.\notes.txtОстаться в текущей папке

06 / Первое знакомство с терминалом

Терминал является приложением, в котором Вы вводите команды и видите текстовый результат. Команды позволяют работать с теми же файлами и папками, которые видны в Проводнике. Набор команд обрабатывает командная оболочка, например PowerShell или cmd. Windows Terminal показывает вкладки и текст, а оболочка внутри вкладки разбирает и выполняет команды.

  1. Откройте «Пуск», найдите «Терминал» / Windows Terminal и запустите обычным способом.
  2. В меню рядом с кнопкой «+» выберите Windows PowerShell или PowerShell. В этом уроке все команды выполняем в PowerShell. Если Терминал недоступен, найдите в «Пуск» Windows PowerShell и откройте его напрямую.
  3. В строке приглашения обычно виден текущий путь, например PS C:\Users\Student>. Вводите только команду, без PS, пути приглашения и знака >. После каждой команды нажимайте Enter.
Первые команды PowerShell
КомандаДействие
dirПоказывает список файлов и папок в текущей папке. Среди результатов ищите столбец Name с именами.
cd Lesson03Переходит в вложенную папку Lesson03.
cd ..Переходит в родительскую папку.
cd .Оставляет текущую папку той же.
cd "C:\Users\Student\Documents\Python Bootcamp"Переходит по абсолютному пути. Кавычки объединяют путь с пробелом в один аргумент.

В PowerShell dir и cd являются короткими именами команд просмотра содержимого и смены расположения. Папка назначения должна уже существовать: cd её не создаёт. Если получили сообщение, что путь не найден, проверьте текущую папку, имя и кавычки.

На практике

Команда может просто вывести текст

PowerShell: одна строка
echo "Hello Windows"
Результат
Hello Windows

Команда echo выводит переданный текст. Кавычки объединяют фразу с пробелом в одну строку; в результате сами кавычки не появляются. Эта команда не создаёт текстовый файл. В следующей паре сохраним результат вручную.
