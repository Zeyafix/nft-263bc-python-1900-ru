01 / Работа с папками и txt-файлами

Теперь соберём результат работы: текстовый файл и скриншот в одной папке, затем архив для отправки. На паре используйте папку Practice04. Для домашнего задания будет отдельная папка HW04.

  1. Нажмите Win + E. Откройте «Документы» и папку курса Python Bootcamp. Если её ещё нет, создайте её через «Создать» → «Папку».
  2. Внутри папки курса нажмите Ctrl + Shift + N, введите Practice04 и нажмите Enter. Откройте новую папку двойным щелчком.
  3. Включите расширения: «Просмотреть» → «Показать» → «Расширения имён файлов».
  4. Щёлкните правой кнопкой по свободному месту, выберите «Создать» → «Текстовый документ». Задайте полное имя notes.txt. Если Windows выделила только основу имени, замените её на notes, сохранив конечное .txt.
  5. Дважды щёлкните по notes.txt. Если открылось другое приложение, используйте «Открыть с помощью» → «Блокнот». Напишите две строки: что Вы создали и где находится файл.
  6. Нажмите Ctrl + S, закройте вкладку с файлом и откройте notes.txt снова из Проводника. Убедитесь, что текст сохранился.
Подсказка

Если нет пункта «Текстовый документ»

Откройте Блокнот через «Пуск», напишите текст и выберите «Файл» → «Сохранить как». В диалоге перейдите в Practice04, укажите имя notes.txt, тип «Текстовые документы (*.txt)» и кодировку UTF-8. После сохранения проверьте в Проводнике, что имя ровно notes.txt, без второго .txt.

Чтобы изменить файл, снова откройте его, дополните текст и нажмите Ctrl + S. Блокнот может восстанавливать несохранённые вкладки после закрытия, поэтому наличие текста в его окне ещё не подтверждает сохранение. Проверяйте сам файл, открывая его по нужному пути.

02 / Скриншот как способ показать результат

Скриншот является изображением того, что было видно на экране. Он помогает показать преподавателю результат, команду или сообщение об ошибке. Скриншот текста не заменяет сам .txt: текстовый файл можно открыть, скопировать и изменить.

  1. Покажите результат на экране. Для тренировки откройте сохранённый notes.txt в Блокноте так, чтобы текст читался.
  2. Нажмите Win + Shift + S и выделите область с нужным окном. Захватите заголовок и результат, оставив текст достаточно крупным.
  3. Нажмите уведомление о снимке, чтобы открыть его в «Ножницах». Если уведомление пропало, откройте «Ножницы» через «Пуск» и при необходимости сделайте снимок кнопкой «Создать».
  4. В «Ножницах» нажмите Ctrl + S или кнопку сохранения, выберите папку Practice04 и имя screenshot.png. Выберите формат PNG и сохраните.
  5. В Проводнике убедитесь, что в Practice04 лежат notes.txt и screenshot.png. Откройте картинку и проверьте читаемость.

Автоматические снимки обычно находятся в «Изображения» → «Снимки экрана». Папка может быть перенесена в OneDrive, а место и автоматическое сохранение «Ножниц» можно изменить в их настройках. Поэтому при выполнении задания явно выбирайте нужную папку при сохранении.

Если notes.txt или снимок уже находятся в другой папке, выделите нужный файл, нажмите Ctrl + X, откройте Practice04 и нажмите Ctrl + V. Повторите для второго файла. Не вставляйте изображение в Блокнот: картинка должна лежать рядом отдельным файлом.

На практике

Как скопировать текст из терминала

В Windows Terminal откройте PowerShell и выполните команду ниже. Мышью выделите только строку результата, затем нажмите Ctrl + Shift + C. В Блокноте нажмите Ctrl + V и сохраните файл через Ctrl + S. Для вставки команды в Windows Terminal используйте Ctrl + Shift + V.

PowerShell: результат для тренировки
echo "Practice04 completed"
Результат

Команда выводит строку без изменения файлов. На домашнем задании таким же способом скопируйте свой результат и сделайте скриншот терминала.

03 / Архивация и разархивация

Определение

Архив

Архив объединяет файлы и папки в один файл, например Practice04.zip, сохраняя их имена и вложенность. Это удобно для передачи целой работы. При архивации данные также могут сжиматься, но размер не всегда заметно уменьшается: изображения часто уже сжаты.

Для этих заданий используем формат ZIP. Windows умеет создавать и распаковывать его встроенными средствами. Архив является отдельным файлом: создание архива не удаляет исходную папку и не превращает её в архив.

  1. Сохраните текст и проверьте, что в Practice04 лежат оба готовых файла.
  2. Поднимитесь в родительскую папку Python Bootcamp и выделите саму папку Practice04.
  3. Нажмите правой кнопкой и выберите «Сжать в ZIP-файл» или «Сжать в…» → «ZIP-файл», если такой пункт есть. Другой путь: «Показать дополнительные параметры» → «Отправить» → «Сжатая ZIP-папка». Названия зависят от версии и языка Windows.
  4. Рядом появится Practice04.zip. Проверьте расширение .zip. Этот файл можно прикрепить к заданию.

Разархивировать означает извлечь файлы и папки из архива в обычную папку, чтобы работать с ними. Двойной щелчок по ZIP показывает содержимое в Проводнике, но сам просмотр ещё не извлекает всю работу.

  1. Нажмите правой кнопкой по Practice04.zip и выберите «Извлечь всё…».
  2. Выберите отдельную папку для проверки, например Practice04-check рядом с архивом. Нажмите «Извлечь».
  3. Откройте извлечённую папку Practice04 внутри Practice04-check. Найдите notes.txt и screenshot.png, откройте их и сравните с исходными.
  4. Если в архиве не хватает файла или лежит старая версия, сохраните изменения в исходной папке и создайте новый ZIP. Существующий архив сам по себе не обновляется при редактировании исходников.
Результат упаковки и проверки (не команда)
Python Bootcamp\
├── Practice04\
│   ├── notes.txt
│   └── screenshot.png
├── Practice04.zip
└── Practice04-check\
    └── Practice04\

04 / Домашние Задания

В MyStat откройте раздел "Домашние задания", перейдите во вкладку "К выполнению". Нажмите на карточку с Домашним Заданием. В правой части указано описание задачи. Если преподаватель прикрепил файл, то через кнопку "Открыть задачу" Вы сможете скачать этот файл.

После того, как Вы выполнили Домашнее Задание, можете перетянуть архив в область "Отправить на проверку", либо нажать на кнопку "Выберите файл", а затем выбрать архив. В будущем Вы будете отправлять ссылки на свои репозитории в текстовую область.
