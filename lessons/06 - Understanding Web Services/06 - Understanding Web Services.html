01 / От сети к веб-сервису

Интернет представляет собой сеть взаимосвязанных сетей. Веб использует эту инфраструктуру для работы сайтов и веб-приложений, к которым обращаются по HTTP или HTTPS. Через интернет также работают другие службы, например передача почты между почтовыми серверами. Поэтому интернет шире веба.

Браузер, сайт и веб-приложение
ПонятиеЧто этоПример
БраузерПрограмма, которая обращается к веб-ресурсам и показывает их пользователюGoogle Chrome, Microsoft Edge, Mozilla Firefox
СайтСвязанные страницы и ресурсы по веб-адресамСайт учебного центра с описанием курсов
Веб-приложениеПрограмма, с которой пользователь взаимодействует через браузерGoogle Диск для файлов, Google Документы для текста

Граница между сайтом и веб-приложением не строгая: сайт может содержать интерактивные функции. Но браузер остаётся отдельной программой, в которой вы открываете эти ресурсы. Закрытие вкладки не удаляет сам сайт.

Пример

Что происходит при открытии папки

  1. Вы открываете Google Диск и выбираете папку.
  2. Браузер отправляет серверу запрос на её содержимое.
  3. Сервис проверяет ваш аккаунт и права, затем возвращает данные о файлах или сообщение об отказе.
  4. Браузер отображает ответ: названия файлов, значки и кнопки действий.

HTTP задаёт правила обмена запросами и ответами в вебе. HTTPS добавляет защиту соединения: шифрует передаваемые данные, помогает обнаружить их изменение в пути и проверяет сертификат сервера для указанного имени. По обычному HTTP эти данные передаются без такой защиты.

Обратите внимание

HTTPS не оценивает честность сайта

Мошенник тоже может создать сайт с HTTPS. Защищённое соединение с неверным адресом всё равно ведёт на неверный сайт. Перед входом в аккаунт смотрите на доменное имя, а не только на значок возле адреса.

  1. Откройте главную страницу badssl.com по HTTPS. Это демонстрационный сайт для проверки поведения браузера при разных настройках соединения.
  2. В новой вкладке откройте http.badssl.com по HTTP. На этих страницах ничего вводить не нужно.
  3. Нажмите на адресную строку, чтобы увидеть полный адрес и схему. Посмотрите сведения о соединении через значок слева от адреса. Значки и формулировки зависят от браузера.
  4. Сравните: у первой ссылки схема https, у второй http. Браузер может предупредить о незащищённом соединении, автоматически перейти на HTTPS или заблокировать HTTP. Если это произошло, достаточно зафиксировать поведение; менять настройки защиты и обходить предупреждения не нужно.
Интересное

DevTools в браузере

Браузеры поддерживают встроенные инструменты разработчика (DevTools), через который можно узнать много интересного — как выглядит структура сайта, какие запросы делает браузер на открытом сайте и многое другое. В частности DevTools позволяют временно изменить текст или оформление уже открытой страницы в своём окне. Такая локальная правка сама по себе не отправляет изменение на сервер и не меняет страницу для остальных пользователей. После перезагрузки браузер снова получает данные сервиса.

Чтобы открыть DevTools, достаточно нажать комбинацию клавиш Ctrl + Shift + C.

02 / Где находятся мои файлы

Когда вы сохраняете notes.txt в обычной папке на диске компьютера, файл находится в локальном хранилище. Для открытия этого файла на том же компьютере интернет не требуется. Другой компьютер не получает к нему доступ автоматически.

Определение

Облачное хранилище

«Облако» состоит из удалённых компьютеров и работающих на них программ. Облачное хранилище принимает файлы, хранит их и выдаёт пользователям с нужными правами. Google Диск предоставляет доступ к такому хранилищу через браузер и приложения.

Направление передачи файла
ДействиеОткуда → кудаРезультат
Загрузить на Диск (upload)Ваш компьютер → облачный сервисФайл появляется в облачном хранилище
Скачать (download)Облачный сервис → ваш компьютерЛокальная копия появляется, например, в папке «Загрузки»

Слова «загрузить» и «скачать» иногда путают. Ориентируйтесь на направление: отправляете свой файл в Google Диск или получаете файл из Диска на компьютер.

Обратите внимание

Одна загрузка не создаёт синхронизацию

Вы загрузили notes.txt через браузер, затем изменили его исходную локальную копию в Блокноте. Облачная копия от этого сама не обновится. Чтобы передать новые данные, нужно отдельно загрузить обновлённый файл. При совпадении имени сервис может предложить обновить версию или сохранить оба файла.

Автоматическая синхронизация выполняется отдельно настроенным приложением, например Google Диском для компьютеров.

Два устройства с доступом к одному облачному файлу могут работать с общим содержимым. Но без сети нельзя связаться с удалённым хранилищем и получить новые изменения. Заранее скачанная копия доступна локально; специально включённый офлайн-режим некоторых приложений тоже позволяет работать с сохранёнными данными, а синхронизация произойдёт после подключения.

03 / Google Диск

Для действий ниже нужен аккаунт Google и подключение к интернету. Откройте Google Диск, войдите в свой аккаунт и проверьте его по значку профиля справа вверху.

Подготовка

Сначала подготовьте txt-файл на компьютере

  1. Создайте на компьютере обычную папку для практики урока 06.
  2. Откройте Блокнот и напишите: Работа с облачными файлами.
  3. Сохраните текст в подготовленной папке с именем notes.txt.
  4. В Проводнике включите показ расширений и убедитесь, что имя не превратилось в notes.txt.txt. Откройте файл ещё раз и проверьте текст.
  1. В Google Диске откройте раздел Мой диск.
  2. Нажмите Правую Кнопку Мыши на пустой области и выберите Новая папка. Назовите её Python Bootcamp.
  3. Откройте папку двойным щелчком. Проверьте её название в цепочке папок над списком файлов.
  4. Нажмите Правую Кнопку Мыши на пустой области, чтобы открыть Контекстное Меню, и выберите Загрузить файл, выберите локальный notes.txt и подтвердите выбор. Ещё один способ — просто перетяните notes.txt в окно браузера в область, которая подсвечивается (процесс называется Drag & Drop или DnD). Дождитесь завершения загрузки.
  5. Убедитесь, что файл появился в папке. Откройте его двойным щелчком и проверьте содержимое предпросмотра.

Если Вы привыкли работать с Windows, то некоторые горячие клавиши и действия для Вас будут знакомы.

04 / Google Документы

Google Документы позволяют создавать и оформлять текст в браузере. Документ хранится в сервисе, и приложение сохраняет ваши изменения при рабочем соединении. Это отличается от ручной загрузки готового txt-файла.

  1. Нажмите Правую Кнопку Мыши на пустой области и выберите Google Документы → Создать документ.
  2. Внутри документа нажмите на название Новый документ в левом верхнем углу и введите My Doc. Это имя файла на Диске.
  3. В области страницы напишите Урок 06. Выделите эту строку и на верхней панели в списке стилей, где обычно показан Обычный текст, выберите Заголовок 1. Обратите внимание, что в самой левой части появился заголовок.
  4. На следующей строке обычным текстом напишите два-три предложения о том, что Вы узнали на этом уроке. Если стиль заголовка сохранился, переключите строку на Обычный текст.
  5. Добавьте строку Что осталось непонятным, а под ней создайте маркированный список кнопкой списка на панели инструментов. Введите несколько пунктов, нажимая Enter после каждого. Два нажатия Enter в конце пустого пункта завершат список.

Пример содержания

Урок 06

Узнал, что есть private IP и public IP. Узнал про клиент-сервер архитектуру.

Что осталось непонятным:

  • Что такое шлюз?
  • Я слышал, что ещё есть понятие порт. Что это?

Название документа сверху помогает найти файл на Диске. Заголовок внутри страницы помогает читателю понять структуру текста.

Обычно изменения сохраняются автоматически. Но при проблемах с сетью проверьте состояние сохранения, прежде чем закрывать вкладку. Если изменения ещё не отправлены, они могут быть недоступны на другом устройстве. Для проверки снова откройте документ из папки и убедитесь, что текст, заголовок и список сохранились.

05 / Google Таблицы

Google Таблицы удобны для списков, чисел и вычислений. Столбцы идут сверху вниз и обозначаются буквами A, B, C. Строки идут слева направо и обозначаются числами 1, 2, 3. На пересечении находится ячейка.

Адрес ячейки состоит из буквы столбца и номера строки. B3 находится во втором столбце и третьей строке. Адрес выделенной ячейки показывается в поле слева над таблицей. В него можно ввести B3 и нажать Enter, чтобы сразу перейти к ячейке.

  1. На Диске откройте папку Python Bootcamp, нажмите Правую Кнопку Мыши на пустой области и выберите Google Таблицы → Создать таблицу.
  2. Нажмите на название файла в левом верхнем углу и задайте tasks.
  3. В A1 введите Задача, в B1 Срок, в C1 Статус. Enter завершает ввод и переводит ниже, Tab переводит вправо.
  4. Заполните строки 2–4 по примеру ниже. Сроки можно заменить своими датами.
  5. Если текст не помещается, расширьте столбец, потянув границу между его буквенным заголовком и соседним.
Содержимое tasks: столбцы A–C и строки 1–4

Попробуйте

Первая формула

  1. Щёлкните на пустую ячейку E2, чтобы не заменять данные задач.
  2. Введите =2+3 и нажмите Enter. В ячейке появится 5.
  3. Выберите E2 снова. В строке формул над таблицей будет видно исходное выражение =2+3.
  4. Замените выражение на =2+4, нажмите Enter и проверьте результат: 6.

Формула начинается со знака равенства. Не ставьте перед ним апостроф: он может превратить запись в текст. Если вы видите саму формулу вместо результата, проверьте формат ячейки и режим показа формул.

Формулы могут брать числа из других ячеек. Например, если в E4 стоит 2, а в E5 стоит 3, то =E4+E5 в E6 даст 5 и пересчитается после изменения этих чисел. Запись B2:B5 обозначает диапазон из четырёх ячеек B2, B3, B4 и B5.

Для среднего значения пригодится =AVERAGE(B2:B5), а при русских названиях функций =СРЗНАЧ(B2:B5).

06 / Доступ и отправка ссылки

Ссылка указывает, какой объект открыть. Разрешения определяют, пустят ли туда получателя и что он сможет сделать. Поэтому перед отправкой нужно ответить на два отдельных вопроса.

Кому доступен файл или папка?

НастройкаКто сможет открыть
Доступ ограничен; добавлены конкретные людиУказанные получатели после входа в аккаунт, которому вы дали доступ
Все, у кого есть ссылкаЛюбой получатель ссылки, в том числе тот, кому её перешлют; такая настройка может быть запрещена учебной организацией

Что разрешено получателю?

РольВозможности
ЧитательПросматривает содержимое; скачивание обычно разрешено, если владелец не ограничил его
КомментаторПросматривает и оставляет комментарии в поддерживаемых файлах, не меняя основной текст напрямую
РедакторИзменяет содержимое; для папки может управлять находящимися в ней объектами в пределах выданных прав

Настроив доступ к папке, вы обычно распространяете его и на содержимое, поэтому проверьте также вложенные файлы.

Порядок действий

Доступ конкретному человеку

  1. На Диске нажмите правой кнопкой на нужный файл или папку и выберите Поделиться. В документе можно использовать кнопку доступа справа вверху.
  2. Введите адрес Google-аккаунта получателя и выберите роль Читатель. Убедитесь, что выбрали правильного человека.
  3. Подтвердите изменение кнопкой Отправить. Если включено уведомление, сервис отправит получателю письмо.
  4. Нажмите Копировать ссылку. Получатель должен открывать её под тем аккаунтом, которому вы выдали доступ.
Порядок действий

Доступ по ссылке

  1. Откройте настройки доступа к нужной папке или файлу.
  2. В разделе Общий доступ переключите Доступ ограничен на Все, у кого есть ссылка.
  3. Выберите роль Читатель и сохраните изменение кнопкой Готово.
  4. Скопируйте ссылку на эту папку и откройте её в приватном окне браузера, где нет входа в ваш аккаунт. Убедитесь, что видны нужные файлы.

Такой способ удобен для сдачи по ссылке, но открыть её сможет любой, кто получит адрес. Делитесь папкой с нужными учебными файлами, а не всем личным хранилищем.

Частая ошибка

Почему ссылка открывается у вас, но не у преподавателя

Вы владелец и уже вошли в аккаунт. Поэтому ограниченная папка открывается у вас по любой её ссылке. У преподавателя может появиться запрос доступа. Кнопка «Копировать ссылку» сама по себе не выдаёт ему разрешение. Вернитесь в настройки и проверьте круг получателей и роль.

07 / Самопроверка

Вопрос

Какие утверждения о вебе и облачных файлах верны?

Под изменением через DevTools здесь понимается правка отображаемого текста или оформления в панели Elements.

Отметьте верные варианты.

При наличии сети и нужного доступа можно обращаться к одному хранилищу с разных устройств.

Для обмена с удалённым сервисом нужна сеть. Скачанная копия или заранее настроенный офлайн-режим позволяют работать с локальными данными, но это не связь с сервером.

Локальное изменение текста или оформления в панели Elements меняет страницу в вашем браузере. Само по себе оно не сохраняется на сервере.

Браузер является программой для работы с веб-ресурсами. Сайт объединяет ресурсы, а веб-приложение предоставляет интерактивные действия.

Ссылка не заменяет разрешения. Нужно убедиться, что у получателя уже есть или ему выдан доступ.
