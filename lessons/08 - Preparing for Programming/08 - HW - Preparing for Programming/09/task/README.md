# Задание 9. Очистка терминала

Файл решения: `main.py`.

Очистите экран после ввода и покажите результат.

## Что сделать

1. Запросите язык программирования через `input()` с подсказкой `Enter programming language: ` и сохраните ответ в переменной.
2. Запросите год через `input()` с подсказкой `Enter year: ` и сохраните ответ в другой переменной.
3. После получения года и перед выводом сообщения очистите экран терминала с помощью строки `"\033[2J\033[H"`.
4. Выведите `In <значение_года> I use <значение_языка> for programming`, подставив введённые значения.

Для очистки передайте эту строку в `print()`. Последовательности `\033[2J` и `\033[H` очищают экран и возвращают курсор в левый верхний угол. Можно использовать `end=""`; также допустим один пробел или переход на новую строку после команды очистки. Запускайте программу в терминале с поддержкой ANSI, например в PowerShell.

После двоеточия в каждой подсказке нужен один пробел. Угловые скобки и обозначения внутри них выводить не нужно. Используйте ответы как текст: сохраняйте пробелы и другие символы, пустой ответ тоже допустим. Вычислений с годом нет, преобразовывать его в число не требуется.

## Пример

Введите `Python`, затем `2026`. После очистки на экране должно остаться сообщение:

```text
In 2026 I use Python for programming
```
