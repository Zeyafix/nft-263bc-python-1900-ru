01 / Инструменты программиста

В этом уроке вы установите инструменты, создадите папку проекта и запустите первую программу. Затем научитесь показывать сообщения, сохранять значения под именами и получать ответы пользователя. Выполняйте шаги на своём компьютере: результат каждого запуска сравнивайте с примером.

Инструкции рассчитаны на Windows. Основной способ работы: писать код в VS Code, сохранять его в файл и запускать из отдельного окна терминала. Для терминальных команд можно использовать PowerShell или командную строку cmd; различия при активации окружения показаны отдельно.

Когда говорят «установить Python», обычно имеют в виду установить интерпретатор и сопутствующие инструменты. Расширение редактора не заменяет интерпретатор: нужны оба. Сам файл с кодом также ничего не выполняет, пока мы не запустим его через Python.

02 / Установка и проверка инструментов

Устанавливайте программы с официальных сайтов. Для курса нужна обычная стабильная версия Python и VS Code.

Установка

Ставим Python на компьютер

Откройте официальную страницу загрузки Python. Для Windows доступен Python Install Manager. Скачайте его и запустите установку.

После установки откройте новое окно терминала и выполните python --version. При первом обращении менеджер может предложить или выполнить установку интерпретатора. Дождитесь завершения.

Чтобы проверить, стоит ли на компьютере Python, выполните команду python --version — она покажет текущую установленную и выбранную версию Python. Затем выполните команду py --list — она покажет список установленных версий Python.

Установка

Ставим VS Code на компьютер

Откройте официальную страницу загрузки VS Code. Скачайте установщик для Windows.

При запуске установщика будет этап, где нужно поставить галочки. Поставьте галочки для следующих пунктов:

  1. Add "Open with Code" action to Windows Explorer file context menu — будет показывать пункт "Open with Code", если нажать Правую Кнопку Мыши по файлу.
  2. Add "Open with Code" action to Windows Explorer directory context menu — будет показывать пункт "Open with Code", если нажать Правую Кнопку Мыши по папке.
  3. Register code as an editor for supported file types — программа VS Code станет приложением по умолчанию для всех файлов, которые она может открывать.
  4. Add to PATH (requires shell restart) — позволит вызывать VS Code из терминала независимо от того, какая сейчас текущая папка.

Откройте новый терминал и впишите в него code. Эта команда запустит VS Code и откроет окно этой программы. В VS Code нажмите комбинацию клавиш Ctrl + Shift + X, чтобы открыть Extensions. Найдите расширение Python с издателем Microsoft и нажмите Install. Это расширение будет давать подсказки во время написания кода на Python.

03 / Папка проекта и первый запуск

Для удобства определитесь с местом, где будете хранить все проекты курса. Создайте в этой папке новую папку с именем 00-first-program — это название проекта. Перейдите в эту папку. Если терминал ещё не открыт в этой папке, то в Проводнике нажмите на адресную строку (там указан путь папки), введите powershell и нажмите Enter. Откроется отдельное окно PowerShell в этой папке. На протяжении всей работы не закрывайте этот терминал — он ещё понадобится.

Убедитесь, что терминал открыт в папке 00-first-program (можете выполнить dir и увидеть, что папка пустая). Это место называется корень проекта. Следующий этап — настройка окружения.

Определение

Окружение для проекта

Виртуальное окружение — это изолированная среда Python, в которой хранятся свой интерпретатор Python и установленные для конкретного проекта библиотеки. Это позволяет разным проектам использовать разные версии пакетов без конфликтов.

Если в папке проекта ещё нет .venv, создайте окружение. Находясь в терминале в корне проекта, выполните python -m venv .venv. Можно заметить, что на время создания терминал перестанет реагировать — это нормально, просто ждите возвращения управления. Окружение нужно создавать только один раз.

Разбор команды python -m venv .venv
Часть командыЧто означаетЧто делает

-mmoduleГоворит Python: «запусти указанный модуль как программу»

Если установлено несколько версий, можно явно выбрать одну из списка py --list. Например, для установленного Python 3.14 вместо предыдущей команды выполните py -3.14 -m venv .venv. Общий шаблон: py -<version> -m venv .venv. Замените <version> реальным номером без угловых скобок. Используйте только один из способов создания окружения.

После того, как настроили окружение, находясь в терминале в корне проекта, выполните code . — откроется VS Code в текущей папке. Создайте файл main.py — это будет точкой входа в программу.

Скопируйте код, указанный ниже, вставьте его в main.py и сохраните (клавиши Ctrl + S). Чтобы запустить этот код, нам нужно вызвать интерпретатор и передать ему файл main.py. Для этого выполните в терминале .venv\Scripts\python.exe main.py.

Терминал: запуск Python из окружения
.venv\Scripts\python.exe main.py
Консоль
Hello World
Подсказка

Если в терминале много текста

Если в терминале слишком много текста, можно вписать команду cls, которая полностью очистит терминал.

Есть несколько способов запустить код на Python.

  1. .venv\Scripts\python.exe main.py — вызов интерпретатора из папки .venv и передача ему файла.
  2. python main.py — вызов глобального интерпретатора, который установлен на компьютере, и передача ему файла.
  3. .venv\Scripts\Activate.ps1 затем python main.py — первая команда "подменит" слово python на .venv\Scripts\python.exe. Это приведёт к тому, что теперь команда python будет означать локальный интерпретатор из папки .venv. Этот процесс называется активация. Для деактивации достаточно написать deactivate.
Подсказка

Если PowerShell запрещает запуск Activate.ps1

Попробуйте выполнить Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process. Эта команда позволит запускать .ps1 скрипты в текущем терминале. Если открыть новый терминал, то эту команду придётся повторить.

04 / Вывод и последовательность действий

Функция выполняет определённую работу, когда мы её вызываем. Встроенная функция print выводит переданные значения. Запись print("Hello World") является вызовом: имя функции, открывающая скобка, значение для вывода и закрывающая скобка.

Текст внутри прямых кавычек является строкой. Кавычки помогают Python отличить текст от имён и команд. В консоль они не попадают. Для простой строки подходят двойные "Hello" или одинарные 'Hello' кавычки; открывающая и закрывающая должны совпадать.

main.py: сообщения по порядку
print("Начало")
print("Hello World")
print("Конец")
Консоль
Начало
Hello World
Конец

В таком простом файле вызовы выполняются сверху вниз. Каждый print() по умолчанию заканчивает вывод переходом на новую строку. Если поменять первую и последнюю строки кода местами, сообщения тоже поменяются местами.

main.py: пустая строка
print("Визитка")
print()
print("Python student")
Консоль
Визитка

Python student

Вызов print() без значений выводит только переход на новую строку. Скобки всё равно нужны, потому что мы вызываем функцию. Одно слово print в файле не выведет сообщение.

05 / Переменная и вывод значения

Определение

Переменная

Переменная позволяет обращаться к значению по имени. Присваивание name = "Teston" связывает имя name со строкой "Teston". Сначала Python получает значение справа от =, затем связывает с ним имя слева.

main.py: значение и его имя
name = "Teston"
print(name)
print("name")
Консоль
Teston
name

Вызов print(name) обращается к переменной и выводит её значение. Вызов print("name") (с кавычками) выводит буквально четыре буквы внутри кавычек. Само присваивание ничего в консоль не печатает. Сначала создайте связь имени со значением, затем используйте имя.

Представьте схему: имя name указывает на объект со значением "Teston" в памяти. На рисунке адрес 0x1A20 служит условной шестнадцатеричной меткой. Записывать такой адрес в программу не нужно. Переменная Python связана с объектом; при новом присваивании имя может указывать на другой объект. Рисунок не означает, что за именем навсегда закреплена одна ячейка памяти.

main.py: новое присваивание
name = "Teston"
print(name)
name = "Kate"
print(name)
Консоль
Teston
Kate

Имена чувствительны к регистру: name и Name являются разными именами. Для первых программ используйте понятные английские слова строчными буквами. Слова внутри имени разделяйте подчёркиванием: student_name. Пробелы и дефисы для этого не подходят, а начинать имя с цифры нельзя.

Чтобы вставить значение в сообщение, удобно использовать f-строку. Поставьте латинскую букву f прямо перед открывающей кавычкой, а имя переменной поместите в фигурные скобки внутри строки.

main.py: значение внутри сообщения
name = "Teston"
print(f"Hello, {name}!")
Консоль
Hello, Teston!

Сначала Python получает значение name и строит строку "Hello, Teston!". Затем print показывает эту строку. Буква f и фигурные скобки в результат не входят. Если забыть f, запись print("Hello, {name}!") выведет Hello, {name}! буквально.

В анимациях выражения в панели файла заменяются их значениями, чтобы показать ход вычисления. При обычном запуске Python не переписывает исходный файл.

06 / Ввод и сохранение ответа

До сих пор все сообщения были заранее записаны в коде. Чтобы спросить что-то у пользователя во время работы программы, нужна функция input. Она показывает подсказку, ждёт ввод с клавиатуры и после нажатия Enter возвращает введённую строку.

main.py: запрос без сохранения ответа
input("Enter your name: ")
Консоль
Enter your name: Teston

В примере «Enter your name: » печатает программа, а «Teston» вводит человек. Пробел перед закрывающей кавычкой отделяет подсказку от ответа. Пока пользователь не нажмёт Enter, программа ждёт. Здесь возвращённый ответ не присвоен имени, поэтому следующая инструкция не сможет обратиться к нему.

Если требуется использовать введённое значение дальше в программе, то результат работы функции input нужно поместить в переменную.

main.py: сохранить ответ
name = input("Enter your name: ")
print(f"Hello, {name}!")
Консоль
Enter your name: Teston
Hello, Teston!

Python начинает с правой части присваивания: вызывает input. Пользователь видит подсказку, вводит имя и нажимает Enter. input возвращает введённую строку, а присваивание связывает её с именем name. Следующая строка строит приветствие и выводит его через print.

Предупреждение

input возвращает текст

Функция input возвращает текст (а точнее тип данных str), даже если пользователь ввёл цифры. Если потребуется применить математические вычисления, то потребуется преобразование в число. Само имя age не превращает введённое в число.

Теперь соберём программу-визитку. Она спрашивает имя, город и занятие, сохраняет ответы, затем выводит их в оформленном сообщении.

main.py: программа-визитка
name = input("Your name: ")
city = input("Your city: ")
hobby = input("Your hobby: ")

print()
print("My business card")
print(f"Name: {name}")
print(f"City: {city}")
print(f"Hobby: {hobby}")
Консоль
Your name: Teston
Your city: Baku
Your hobby: creating games

My business card
Name: Teston
City: Baku
Hobby: creating games

Пустая строка между командами в исходном файле нужна для удобства чтения кода и сама ничего не выводит. Пустую строку в консоли создаёт print(). Для каждого нового запуска ответы запрашиваются заново.

Подсказка

Как очистить экран терминала

Чтобы при запуске визитки убрать прежний вывод с экрана, добавьте перед первым вопросом:

main.py: очистка экрана
print("\033[2J\033[H", end=" ")

В строке записаны управляющие последовательности ANSI. Терминал с их поддержкой воспринимает их как команды оформления. \033 обозначает специальный символ Escape, а не видимые цифры. Последовательность \033[2J очищает видимую область экрана, а \033[H перемещает курсор в левый верхний угол. История прокрутки при этом может сохраниться.

Параметр end задаёт, что print добавит в конце вывода. Обычно это переход на новую строку. Здесь end=" " заменяет его одним пробелом, поэтому следующий вывод начнётся в первой строке после этого пробела. Если пробел не нужен, используйте end="".

Проверяйте эту команду в терминале с поддержкой ANSI, например Windows Terminal. Панель Output и некоторые консоли редакторов могут не обрабатывать такие последовательности.
