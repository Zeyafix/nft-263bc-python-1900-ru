# Задание 3. Язык программирования

Файл решения: `main.py`.

Подставьте значение переменной в сообщение.

## Что сделать

1. Создайте переменную со строкой `Python`.
2. Выведите `I use <значение_переменной> for programming`, подставив значение переменной вместо обозначения в угловых скобках.

## Пример

```text
I use Python for programming
```
