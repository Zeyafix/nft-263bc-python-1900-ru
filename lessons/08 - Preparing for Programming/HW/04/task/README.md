# Задание 4. Год и язык

Файл решения: `main.py`.

Подставьте значения двух переменных в сообщение.

## Что сделать

1. Создайте переменную с числом `2026`.
2. Создайте другую переменную со строкой `Python`.
3. Выведите `In <значение_года> I use <значение_языка> for programming`, подставив значения обеих переменных.

## Пример

```text
In 2026 I use Python for programming
```
