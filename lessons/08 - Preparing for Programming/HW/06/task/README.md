# Задание 6. Язык из консоли

Файл решения: `main.py`.

Используйте ответ пользователя в сообщении.

## Что сделать

1. Запросите язык программирования через `input()` с подсказкой `Enter programming language: ` и сохраните ответ в переменной.
2. Выведите `I use <значение_переменной> for programming`, подставив введённые значения.

После двоеточия в каждой подсказке нужен один пробел. Угловые скобки и обозначения внутри них выводить не нужно. Используйте ответы как текст: сохраняйте пробелы и другие символы, пустой ответ тоже допустим.

## Пример

Ниже показан диалог: ответы после подсказок вводит пользователь.

```text
Enter programming language: Python
I use Python for programming
```
