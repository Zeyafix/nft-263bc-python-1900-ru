# Задание 7. Год и язык из консоли

Файл решения: `main.py`.

Соберите сообщение из двух ответов пользователя.

## Что сделать

1. Запросите язык программирования через `input()` с подсказкой `Enter programming language: ` и сохраните ответ в переменной.
2. Запросите год через `input()` с подсказкой `Enter year: ` и сохраните ответ в другой переменной.
3. Выведите `In <значение_года> I use <значение_языка> for programming`, подставив введённые значения.

После двоеточия в каждой подсказке нужен один пробел. Угловые скобки и обозначения внутри них выводить не нужно. Используйте ответы как текст: сохраняйте пробелы и другие символы, пустой ответ тоже допустим. Вычислений с годом нет, преобразовывать его в число не требуется.

## Пример

Ниже показан диалог: ответы после подсказок вводит пользователь.

```text
Enter programming language: Python
Enter year: 2026
In 2026 I use Python for programming
```
