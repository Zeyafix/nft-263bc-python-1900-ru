# Задание 3. Место учёбы

Файл решения: `main.py`.

Подставьте значение переменной в сообщение.

## Что сделать

1. Создайте переменную со строкой `Academy`.
2. Выведите `I am at the <значение_переменной> right now`, подставив значение переменной вместо обозначения в угловых скобках.

## Пример

```text
I am at the Academy right now
```
