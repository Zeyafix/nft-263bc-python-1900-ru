# Задание 4. Год и место

Файл решения: `main.py`.

Подставьте значения двух переменных в сообщение.

## Что сделать

1. Создайте переменную с числом `2026`.
2. Создайте другую переменную со строкой `Academy`.
3. Выведите `In <значение_года> I entered the <значение_места> to study programming`, подставив значения обеих переменных.

## Пример

```text
In 2026 I entered the Academy to study programming
```
