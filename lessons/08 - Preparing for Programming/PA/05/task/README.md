# Задание 5. Пауза перед выходом

Файл решения: `main.py`.

Дождитесь нажатия Enter, не сохраняя ответ.

## Что сделать

1. Вызовите `input()` с подсказкой `Press enter to exit...`.
2. Не сохраняйте и не используйте результат ввода. После нажатия Enter программа должна завершиться без дополнительных сообщений.

После трёх точек в подсказке нет пробела. Пользователь может просто нажать Enter; если он сначала введёт текст, программа всё равно должна завершиться.

## Пример

Появится подсказка. Нажмите Enter — программа завершится.

```text
Press enter to exit...
```
