02 / Значения и Типы

Программа работает с данными: количеством покупок, температурой, именем человека. Конкретные данные, с которыми мы работаем, называются значениями. Например, количество покупок может иметь значение 3.

Определение

Значение, литерал и тип

  • Значение отвечает на вопрос «какие именно данные?»: число 5869 или текст из четырёх цифр.
  • Литерал позволяет записать значение прямо в коде: 5869, 58.69, "5869". Кавычки обозначают границы строкового литерала, в сам текст они не входят.
  • Тип определяет, что это за данные и какие операции с ними возможны. Например, целое число, число с плавающей точкой или строка.
Похожие записи, разные типы
ЛитералТипКак прочитать
5869intЦелое число: можно прибавить 1 и получить 5870.
58.69floatЧисло с плавающей точкой: в коде дробная часть отделяется точкой.
"5869"strСтрока из четырёх символов: цифры используются как текст.

Имя переменной само по себе не является литералом. В записи code = "5869" слева находится имя, справа строковый литерал. В дальнейшем имя code позволяет обратиться к этому значению.

03 / Числа и Строки

Выбирайте тип по смыслу данных. Количество студентов удобно хранить как целое число, длину маршрута как число с дробной частью, а имя или номер телефона как текст. Номер телефона не складывают с другим номером; кроме цифр, в нём могут быть + и ведущие нули.

Когда нужны int, float и str
Тип данныхДля чегоПримеры
intЦелые количества, годы, счётчики; возможны ноль и отрицательные значения.26, 0, -5
floatИзмерения, коэффициенты и результаты обычного деления. Возможна небольшая погрешность представления.58.69, 0.25, 50.0
strТекст, в том числе цифры, пробелы и пустая строка."Alex", "0058", ""

Даже у 50.0 тип float: наличие целого математического значения не превращает объект в int. Для строк подходят одинарные и двойные кавычки; начало и конец записи должны совпадать по виду кавычек.

Важно

input всегда возвращает строку

Когда пользователь вводит 2000 и нажимает Enter, input() возвращает "2000". Кавычки пользователь не вводит: так мы показываем строковое значение в коде. Чтобы вычитать год из другого числа, сначала вызываем int().

Возраст в 2026 году
year = int(input("Enter your birth year: "))
age = 2026 - year
print(f"Your age is {age}")
Консоль
Enter your birth year: 2000
Your age is 26
  1. input("Enter your birth year: ") выводит подсказку и ждёт ответа. Вводим 2000 и нажимаем Enter.
  2. input() возвращает строку "2000". Внешний вызов int("2000") создаёт целое число 2000, которое присваивается year.
  3. В выражение 2026 - year подставляется число 2000. Результат 26 присваивается age.
  4. f-строка подставляет 26 вместо {age}. Функция print() выводит готовую строку Your age is 26.

Ниже указан ещё один пример. Программа запрашивает процент и число, затем применяет процент к введённому числу и выводит ответ.

Процент от числа
num = int(input("Enter num: "))
percent = int(input("Enter percent (%): "))
coef = percent / 100
result = num * coef
print(f"{percent}% of {num} is {result}.")
Консоль
Enter num: 200
Enter percent (%): 25
25% of 200 is 50.0.
  1. Два вызова input() возвращают "200" и "25". Два вызова int() превращают их в целые числа.
  2. 25 / 100 даёт 0.25. У coef теперь значение типа float: обычное деление целых чисел тоже возвращает этот тип.
  3. 200 * 0.25 даёт 50.0. При умножении int на float в этом примере получаем float.
  4. f-строка подставляет 25, 200 и 50.0. Знак % внутри текста выводится как обычный символ.

В этом примере вводятся целые числа, а float появляется в результате деления. Если нужны дробное число или дробный процент при вводе, замените соответствующий int(input(...)) на float(input(...)) и вводите дробную часть через точку. Например, float("12.5") даёт 12.5.

04 / Логические значения и Отсутствие значения

Иногда нужно хранить ответ на вопрос «да или нет»: активна ли подписка, успешно ли завершено действие. Для этого есть тип bool с двумя значениями: True и False. Они пишутся с заглавной буквы и без кавычек.

Признаки состояния
has_subscription = True
is_success = False
print(has_subscription)
print(is_success)
Консоль
True
False

"False" в кавычках уже строка, а не логическое значение. Ноль и единица тоже не являются литералами типа bool, хотя при некоторых сравнениях ведут себя похоже на False и True.

Определение

None обозначает отсутствие значения

Если ответ ещё неизвестен или значение не задано, можно сохранить None. Это отдельное значение со своим типом NoneType. Оно не равно по смыслу нулю, пустому тексту или отрицательному ответу.

Разные состояния анкеты
ЗаписьЧто известно
children_count = NoneКоличество детей ещё не указано. Мы не знаем ответ.
children_count = 0Ответ известен: детей нет. Ноль является числом.
comment = ""Текст комментария пустой: в строке нет символов.
has_subscription = FalseИзвестно, что подписка не активна. Это ответ «нет».
Значение ещё не задано
delivery_date = None
print(delivery_date)
Консоль
None

Название NoneType понадобится, чтобы читать результат определения типа. Для отсутствующего значения пишите None. Не путайте None со строкой "None", состоящей из четырёх букв.

06 / Преобразование типов

Преобразование позволяет получить значение подходящего типа. Например, сначала прочитать текст из консоли, затем получить из него число для расчёта. Функции int(), float() и str() возвращают результат: его нужно использовать или присвоить переменной.

Основные преобразования
ВыражениеРезультатТип результата
int("25")25int
float("25.5")25.5float
float(25)25.0float
str(25)"25"str
str(25.5)"25.5"str
int(25.9)25int
Исходная строка и полученное число
raw_age = "26"
age = int(raw_age)
print(type(raw_age))
print(type(age))
Консоль
<class 'str'>

Важно

int не округляет к ближайшему целому

int(25.9) даёт 25, а int(-25.9) даёт -25. Дробная часть отбрасывается, движение идёт к нулю. Это отличается от округления вниз для отрицательных чисел.

bool() отвечает на вопрос, считается ли значение истинным в логическом контексте. Среди изученных значений нули, пустая строка и None дают False. Ненулевые числа и непустые строки дают True.

Преобразуем в bool

print(bool(0), 0)
print(bool(25.5), 25.5)
print(bool(0.0), 0.0)
print(bool(0.000001), 0.000001)
print(bool("abc"), "abc")
print(bool(""), "")
print(bool("0"), "0")
print(bool("0.0"), "0.0")
print(bool(None), None)
print(bool("None"), "None")

Правила bool для изучаемых значений
Что передалиКогда TrueКогда False
Целое число, bool(integer_value)Число не равно 0, в том числе отрицательное.Число равно 0.
Число с точкой, bool(float_value)Число не равно 0.0, даже очень маленькое.Число равно 0.0, включая -0.0.
Строка или коллекция, bool(collection)Есть хотя бы один элемент или символ.Нет элементов или символов.
bool(None)Никогда.Всегда.

В таблице integer_value, float_value и collection обозначают переменные со значениями, которые проверяем. Коллекции хранят элементы; их изучим позже. Для строки элементами в этой проверке служат символы.

Важно

bool не читает смысл текста

"0", "0.0", "None" и даже "False" являются непустыми строками, поэтому дают True. Строка " " с пробелом тоже не пустая. Только "" не содержит ни одного символа.

Преобразование возможно не для любого значения. Если текст не подходит для нужного числового формата, Python сообщает об ошибке. В обычном запуске без обработки ошибки выполнение программы на этом месте прекращается. Примеры ниже запускайте по одному.

Когда преобразование не получается
ВыражениеЧто произойдётПочему и что проверить
int("25.9")ValueErrorint ожидает строковую запись целого. Для дробного числа используйте float; если затем вызвать int, дробная часть потеряется.

int("")ValueErrorПустой ввод не содержит числа.

Даже успешное преобразование может потерять важную информацию: int("0058") даёт 58, а int(25.9) теряет дробную часть. Поэтому коды с ведущими нулями хранят строками. Преобразование выбирают по задаче, а не только по отсутствию ошибки.
