# Задание 1. Вес по упрощённой формуле

Файл решения: `main.py`.

Напишите программу, которая рассчитывает вес по учебной формуле: рост в сантиметрах разделить на 2.5.

Запросите положительный рост с подсказкой `Enter your height (cm): `.

Выведите `Optimal weight: <вес> kg`. Покажите вес ровно с двумя знаками после точки, округлив отображаемое значение.

Пример работы (после подсказки показан ввод пользователя):

```text
Enter your height (cm): 173.33
Optimal weight: 69.33 kg
```

При росте `180` строка результата должна быть `Optimal weight: 72.00 kg`.
