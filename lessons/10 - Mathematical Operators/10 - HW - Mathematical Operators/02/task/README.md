# Задание 2. Исправьте преобразование ввода

Файл решения: `main.py`.

В файле [main.py](main.py) программа запрашивает целое число и должна прибавлять к нему 10. Сейчас она завершается с ошибкой.

Исправьте программу, сохранив сложение с 10. Подсказка и формат результата должны остаться такими же. Пользователь может ввести положительное число, ноль или отрицательное целое число.

Пример после исправления:

```text
Enter a number: 7
Result: 17
```
