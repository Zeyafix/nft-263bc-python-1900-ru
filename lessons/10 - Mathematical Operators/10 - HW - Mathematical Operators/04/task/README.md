# Задание 4. Исправьте формулу

Файл решения: `main.py`.

Нужно посчитать стоимость покупки после скидки на каждую единицу товара. Цена одной единицы — `price`, скидка с одной единицы — `discount`, количество — `quantity`.

Формула: `(price - discount) * quantity`.

В файле [main.py](main.py) уже есть код, но он выводит неверный ответ.

Исправьте вычисление `total`. Значения `price`, `discount` и `quantity` оставьте прежними. Результат должен вычисляться из этих переменных: нельзя просто записать готовый ответ. Можно заменить `*=` обычным присваиванием или разбить расчёт на несколько действий. Ввода с клавиатуры нет.

Ожидаемый вывод:

```text
Total: 300
```
