# Задание 8. Подарки поровну

Файл решения: `main.py`.

Распределите как можно больше подарков так, чтобы каждый человек получил одинаковое целое количество. Оставшиеся подарки остаются в коробке.

Запросите по порядку:

- `Number of people: ` — положительное целое количество людей;
- `Number of gifts: ` — целое количество подарков от 0.

Выведите:

```text
<gifts_per_person> gifts per person.
<gifts_left> left in box.
```

Пример работы:

```text
Number of people: 4
Number of gifts: 19
4 gifts per person.
3 left in box.
```
