# Задание 11. Время скачивания

Файл решения: `main.py`.

Рассчитайте время скачивания по размеру файла и постоянной скорости.

Запросите по порядку:

- размер файла в ГБ с подсказкой `File size (GB): `;
- скорость в МБ/сек с подсказкой `Download speed (MB/s): `.

Считайте, что 1 ГБ = 1000 МБ.

В этой задаче выводим только полные секунды, дробную часть общего времени отбросьте. Например, 3661.8 секунды считаем как 3661 полную секунду.

Разложите это время на целые часы, оставшиеся минуты и оставшиеся секунды. Часы могут быть больше 23; минуты и секунды — от 0 до 59 включительно.

Выведите три строки:

```text
Hours: <hours>
Minutes: <minutes>
Seconds: <seconds>
```

Пример работы:

```text
File size (GB): 9.1545
Download speed (MB/s): 2.5
Hours: 1
Minutes: 1
Seconds: 1
```
