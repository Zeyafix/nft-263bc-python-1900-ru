01 / Арифметические выражения

Вы уже знаете, что числа и строки ведут себя по-разному. Теперь научимся читать числовые выражения, выбирать нужное деление и изменять значения переменных. Запускайте примеры по отдельности и сначала предсказывайте результат.

Определение

Из чего состоит выражение

В выражении 5 + 3 знак + является оператором: он обозначает действие. Числа 5 и 3 являются его операндами: данными для действия. Результат выражения равен 8. Операндом может быть и переменная, и целое вложенное выражение.

Составное выражение
num_1 = 10
num_2 = 3
num_2_count = 4
total_sum = num_1 + num_2 * num_2_count
print(total_sum)
Консоль
22
  • Для * операндами служат num_2 и num_2_count. Их произведение равно 12.
  • Для + операндами служат num_1 и результат выражения num_2 * num_2_count. Получаем 10 + 12, то есть 22.
  • = обозначает присваивание. Справа находится вычисляемое выражение, слева total_sum, имя для результата.

При чтении сначала разбирайте правую часть, затем присваивание результата.

Основные арифметические операторы
ОператорДействиеПримерРезультат
+Сложение8 + 311
-Вычитание8 - 35
*Умножение8 * 324
/Обычное деление8 / 24.0
**Возведение в степень2 ** 38

2 ** 3 означает 2 × 2 × 2. Для степени в Python нужны две звёздочки.

Отрицательные числа
temperature = -5
print(temperature + 2)
print(3 - 8)
print(-temperature)
Консоль
-3
-5
5

Минус может находиться между двумя операндами, как в 3 - 8, или перед одним значением, как в -temperature. Во втором случае он меняет знак значения; переменная temperature при таком выводе остаётся равной -5.

Важно

Обычное деление возвращает float

Для обычных чисел int и float операция / возвращает float. Даже когда деление происходит нацело: 8 / 2 даёт 4.0, а не 4.

02 / Деление с округлением вниз и Остаток

Представьте 23 предмета и коробки вместимостью 9 предметов. Сколько полных коробок получится и сколько предметов останется? Обычное деление 23 / 9 даёт дробное число. Для этой задачи удобны две отдельные операции.

Коробки и оставшиеся предметы
item_count = 23
box_capacity = 9
full_boxes = item_count // box_capacity
remaining_items = item_count % box_capacity
print(full_boxes)
print(remaining_items)
Консоль
2
5
  • 23 // 9 даёт 2. Две полные коробки вмещают 18 предметов, а на третью не хватает.
  • 23 % 9 даёт 5. Это остаток после заполнения полных коробок: 23 - 2 * 9.
Важно

// округляет результат вниз

Операция // берёт частное и округляет его к меньшему целому. Для положительных чисел это похоже на отбрасывание дробной части. Для отрицательных нужно помнить направление: вниз по числовой прямой.

Отрицательное частное
print(-23 / 9)
print(-23 // 9)
print(int(-23 / 9))
print(-23 % 9)
Консоль
-2.5555555555555554
-3
-2
4

Число -3 меньше -2.555…, поэтому -23 // 9 равно -3. А int() отбрасывает дробную часть к нулю и даёт -2. Остаток согласован с делением: -23 = (-3) * 9 + 4. Для целых чисел и ненулевого делителя работает связь a == (a // b) * b + a % b.

Ненулевой остаток в Python имеет знак делителя. Например, 23 % -9 равно -4.

Тип результата //
print(23 // 9)
print(23.0 // 9)
print(type(23.0 // 9))
Консоль
2
2.0
<class 'float'>

Если хотя бы один из этих числовых операндов имеет тип float, результат // тоже будет float, хотя значение целое. Поэтому название «целочисленное деление» не означает, что тип результата всегда int.

Получаем цифру числа
num = 5869
print(num % 10)
print(num // 100 % 10)
Консоль
9
8

Остаток от деления положительного целого на 10 даёт последнюю цифру. Чтобы получить цифру сотен, сначала 5869 // 100 убирает две последние цифры и даёт 58, затем 58 % 10 оставляет 8.

03 / Порядок действий

Python использует приоритеты, чтобы понять, какие операнды относятся к каждому оператору. Например, 2 + 3 * 4 означает 2 + (3 * 4) и даёт 14. Скобки позволяют изменить группировку: (2 + 3) * 4 даёт 20.

Выражение для разбора
result = 30 - 5 + 4 * 11 ** (1 + 1) // 10 % 10 / 2
print(result)
Консоль
29.0

Разделим выражение по последнему сложению: слева 30 - 5, справа 4 * 11 ** (1 + 1) // 10 % 10 / 2. Python вычисляет левый операнд сложения, затем правый. Внутри каждого операнда действуют приоритеты.

Последовательное вычисление
ШагЧто вычисляемЧто остаётся
130 - 5 → 2525 + 4 * 11 ** (1 + 1) // 10 % 10 / 2
2(1 + 1) → 225 + 4 * 11 ** 2 // 10 % 10 / 2
311 ** 2 → 12125 + 4 * 121 // 10 % 10 / 2
44 * 121 → 48425 + 484 // 10 % 10 / 2
5484 // 10 → 4825 + 48 % 10 / 2
648 % 10 → 825 + 8 / 2
78 / 2 → 4.025 + 4.0
825 + 4.0 → 29.029.0
Приоритеты от высокого к низкому
ЗаписьКак группируется
(…)Скобки явно задают вложенное выражение.
**Степень; цепочка степеней группируется справа налево.
+x, -xЗнак одного числа; особенность рядом со степенью показана ниже.
*, /, //, %Один уровень приоритета; цепочка группируется слева направо.
+, -Сложение и вычитание; цепочка группируется слева направо.
Важно

Приоритет и порядок вычисления связаны, но различаются

Правило «сначала скобки» удобно для ручного счёта, но не означает, что Python ищет все скобки во всей строке и начинает с них. В нашем выражении он может вычислить 30 - 5 до скобок внутри правого операнда. Приоритет при этом не нарушен: финальное сложение ждёт результата всей правой части.

Одинаковый приоритет и степени
print(20 / 2 * 5)
print(2 ** 3 ** 2)
print((2 ** 3) ** 2)
print(-2 ** 2)
print((-2) ** 2)
print(2 ** -2)
Консоль
50.0
512
64
-4
4
0.25

Первый пример читается как (20 / 2) * 5, а не 20 / (2 * 5). Цепочка степеней 2 ** 3 ** 2 означает 2 ** (3 ** 2). Минус слева от степени применяется после неё: -2 ** 2 означает -(2 ** 2). Чтобы возвести отрицательное число в степень, пишите скобки. Справа от ** допустим отрицательный показатель: 2 ** -2 равно 1 / (2 ** 2).

04 / Изменение числовых значений

В играх, счётчиках и расчётах часто нужно обновить уже существующее число. Например, добавить к текущим очкам ещё 10. Это не математическое уравнение: Python сначала получает новое значение справа, затем связывает с ним имя слева.

Полная запись
score = 5
score = score + 10
print(score)
Консоль
15
Сокращённая запись
score = 5
score += 10
print(score)
Консоль
15

Для рассматриваемых чисел и простого имени переменной эти варианты дают один результат. Перед score += 10 переменная уже должна существовать. Если ещё не присвоили ей значение, Python сообщит NameError.

Сокращённые присваивания для чисел
Короткая записьПолная записьПри начальном score = 20
score += 10score = score + 1030
score -= 10score = score - 1010
score *= 10score = score * 10200
score /= 10score = score / 102.0
score %= 6score = score % 62
score //= 6score = score // 63
score **= 2score = score ** 2400

Каждая строка таблицы начинается с нового score = 20, строки не выполняются одна за другой. Обратите внимание: /= сохраняет результат обычного деления, поэтому значение становится float.

Важно

Сначала вычислите всю правую часть

В записи score *= score + 10 сперва выполняется правая часть выражения от знака присваивания: score + 10. Затем старое значение score умножается на этот результат. Для простого числового имени это соответствует score = score * (score + 10). Скобки при раскрытии сокращённой записи обязательны.

Умножение на вычисленное значение
score = 5
score *= score + 10
print(score)
Консоль
75
  1. Старое значение score равно 5.
  2. Справа вычисляем 5 + 10 и получаем 15.
  3. Умножаем старые 5 на 15 и получаем 75.
  4. Присваиваем 75 переменной score.

Запись score = score * score + 10 дала бы 35 при начальном значении 5. Это другое выражение, потому что сложение осталось за пределами множителя.

05 / Частые ошибки

Сообщение об ошибке помогает понять, какая операция не удалась. Читайте последнюю строку сообщения и строку кода, на которую указал Python. Примеры с ошибками ниже нужно запускать отдельно: необработанная ошибка прерывает текущий запуск.

Деление на ноль
print(5869 / 0)

Получим ZeroDivisionError. На ноль нельзя делить ни через /, ни через //; вычисление % 0 тоже вызовет эту ошибку. Проверьте значение делителя, особенно если оно пришло из ввода пользователя.

Строки и числа при сложении
ВыражениеРезультатОбъяснение
"2" + "3""23", тип strСоединение двух строк.
2 + 35, тип intСложение двух целых чисел.
"2" + 3TypeErrorСкладывать строку и число таким способом нельзя.

Если нужен расчёт, преобразуйте числовой текст в число. Если нужно собрать сообщение, преобразуйте число в строку или используйте f-строку. Внешне вывод 23 не показывает тип, поэтому при сомнении проверяйте его через type().

Рассмотрим особенность с float.

Погрешность float
result = 123.45 % 10
print(result)
Консоль
3.450000000000003

Почему не ровно 3.45? Компьютер хранит float с ограниченной точностью в двоичной системе. Многие десятичные дроби, в том числе 123.45, нельзя представить в ней точно. Похоже на попытку записать 1/3 конечным количеством десятичных цифр: запись приходится обрывать.

Если в задачах требуется высокая точность, то обычно используют специальный тип данных, либо специальные математические подходы при вычислениях. Для наших же задач достаточно будет использовать округление при выводе.

Вывод с двумя знаками после точки
result = 123.45 % 10
print(f"{result:.2f}")
print(result)
Консоль
3.45
3.450000000000003

Формат :.2f внутри f-строки показывает число с двумя знаками после точки. Он округляет отображение, но не меняет сохранённое значение result. Это удобно для читаемого вывода.
