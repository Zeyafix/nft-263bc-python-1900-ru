# Задание 3. Исправьте формулу

Нужно вычислить значение формулы `2 × (x + 3)²`.

Готовая программа в `main.py` запускается, но считает неверно. Исправьте программу. Сохраните операторы `**` и `*=`. Не заменяйте вычисление готовым ответом.

Пример работы в консоли (после подсказок показан ввод пользователя):
