# Задание 5. Байты и килобайты

Файл решения: `main.py`.

Запросите объём данных в байтах с подсказкой `Enter the size in bytes: ` и переведите его в килобайты. В этой задаче считаем, что один килобайт равен 1024 байтам.

Выведите объём в килобайтах с подписью `Size in kilobytes: ` и ровно двумя знаками после точки. Округляйте только при выводе, не в промежуточных вычислениях.

Сохраните точный текст подсказок и подписей, включая пробел после двоеточия.

## Пример

Пример работы в консоли (после подсказок показан ввод пользователя):

```text
Enter the size in bytes: 1536
Size in kilobytes: 1.50
```
