# Задание 9. Скидка 15 процентов

Файл решения: `main.py`.

Магазин даёт скидку 15% на товар. Запросите исходную цену с подсказкой `Enter the original price: ` и определите размер скидки в деньгах и цену после скидки. Скидка фиксирована: её не нужно вводить.

Выведите на отдельных строках сначала размер скидки с подписью `Discount: `, затем цену после скидки с подписью `Total: `. Обе суммы покажите ровно с двумя знаками после точки. Округляйте только при выводе, не в промежуточных вычислениях.

Сохраните точный текст подсказок и подписей, включая пробел после двоеточия.

## Пример

Пример работы в консоли (после подсказок показан ввод пользователя):

```text
Enter the original price: 200
Discount: 30.00
Total: 170.00
```
