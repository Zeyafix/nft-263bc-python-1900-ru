# Задание 10. Разложите сумму на купюры

Файл решения: `main.py`.

Запросите общую сумму денег с подсказкой `Enter the amount: `. Определите число купюр по 100, затем по 50, затем по 20 и оставшуюся сумму в единицах. На каждом шаге берите максимально возможное число купюр указанного номинала из текущего остатка. Других номиналов в задаче нет.

Выведите на отдельных строках количество купюр по 100 с подписью `Banknotes of 100: `, по 50 — `Banknotes of 50: `, по 20 — `Banknotes of 20: `, затем оставшуюся сумму в единицах с подписью `Remaining units: `. Все значения покажите без дробной части.

Сохраните точный текст подсказок и подписей, включая пробел после двоеточия.

## Пример

Пример работы в консоли (после подсказок показан ввод пользователя):

```text
Enter the amount: 289
Banknotes of 100: 2
Banknotes of 50: 1
Banknotes of 20: 1
Remaining units: 19
```
