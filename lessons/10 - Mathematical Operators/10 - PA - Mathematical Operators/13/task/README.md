# Задание 13. Разделите пиццу

Файл решения: `main.py`.

Пиццы одинаково нарезаны. Запросите количество пицц с подсказкой `Enter the number of pizzas: `, затем количество кусочков в одной пицце с подсказкой `Enter the slices per pizza: ` и количество участников с подсказкой `Enter the number of people: `.

Определите, сколько целых кусочков получит каждый участник, если раздать всем поровну максимально возможное количество, и сколько кусочков останется. Разрезать кусочки дополнительно нельзя.

Выведите на отдельных строках сначала количество кусочков для каждого участника с подписью `Slices per person: `, затем количество оставшихся кусочков с подписью `Slices left: `. Оба значения покажите без дробной части.

Сохраните точный текст подсказок и подписей, включая пробел после двоеточия.

## Пример

Пример работы в консоли (после подсказок показан ввод пользователя):

```text
Enter the number of pizzas: 3
Enter the slices per pizza: 8
Enter the number of people: 5
Slices per person: 4
Slices left: 4
```
