# Задание 5. Сумма купюр

Файл решения: `main.py`.

Все купюры имеют одинаковый номинал. По количеству купюр и их номиналу посчитайте общую сумму денег.

Запросите по порядку:

- количество купюр с подсказкой `Number of banknotes: ` — целое число от 0;
- номинал с подсказкой `Banknote value: ` — положительное целое число.

Выведите `Total: <сумма>`, где сумма — целое число.

Пример работы:

```text
Number of banknotes: 7
Banknote value: 20
Total: 140
```
