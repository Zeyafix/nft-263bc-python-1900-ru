# Задание 6. Дни в часах, минутах и секундах

Файл решения: `main.py`.

Создайте программу, которая переводит количество дней в общее количество часов, минут и секунд.

Запросите целое число дней от 0 с подсказкой `Enter days: `.

Выведите три строки с целыми числами:

```text
Hours: <hours>
Minutes: <minutes>
Seconds: <seconds>
```

В каждой строке нужно полное количество единиц за все введённые дни.

Пример работы:

```text
Enter days: 2
Hours: 48
Minutes: 2880
Seconds: 172800
```
