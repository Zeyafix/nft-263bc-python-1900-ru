# Задание 7. Вес по ИМТ 22

Файл решения: `main.py`.

Рассчитайте вес по учебной формуле с фиксированным индексом массы тела (ИМТ), равным 22:

`вес = ИМТ * квадрат_роста_в_метрах`

Запросите положительный рост в сантиметрах с подсказкой `Enter your height (cm): `.

Выведите `Optimal weight: <weight> kg`. Покажите вес ровно с двумя знаками после точки, округлив отображаемое значение.

Пример работы:

```text
Enter your height (cm): 175
Optimal weight: 67.38 kg
```
