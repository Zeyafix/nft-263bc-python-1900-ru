# Задание 9. Часы из секунд

Файл решения: `main.py`.

Пользователь вводит, сколько секунд прошло с полуночи. Покажите время на часах.

Запросите целое неотрицательное число с подсказкой `Enter seconds: `. Время может превышать одни сутки.

Выведите одну строку `<hours>:<minutes>:<seconds>`:

- часы от 0 до 23 включительно; после 23 наступает 0;
- минуты и секунды от 0 до 59 включительно;
- без пробелов и без ведущих нулей: `0:0:0`, а не `00:00:00`.

Пример работы:

```text
Enter seconds: 90061
1:1:1
```

При вводе `86400` результат — `0:0:0`, при `86399` — `23:59:59`.
