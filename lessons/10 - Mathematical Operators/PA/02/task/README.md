# Задание 2. Исправьте сообщение

В файле `main.py` программа получает целое число баллов, добавляет 5 и составляет сообщение. Вычисление проходит, но при создании сообщения программа падает. Исправьте программу: сохраните ввод через `int` и соединение строк оператором `+`.

## Пример

Пример работы в консоли (после подсказок показан ввод пользователя):

```text
Enter the score: 12
Score: 17
```
