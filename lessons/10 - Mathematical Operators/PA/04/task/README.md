# Задание 4. Температура по Фаренгейту

Файл решения: `main.py`.

Запросите температуру в градусах Цельсия с подсказкой `Enter the temperature in Celsius: ` и переведите её в градусы Фаренгейта по формуле `F = C × 9 / 5 + 32`.

Выведите результат с подписью `Temperature in Fahrenheit: ` и ровно двумя знаками после точки. Округляйте только при выводе, не в промежуточных вычислениях.

Сохраните точный текст подсказок и подписей, включая пробел после двоеточия.

## Пример

Пример работы в консоли (после подсказок показан ввод пользователя):

```text
Enter the temperature in Celsius: 0
Temperature in Fahrenheit: 32.00
```
