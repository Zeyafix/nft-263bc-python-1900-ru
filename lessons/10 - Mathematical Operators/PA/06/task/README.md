# Задание 6. Средняя оценка

Файл решения: `main.py`.

Запросите три оценки студента: первую с подсказкой `Enter the first grade: `, вторую — `Enter the second grade: `, третью — `Enter the third grade: `. Вычислите их среднее арифметическое.

Выведите среднюю оценку с подписью `Average grade: ` и ровно двумя знаками после точки. Округляйте только при выводе, не в промежуточных вычислениях.

Сохраните точный текст подсказок и подписей, включая пробел после двоеточия.

## Пример

Пример работы в консоли (после подсказок показан ввод пользователя):

```text
Enter the first grade: 80
Enter the second grade: 90
Enter the third grade: 100
Average grade: 90.00
```
