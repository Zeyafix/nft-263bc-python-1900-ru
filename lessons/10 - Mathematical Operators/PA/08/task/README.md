# Задание 8. Верните операторы на места

В `main.py` перепутаны операторы `/`, `//` и `%`. Программа должна показать результат обычного деления, целую часть частного и остаток. Исправьте операторы в трёх вычислениях, сохранив назначение переменных и формат сообщений.

Программа запрашивает сначала делимое с подсказкой `Enter the dividend: `, затем делитель с подсказкой `Enter the divisor: `.

Выведите на отдельных строках сначала результат обычного деления с подписью `Division: `, затем целую часть частного с подписью `Whole: ` и остаток с подписью `Remainder: `. Результат обычного деления покажите ровно с двумя знаками после точки, остальные два значения — без дробной части. Округляйте только при выводе, не в промежуточных вычислениях.

Сохраните точный текст подсказок и подписей, включая пробел после двоеточия.

## Пример

Пример работы в консоли (после подсказок показан ввод пользователя):

```text
Enter the dividend: 17
Enter the divisor: 5
Division: 3.40
Whole: 3
Remainder: 2
```
