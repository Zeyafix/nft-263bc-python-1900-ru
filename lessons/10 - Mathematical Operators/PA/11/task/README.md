# Задание 11. Топливо для поездки

Файл решения: `main.py`.

Запросите сначала длину маршрута в километрах с подсказкой `Enter the distance in km: `, затем расход автомобиля в литрах на один километр с подсказкой `Enter the fuel consumption in liters per km: `. Определите, сколько литров топлива понадобится для поездки.

Выведите необходимое количество топлива с подписью `Fuel in liters: ` и ровно двумя знаками после точки. Округляйте только при выводе, не в промежуточных вычислениях.

Сохраните точный текст подсказок и подписей, включая пробел после двоеточия.

## Пример

Пример работы в консоли (после подсказок показан ввод пользователя):

```text
Enter the distance in km: 150
Enter the fuel consumption in liters per km: 0.08
Fuel in liters: 12.00
```
