# Задание 14. Сколько дней читать книгу

Файл решения: `main.py`.

Запросите количество страниц в книге с подсказкой `Enter the number of pages: `, затем количество страниц, которые человек может прочитать за день, с подсказкой `Enter the pages per day: `. Определите, сколько дней нужно, чтобы дочитать книгу.

Ответ — целое количество дней. Даже если на последний день остаётся одна страница, этот день тоже считается: 101 страница при скорости 50 страниц в день требует 3 дня. Если книга прочитана ровно за несколько дней, лишний день добавлять не нужно.

Выведите количество дней с подписью `Days: ` без дробной части.

Сохраните точный текст подсказок и подписей, включая пробел после двоеточия.

## Пример

Пример работы в консоли (после подсказок показан ввод пользователя):

```text
Enter the number of pages: 101
Enter the pages per day: 50
Days: 3
```
