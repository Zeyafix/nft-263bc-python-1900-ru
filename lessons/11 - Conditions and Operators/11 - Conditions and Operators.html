02 / Условия и логические значения

На вопрос «Сколько вам лет?» нужен числовой ответ. На вопрос «Вам уже исполнилось 18 лет?» можно ответить «да» или «нет». Второй вопрос превращается в условие: утверждение, истинность которого программа может проверить.

Определение

Два значения типа bool

Тип bool содержит два логических значения: True означает «истина», а False означает «ложь». Для условия это ответы «да, выполняется» и «нет, не выполняется».

Пишите их с заглавной буквы и без кавычек. True является логическим значением, а "True" является строкой. Запись true Python воспримет как имя переменной; если такого имени нет, возникнет NameError.

Логические значения и их тип
is_open = True
is_closed = False
print(is_open)
print(is_closed)
print(type(is_open))
Консоль
True
False
<class 'bool'>

Представьте заслонку в трубе. Наш вопрос: «Проход открыт?» Открытая заслонка соответствует True, закрытая соответствует False. Значение описывает ответ на выбранный вопрос. Если спросить «Проход закрыт?», ответы для тех же состояний поменяются местами.

Сохраняем результат проверки
age = 20
is_adult = age >= 18
print(is_adult)
print(type(is_adult))
Консоль
True
<class 'bool'>

Знак >= читается «больше или равно». Сначала Python проверяет age >= 18, получает True, затем сохраняет это значение в is_adult. В переменной находится уже полученный ответ, а не постоянно работающая проверка.

При изменении возраста проверку нужно повторить
age = 17
is_adult = age >= 18
age = 18
print(is_adult)
is_adult = age >= 18
print(is_adult)
Консоль
False
True
Совет

Называйте переменную как понятное утверждение

Используйте английские имена в snake_case: is_adult («совершеннолетний»), has_ticket («есть билет»), can_enter («может войти»). Начала is_, has_ и can_ помогают читать код. Это соглашение об именах, а не обязательный синтаксис Python.

03 / Операторы сравнения

Сравнение отвечает на вопрос об отношениях между значениями. Для чисел и строк, которые мы используем в уроке, результат сравнения имеет тип bool. Операнды стоят слева и справа от оператора.

  • ==: равно ли одно значение другому?
  • !=: различаются ли значения?
  • > и <: строго больше и строго меньше.
  • >= и <=: больше или равно и меньше или равно. Знак равенства включает граничное значение.

В анимации ниже проверяется, опустился ли уровень воды ниже отметки 80. Условие water_level < 80 разрешает подачу воды. При достижении отметки 80 ответ уже False: строгое сравнение не включает равенство. Движение воды показано с задержкой, но логическая проверка имеет только два результата.

Порог наполнения

Важно

Не путайте = и ==

= выполняет присваивание: сохраняет значение под именем. == сравнивает значения и даёт логический ответ. Сравнение само по себе не изменяет переменную.

Присваивание и сравнение
age = 18
print(age == 20)
print(age)
is_eighteen = age == 18
print(is_eighteen)
Консоль

В последней проверке сначала вычисляется age == 18, затем знак = связывает имя is_eighteen с ответом. Чтобы проверить равенство, нужны именно два знака.

04 / Что именно мы сравниваем

Одинаковый внешний вид ещё не делает данные одинаковыми. Число 10 участвует в вычислениях как число. Строка "10" содержит два символа. Python не превращает эту строку в число автоматически при сравнении.

Значения и типы
print("10" == 10)
print("10" != 10)
print(10 == 10.0)
print(int("10") == 10)
Консоль
False
True
True
True

"10" == 10 даёт False, потому что сравниваются строка и число. При этом правило «разные типы всегда не равны» неверно: целое 10 и дробное 10.0 равны по числовому значению. Явное преобразование int("10") позволяет сравнить именно числа.

Сравниваем текст и сравниваем числа
print("10" < "2")
print(10 < 2)
print("Python" == "python")
Консоль
True
False
False

Две строки сравниваются посимвольно слева направо. В "10" < "2" уже первые символы определяют результат: символ "1" идёт раньше "2" по коду Unicode. До длины строк дело не доходит. Регистр тоже важен, поэтому "Python" и "python" не равны.

Важно

Равенство и порядок ведут себя по-разному

Сравнение "10" == 10 допустимо и возвращает False. А попытка вычислить "10" < 10 вызывает TypeError: Python не задаёт порядок между строкой и числом. Сначала решите, нужны вам символы или числовое значение, и при необходимости преобразуйте данные.

05 / Несколько требований: and

Предположим, что на мероприятие можно войти, только если человеку уже исполнилось 18 лет и у него есть билет. Одного выполненного требования мало. Оператор and объединяет проверки словом «и».

Определение

Как работает оператор and?

Если операнды имеют тип bool, выражение left and right даёт True, только когда оба значения равны True. Любое False делает результат ложным.

Таблица истинности and
Первое условиеВторое условиеРезультат and
FalseFalseFalse
FalseTrueFalse
TrueFalseFalse
TrueTrueTrue
Возраст и билет
age = 20
has_ticket = True
is_adult = age >= 18
can_enter = is_adult and has_ticket
print(can_enter)
Консоль
True

Здесь is_adult равно True и has_ticket равно True, поэтому вход разрешён. При age = 17 результат станет False, даже если билет есть. При has_ticket = False возраст тоже не поможет.

Объединяем больше двух требований
age = 20
has_ticket = True
is_banned = False
can_enter = age >= 18 and has_ticket and not is_banned
print(can_enter)
Консоль
True

Здесь добавлено требование «человек не заблокирован». Оператор not означает отрицание; подробно разберём его ниже. Цепочка из нескольких and требует выполнения каждого условия.

06 / Альтернативы: or

Теперь другое правило: в учебном примере для подтверждения личности принимают паспорт или водительские права. Достаточно любого из этих документов. Оператор or объединяет допустимые альтернативы.

Определение

Как работает оператор or?

Для логических операндов left or right даёт True, если хотя бы один операнд равен True. Результат будет False, только если оба значения равны False. Если верны оба условия, ответ тоже True.

Таблица истинности or
Первое условиеВторое условиеРезультат or
FalseFalseFalse
FalseTrueTrue
TrueFalseTrue
TrueTrueTrue
Паспорт или водительские права
has_passport = False
has_driver_license = True
can_identify = has_passport or has_driver_license
print(can_identify)
Консоль
True

Паспорта нет, но права есть, поэтому условие выполнено. Если оба документа отсутствуют, ответ будет False. Наличие обоих документов условию не мешает: Python использует «или» в смысле «хотя бы одно», а не «ровно одно».

Совет

Сначала сформулируйте правило словами

«Есть возраст и билет» требует and. «Есть паспорт или права» требует or. Замена оператора меняет правило допуска, даже если на некоторых входных данных результат случайно совпадёт.

07 / Отрицание: not

Иногда нужен ответ на противоположный вопрос. Есть переменная is_banned, а нам важно, что человек не заблокирован. Оператор not ставится перед одним операндом и отрицает его логическое значение.

Таблица истинности not
УсловиеРезультат not
TrueFalse
FalseTrue
Отрицаем условие
is_banned = False
can_continue = not is_banned
print(can_continue)
print(is_banned)
Консоль
True
False

not is_banned читается «не заблокирован». Результат равен True, но сама переменная is_banned остаётся равной False. Отрицание создаёт результат выражения, а не меняет исходную переменную.

Отрицание сравнения
age = 16
is_minor = not (age >= 18)
print(is_minor)
print(age < 18)
print(not (age <= 65))
print(age > 65)
Консоль
True
True
False
False

Для обычных числовых значений из урока «не больше или равно 18» означает «меньше 18». А «не меньше или равно 65» означает «больше 65». При отрицании не теряйте равенство: противоположность <= это >, а не >=.

Важно

Отрицание пишется словом not

В Python отдельный знак ! не заменяет not. При этом != является самостоятельным оператором «не равно». Скобки в not (age >= 18) помогают увидеть, какую именно проверку мы отрицаем.

08 / Сложные условия и порядок вычисления

Одно правило может содержать несколько групп требований. Чтобы не потерять смысл, сначала сформулируйте его словами, затем расставьте скобки и дайте промежуточным результатам понятные имена.

Приоритет среди операций этого урока, от высокого к низкому
ОперацииКак читать
(...)Скобки явно группируют часть выражения.
Арифметические операторыСначала находим значения для сравнения, сохраняя знакомый порядок арифметики.
==, !=, >, <, >=, <=Сравниваем полученные значения.
notОтрицаем результат проверки.
andОбъединяем обязательные требования.
orОбъединяем альтернативы.

Например, True or False and False группируется как True or (False and False) и даёт True. А (True or False) and False даёт False: скобки изменили смысл.

Важно

Приоритет задаёт группировку, а не обязательный расчёт всех частей

Python читает логическое выражение слева направо и может остановиться, если ответ уже известен. Поэтому скобки справа от or не заставляют вычислить правую часть раньше левой. Это видно в следующей анимации; само правило остановки разберём в разделе 09.

Разберём правило входа: «В 2026-м году человек уже совершеннолетний и у него есть билет, или в 2026-м году человек несовершеннолетний и есть родитель или опекун, а также есть билет». Уточняем группировку: для несовершеннолетнего требуется билет и хотя бы один сопровождающий.

Для примера возьмём год рождения 2000, наличие билета, родителя и опекуна обозначим значениями True. Считаем, что день рождения в 2026 году уже прошёл.

Правило в одном выражении
print((2026 - 2000) >= 18 and True or not ((2026 - 2000) >= 18) and (True or True) and True)
Консоль
True
  1. Вычисляем левое 2026 - 2000 и получаем 26.
  2. Проверяем 26 >= 18 и получаем True.
  3. Левая группа теперь True and True. Билет есть, поэтому вся группа равна True.
  4. Осталось True or not ((2026 - 2000) >= 18) and (True or True) and True. Левая альтернатива уже истинна, поэтому Python возвращает True. Часть о несовершеннолетнем и сопровождающих не вычисляется.
То же правило с понятными именами
current_year = 2026
birth_year = 2000
has_ticket = True
has_parent = True
has_guardian = True

is_adult = current_year - birth_year >= 18
can_enter = (is_adult and has_ticket) or (
    not is_adult and (has_parent or has_guardian) and has_ticket
)
print(can_enter)
Консоль
True

Слева от внешнего or находится путь для совершеннолетнего, справа путь для несовершеннолетнего. В каждой группе нужен билет. Скобки вокруг has_parent or has_guardian сохраняют смысл «хотя бы один сопровождающий». Переносы строк внутри общей пары скобок разрешены в Python.

Проверьте правило мысленно: человеку 16 лет, билет есть, родителя нет, опекун есть. Левая группа ложна, правая истинна, вход разрешён. Если убрать билет, обе группы станут ложными.

09 / Short-circuit evaluation

Определение

Вычисление останавливается, когда ответ уже известен

Short-circuit evaluation называют коротким замыканием или сокращённым вычислением. Для and ложная левая часть уже делает всё условие ложным. Для or истинная левая часть уже делает всё условие истинным. Правую часть в этих случаях Python не вычисляет.

Когда нужна правая часть
ВыражениеВычисляется ли правая часть?
False and ...Нет: ложного условия достаточно.
True and ...Да: нужно проверить оставшееся требование.
True or ...Нет: истинной альтернативы достаточно.
False or ...Да: правая альтернатива ещё может оказаться истинной.
Проверяем делитель до деления
total = 30
divisor = 0
is_large_share = divisor != 0 and total / divisor > 5
print(is_large_share)
Консоль
False

Сначала выполняется divisor != 0. При нулевом делителе это False, поэтому total / divisor > 5 пропускается. Деления на ноль не происходит. При divisor = 3 первая проверка истинна, Python делит 30 / 3, сравнивает 10.0 > 5 и получает True.

Важно

Защитная проверка должна стоять слева

В записи total / divisor > 5 and divisor != 0 Python сначала попробует выполнить деление. При divisor = 0 возникнет ZeroDivisionError. Правая проверка не сможет предотвратить уже начатое деление.

Вернёмся к правилу входа. После вычисления левой группы выражение имеет следующий вид:

Левая альтернатива уже истинна
True or not ((2026 - 2000) >= 18) and (True or True) and True

Оператор or получает True слева. Ни повторное вычисление возраста, ни not, ни проверка сопровождающих справа теперь не нужны. Это объясняет, почему анимация сразу переходит к итоговому True.

Важно

and и or возвращают один из операндов

До этого мы объединяли значения bool, поэтому и результат был bool. Но and и or не обязаны возвращать именно True или False. Они проверяют истинность значения и возвращают выбранный операнд без преобразования.

  • left and right: если слева ложное значение, возвращается оно; иначе вычисляется и возвращается правое.
  • left or right: если слева истинное значение, возвращается оно; иначе вычисляется и возвращается правое.
  • У чисел ноль считается ложным, любое ненулевое число истинным. Пустая строка считается ложной, непустая истинной, даже если это "False" или "0".
  • bool(value) явно получает логическое значение. Оператор not тоже всегда возвращает bool.
Логическая проверка и возвращаемое значение
print(7 and 12)
print(0 and 12)
print(7 or 12)
print(0 or 12)
print(bool(7 and 12))
print(not 7)
Консоль
12
0
7

10 / Диапазоны и границы

Пусть возраст должен находиться от 18 до 65 лет включительно. Требуются сразу две проверки: возраст не меньше нижней границы и не больше верхней.

Два способа проверить диапазон
age = 18
print(age >= 18 and age <= 65)
print(18 <= age <= 65)
Консоль
True
True

Запись 18 <= age <= 65 называется цепочкой сравнений. Читаем её слева направо: «18 меньше или равно возрасту, а возраст меньше или равен 65». Для этой переменной смысл совпадает с 18 <= age and age <= 65. Среднее выражение в цепочке вычисляется один раз; если первая проверка ложна, дальше проверять не нужно.

Как знаки сравнения меняют границы

18 < age < 65Не входитНе входит
18 <= age < 65ВходитНе входит
18 < age <= 65Не входитВходит
Проверяем выход за диапазон
age = 70
is_outside = age < 18 or age > 65
print(is_outside)
print(not (18 <= age <= 65))
Консоль
True
True

Чтобы оказаться снаружи, достаточно быть меньше 18 или больше 65. Поэтому нужен or. Выражение age < 18 and age > 65 для обычного возраста всегда ложно: число не может одновременно находиться с обеих сторон диапазона.

Для целочисленного возраста удобно брать 17, 18, 19 и 64, 65, 66. Такие проверки помогают заметить случайно потерянный знак =. В записи с and каждая часть должна быть полным условием: age >= 18 and age <= 65.

11 / Самопроверка

Вопрос

Какие операторы дают ответ в виде типа данных bool?

Рассматривайте сравнения обычных чисел, логические операции над значениями bool и арифметику чисел. Уточнение про логические операнды важно: с другими данными результат and и or может иметь другой тип.

Отметьте верные варианты.

not всегда возвращает логическое значение.

При операндах типа bool выбранный операнд тоже имеет тип bool. С числами результат может быть числом.

При операндах типа bool результат имеет тип bool. Вообще or возвращает один из операндов.

Сравнение изученных значений на равенство даёт True или False.

Проверка «больше» для чисел даёт логический ответ.

Проверка «меньше или равно» для чисел даёт логический ответ.

Сложение чисел даёт число. Даже True + True даёт целое число 2.

Умножение чисел даёт число. Даже True * True даёт целое число 1.

Присваивание связывает имя со значением. Это не проверка, возвращающая логический ответ.

Вопрос

Какой оператор даёт True, если оба операнда обязательно должны быть True?

Оба операнда имеют тип bool. Требование должно выполняться для всех сочетаний значений.

Отметьте верные варианты.

and даёт True только для сочетания True and True.

Равенство даёт True также для False == False.

Какой оператор даёт True, если хотя бы один операнд True?

Оба операнда имеют тип bool. При двух ложных операндах результат должен быть False.

Отметьте верные варианты.

or ложен только при двух ложных операндах.

True == False ложно, хотя один из операндов истинен.

and требует истинности обоих операндов.

not меняет логическое значение одного операнда на противоположное.

Какой оператор превратит результат работы оператора <= в результат работы оператора >?

Сравниваем обычные целые числа. Нужный оператор применяется ко всему результату сравнения.

Отметьте верные варианты.

Для целых чисел not (a <= b) равнозначно a > b.

Самостоятельного оператора ! в Python нет.

and объединяет требования и не отрицает сравнение.

or объединяет альтернативы и не отрицает сравнение.

True and (5869 // 10 % 10 == 1 or 5869 // 100 % 10 == 2)

Слева от and стоит True, поэтому нужен результат справа. Там 6 == 1 ложно, затем 8 == 2 тоже ложно; итог False.

and пропускает правую часть при ложном левом операнде. Здесь левый операнд истинен.

Здесь second_digit обозначает вторую цифру слева в данном четырёхзначном числе, то есть цифру сотен.

Отметьте верные варианты.

second_digit равно 8, поэтому деление допустимо. Выражение справа вычисляется, итоговый result равен False. При нулевой цифре левая проверка остановила бы вычисление до деления.

Вопрос

Что мы увидим в терминале при запуске следующего кода?

Числовые операнды and
print(5869 % 10 and 5869 // 10)
Отметьте верные варианты.

5869 % 10 даёт 9. Это истинное значение, поэтому and возвращает правый операнд: 5869 // 10, то есть число 586.

and возвращает операнд, а не преобразует его в bool. Значение True получилось бы при явном bool(5869 % 10 and 5869 // 10).

Оба числа ненулевые, а результат здесь является числом из правой части, а не False.

and может работать с числами: Python проверяет их истинность.

Синтаксис выражения корректен, оба операнда записаны полностью.

Вопрос

Что мы увидим в терминале при запуске следующего кода?

Полнота условий

Отметьте верные варианты.

После and нет левого операнда для <=. Правильно: age >= 18 and age <= 65 или 18 <= age <= 65. Ошибка синтаксиса обнаруживается до выполнения программы.

Программа не доходит до вычисления логического результата: правая проверка записана не полностью.

Проблема в синтаксисе, а не в совместимости типов.

Возраст 20 вошёл бы в диапазон при правильной записи, но Python не подставляет age после and автоматически.
