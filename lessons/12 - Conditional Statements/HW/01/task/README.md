# Задание 1. Ближе к нулю

Запросите два числа. Покажите число, которое ближе к нулю, в строке `Closest: <число>`.
Если расстояния одинаковы, выведите только `Equal distance`. Числа могут быть отрицательными и содержать дробную часть.

Перед каждым вводом покажите понятную подсказку на английском: что именно нужно ввести. Точную формулировку можно выбрать самостоятельно.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
First number: -2
Second number: 5

Closest: -2.0
```
