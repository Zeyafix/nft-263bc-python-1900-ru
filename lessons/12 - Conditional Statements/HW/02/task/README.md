# Задание 2. Три числа

Запросите три числа. Выведите ровно одно сообщение: `All equal`, если равны все три; `Two equal`, если равны только два; `All different`, если все разные.

Перед каждым вводом покажите понятную подсказку на английском: что именно нужно ввести. Точную формулировку можно выбрать самостоятельно.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
First number: 2
Second number: 2
Third number: 2

All equal
```
