# Задание 3. Время года

Запросите номер месяца. Декабрь, январь и февраль относятся к зиме, март–май к весне, июнь–август к лету, сентябрь–ноябрь к осени.
Выведите `Winter`, `Spring`, `Summer` или `Autumn`. Для номера вне 1–12 выведите `Input error`. Номер вводится без дробной части.

Перед каждым вводом покажите понятную подсказку на английском: что именно нужно ввести. Точную формулировку можно выбрать самостоятельно.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Month: 0

Input error
```
