# Задание 5. Цвет шахматной клетки

Запросите номер столбца, затем номер строки шахматной доски. Каждый номер — от 1 до 8 без дробной части. Клетка (1, 1) чёрная, соседние по стороне клетки имеют разные цвета.
Выведите `Black` или `White`. Если хотя бы одна координата вне доски, выведите `Input error`.

Перед каждым вводом покажите понятную подсказку на английском: что именно нужно ввести. Точную формулировку можно выбрать самостоятельно.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Column: 1
Row: 1

Black
```
