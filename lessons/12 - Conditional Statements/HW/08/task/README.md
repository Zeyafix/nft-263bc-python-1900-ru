# Задание 8. Максимум из пяти чисел

Запросите пять чисел и выведите `Maximum: <наибольшее число>`. Числа могут быть отрицательными, равными и содержать дробную часть.
Решите задачу без использования функции `max()`.

Перед каждым вводом покажите понятную подсказку на английском: что именно нужно ввести. Точную формулировку можно выбрать самостоятельно.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
First number: 10
Second number: -2
Third number: -3
Fourth number: -4
Fifth number: -5

Maximum: 10.0
```
