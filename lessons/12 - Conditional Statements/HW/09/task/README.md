# Задание 9. Температура за неделю

Запросите температуру за каждый из семи дней недели, начиная с понедельника. Допускаются отрицательные значения и дробная часть.
Выведите `Average: <средняя температура>` с двумя знаками после точки. Затем покажите дни, температура которых строго выше среднего: по одному английскому названию на строке, в порядке недели (`Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`, `Sunday`). Сравнивайте с точным средним до округления для вывода.
Если таких дней нет, после среднего выведите `No days above average`.

Перед каждым вводом покажите понятную подсказку на английском: что именно нужно ввести. Точную формулировку можно выбрать самостоятельно.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Monday temperature: 1
Tuesday temperature: 2
Wednesday temperature: 3
Thursday temperature: 4
Friday temperature: 5
Saturday temperature: 6
Sunday temperature: 7

Average: 4.00
Friday
Saturday
Sunday
```
