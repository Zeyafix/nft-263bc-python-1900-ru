# Задание 11. Конвертер валют

Напишите конвертер для AZN, RUB и USD. В начале программы находятся коэффициенты:

```python
azn_to_rub = 49.33
azn_to_usd = 0.59
rub_to_usd = 0.012
```

Это учебные фиксированные коэффициенты: сколько целевой валюты дают за единицу исходной. Обратное направление использует обратный коэффициент соответствующей пары. Не переводите через третью валюту: заданные коэффициенты независимы.

1. Покажите меню исходной валюты: `1. AZN`, `2. RUB`, `3. USD`, каждый пункт на отдельной строке. Запросите выбор.
2. После любого выбора очистите терминал. Если введено что-либо кроме `1`, `2`, `3`, выведите `Invalid currency` и завершите программу.
3. Покажите `Source: <валюта>`, пустую строку и такое же меню целевой валюты. Запросите выбор и снова очистите терминал при любом ответе. Неверный пункт даёт `Invalid currency` и завершает программу. Совпадение валют даёт `Same currency` и завершает программу.
4. Покажите `Conversion: <исходная> -> <целевая>`, затем `Rate: <курс>` с шестью знаками после точки. Запросите сумму. Отрицательная сумма даёт `Invalid amount`, ноль допустим.
5. На следующей строке выведите `Result: <сумма> <целевая валюта>` с двумя знаками после точки. Для расчёта используйте курс до округления для показа.

При ошибке не запрашивайте следующие данные. Очистка должна происходить в терминале; печатать вместо неё сообщение не нужно.

Перед каждым вводом покажите понятную подсказку на английском: что именно нужно ввести. Точную формулировку можно выбрать самостоятельно.

## Пример

Пример диалога: после подсказок показаны ответы пользователя. `[экран очищен]` обозначает очистку терминала; эту строку программа не печатает.

```text
1. AZN
2. RUB
3. USD
Source currency: 1
[экран очищен]
Source: AZN

1. AZN
2. RUB
3. USD
Target currency: 2
[экран очищен]
Conversion: AZN -> RUB
Rate: 49.330000
Amount: 10
Result: 493.30 RUB
```
