# Задание 12. Исправление HTTP-статуса

Исправьте программу из [starter.py](starter.py). Она получает код HTTP без дробной части. Для любого значения вне [100, 599] нужен результат `Input error`.
Для допустимого кода выведите ровно одну категорию: 100–199 — `Informational`, 200–299 — `Success`, 300–399 — `Redirection`, 400–499 — `Client Error`, 500–599 — `Server Error`.

Справа от исправленных строк оставьте комментарии: объясните, почему изменение делает программу правильной.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Enter code: -100

Input error
```
