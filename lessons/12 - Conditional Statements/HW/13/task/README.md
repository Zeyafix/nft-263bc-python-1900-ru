# Задание 13. Исправление меню даты и времени

Исправьте [starter.py](starter.py). Сохраните меню `1. Show current date`, `2. Show current time` и разделитель `===========================` после ввода.
Выбор `1` показывает текущую локальную дату в формате `YYYY-MM-DD`; `2` — текущее локальное время `HH:MM:SS` (дробная часть секунды допустима). Любой другой ввод, включая буквы, даёт только `Incorrect choice!` после разделителя. При правильном выборе сообщение об ошибке не появляется.

Справа от исправленных строк оставьте комментарии: объясните, почему изменение делает программу правильной.

## Пример

Пример диалога: после подсказок показаны ответы пользователя. Здесь программа запущена 3 февраля 2031 года; дата зависит от момента запуска.

```text
1. Show current date
2. Show current time
Choice: 1
===========================
2031-02-03
```
