# Задание 14. Исправление проверки карты

Исправьте учебный прототип из [starter.py](starter.py). Запросите номер карты, месяц, год и CVV/CVC в этом порядке. Успешен только точный набор `5869586958695869`, `03`, `28`, `094`: выведите `Success!`.
Любое отличие хотя бы в одном поле даёт `Error!`. Начальные нули значимы: `3` вместо `03` и `94` вместо `094` не подходят. Используйте только указанные вымышленные тестовые данные.

Справа от исправленных строк оставьте комментарии: объясните, почему изменение делает программу правильной.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Card ID: 5869586958695869
Month: 03
Year: 28
CVV/CVC: 094

Success!
```
