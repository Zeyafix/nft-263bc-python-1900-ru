# Задание 15. Категория по баллу

Запросите целый балл от 0 до 100 включительно и выведите категорию: `A` — 91–100, `B` — 81–90, `C` — 71–80, `D` — 61–70, `E` — 51–60, `F` — 0–50.
Если введён балл за пределами 0–100, выведите `Input error`.

Перед каждым вводом покажите понятную подсказку на английском: что именно нужно ввести. Точную формулировку можно выбрать самостоятельно.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Score: -1

Input error
```
