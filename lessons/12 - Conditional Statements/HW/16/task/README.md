# Задание 16. Вход в аккаунт

Запросите логин и пароль. Допустимы только пары `admin` / `root1234` и `guest` / `5869`. Регистр и каждый символ имеют значение.
Если логин и соответствующий пароль верны, выведите `Login successful`. Иначе выведите `Invalid login or password`.

Перед каждым вводом покажите понятную подсказку на английском: что именно нужно ввести. Точную формулировку можно выбрать самостоятельно.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Login: admin
Password: root1234

Login successful
```
