# Задание 18. Доступ к файлу

Запросите: наличие прав администратора, является ли пользователь создателем файла, уровень конфиденциальности файла, уровень доступа пользователя, заблокирован ли файл. Только `Y` означает подтверждение, любой другой ответ — «нет». Уровни — неотрицательные числа без дробной части.
Доступ разрешён, когда пользователь — администратор или создатель, конфиденциальность не выше уровня доступа и файл не заблокирован. Администратор тоже подчиняется ограничениям уровня и блокировки.
Выведите `Access granted` или `Access denied`.

Перед каждым вводом покажите понятную подсказку на английском: что именно нужно ввести. Точную формулировку можно выбрать самостоятельно.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Administrator (Y/N): Y
File creator (Y/N): N
Confidentiality level: 2
Access level: 2
File locked (Y/N): N

Access granted
```
