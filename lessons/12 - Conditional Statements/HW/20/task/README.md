# Задание 20. Исправление прогноза дождя

Исправьте [starter.py](starter.py), чтобы для одной вероятности выводилась одна интерпретация.
Для устранения пересечений используйте такие границы:

- От 0 включительно до 30: `Low probability.`
- От 30 включительно до 60: `Average probability.`
- От 60 включительно до 80: `High probability.`
- От 80 до 100 включительно: `Very high probability.`

Значения вне [0, 100] дают `Input error`. Допускается дробная часть.

Справа от исправленных строк оставьте комментарии: объясните, почему изменение делает программу правильной.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Enter rain probability (%): -0.1

Input error
```
