# Задание 21. Упрощение условия стипендии

Упростите условие из [starter.py](starter.py) и рядом с исправлениями оставьте комментарии с объяснениями причины изменения.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Student average rating: 79
Student age: 21
Student has debt (Y/N): Y
Student has recommendation (Y/N): Y

Student cannot receive a scholarship.
```
