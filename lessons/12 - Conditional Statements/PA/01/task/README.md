# Задание 1. Знак числа

Запросите число с подсказкой `Number: `. Оно может быть отрицательным или дробным. Выведите `Positive`, если число положительное, `Negative`, если отрицательное, или `Zero`, если это ноль.

## Примеры

После подсказок показан ввод пользователя.

```text
Number: -2.5

Negative
```

```text
Number: 0

Zero
```
