# Задание 2. Чётное или нечётное

Запросите число без дробной части с подсказкой `Number: `. Допускаются отрицательные числа и ноль. Выведите `Even` для чётного числа или `Odd` для нечётного. Ноль считается чётным.

## Примеры

После подсказок показан ввод пользователя.

```text
Number: 4

Even
```

```text
Number: 3

Odd
```
