# Задание 3. Сравните два числа

Запросите два числа с подсказками `First: ` и `Second: `. Числа могут быть отрицательными и дробными. Выведите `First is greater`, `Second is greater` или `Equal` в зависимости от результата сравнения.

## Примеры

После подсказок показан ввод пользователя.

```text
First: 10
Second: 2

First is greater
```

```text
First: 2
Second: 10

Second is greater
```
