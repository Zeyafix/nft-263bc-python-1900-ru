# Задание 4. Наибольшее из трёх

Запросите три числа без дробной части с подсказками `First: `, `Second: ` и `Third: `. Выведите наибольшее с подписью `Maximum: `. Числа могут быть отрицательными и совпадать. При совпадении наибольших значений выведите это значение один раз.

## Примеры

После подсказок показан ввод пользователя.

```text
First: 9
Second: 2
Third: 3

Maximum: 9
```

```text
First: 2
Second: 9
Third: 3

Maximum: 9
```
