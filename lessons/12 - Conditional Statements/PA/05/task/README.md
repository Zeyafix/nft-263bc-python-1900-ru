# Задание 5. Число в диапазоне

Запросите по очереди число с подсказкой `Number: `, нижнюю границу с подсказкой `Lower bound: ` и верхнюю границу с подсказкой `Upper bound: `. Значения могут быть отрицательными и дробными; нижняя граница не больше верхней. Сохраните результат проверки попадания числа в диапазон в переменную-флаг. Обе границы входят в диапазон. После ввода выведите только значение флага: `True` или `False`, без подписи.

## Примеры

После подсказок показан ввод пользователя.

```text
Number: 5
Lower bound: 1
Upper bound: 10

True
```

```text
Number: 1
Lower bound: 1
Upper bound: 10

True
```
