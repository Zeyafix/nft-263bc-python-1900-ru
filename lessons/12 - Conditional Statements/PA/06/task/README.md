# Задание 6. Возрастная категория

Запросите возраст в полных годах с подсказкой `Age: `. Возраст неотрицательный. До 12 лет включительно это ребёнок (`Child`), с 13 до 17 включительно — подросток (`Teenager`), с 18 — взрослый (`Adult`). Выведите соответствующее слово.

## Примеры

После подсказок показан ввод пользователя.

```text
Age: 0

Child
```

```text
Age: 12

Child
```
