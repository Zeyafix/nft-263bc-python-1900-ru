# Задание 7. Проверка пароля

Запросите пароль с подсказкой `Password: `. Правильный пароль — `python123`, регистр важен. Сохраните результат сравнения в переменную-флаг `is_correct`. По этому флагу выведите `Access granted` или `Access denied`.

## Примеры

После подсказок показан ввод пользователя.

```text
Password: python123

Access granted
```

```text
Password: Python123

Access denied
```
