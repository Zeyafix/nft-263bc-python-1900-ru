# Задание 8. Вход по возрасту и билету

Запросите возраст в полных годах с подсказкой `Age: `, затем наличие билета с подсказкой `Ticket (Y/N): `. Вход разрешён с 16 лет включительно при наличии билета. Только `Y` подтверждает наличие билета, любой другой ответ означает его отсутствие. Возраст неотрицательный. Выведите `Entry allowed` или `Entry denied`.

## Примеры

После подсказок показан ввод пользователя.

```text
Age: 16
Ticket (Y/N): Y

Entry allowed
```

```text
Age: 15
Ticket (Y/N): Y

Entry denied
```
