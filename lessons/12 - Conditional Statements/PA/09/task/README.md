# Задание 9. Заблокирован ли аккаунт

Запросите количество полных дней с последнего входа с подсказкой `Days since last login: `. Оно неотрицательное. Если прошло больше 180 дней, аккаунт заблокирован. Сохраните состояние блокировки во флаг `is_blocked`. Используйте этот флаг и `not`, чтобы выбрать ответ: `Account active`, если блокировки нет, иначе `Account blocked`.

## Примеры

После подсказок показан ввод пользователя.

```text
Days since last login: 0

Account active
```

```text
Days since last login: 179

Account active
```
