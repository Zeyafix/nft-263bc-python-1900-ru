# Задание 10. Категория по баллам

Запросите количество баллов от 1 до 12 без дробной части с подсказкой `Score: `. Для 1–3 выведите `Very poor`, для 4–6 — `Poor`, для 7–9 — `Good`, для 10–12 — `Excellent`.

## Примеры

После подсказок показан ввод пользователя.

```text
Score: 1

Very poor
```

```text
Score: 3

Very poor
```
