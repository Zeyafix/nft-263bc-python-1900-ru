# Задание 11. Будний или выходной день

Запросите положительный номер дня без дробной части с подсказкой `Day number: `. 1 — понедельник, 2 — вторник, …, 7 — воскресенье, 8 — снова понедельник. Номер может быть больше 7. Для субботы и воскресенья выведите `Weekend`, для остальных дней — `Weekday`.

## Примеры

После подсказок показан ввод пользователя.

```text
Day number: 1

Weekday
```

```text
Day number: 5

Weekday
```
