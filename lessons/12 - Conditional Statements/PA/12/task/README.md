# Задание 12. Положение точки

Запросите координаты точки с подсказками `X: ` и `Y: `. Допускаются отрицательные и дробные значения. Для начала координат выведите `Origin`, для точки на горизонтальной оси — `X axis`, на вертикальной — `Y axis`. Для остальных точек выведите `Quadrant I` при положительных x и y, `Quadrant II` при отрицательном x и положительном y, `Quadrant III` при отрицательных x и y или `Quadrant IV` при положительном x и отрицательном y. Нужен ровно один ответ.

## Примеры

После подсказок показан ввод пользователя.

```text
X: 0
Y: 0

Origin
```

```text
X: 3
Y: 0

X axis
```
