# Задание 13. Дата и время по выбору

Запросите выбор с подсказкой `Choice (1-date, 2-time, 3-weekday, 4-month): `. При выборе `1` выведите текущую дату в формате `DD/MM/YYYY`, при `2` — время `HH:MM`, при `3` — полное название дня недели, при `4` — полное название месяца. Используйте локальные дату и время компьютера в момент запуска. Для любого другого выбора выведите `Invalid choice`. Название дня и месяца зависит от настроек языка системы; в примерах используется английский язык.

## Подсказки

Чтобы работать с датами, напишите в самом верху программы:

```python
from datetime import datetime
```

Показать текущую дату:

```python
print(datetime.now().strftime("%d/%m/%Y"))
```

Показать текущее время:

```python
print(datetime.now().strftime("%H:%M"))
```

Показать день недели:

```python
print(datetime.now().strftime("%A"))
```

Показать текущий месяц:

```python
print(datetime.now().strftime("%B"))
```

## Примеры

В примерах локальные дата и время — 22 сентября 2026 года, 09:07.

После подсказок показан ввод пользователя.

```text
Choice (1-date, 2-time, 3-weekday, 4-month): 1

22/09/2026
```

```text
Choice (1-date, 2-time, 3-weekday, 4-month): 2

09:07
```
