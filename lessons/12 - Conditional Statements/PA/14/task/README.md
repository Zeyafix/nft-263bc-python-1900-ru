# Задание 14. Сдача или доплата

Запросите итоговую стоимость покупки с подсказкой `Total: `, затем сумму покупателя с подсказкой `Paid: `. Обе суммы неотрицательные, возможны копейки. Если покупатель дал больше, выведите сдачу с подписью `Change: `; если меньше — недостающую сумму с подписью `Additional payment: `. При точной оплате выведите `Goodbye!`. Денежный результат показывайте с двумя знаками после точки.

## Примеры

После подсказок показан ввод пользователя.

```text
Total: 80
Paid: 100

Change: 20.00
```

```text
Total: 100
Paid: 80

Additional payment: 20.00
```
