# Задание 16. Доступ в лабораторию

По очереди запросите специальное разрешение (`Special permission (Y/N): `), уровень доступа (`Access level: `), текущий час (`Hour: `), ночное разрешение (`Night permission (Y/N): `) и наличие в списке запрета (`Banned (Y/N): `). Уровень — неотрицательное число без дробной части, час — от 0 до 23 без дробной части. Только `Y` означает подтверждение; любой другой ответ — отказ.

Доступ разрешён, когда выполнены все правила:

- Есть специальное разрешение или уровень доступа выше 3.
- Сейчас от 8 до 18 часов включительно либо есть ночное разрешение.
- Сотрудник не находится в списке запрета.

Ночное разрешение отменяет только ограничение по времени. Выведите `Access granted` или `Access denied`.

## Примеры

После подсказок показан ввод пользователя.

```text
Special permission (Y/N): Y
Access level: 0
Hour: 8
Night permission (Y/N): N
Banned (Y/N): N

Access granted
```

```text
Special permission (Y/N): N
Access level: 4
Hour: 18
Night permission (Y/N): N
Banned (Y/N): N

Access granted
```
