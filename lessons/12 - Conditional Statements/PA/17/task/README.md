# Задание 17. Накопи скидку

Запросите стоимость корзины (`Cart: `), количество дней непрерывных покупок (`Consecutive days: `) и подтверждение положительного отзыва в текущем месяце (`Positive review (Y/N): `). Стоимость неотрицательная, возможны копейки; число дней неотрицательное и без дробной части. Только `Y` подтверждает отзыв.

Скидки складываются в один процент от исходной стоимости корзины:

- От 7 дней подряд: 2%.
- От 14 дней: ещё 3%.
- От 21 дня: ещё 5%.
- Корзина от 1000 включительно: ещё 10%.
- Положительный отзыв: ещё 5%.

Сначала выведите накопленную денежную скидку с подписью `Discount: `, затем запросите её применение с подсказкой `Apply discount (Y/N): `. Только `Y` разрешает применить скидку; при любом другом ответе покупатель платит полную стоимость. Выведите сумму оплаты с подписью `Payment: `. Обе денежные суммы покажите с двумя знаками после точки; округляйте только при выводе.

## Примеры

После подсказок показан ввод пользователя.

```text
Cart: 500
Consecutive days: 6
Positive review (Y/N): N

Discount: 0.00
Apply discount (Y/N): Y

Payment: 500.00
```

```text
Cart: 500
Consecutive days: 7
Positive review (Y/N): N

Discount: 10.00
Apply discount (Y/N): Y

Payment: 490.00
```
