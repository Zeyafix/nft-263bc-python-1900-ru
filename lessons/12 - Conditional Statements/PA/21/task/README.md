# Задание 21. Снятие денег в банкомате

Запросите PIN-код (`PIN: `), баланс (`Balance: `) и сумму снятия (`Amount: `). Правильный PIN — `5869`, начальный ноль важен. Баланс неотрицательный, суммы могут содержать копейки. Лимит одной операции — 5000 включительно.

Если PIN неверен, выведите `Invalid PIN`. Иначе при сумме не больше нуля выведите `Invalid amount`, затем проверьте превышение лимита (`Limit exceeded`), затем нехватку денег (`Insufficient funds`). При нескольких проблемах выводится только первая в указанном порядке. Если снятие разрешено, выведите оставшийся баланс с подписью `Balance: ` и двумя знаками после точки. Все три значения запрашиваются до вывода результата.

## Примеры

После подсказок показан ввод пользователя.

```text
PIN: 5869
Balance: 1000
Amount: 250.5

Balance: 749.50
```

```text
PIN: 5869
Balance: 5000
Amount: 5000

Balance: 0.00
```
