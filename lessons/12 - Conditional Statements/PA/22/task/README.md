# Задание 22. Оплата мобильного тарифа

Запросите использованный интернет в ГБ (`Data used (GB): `), затем наличие дополнительного пакета (`Extra package (Y/N): `). Объём неотрицательный и может быть дробным; только `Y` подтверждает пакет. Основной тариф стоит 300 и включает 10 ГБ. Подключённый пакет добавляет 5 ГБ и стоит ещё 100 независимо от использования. За каждый ГБ сверх доступного объёма начисляется 50; неполный ГБ оплачивается пропорционально, без округления до целого. Выведите всю оплату с подписью `Payment: ` и двумя знаками после точки.

## Примеры

После подсказок показан ввод пользователя.

```text
Data used (GB): 0
Extra package (Y/N): N

Payment: 300.00
```

```text
Data used (GB): 10
Extra package (Y/N): N

Payment: 300.00
```
