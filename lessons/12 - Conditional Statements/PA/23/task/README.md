# Задание 23. Можно ли ехать в лифте

Запросите допустимый вес в килограммах (`Capacity (kg): `), средний вес человека в килограммах (`Average weight (kg): `) и количество пассажиров (`Passengers: `). Оба веса положительные и могут быть дробными; пассажиров не меньше нуля, количество без дробной части. Считайте общий вес равным среднему весу, умноженному на количество пассажиров. Если он не превышает допустимый, выведите `Ride allowed`, иначе `Overloaded`. При отсутствии пассажиров поездка разрешена.

## Примеры

После подсказок показан ввод пользователя.

```text
Capacity (kg): 400
Average weight (kg): 80
Passengers: 4

Ride allowed
```

```text
Capacity (kg): 400
Average weight (kg): 80
Passengers: 5

Ride allowed
```
