# Задание 24. Скидка постоянному клиенту

Запросите три стоимости с подсказками `First price: `, `Second price: ` и `Third price: `, затем статус постоянного клиента с подсказкой `Regular customer (Y/N): `. Стоимости неотрицательные, возможны копейки. Только `Y` подтверждает статус. При общей сумме от 1000 включительно скидка составляет 5%. Постоянному клиенту добавляется 10%. Проценты складываются и применяются к исходной общей сумме: при обоих условиях скидка 15%. Выведите итог с подписью `Total: ` и двумя знаками после точки.

## Примеры

После подсказок показан ввод пользователя.

```text
First price: 300
Second price: 300
Third price: 399
Regular customer (Y/N): N

Total: 999.00
```

```text
First price: 300
Second price: 300
Third price: 400
Regular customer (Y/N): N

Total: 950.00
```
