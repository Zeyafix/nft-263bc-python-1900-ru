# Задание 25. Корзина и доставка

Запросите стоимость корзины с подсказкой `Cart: `. Сумма неотрицательная, возможны копейки. Доставка стоит 10% от исходной стоимости корзины. При исходной стоимости от 700 включительно доставка бесплатная. При исходной стоимости от 730 включительно действует скидка 5% на корзину. Пороги проверяются по стоимости до скидки. Выведите две строки: оплату за корзину с подписью `Cart payment: ` и отдельно стоимость доставки с подписью `Delivery: `. Обе суммы — с двумя знаками после точки; бесплатная доставка отображается как `0.00`.

Соблюдайте указанные подсказки и строки результата. Каждое значение вводится отдельно. Данные соответствуют описанным ограничениям; дополнительные проверки не требуются. Весь текст в коде, включая комментарии и сообщения, должен быть на английском.

## Примеры

После подсказок показан ввод пользователя.

```text
Cart: 0

Cart payment: 0.00
Delivery: 0.00
```

```text
Cart: 100

Cart payment: 100.00
Delivery: 10.00
```
