02 / Зачем нужны циклы

Представьте обратный отсчёт перед стартом. Для трёх чисел можно написать несколько print подряд. Но если нужно начать с тысячи, список команд станет огромным. При изменении правила вывода придётся исправлять много одинаковых строк, и одну легко пропустить.

Отсчёт без цикла 
print(3)
print(2)
print(1)
print("Start!")
Консоль
3
2
1
Start!

Вместо копирования команд опишем одно действие и условие, при котором его нужно повторять. Переменная count хранит текущее число. Пока оно больше нуля, выводим его и уменьшаем на единицу.

Тот же отсчёт с циклом 
count = 3
while count > 0:
    print(count)
    count -= 1

print("Start!")
Консоль
3
2
1
Start!

Теперь для отсчёта от тысячи достаточно изменить начальное значение count. Строка count -= 1 означает count = count - 1. Она приближает значение к моменту, когда условие станет ложным.

Определение

Повторение по условию

Цикл позволяет выполнять один блок команд повторно. Цикл while читается как «пока»: пока условие истинно, выполняй тело цикла.

Вторая частая задача: пользователь вводит ответ с нескольких попыток. Заранее неизвестно, сколько их понадобится. Копирование трёх input ограничит нас тремя запросами, а цикл сможет запрашивать данные до подходящего ответа. Эту задачу разберём после счётчиков.

03 / Как устроен while

После while записывается условие и двоеточие. Ниже с отступом в четыре пробела идут команды тела цикла. В этом примере тело состоит из print и увеличения num. Строка без этого отступа уже находится после цикла.

Три повторения 
num = 0
while num < 3:
    print(num)
    num += 1

print("Program end")
Консоль
0
1
2
Program end
  1. Присваиваем num = 0. Эта строка находится перед циклом и выполняется один раз.
  2. Проверяем num < 3. При num = 0 условие истинно, поэтому входим в тело.
  3. Выводим текущее значение и увеличиваем его на единицу. После первой пары команд num равен 1.
  4. Возвращаемся к строке while и заново вычисляем условие с новым значением num.
  5. При num = 1 и num = 2 повторяем тело. После вывода 2 переменная становится равной 3.
  6. Проверка 3 < 3 ложна. Пропускаем тело и выполняем print("Program end").

Определение

Что такое итерация

Итерация означает один проход тела цикла. В примере тело прошло три раза, поэтому было три итерации. Проверок условия было четыре: последняя остановила повторение и не запустила новую итерацию.

Условие проверяется перед каждым новым проходом, а не непрерывно после каждой команды. Если в середине тела значение изменилось, оставшиеся команды тела всё ещё выполняются. Затем Python возвращается к условию. Позже увидим, как break и continue меняют этот порядок.

Сравним if и while.

Те же команды внутри if 
num = 0
if num < 3:
    print(num)
    num += 1

print("Program end")
Консоль
0
Program end

if проверяет условие и при истинном результате выполняет блок один раз за этот проход программы. Он не возвращается к своей проверке. while после тела возвращается и проверяет снова. Поэтому одинаковые команды здесь дают разный вывод.

При работе с циклами while могут возникать ситуации, когда нет ни одной итерации.

Ни одной итерации 
num = 3
while num < 3:
    print(num)
    num += 1

print("Program end")
Консоль
Program end

Уже первая проверка ложна, поэтому ни print внутри тела, ни увеличение num не выполнятся. Цикл while не обещает выполнить тело хотя бы один раз. Это удобно: если повторять нечего, программа сразу идёт дальше.

04 / Счётчик и шаг

Счётчик хранит текущее число или количество сделанных шагов. До цикла ему задают начальное значение. Внутри цикла его меняют на шаг: например, прибавляют 1, прибавляют 5 или вычитают 3. Условие определяет, какие значения ещё допустимы.

Чтобы пройти диапазон по возрастанию, начнём с start и будем прибавлять положительный step. Включим правую границу через <=. До входа в цикл проверим и направление диапазона, и шаг.

По возрастанию: ввод 5, 20, 5 
start = int(input("Start: "))
end = int(input("End: "))
step = int(input("Step: "))

if step > 0 and start <= end:
    current = start
    while current <= end:
        print(current)
        current += step
else:
    print("Invalid range or step")
Консоль
Start: 5
End: 20
Step: 5
5
10
15
20

Сначала if разрешает запуск. Затем current принимает 5, 10, 15 и 20, каждый раз выводится и увеличивается на 5. После 20 получаем 25: оно уже больше end, поэтому новая итерация не начинается. Здесь выполняется четыре итерации.

Для движения вниз шаг по-прежнему вводим положительным, но вычитаем его. Условия меняем на start >= end и current >= end. Вложенное тело while имеет восемь пробелов, потому что сам цикл находится внутри if.

По убыванию: ввод 19, 10, 3

05 / Накопление результата

Иногда нужно не просто повторить вывод, а собрать общий результат из многих вводов. Для этого заводят отдельные переменные: одна считает все обработанные значения, другая считает только подходящие, третья хранит их сумму. У этих переменных разные задачи.

Сумма и количество положительных чисел 
request_count = int(input("How many numbers: "))

if request_count > 0:
    processed_count = 0
    positive_count = 0
    positive_sum = 0

    while processed_count < request_count:
        number = int(input("Number: "))
        if number > 0:
            positive_sum += number
            positive_count += 1
        processed_count += 1

    print(f"Positive count: {positive_count}")
    print(f"Positive sum: {positive_sum}")
else:
    print("Count must be positive")

  1. Перед циклом: обнуляем processed_count, positive_count и positive_sum. Пока не введено ни одного числа, считать и суммировать нечего.
  2. На каждой итерации: запрашиваем одно число. При number > 0 прибавляем его к сумме и увеличиваем количество положительных.
  3. При любом числе: увеличиваем processed_count. Эта строка находится вне внутреннего if, иначе отрицательные числа не засчитывались бы как обработанные вводы.
  4. После цикла: выводим общие результаты. Эти print остаются внутри внешнего if, но уже находятся вне while.

06 / Повторный ввод данных

Теперь количество повторений заранее неизвестно. Пользователь вводит команды, пока не напишет stop. Сначала получим команду перед циклом: переменная должна существовать к моменту первой проверки. В конце тела запросим следующую.

Команды до stop: остановка на пятом запросе 
command = input("Command: ")

while command != "stop":
    print(f"Received: {command}")
    command = input("Command: ")

print("Program end")

Текущая итерация заканчивается, условие становится ложным, и новая итерация не начинается. Само слово stop как Received не выводится.

07 / Бесконечный цикл и break

Цикл завершается через условие только тогда, когда оно становится ложным. Если данные не меняются или меняются в неверную сторону, повторение может продолжаться бесконечно. Два следующих фрагмента намеренно ошибочны.

Ошибка

Счётчик не изменяется

Ошибка: нет изменения num 
num = 0
while num < 3:
    print(num)

num остаётся равным 0, поэтому проверка каждый раз истинна. Терминал непрерывно заполняется нулями.

Ошибка

Шаг уводит от остановки

Ошибка: движение вниз вместо движения вверх 
num = 0
while num < 3:
    print(num)
    num -= 1

Значения 0, -1, -2 и следующие всё ещё меньше 3. Самого изменения переменной недостаточно: оно должно приближать к ложному условию.

Если запустили такой пример, переключитесь в терминал программы и нажмите Ctrl + C. Обычно Python остановит выполнение и покажет KeyboardInterrupt. Это ручное прерывание программы; после него исправьте причину и запустите файл заново.

Иногда требуется специально сделать условие цикла неизменяемым. Но чтобы была возможность прервать такой цикл изнутри, используют оператор break.

Определение

Оператор break

break немедленно завершает ближайший содержащий его цикл. Оставшиеся команды тела пропускаются, выполнение продолжается после цикла. Условие while при таком выходе не обязано стать ложным.

Запись while True: всегда проходит проверку. Это полезно, если решение о выходе принимается после ввода внутри тела. Для наших команд поместим input в начало и выйдем через break сразу после stop.

Те же команды с break 
while True:
    command = input("Command: ")
    if command == "stop":
        break
    print(f"Received: {command}")

print("Program end")

После ввода stop выполняется break. Строка print(f"Received: {command}") в этой итерации уже не запускается, а print("Program end") запускается. В отличие от предыдущей версии, здесь пять итераций: пятый ввод находится внутри тела. Видимый результат у программ одинаковый.

Если stop введён первым, будет одна итерация с немедленным выходом. В версии из предыдущего раздела при таком вводе было ноль итераций. Считайте проходы тела, а не количество напечатанных сообщений.

08 / Пропуск итерации: continue

Определение

Переход к следующей проверке

continue пропускает оставшуюся часть текущего тела и сразу возвращает выполнение к условию while. Цикл целиком при этом не завершается. Если условие снова истинно, начинается следующая итерация.

Пропускаем вывод числа 3 
num = 0
while num < 5:
    num += 1
    if num == 3:
        continue
    print(num)

print("Program end")
Консоль

2
4
5
Program end

На третьей итерации num становится равным 3 и срабатывает continue. Только print этой итерации пропущен. Новая проверка 3 < 5 истинна, поэтому продолжаем с увеличения до 4. Когда num увеличится с 4 до 5, print всё ещё выполнится: условие проверялось до этого увеличения.

Тот же пример, но вместо continue подставим break.

В том же месте стоит break 
num = 0
while num < 5:
    num += 1
    if num == 3:
        break
    print(num)

print("Program end")
Консоль
1
2
Program end

Теперь при num = 3 повторение прекращается полностью. Значения 4 и 5 уже не обрабатываются. Оба оператора пропускают остаток текущего тела, но continue возвращает к условию, а break выходит за цикл.

Ошибка

Обновление оказалось после continue

Ошибка: num застревает на 3 
num = 0
while num < 5:
    if num == 3:
        continue
    print(num)
    num += 1

Программа выведет 0, 1, 2, затем num станет равным 3. Каждый следующий проход попадёт в continue до увеличения. Условие останется истинным, а вывода больше не будет. Бесконечный цикл может выглядеть как зависание без сообщений. Остановите его через Ctrl + C.

continue особенно полезен, когда после проверки идут ещё несколько действий. Представим учебное подтверждение заявки. Нужно последовательно ввести код приглашения, группу и согласие. Любая неудачная проверка начинает всю цепочку заново с первого запроса.

Проверяем три ответа подряд 
while True:

    if invite_code != "PY13":
        print("Invalid invite code")
        continue

    group = input("Group: ")
    if group != "A":
        print("Invalid group")
        continue

    confirmation = input("Confirm (yes): ")
    if confirmation != "yes":
        print("Not confirmed")
        continue

    print("Request accepted")
    break

print("Program end")

  1. Попытка 1: BAD не подходит. Запросы группы и согласия пропускаются.
  2. Попытка 2: PY13 подходит, B не подходит. Согласие не запрашивается, следующий запрос снова Invite code.
  3. Попытка 3: PY13 и A подходят, no не подходит. Возвращаемся к началу тела.
  4. Попытка 4: PY13, A и yes проходят проверки. Заявка принята, break завершает цикл.

09 / Несколько условий завершения

Пусть на ответ на вопрос «сколько будет 2 + 2?» разрешено три попытки. Есть две причины остановки: ответ оказался верным или закончились попытки. Чтобы продолжать, одновременно нужны оставшиеся попытки и отсутствие успеха. Поэтому в условии продолжения используется and.

Составное условие и флаг 
attempts_left = 3
is_correct = False

while attempts_left > 0 and not is_correct:
    answer = input("2 + 2 = ")
    attempts_left -= 1
    is_correct = answer == "4"
    if not is_correct:
        print(f"Wrong answer. Attempts left: {attempts_left}")

if is_correct:
    print("Correct!")
else:
    print("No attempts left")
Консоль
2 + 2 = 5
Wrong answer. Attempts left: 2
2 + 2 = 4
Correct!

Флаг is_correct начинается с False: правильного ответа ещё нет. После каждого ввода сравнение обновляет его. Число попыток уменьшается при любом ответе. Условие while вычисляется заново, поэтому цикл видит оба изменившихся значения.

Когда продолжаем задавать вопрос
Есть попыткиОтвет верныйПродолжаем
ДаНетДа
ДаДаНет: успех
НетНетНет: попытки закончились
НетДаНет: успех на последней попытке

Последний случай важен: если правильный ответ дан с третьей попытки, attempts_left уже равен 0, но результат всё равно успешный. После цикла проверяем именно флаг, а не только количество оставшихся попыток.

То же правило с досрочным выходом 
attempts_left = 3
is_correct = False

while attempts_left > 0:
    answer = input("2 + 2 = ")
    attempts_left -= 1
    if answer == "4":
        is_correct = True
        break
    print(f"Wrong answer. Attempts left: {attempts_left}")

if is_correct:
    print("Correct!")
else:
    print("No attempts left")
Консоль
2 + 2 = 5
Wrong answer. Attempts left: 2
2 + 2 = 4
Correct!

В первой версии обе причины остановки видны в строке while. В этой же версии программы условие отвечает за лимит, а break останавливает цикл в момент успеха. Флаг остаётся полезен для сообщения после цикла. Выбирайте запись, в которой проще проследить, что меняется и почему произойдёт выход.

Важно

Не заменяйте and на or

При attempts_left > 0 or not is_correct цикл может продолжиться даже после исчерпания попыток, если ответа всё ещё нет. Для продолжения нужны оба условия, а для остановки достаточно нарушения любого из них.

10 / Вложенные циклы while

Одно повторение может содержать другое. Нарисуем прямоугольник из звёздочек шириной 5 и высотой 3. Внешний цикл отвечает за строки, внутренний за символы в текущей строке. Для каждого направления нужен свой счётчик.

Прямоугольник 5 × 3 
width = 5
height = 3
row = 0

while row < height:
    column = 0
    while column < width:
        print("*", end="")
        column += 1
    print()
    row += 1
Консоль
*****
*****
*****

Обычно print завершает вывод переводом строки. Аргумент end="" заменяет это окончание пустой строкой, поэтому звёздочки появляются рядом. Отдельный print() без аргументов переводит вывод на следующую строку после пяти звёздочек.

  1. row равен 0. Внешняя проверка истинна; задаём column = 0.
  2. Внутренний while проходит пять раз. Значения column перед печатью: 0, 1, 2, 3, 4.
  3. При column = 5 внутренняя проверка ложна. Выполняем print() и увеличиваем row до 1.
  4. Внешняя проверка снова истинна. Заново задаём column = 0, иначе печатать новую строку было бы нечем.
  5. После строки с row = 2 увеличиваем row до 3. Внешняя проверка ложна, оба цикла закончены.

Всего три итерации внешнего цикла и по пять внутренних на каждую: звёздочка печатается 3 * 5, то есть 15 раз. Внутренний цикл каждый раз завершается прежде, чем внешний перейдёт к следующей строке.

Важно

Где обнулять внутренний счётчик

column = 0 должен находиться внутри внешнего цикла перед внутренним. Если перенести его перед обоими циклами, после первой строки column останется равным 5. В следующих строках внутренний цикл не выполнится ни разу.

11 / break и continue во вложенных циклах

Когда цикл находится внутри другого, break и continue относятся к ближайшему циклу, внутри тела которого записаны. Условная конструкция if не является циклом и не меняет это правило. Внутренний break не останавливает внешний while.

break во внутреннем цикле 
row = 1
while row <= 2:
    column = 1
    while column <= 3:
        if column == 2:
            break
        print(f"Cell: {row}, {column}")
        column += 1
    print(f"Row {row} done")
    row += 1

print("Program end")
Консоль
Cell: 1, 1
Row 1 done
Cell: 2, 1
Row 2 done
Program end
  1. При row = 1 и column = 1 выводим ячейку и увеличиваем column до 2.
  2. В следующем проходе внутреннего цикла срабатывает break. Печать ячейки и увеличение column пропускаются.
  3. Продолжаем внутри внешнего тела: печатаем Row 1 done и увеличиваем row.
  4. Для row = 2 обнуляем ход внутреннего счётчика присваиванием column = 1. Всё повторяется. Внешний цикл завершится только при row = 3.

Возьмём тот же пример и заменим break на continue, и для наглядности переместим column += 1 до условной конструкции.

continue во внутреннем цикле 
row = 1
while row <= 2:
    column = 0
    while column < 3:
        column += 1
        if column == 2:
            continue
        print(f"Cell: {row}, {column}")
    print(f"Row {row} done")
    row += 1

print("Program end")
Консоль
Cell: 1, 1
Cell: 1, 3
Row 1 done
Cell: 2, 1
Cell: 2, 3
Row 2 done
Program end

continue при column = 2 возвращает к while column < 3. При этом row остаётся прежним, до сообщения Row done выполнение ещё не дошло. Затем column увеличивается до 3 и ячейка печатается. Только после завершения внутреннего цикла выполняются сообщение о строке и изменение row.

Внешний цикл не получает скрытой команды выхода. Если нужно остановить оба уровня, можно сохранить флаг завершения и проверить его во внешнем цикле, как мы делали с is_correct.

12 / Собираем программу с меню

Соберём учебную программу с двумя меню. В меню входа пользователь может войти в аккаунт или завершить программу. После верного логина и пароля появляется меню действий: посмотреть баланс, пополнить его, снять средства или выйти из аккаунта обратно в меню входа. Баланс храним целым числом условных единиц; начальное значение равно 1000.

Здесь два вложенных цикла: внешний повторяет меню входа, внутренний повторяет меню действий. До внутреннего цикла выполнение доходит только после проверки логина и пароля. Используем учебные данные student и python13. Это демонстрация управления выполнением: пароль виден при вводе и хранится прямо в файле, поэтому реальные пароли сюда не вводим.

Выбор пункта оставляем строкой. Так любой текст, пустой ввод или число вне списка попадут в else, а не вызовут ошибку преобразования int. Сумму пока вводим целым числом; проверим, что она положительная и что при снятии хватает баланса.

Полная программа с меню 
expected_login = "student"
expected_password = "python13"
balance = 1000

while True:
    print("1. Log in")
    print("0. Exit program")
    login_choice = input("Choose an option: ")
    print("\033[2J\033[H", end="")

    if login_choice == "0":
        print("Goodbye!")
        break
    elif login_choice != "1":
        print("Unknown option")
        continue

    login = input("Login: ")
    password = input("Password: ")
    if not (login == expected_login and password == expected_password):
        print("Invalid login or password")
        continue

    print("Login successful")
    while True:
        print("1. Personal account")
        print("2. Deposit")
        print("3. Withdraw")
        print("0. Log out")
        choice = input("Choose an action: ")
        print("\033[2J\033[H", end="")

        if choice == "1":
            print(f"User: {login}")
            print(f"Balance: {balance}")
        elif choice == "2":
            amount = int(input("Deposit amount: "))
            if amount > 0:
                balance += amount
                print(f"Balance: {balance}")
            else:
                print("Amount must be positive")
        elif choice == "3":
            amount = int(input("Withdraw amount: "))
            if amount <= 0:
                print("Amount must be positive")
            elif amount > balance:
                print("Not enough funds")
            else:
                balance -= amount
                print(f"Balance: {balance}")
        elif choice == "0":
            print("Logged out")
            break
        else:
            print("Unknown action")

Строка print("\033[2J\033[H", end="") выполняется сразу после каждого выбора в обоих меню, поэтому очищение происходит для всех пунктов, включая выход и неизвестную команду. В терминале с поддержкой ANSI первая последовательность очищает экран, вторая переносит курсор в начало. end="" не добавляет перевод строки.

  1. Внешний while показывает меню входа. Пункт 0 выполняет break этого цикла и завершает программу. Неизвестный пункт выполняет continue и возвращает к меню входа без запроса логина и пароля.
  2. Пункт 1 запрашивает логин и пароль. and требует совпадения обоих значений. Если хотя бы одно неверно, not делает условие истинным: выводим ошибку и через continue возвращаемся к меню входа. Внутренний цикл при этом не запускается.
  3. После успешного входа запускается внутренний while. Каждый его проход показывает меню действий и получает новый choice. После очистки экрана if / elif выбирает подходящий пункт.
  4. balance задаётся перед внешним циклом один раз. Поэтому баланс сохраняется и при повторном показе меню действий, и после выхода из аккаунта и нового входа.
  5. Пункт 1 показывает кабинет: логин и текущее значение баланса. Пункт 2 прибавляет допустимую сумму. Пункт 3 сначала отклоняет неположительную сумму, затем проверяет доступные средства.
  6. В ветке неизвестного пункта выводится Unknown action. После неё, как и после пунктов 1, 2, 3, тело заканчивается и меню появляется снова.
  7. Пункт 0 в меню действий выполняет break только внутреннего цикла. После него тело внешнего цикла заканчивается, начинается его следующая итерация и снова появляется меню входа. Чтобы открыть действия ещё раз, нужно заново ввести верные логин и пароль.

Поскольку экран очищается, предыдущий диалог не остаётся целиком видимым. Ниже показано, что должно произойти в последовательном пробном запуске. Нажимайте Enter после каждого значения.

Если в поле суммы написать текст вместо целого числа, int завершит программу с ValueError. Этот пример пока проверяет числовые ограничения суммы и любые неправильные пункты меню. Обработку ошибок преобразования изучим отдельно. Не добавляйте неразобранные конструкции только ради большого примера: сначала уверенно проследите оба цикла и каждую ветку.

13 / Самопроверка

Вопрос

Что такое итерация?

Отметьте все подходящие варианты.

Каждое новое выполнение тела считается очередной итерацией.

В программе может быть много циклов и много итераций каждого.

Ложная проверка while не запускает итерацию. Проверок может быть больше, чем проходов тела.

Тело может содержать любые изученные команды, а счётчика может вообще не быть.

Вопрос

Почему цикл не останавливается?

Найдите пропущенное обновление 
num = 0
while num < 5:
    if num == 2:
        continue
    print(num)
    num += 1
Отметьте все подходящие варианты.

После значения 1 счётчик становится равным 2. Теперь каждый проход уходит в continue до изменения счётчика.

Сравнение с < допустимо. Проблема в том, что значение больше не меняется.

print только выводит значение. Переход здесь происходит из-за continue.

continue не мешает завершению, если нужные переменные меняются и условие может стать ложным.

Вопрос

Какой цикл прервёт break?

Выход из вложенного цикла 
row = 0
while row < 3:
    column = 0
    while column < 5:
        if column == 2:
            break
        print(row, column)
        column += 1
    row += 1

print("Done")
Отметьте все подходящие варианты.

Это ближайший содержащий break цикл. После него выполнится row += 1.

break расположен внутри тела внутреннего while, поэтому до внешнего не распространяется.

Один break завершает один ближайший цикл. Внешний продолжает работу.

После завершённого цикла выполнение продолжается. Здесь позже будет выведено Done.
