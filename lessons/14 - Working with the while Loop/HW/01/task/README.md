# Задание 1. Последовательность с шагом

Запросите количество чисел, затем шаг. Выведите ровно столько чисел, сколько запросил пользователь.
Первое число — 0, каждое следующее отличается от предыдущего на заданный шаг. Каждое число выводите на отдельной строке без подписи.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
Count: 5
Step: 3
0
3
6
9
12
```
