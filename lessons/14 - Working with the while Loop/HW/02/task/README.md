# Задание 2. Числа в диапазоне

Запросите границы `start` и `stop` без дробной части. Если `start` меньше `stop`, поменяйте их значения местами.
Просмотрите диапазон от `start` к `stop` по убыванию, включая обе границы.
Выведите числа, которые делятся на 3 без остатка, но не делятся на 5 без остатка.
Каждое подходящее число — на отдельной строке без подписи. Если таких чисел нет, результат пустой.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
Start: 3
Stop: 16
12
9
6
3
```
