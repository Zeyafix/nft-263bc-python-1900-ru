# Задание 3. Сумма в диапазоне

Запросите границы `start` и `stop` без дробной части. Если `start` меньше `stop`, поменяйте их значения местами.
Найдите сумму всех чисел от `start` до `stop`, включая обе границы.
Выведите `Sum: <сумма>`. При одинаковых границах в сумму входит одно число.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
Start: 2
Stop: 5
Sum: 14
```
