# Задание 4. Положительные, отрицательные и нули

Запросите количество чисел. Затем запросите ровно это количество чисел.
Сами числа могут быть отрицательными и содержать дробную часть, например -2.5.
Подсчитайте положительные числа, отрицательные числа и нули.
Выведите три строки в таком порядке: `Positive: <количество>`, `Negative: <количество>`, `Zero: <количество>`.
Если количество равно 0, все три результата равны 0.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
Count: 5
Number: 2
Number: -3
Number: 0
Number: 1.5
Number: -0.5

Positive: 2
Negative: 2
Zero: 1
```
