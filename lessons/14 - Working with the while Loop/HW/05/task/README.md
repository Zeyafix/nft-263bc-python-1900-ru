# Задание 5. Средняя оценка

Запросите количество оценок. Затем запросите ровно столько оценок.
Каждая оценка — от 1 до 12 без дробной части.
Определите среднюю оценку и выведите `Average: <средняя оценка>` с двумя знаками после точки.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
Grade count: 3
Grade: 8
Grade: 9
Grade: 11

Average: 9.33
```
