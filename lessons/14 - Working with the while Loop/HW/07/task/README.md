# Задание 7. Самое длинное слово

Запрашивайте слова по одному до команды `stop`. Требуется определить самое длинное слово.
Если несколько слов имеют одинаковую максимальную длину,выберите первое из них. Выведите `Longest: <слово>`.
Команда `stop` пишется именно строчными буквами и не участвует в сравнении.
Если пользователь сразу ввёл `stop`, выведите `No words`.

Подсказка: `len(word)` позволяет узнать длину слова `word`.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
Word or stop: cat
Word or stop: python
Word or stop: planet
Word or stop: stop

Longest: python
```
