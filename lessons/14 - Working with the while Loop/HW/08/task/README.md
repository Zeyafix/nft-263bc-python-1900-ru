# Задание 8. Сумма с пропусками

Запрашивайте числа без дробной части до команды `stop`.
Числа, кратные 3, пропускайте: они не влияют на сумму, но ввод продолжается.
Остальные числа суммируйте. После команды выведите `Sum: <сумма>`.
Числа могут быть отрицательными и нулевыми. Если подходящих чисел не было, сумма равна 0.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
Number or stop: 4
Number or stop: 3
Number or stop: -2
Number or stop: 6
Number or stop: 5
Number or stop: stop

Sum: 7
```
