# Задание 9. Заполненный прямоугольник

Запросите ширину, затем высоту прямоугольника.
Выведите заполненный прямоугольник из символов `*`.
В каждой строке столько звёздочек, какова ширина, а строк столько, какова высота.
Между звёздочками нет пробелов. Подписи к рисунку не нужны.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
Width: 4
Height: 3

****
****
****
```
