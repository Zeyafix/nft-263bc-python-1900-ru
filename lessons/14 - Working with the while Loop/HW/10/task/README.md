# Задание 10. Конвертер в сантиметры

Показывайте меню перед каждым выбором:

```text
1. Meters to centimeters
2. Kilometers to centimeters
0. Exit
```

При выборе 1 запросите расстояние в метрах, при выборе 2 — в километрах.
Расстояние неотрицательное, может содержать дробную часть, например 1.25.
Покажите `Centimeters: <значение>` с двумя знаками после точки и вернитесь к меню.

В метре 100 сантиметров, в километре — 100000.

При выборе 0 покажите `Goodbye` и завершите программу. Любой другой выбор — `Invalid option` и возврат к меню без запроса расстояния.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
1. Meters to centimeters
2. Kilometers to centimeters
0. Exit
Choice: 1

Distance: 1.25
Centimeters: 125.00

1. Meters to centimeters
2. Kilometers to centimeters
0. Exit
Choice: 0

Goodbye
```
