# Задание 11. Категории баллов

Запрашивайте баллы без дробной части до команды `stop`.
Допустимы баллы от 0 до 100 включительно. Если значение меньше 0 или больше 100, покажите `Invalid score`, не учитывайте его и продолжайте ввод.
Посчитайте количество введённых допустимых баллов в каждой категории:

| Категория | Баллы |
| --- | --- |
| A | 91–100 |
| B | 81–90 |
| C | 71–80 |
| D | 61–70 |
| E | 51–60 |
| F | 0–50 |

После `stop` выведите все шесть категорий от A до F включительно, каждую на отдельной строке в формате `<категория> - <количество>`. После дефиса стоит количество оценок этой категории, а не сумма баллов. Категории без оценок тоже выводятся, с количеством 0.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
Score or stop: 95
Score or stop: 82
Score or stop: 50
Score or stop: 100
Score or stop: stop

A - 2
B - 1
C - 0
D - 0
E - 0
F - 1
```
