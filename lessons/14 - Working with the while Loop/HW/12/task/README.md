# Задание 12. Банкомат с PIN-кодом

У банкомата PIN-код `1234`, начальный баланс — 1000.00. На ввод PIN даются три попытки.
После каждого неправильного PIN выводите `Invalid PIN`. После третьей ошибки дополнительно выведите `Access denied` и завершите программу.
Правильный PIN на любой из трёх попыток открывает меню.

После входа и перед каждым следующим выбором показывайте текущий баланс с двумя знаками после точки и меню:

```text
Balance: 1000.00
1. Deposit
2. Withdraw
0. Exit
```

При выборе пункта 1: запросите сумму пополнения. Если она больше 0, увеличьте баланс и покажите `Deposit successful`.

При выборе пункта 2: запросите сумму снятия. Если она больше 0 и не превышает баланс, уменьшите баланс и покажите `Withdrawal successful`.

Для обеих операций сумма 0 или меньше означает `Invalid amount`. Снятие сверх баланса означает `Insufficient funds`. При ошибке баланс не меняется.

При выборе пункта 0: покажите `Goodbye` и завершите программу.

Другой пункт: `Invalid option`, без запроса суммы.

После операции или ошибки возвращайтесь к балансу и меню. Суммы вводятся с точностью до сотых, например 25.50.
Снять весь баланс разрешено. Баланс хранится только до завершения программы.

## Пример диалога

После подсказок показаны ответы пользователя. Формулировки подсказок можно выбрать самостоятельно.

```text
PIN: 1234

Balance: 1000.00
1. Deposit
2. Withdraw
0. Exit
Choice: 2

Amount: 250
Withdrawal successful

Balance: 750.00
1. Deposit
2. Withdraw
0. Exit
Choice: 0

Goodbye
```
