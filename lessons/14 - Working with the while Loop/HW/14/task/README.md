# Задание 14. Три аккаунта

Создайте учебную систему с тремя слотами для аккаунтов. При запуске все слоты свободны.
У каждого аккаунта есть логин, пароль и отдельный баланс, изначально 0.00.
Аккаунты и их балансы сохраняются при выходе из аккаунта, но только до завершения программы.

Главное меню показывайте перед каждым выбором:

```text
1. Register
2. Login
0. Exit
```

При выборе пункта 1 (Register): покажите три строки `<номер слота>. <логин>` в порядке 1, 2, 3.
Для свободного слота вместо логина пишите `Empty`. Например:

```text
1. alice
2. Empty
3. Empty
```

Запросите номер слота. Если это не 1, 2 или 3, покажите `Invalid slot`. Если слот занят, покажите `Slot occupied`. В обоих случаях сразу вернитесь в главное меню.

Для свободного слота запросите новый логин. Если он уже занят в любом слоте, покажите `Login taken` и вернитесь в главное меню без запроса пароля. Иначе запросите пароль, создайте аккаунт, покажите `Registered` и вернитесь в главное меню.

Новые логины непустые, состоят из английских букв, цифр и подчёркиваний. Значение `Empty` не вводится.
Новые пароли непустые.

При выборе пункта 2 (Login): запросите логин, затем пароль. Они должны совпасть с данными одного зарегистрированного аккаунта.
При ошибке покажите `Invalid login or password` и вернитесь в главное меню.
При успехе показывайте логин, текущий баланс с двумя знаками после точки и меню аккаунта:

```text
Account: alice
Balance: 0.00
1. Deposit
2. Withdraw
3. Transfer
4. Logout
0. Exit
```

При выборе пункта 1: запросите сумму пополнения. Увеличьте баланс и покажите `Deposit successful`.

При выборе пункта 2: запросите сумму снятия. Уменьшите баланс и покажите `Withdrawal successful`.

При выборе пункта 3: сначала запросите логин получателя. Если аккаунта нет, покажите `Account not found`. Если это текущий аккаунт, покажите `Cannot transfer to yourself`. В этих случаях сумму не запрашивайте.
Иначе запросите сумму перевода, снимите её у отправителя и прибавьте получателю. Покажите `Transfer successful`.

Для всех трёх операций сумма должна быть больше 0, иначе покажите `Invalid amount`.
Для снятия и перевода сумма не должна превышать баланс, иначе покажите `Insufficient funds`.
Ошибочная операция не меняет ни один баланс. Снять или перевести весь остаток разрешено.

При выборе пункта 4: покажите `Logged out` и вернитесь в главное меню.
При выборе пункта 0: покажите `Goodbye` и завершите всю программу.

После операции или ошибки снова показывайте логин, баланс и меню аккаунта.
В главном меню 0 тоже завершает программу со строкой `Goodbye`.
Неизвестный пункт любого меню означает `Invalid option` и повтор этого меню без дополнительных запросов.
