# Задание 3. Чётные числа диапазона

Запросите границы с подсказками `Start: ` и `Stop: ` и сохраните их в `start` и `stop`. Гарантируется `start < stop`.
Выведите все чётные числа от `start` до `stop` включительно по возрастанию, каждое на отдельной строке. Ноль тоже считается чётным.

## Пример

После подсказок показан ввод пользователя.

```text
Start: 3
Stop: 8
4
6
8
```
