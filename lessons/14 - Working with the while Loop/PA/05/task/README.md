# Задание 5. Произведение диапазона

Запросите конец диапазона с подсказкой `Stop: ` и сохраните его в `stop`.
Найдите произведение целых чисел от 1 до `stop` включительно и выведите его с подписью `Product: `.

## Пример

После подсказок показан ввод пользователя.

```text
Stop: 5
Product: 120
```
