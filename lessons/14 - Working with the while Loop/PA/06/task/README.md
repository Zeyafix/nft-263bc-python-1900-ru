# Задание 6. Сумма заданного количества цен

Запросите количество цен с подсказкой `Price count: `.
Затем запросите ровно столько цен с подсказкой `Price: `. Каждая цена неотрицательна, например `12.50`. Выведите их сумму с подписью `Total: ` и двумя знаками после точки.
Если цен нет, итог равен `0.00`.

## Пример

После подсказок показан ввод пользователя.

```text
Price count: 3
Price: 10.50
Price: 0
Price: 2.25
Total: 12.75
```
