# Задание 7. Количество введённых чисел

Запрашивайте число с подсказкой `Number or stop: `, пока пользователь не введёт `stop`. Числа могут быть отрицательными, нулевыми и дробными. Выведите количество введённых чисел с подписью `Count: `. Команда `stop` не входит в количество; если она введена сразу, результат равен нулю.

## Пример

После подсказок показан ввод пользователя.

```text
Number or stop: -2
Number or stop: 0
Number or stop: 3.5
Number or stop: stop
Count: 3
```
