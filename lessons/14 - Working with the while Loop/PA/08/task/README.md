# Задание 8. Средняя оценка

Запрашивайте оценку с подсказкой `Grade or stop: ` до команды `stop`. Допустимы оценки от 0 до 12 без дробной части.
После завершения выведите среднее значение с подписью `Average: ` и двумя знаками после точки. Если ни одной оценки нет, выведите `No grades`.

## Пример

После подсказок показан ввод пользователя.

```text
Grade or stop: 7
Grade or stop: 10
Grade or stop: stop
Average: 8.50
```
