# Задание 9. Минимум и максимум

Запрашивайте число с подсказкой `Number or stop: ` до команды `stop`. Гарантируется хотя бы одно число. Значения могут быть отрицательными, нулевыми и дробными.
После команды выведите минимум с подписью `Min: ` и максимум с подписью `Max: ` на отдельных строках, оба с двумя знаками после точки.

## Пример

После подсказок показан ввод пользователя.

```text
Number or stop: 2.5
Number or stop: -4
Number or stop: 8
Number or stop: stop
Min: -4.00
Max: 8.00
```
