# Задание 10. Сумма положительных чисел

Запрашивайте число с подсказкой `Number or stop: ` до команды `stop`. Числа могут быть дробными.
Найдите сумму только положительных чисел; отрицательные числа пропускайте через `continue`. Ноль не меняет сумму.
После завершения выведите `Positive sum: ` и результат с двумя знаками после точки. Если положительных чисел не было, результат равен `0.00`.

## Пример

После подсказок показан ввод пользователя.

```text
Number or stop: -2
Number or stop: 3.5
Number or stop: -1
Number or stop: 0
Number or stop: 2
Number or stop: stop
Positive sum: 5.50
```
