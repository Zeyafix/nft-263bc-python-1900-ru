# Задание 11. Остановка на первом нуле

Запрашивайте число с подсказкой `Number or stop: ` до команды `stop`. Числа могут быть отрицательными и дробными.
После каждого ненулевого числа выводите `Accepted: ` и это число с двумя знаками после точки.
При первом нуле выведите `Zero found` и остановите цикл через `break`, не запрашивая следующий ввод.
При команде `stop` сообщение `Zero found` не выводится. После любого завершения выведите `Done`.

## Пример

После подсказок показан ввод пользователя.

```text
Number or stop: -2
Accepted: -2.00
Number or stop: 1.5
Accepted: 1.50
Number or stop: 0
Zero found
Done
```
