# Задание 13. Меню вычислений

Перед каждым выбором показывайте меню:

```text
1. Add
2. Square
0. Exit
```

Запросите пункт с подсказкой `Choice: `.

Пункт `1` запрашивает два числа с подсказками `First: ` и `Second: `, затем показывает их сумму с подписью `Result: `.

Пункт `2` запрашивает число с подсказкой `Number: ` и показывает его квадрат с той же подписью.
Числа могут быть отрицательными и дробными; результат показывайте с двумя знаками после точки. После вычисления снова показывайте меню.

Пункт `0` выводит `Goodbye` и завершает программу. Любой другой ответ выводит `Unknown option` и возвращает к меню.

## Пример

После подсказок показан ввод пользователя.

```text
1. Add
2. Square
0. Exit
Choice: 1

First: -2.5
Second: 4
Result: 1.50

1. Add
2. Square
0. Exit
Choice: 2

Number: -3
Result: 9.00

1. Add
2. Square
0. Exit
Choice: 0

Goodbye
```
