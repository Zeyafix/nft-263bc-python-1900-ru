# Задание 14. PIN-код терминала

В учебном терминале установлен PIN-код `5869`. У пользователя ровно три попытки. Каждый раз запрашивайте код с подсказкой `PIN: `.
При верном коде выведите `Access granted` и завершите программу.
После неверного кода выведите `Wrong PIN`. Если попытки ещё остались, выведите `Attempts left: ` и их количество, затем повторите запрос.
После третьего неверного кода выведите `Card blocked` и завершите программу без нового запроса.
Ввод может содержать любой текст, в том числе быть пустым.

## Пример

После подсказок показан ввод пользователя.

```text
PIN: 5869
Access granted
```
