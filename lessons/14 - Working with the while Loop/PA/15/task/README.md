# Задание 15. Подсчёт товаров на складе

Запрашивайте название товара с подсказкой `Product or stop: `. Команда `stop` завершает учёт.
После каждого названия запросите количество единиц этого товара с подсказкой `Quantity: `.
Сложите количества всех введённых партий и после завершения выведите `Total items: ` и итог.
Одинаковые названия могут повторяться: каждая партия учитывается. Сами названия сохранять не требуется.
Для команды `stop` количество не запрашивается. Если товаров нет, итог равен нулю.


## Пример

После подсказок показан ввод пользователя.

```text
Product or stop: Pen
Quantity: 3
Product or stop: Notebook
Quantity: 0
Product or stop: Pen
Quantity: 5
Product or stop: stop

Total items: 8
```
