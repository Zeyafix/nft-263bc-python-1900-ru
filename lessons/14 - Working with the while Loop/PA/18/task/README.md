# Задание 18. Угадай число: уровни и повторная игра

Перед каждым раундом показывайте меню сложности:

```text
1. Easy (1-10, 5 attempts)
2. Medium (1-50, 5 attempts)
3. Hard (1-100, 3 attempts)
```

Запросите уровень с подсказкой `Level: `. Другой ответ выводит `Unknown option` и повторяет меню сложности. 

После выбора уровня загадайте случайное число: `randint(1, 10)` на лёгком, `randint(1, 50)` на среднем и `randint(1, 100)` на сложном. Обе границы входят в диапазон. Сохраните результат в `secret`: число выбирается один раз за раунд и не меняется при вводе догадок.
Подсказка: добавьте в начало программы импорт `from random import randint`.

Запрашивайте догадку с подсказкой `Guess: `. Гарантируется значение в диапазоне выбранного уровня без дробной части. Каждый такой ввод расходует одну попытку. Если догадка меньше секрета, выведите `Higher`, если больше — `Lower`. Подсказка выводится даже после последней неверной попытки.

При совпадении выведите `You won`, в том числе если угадали с последней попытки.
Если попытки закончились без победы, выведите `You lost. Number: ` и секрет.
После любого результата покажите число использованных попыток с подписью `Attempts used: `, затем меню:

```text
1. Play again
0. Exit
```

Запросите действие с подсказкой `Choice: `. Пункт `1` начинает новый раунд с выбора сложности. Заново выберите случайное число и обнулите счётчик попыток.

Пункт `0` выводит `Goodbye` и завершает программу.
При другом ответе выведите `Unknown option` и повторите только меню повторной игры.
Строка `Attempts used: ` выводится один раз за раунд.

## Пример

В этом примере выпало число `7`. После подсказок показан ввод пользователя.

```text
1. Easy (1-10, 5 attempts)
2. Medium (1-50, 5 attempts)
3. Hard (1-100, 3 attempts)
Level: 1

Guess: 7
You won

Attempts used: 1
1. Play again
0. Exit
Choice: 0

Goodbye
```
