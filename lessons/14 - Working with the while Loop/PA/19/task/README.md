# Задание 19. Касса магазина

Корзина в начале пуста. Перед каждым выбором показывайте меню:

```text
1. Add product
2. Clear cart
0. Checkout
```

Запросите пункт с подсказкой `Choice: `.
Пункт `1` запрашивает цену одной единицы с подсказкой `Price: `, затем количество с подсказкой `Quantity: `. Добавьте стоимость партии в корзину и выведите `Cart total: ` и текущую сумму. Названия товаров и список покупок хранить не требуется.

Пункт `2` удаляет все покупки из корзины, выводит `Cart cleared` и возвращает к меню, даже если корзина уже пуста.

Пункт `0` выводит `To pay: ` и итоговую сумму, затем завершает программу. Для пустой корзины итог `0.00`.
Другой ответ выводит `Unknown option` и повторяет меню, сохраняя корзину.
Все суммы показывайте с двумя знаками после точки.

## Пример

После подсказок показан ввод пользователя.

```text
1. Add product
2. Clear cart
0. Checkout
Choice: 1

Price: 2.50
Quantity: 3
Cart total: 7.50

1. Add product
2. Clear cart
0. Checkout
Choice: 1

Price: 1.25
Quantity: 2
Cart total: 10.00

1. Add product
2. Clear cart
0. Checkout
Choice: 0

To pay: 10.00
```
