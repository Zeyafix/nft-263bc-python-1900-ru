# Задание 20. Мониторинг температуры

Запрашивайте показание датчика в градусах Цельсия с подсказкой `Temperature or stop: ` до команды `stop`.

Значения ниже -50 или выше 150 считаются ошибкой датчика: выведите `Sensor error` и переходите к следующему показанию. Границы -50 и 150 допустимы.

Среди допустимых показаний температура от 80 включительно считается критической: выведите `Critical temperature` и завершите программу без нового запроса.

Для остальных допустимых значений выводите `Temperature: ` и показание с одним знаком после точки. При команде `stop` выведите `Monitoring stopped` и завершите программу.

## Пример

После подсказок показан ввод пользователя.

```text
Temperature or stop: -51
Sensor error
Temperature or stop: 151
Sensor error
Temperature or stop: 23.5
Temperature: 23.5
Temperature or stop: 80
Critical temperature
```
