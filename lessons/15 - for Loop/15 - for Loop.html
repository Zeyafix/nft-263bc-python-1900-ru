Вопрос

Что такое итерация?

Отметьте все подходящие варианты.

Итерация означает один проход по телу цикла. За время работы цикла таких проходов может быть много.

Программа может содержать несколько циклов и много отдельных итераций.

Проверка условия решает, начинать ли проход по телу while. Если условие сразу ложно, тело не выполнится ни разу.

Переменную можно создать и без цикла. Итерацией называют проход по телу цикла.

Вопрос

Какой цикл прервёт break?

Обратите внимание на отступ строки break. Внутренний цикл к этому моменту уже завершил свою работу.

Два цикла while 
row = 1
while row <= 3:
    column = 1
    while column <= 2:
        print(row, column)
        column += 1
    break
print("Done")
Отметьте все подходящие варианты.

break находится в теле внешнего while, после внутреннего цикла. Выполнение продолжится с print("Done").

Строка break не входит в тело внутреннего цикла: у неё меньше отступ. Внутренний while уже закончился по своему условию.

break завершает только ближайший цикл, в тело которого он входит. Здесь это внешний while.

break завершает цикл. Условие не является отдельным блоком, который можно прервать этим словом.

Вопрос

Почему ввод 0 не завершает цикл?

Пользователь вводит 0 и нажимает Enter, но программа снова запрашивает ввод. Почему?

Строка и число 
value = input("Enter 0 to stop: ")
while value != 0:
    value = input("Enter 0 to stop: ")
Отметьте все подходящие варианты.

Строка "0" не равна числу 0, поэтому условие остаётся истинным. Можно сравнивать с "0" или преобразовывать каждый ввод через int, если ожидаются целые числа.

input возвращает строку, независимо от того, какие цифры вы набрали.

Такое сравнение допустимо. Здесь проблема в разных типах сравниваемых значений.

В теле есть присваивание нового результата input переменной value. Но новый результат опять имеет тип str.

Условие проверяется перед каждой итерацией. Сравнение строки с числом каждый раз даёт тот же результат.

while завершится без break, если его условие станет ложным. Здесь ввод строки не может сделать её равной числу 0.

Одного Enter достаточно для завершения input. Дополнительный Enter не преобразует строку в число.

02 / Как устроен for

Представьте, что нужно напечатать числа 1, 2 и 3. С while мы сами задавали начальное число, проверяли границу и увеличивали счётчик. У for другой порядок работы: мы указываем, откуда брать значения, а цикл получает их по очереди.

Определение

Перебор значений

Цикл for выполняет тело для очередного значения из источника перебора. Такое значение записывается в переменную цикла. Когда значения заканчиваются, программа переходит к командам после цикла.

Общая форма заголовка: for number in ...:. Многоточие здесь обозначает место для источника значений. В рабочей программе его нужно заменить, например, на range(1, 4). Этот диапазон даст числа 1, 2 и 3. Все формы range() подробно разберём в следующем разделе.

Первый цикл for 
for number in range(1, 4):
    print(number)
print("Done")
Консоль
1
2
3
Done
  • for начинает цикл.
  • number является переменной цикла. При каждом проходе она получает очередное значение. Заранее писать number = 1 не нужно.
  • in отделяет имя переменной от источника значений. Здесь можно прочитать: «для каждого number из диапазона».
  • range(1, 4) задаёт источник значений. Это не условие вида number < 4.
  • Двоеточие : завершает заголовок. На следующих строках с отступом в четыре пробела находится тело цикла.
  • print("Done") записан без отступа, поэтому выполняется после завершения цикла один раз.

Проследим выполнение программы по шагам:

  1. Python получает источник range(1, 4) перед началом перебора.
  2. Берёт первое значение 1, присваивает его number и выполняет всё тело: печатает 1.
  3. Берёт следующее значение 2, снова присваивает его number и печатает 2.
  4. Так же обрабатывает 3.
  5. Следующего значения нет. Цикл заканчивается, выполняется print("Done").

В теле может быть несколько команд. Все команды с одинаковым отступом относятся к одному проходу, а уже после них цикл получает следующее значение.

Две команды в одной итерации 
for number in range(1, 3):
    print("Number:", number)
    print("Ready")
print("Finished")
Консоль
Number: 1
Ready
Number: 2
Ready
Finished

03 / Повторение с range

range() задаёт последовательность целых чисел с постоянным шагом. Он удобен, когда нужно повторить действие известное число раз или пройти от одной числовой границы к другой. Диапазон не хранит отдельный список всех чисел: он описывает, какие значения цикл должен получить.

Если указать только stop, отсчёт начинается с нуля, а шаг равен единице. Граница stop не входит в диапазон. Поэтому range(5) даёт 0, 1, 2, 3, 4: пять значений, хотя последнее число равно четырём.

Пять значений 
for number in range(5):
    print(number)
Консоль
0
1
2
3
4

Само значение переменной не обязательно использовать в теле. Чтобы три раза вывести одинаковое сообщение, достаточно трёх значений из range(3). Имя repeat здесь напоминает о повторении.

Повторить действие три раза 
for repeat in range(3):
    print("Hello!")
Консоль
Hello!
Hello!
Hello!

При двух аргументах первое число задаёт начало, второе задаёт границу остановки. Начало входит в диапазон, граница остановки не входит. По умолчанию шаг по-прежнему равен 1. Например, range(2, 5) даёт 2, 3, 4. Если по условию задачи нужно вывести числа от 1 до некоторого числа включительно, верхнюю границу диапазона увеличивают на один. В следующем примере переменная stop хранит последнее нужное число, а в range() мы передаём stop + 1.

От одного до stop включительно 
stop = 5
for number in range(1, stop + 1):
    print(number)
Консоль
1
2
3
4
5

Отрицательные границы тоже допустимы. Правило исключённой границы не меняется: range(-3, 2) начинается с −3 и заканчивается на 1. Отрицательное начало само по себе не означает движение назад.

Из отрицательных чисел к положительным 
for number in range(-3, 2):
    print(number)
Консоль
-3
-2
-1
0
1

Третий аргумент step задаёт, на сколько меняется очередное значение. Сначала берётся start, затем к нему прибавляется шаг, затем шаг прибавляется ещё раз. При положительном шаге цикл берёт только значения меньше stop.

Шаг четыре 
for number in range(3, 19, 4):
    print(number)
Консоль
3
7
11
15

Начинаем с 3. Затем получаем 7, 11 и 15. Следующим было бы 19, но граница не включается, поэтому цикл заканчивается. Граница не обязана совпадать со следующим числом: range(3, 18, 4) даст те же 3, 7, 11, 15, потому что 19 уже больше 18.

Для движения назад нужен отрицательный шаг. В этом случае берутся только значения больше stop. Чтобы включить в обратный отсчёт единицу, укажите границу 0.

Обратный отсчёт 
for number in range(5, 0, -1):
    print(number)
print("Go!")

Важно

Аргументы должны быть целыми

В наших примерах start, stop и step имеют тип int. Запись range(1, 4, 0.5) вызовет TypeError: дробный шаг не поддерживается. Строка "5" тоже не заменяет число 5.

Переменная цикла и источник значений выполняют разные роли. range() задаёт последовательность, а number хранит текущее полученное значение. Присваивание number = 0 изменяет переменную, но не перестраивает диапазон.

Присваивание не меняет диапазон

04 / Когда цикл не выполнится

У диапазона может не быть ни одного значения. Это нормальная ситуация: тело for не выполняется, и Python сразу переходит к следующей команде после цикла. Даже первое значение должно удовлетворять правилу границы.

Почему диапазон пуст
ДиапазонПричинаИтерации
range(0)Начало 0, граница 0. Первое число уже на исключённой границе.0
range(4, 4)Начало совпадает с границей остановки.0
range(9, 4)Шаг +1, но начало уже больше границы. Движение вперёд не даст числа меньше 4.0
range(-5)Начало по умолчанию 0, шаг +1. Для этого направления 0 уже за границей −5.0
range(3, 9, -2)Шаг отрицательный, но начало меньше границы. Для движения назад нужно начать выше stop.0
Тело пропускается целиком 
for number in range(9, 4):
    print("Inside:", number)
print("After the loop")
Консоль
After the loop

Если нужен обратный перебор от 9 к 5, надо явно указать отрицательный шаг: range(9, 4, -1). Python не выбирает направление автоматически по порядку границ. Если шаг не написан, он всегда равен 1.

Важно

Нулевой шаг вызывает ошибку

Пустой диапазон и недопустимый диапазон ведут себя по-разному. range(1, 5, 0) вызывает ValueError ещё при создании диапазона. Шаг 0 не продвигает нас к границе, поэтому Python запрещает его. Это не способ получить пустой диапазон или бесконечный цикл.

Недопустимый шаг 
for number in range(1, 5, 0):
    print(number)
print("After the loop")

Последняя строка сообщения об ошибке: ValueError: range() arg 3 must not be zero. Тело не начнётся, но и print("After the loop") не выполнится: необработанная ошибка остановит программу.

Чтобы проверить диапазон вручную, сначала посмотрите на знак шага. Для положительного шага начальное число должно быть меньше stop, для отрицательного должно быть больше stop. Если это не так, диапазон пуст. Для любого допустимого шага одинаковые границы тоже дают пустой диапазон.

Совет

Не рассчитывайте на переменную из пустого цикла

Если цикл не выполнился, он не присвоил переменной ни одного значения. Поэтому не стоит читать number после пустого цикла, если до него переменная не была создана: получите NameError.

Вызов переменной цикла вне цикла 
for number in range(9, 5, 1):
    print(number)
print("After the loop")
print(number)

В примере выше после цикла выводится готовая строка, а затем возникает ошибка NameError, так как цикл ни разу не запустился, из-за чего переменная number не определена.

05 / От while к for

Решим одну задачу двумя способами: выведем числа от 1 до 5 включительно. Сначала используем знакомый while. Здесь мы вручную управляем счётчиком: создаём его, проверяем условие и увеличиваем.

Числа от 1 до 5 через while 
number = 1
while number <= 5:
    print(number)
    number += 1
Консоль
1
2
3
4
5

В версии с for нужные значения описаны диапазоном. Цикл сам по очереди присваивает их переменной. Отдельное увеличение счётчика в теле не требуется.

Те же числа через for 
for number in range(1, 6):
    print(number)
Консоль
1
2
3
4
5

Вывод одинаковый, но способ управления разный. while проверяет условие и не знает, как вы собираетесь его менять. for получает очередное значение из источника перебора и заканчивает работу, когда источник больше ничего не даёт. Поэтому забытое number += 1 в первом примере сделало бы цикл бесконечным, а во втором эта команда вообще не нужна.

break в for работает так же, как в while: немедленно завершает ближайший охватывающий цикл. Остальные значения диапазона этот цикл уже не получит.

Остановка перед четвёркой 
for number in range(1, 7):
    if number == 4:
        break
    print(number)
print("Done")
Консоль
1
2
3
Done

На значении 4 условие становится истинным, и break срабатывает до print(number). Поэтому четвёрка в вывод не попадает. Значения 5 и 6 не обрабатываются. После выхода выполняется print("Done"). Если перенести вывод перед проверкой, четвёрка тоже будет напечатана: порядок команд важен.

continue в for работает так же, как в while: не завершает весь цикл. Он пропускает команды ниже себя в текущем проходе, а затем for получает следующее значение. Возьмём range(10) и пропустим 5, 6, 8 и 9.

Пропуск чисел в for 
for number in range(10):
    if number == 5 or number == 6 or number == 8 or number == 9:
        continue
    print(number)
Консоль
0
1
2
3
4
7

Числа 0, 1, 2, 3 и 4 проходят проверку и выводятся. На 5 и 6 команда continue пропускает print. Затем 7 выводится, а 8 и 9 пропускаются. После 9 значения заканчиваются. Ноль здесь есть, потому что range(10) начинается с нуля; в вопросе на повторение перебор начинался с единицы.

Внутри for можно написать ещё один цикл. В следующем примере для каждого значения row внутренний цикл заново перебирает все значения column. Используйте разные имена переменных, чтобы внешний и внутренний циклы не перезаписывали друг другу текущее значение.

Две строки по три столбца 
for row in range(1, 3):
    for column in range(1, 4):
        print(row, column)
Консоль
1 1
1 2
1 3
2 1
2 2
2 3

При row = 1 внутренний цикл получает 1, 2 и 3. После его завершения внешний получает row = 2, и внутренний перебор снова начинается с 1. Всего команда print выполняется 2 × 3 = 6 раз. Её отступ в восемь пробелов показывает, что она находится внутри двух циклов.

break внутри внутреннего цикла 
for row in range(1, 3):
    for column in range(1, 4):
        if column == 2:
            break
        print(row, column)
print("Done")
Консоль
1 1
2 1
Done

Здесь break завершает только цикл по column. Внешний цикл продолжает работу со следующей строкой. continue внутри внутреннего цикла тоже относится только к нему. Циклы можно смешивать: for внутри while или while внутри for. Чтобы понять, какой цикл затронут, смотрите на вложенность и отступы команды.

06 / for или while

Выбор зависит от того, что управляет повторением. Если нужно пройти по готовым значениям или повторить действие заданное число раз, обычно удобен for. Если нужно продолжать работу, пока выполняется условие, обычно удобен while.

Как выбрать цикл
ЗадачаУдобный выборПочему
Пять раз вывести сообщениеfor с range(5)Число повторений известно заранее.
Вывести чётные числа от 2 до 10for с range(2, 11, 2)Начало, граница и шаг описывают все нужные значения.
Обработать каждое имя в спискеforЕсть источник элементов. Не нужно вручную считать их или менять счётчик.
Спрашивать команду до ввода stopwhileЧисло вводов неизвестно. Продолжение зависит от ответа пользователя.
Повторять действие, пока баланс меньше целиwhileРешение о следующем повторении зависит от текущего состояния.

Например, пользователь может ввести команду остановки сразу, а может сделать это после двадцати других команд. Здесь повторение удобно выразить условием.

Ввод до команды stop 
command = input("Command (stop to exit): ")
while command != "stop":
    print("Received:", command)
    command = input("Command (stop to exit): ")
print("Finished")

В консоли показан пример запуска: пользователь ввёл hello, затем stop. Здесь обе стороны сравнения являются строками, поэтому условие действительно станет ложным. При других ответах вывод и количество повторений изменятся.

В следующих уроках о коллекциях мы рассмотрим больше полезных применений for: обработку строк, списков и других наборов данных. Уже сейчас можно увидеть общий принцип. В переменной names находится список имён, а цикл получает из него очередное имя целиком.

Имена, начинающиеся с A 
names = ["Arthur", "Tom", "Kate", "Bob", "Alice", "Astrid"]
count = 0

for name in names:
    if name[0] == "A":
        count += 1

print(count)
Консоль
3
  • Квадратные скобки в names = [...] создают список. Его элементы здесь являются строками с именами.
  • count = 0 стоит до цикла, чтобы счётчик начал работу с нуля и не сбрасывался на каждом имени.
  • for name in names: по очереди присваивает переменной name строки из списка.
  • name[0] получает первый символ строки. Нумерация символов начинается с нуля. Все имена в этом примере непустые, поэтому первый символ у каждого есть.
  • Если этот символ равен заглавной "A", команда count += 1 увеличивает счётчик. Сравнение чувствительно к регистру: маленькая "a" здесь не подходит.
  • print(count) стоит после цикла и выводит итог один раз.

Здесь range() не нужен: источник уже есть, это список names. Мы не увеличиваем name вручную и не проверяем, осталось ли ещё имя. Цикл сам получает следующий элемент. Вопрос

Какой цикл завершится по break?

Внутри while находится for. Определите, к какому циклу относится строка break.

for внутри while 
attempt = 1

    for number in range(2):
        print(attempt, number)
    break

Отметьте все подходящие варианты.

break записан в теле while после for. Внутренний for уже перебрал 0 и 1, а break завершает while.

У break такой же отступ, как у заголовка for. В тело for эта команда не входит.

break относится только к ближайшему охватывающему циклу. Здесь это while, а for к этому моменту уже закончился обычным образом.

Вложенные for и while допустимы. break работает по тому же правилу вложенности.
