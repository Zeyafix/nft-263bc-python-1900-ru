# Задание 01. Повтор с номером

Запросите количество повторений, затем одно слово. Выведите слово указанное количество раз, добавляя номер повторения от 1 до введённого количества включительно.

Каждое повторение выводите на отдельной строке в формате `<номер>: <слово>`. Если количество равно 0, слово всё равно нужно запросить, а строк повторения не будет.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Repetition count: 3
Word: Hello

1: Hello
2: Hello
3: Hello
```
