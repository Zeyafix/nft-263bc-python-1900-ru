# Задание 03. Строго между границами

Запросите `start`, затем `stop`, причём `start < stop`. Выведите все числа строго между ними по возрастанию. Каждое число — на отдельной строке. Сами границы не выводите. Если между ними нет подходящих чисел, строк результата не будет.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Start: 2
Stop: 6
3
4
5
```
