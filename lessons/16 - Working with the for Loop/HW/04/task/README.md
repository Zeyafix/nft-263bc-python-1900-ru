# Задание 04. Нечётные по убыванию

Запросите `start`, затем `stop`. Начало `start` нечётное, и `start > stop`. Значение `stop` может быть чётным или нечётным.

Начиная со `start`, выводите числа по убыванию с шагом 2, каждое на отдельной строке. Выводите только числа не меньше `stop`. Если последовательность попадает точно на `stop`, выведите и его.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Start (odd): 9
Stop: 3
9
7
5
3
```
