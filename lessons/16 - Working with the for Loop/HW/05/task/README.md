# Задание 05. Свой шаг

Запросите `start`, `stop`, затем `step`. Границы могут идти в любом порядке и могут совпадать.

При положительном шаге начните с меньшей границы и двигайтесь к большей. При отрицательном — начните с большей и двигайтесь к меньшей. Расстояние между соседними числами равно величине шага. Каждое число выводите на отдельной строке.

Границы включены в допустимый промежуток: начальную выводите всегда, конечную — только если последовательность попадает на неё точно. При совпадающих границах выведите одно число.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
First boundary: 8
Second boundary: 2
Step (nonzero): 3
2
5
8
```

## Ещё один пример

```text
First boundary: 1
Second boundary: 6
Step (nonzero): 2
1
3
5
```
