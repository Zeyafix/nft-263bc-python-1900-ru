# Задание 07. Где заканчивается тело цикла

В `main.py` числа должны выводиться на каждой итерации: сначала 1, затем 2, затем 3. После цикла должно один раз появиться сообщение `Finished`. Исправьте только отступы, не меняя порядок и остальной текст строк. Ввода нет.

## Ожидаемый вывод

```text
1
2
3
Finished
```
