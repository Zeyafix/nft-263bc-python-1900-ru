# Задание 08. Ввод с обратным отсчётом

Запросите количество чисел. Перед каждым следующим запросом выведите отдельную строку `Remaining: <left>`, где `<left>` — сколько чисел ещё предстоит ввести, включая текущее.

После этого запросите число, удвойте его и сразу выведите `Doubled: <result>`, прежде чем переходить к следующему запросу. При количестве 0 дополнительных запросов и результатов нет.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Number count: 3

Remaining: 3
Number: 2
Doubled: 4.0

Remaining: 2
Number: -1.5
Doubled: -3.0

Remaining: 1
Number: 0
Doubled: 0.0
```
