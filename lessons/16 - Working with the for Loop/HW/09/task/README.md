# Задание 09. Произведение

Запросите количество чисел, затем каждое число отдельно. Числа могут быть отрицательными, положительными и нулём.

Найдите произведение всех введённых чисел и выведите `Product: <result>`. Даже если встретился ноль, запросите все оставшиеся числа.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Number count: 3

Number: 2
Number: 3
Number: 4

Product: 24.0
```
