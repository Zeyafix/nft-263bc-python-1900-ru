# Задание 10. Два счётчика

Запросите количество чисел, затем каждое число отдельно.

Отдельно посчитайте положительные и отрицательные числа. Нули не учитывайте. Выведите две строки: `Positive: <positive>` и `Negative: <negative>`. При отсутствии чисел оба счётчика равны 0.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Number count: 6

Number: 1
Number: -2
Number: 0
Number: 0.5
Number: -0.5
Number: 0

Positive: 2
Negative: 2
```
