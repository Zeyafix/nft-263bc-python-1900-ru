# Задание 11. Сумма до остановки

Запросите количество чисел и сами числа. При первом отрицательном числе завершите ввод с помощью `break`. Это число не включайте в сумму и больше ничего не запрашивайте.

Выведите сумму чисел, введённых до остановки, в формате `Sum: <result>`. Если отрицательных нет, сложите все числа. Если ни одного числа не вошло в сумму, результат равен 0.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Number count: 5

Number: 2
Number: 3.5
Number: -1

Sum: 5.5
```

## Ещё один пример

```text
Number count: 4

Number: -2

Sum: 0
```
