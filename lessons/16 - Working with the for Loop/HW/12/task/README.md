# Задание 12. Из while в for

В `main.py` программа запрашивает `limit` и выводит квадраты чисел от 1 до `limit` включительно, каждый на отдельной строке. При 0 строк результата нет.

Замените цикл `while` циклом `for`, сохранив порядок ввода и результат для любого допустимого `limit`. В готовой программе не должно остаться циклов `while`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Limit: 3
1
4
9
```
