# Задание 13. Из for в while

В `main.py` программа запрашивает `start` и выводит обратный отсчёт от `start` до 1, затем один раз `Go!`. При 0 выводится только `Go!`.

Замените цикл `for` циклом `while`, сохранив поведение для любого допустимого `start`. В готовой программе не должно остаться циклов `for`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Start: 3
3
2
1
Go!
```
