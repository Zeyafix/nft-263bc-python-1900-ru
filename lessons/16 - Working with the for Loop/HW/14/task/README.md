# Задание 14. Из вложенных while во вложенные for

Программа в `main.py` запрашивает количество рядов и мест в каждом ряду. Затем выводит все места по рядам в формате `Row <row>, seat <seat>`. Нумерация начинается с 1. Если рядов или мест 0, строк результата нет.

Замените оба цикла `while` циклами `for`: один внешний и один вложенный. Сохраните поведение для всех допустимых размеров. Циклов `while` в решении быть не должно.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Row count: 2
Seats per row: 3
Row 1, seat 1
Row 1, seat 2
Row 1, seat 3
Row 2, seat 1
Row 2, seat 2
Row 2, seat 3
```
