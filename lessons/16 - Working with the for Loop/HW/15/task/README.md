# Задание 15. Из вложенных for во вложенные while

Программа в `main.py` запрашивает количество групп и раундов в каждой группе. Группы идут по возрастанию от 1, раунды в каждой группе — по убыванию до 1. Каждая строка имеет вид `Group <group>, round <round>`. При нулевом количестве групп или раундов строк результата нет.

Замените оба цикла `for` циклами `while`: один внешний и один вложенный. Сохраните поведение для всех допустимых значений. Циклов `for` в решении быть не должно.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Group count: 2
Rounds per group: 3
Group 1, round 3
Group 1, round 2
Group 1, round 1
Group 2, round 3
Group 2, round 2
Group 2, round 1
```
