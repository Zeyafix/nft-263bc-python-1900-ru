# Задание 16. Шкала ёмкости

Запросите объём резервуара в литрах. Затем запросите количество отметок.

Постройте равномерную шкалу заполнения. Количество отметок включает обе крайние: первая — 0 литров и 0%, последняя — полный объём и 100%. Остальные отметки расположены на одинаковом расстоянии друг от друга.

Для каждой отметки по возрастанию заполнения выведите `Liters: <liters>; percent: <percent>%`. Литры и проценты показывайте с двумя знаками после точки. Например, для 80 литров и 5 отметок нужны уровни 0, 20, 40, 60 и 80 литров.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Capacity in liters: 80
Mark count (including endpoints): 5
Liters: 0.00; percent: 0.00%
Liters: 20.00; percent: 25.00%
Liters: 40.00; percent: 50.00%
Liters: 60.00; percent: 75.00%
Liters: 80.00; percent: 100.00%
```
