# Задание 17. Стоимость аренды

За выдачу велосипеда берут фиксированную плату 50 денежных единиц. Она входит в каждую итоговую стоимость один раз.

Запросите почасовой тариф, затем количество часов. Для каждого срока от 1 до указанного количества часов включительно выведите отдельную строку `Hours: <hours>; cost: <cost>`. Стоимость складывается из платы за выдачу и оплаты всех часов аренды. Сумму показывайте с двумя знаками после точки.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Hourly rate: 12.5
Maximum hours: 3
Hours: 1; cost: 62.50
Hours: 2; cost: 75.00
Hours: 3; cost: 87.50
```
