# Задание 18. Время в дороге

Запросите число участков маршрута. Для каждого участка сначала запросите длину в километрах, затем скорость в километрах в час.

Найдите общее время движения без остановок. На каждом участке скорость постоянна. Выведите суммарное время в часах в формате `Time: <hours> h` с двумя знаками после точки. Не округляйте время отдельных участков до подсчёта итога.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Route section count: 2

Section 1 distance in km: 60
Section 1 speed in km/h: 30

Section 2 distance in km: 90
Section 2 speed in km/h: 60

Time: 3.50 h
```
