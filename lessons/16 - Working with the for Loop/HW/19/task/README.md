# Задание 19. Нарушения скорости

Ограничение скорости — 60 км/ч. Запросите количество автомобилей, затем скорость каждого автомобиля.

Нарушителем считается автомобиль со скоростью строго больше 60 км/ч. Посчитайте нарушителей и найдите самое большое превышение ограничения, а не самую большую скорость.

Выведите `Violations: <count>`, затем `Max excess: <speed> km/h`. Превышение показывайте с двумя знаками после точки. Если нарушителей нет, превышение равно `0.00`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Car count: 4

Speed in km/h: 60
Speed in km/h: 80
Speed in km/h: 59
Speed in km/h: 72.5

Violations: 2
Max excess: 20.00 km/h
```
