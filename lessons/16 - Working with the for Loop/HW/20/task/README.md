# Задание 20. Самая длинная серия тренировок

Запросите количество дней. Для каждого дня по порядку запросите ответ: `1`, если была тренировка, или `0`, если её не было. Других ответов не будет.

Найдите максимальное число тренировочных дней подряд. День без тренировки прерывает серию. Выведите `Longest streak: <count>`. Если тренировок не было или дней 0, результат равен 0.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Day count: 7

Day 1, training (1=yes, 0=no): 1
Day 2, training (1=yes, 0=no): 1
Day 3, training (1=yes, 0=no): 0
Day 4, training (1=yes, 0=no): 1
Day 5, training (1=yes, 0=no): 1
Day 6, training (1=yes, 0=no): 1
Day 7, training (1=yes, 0=no): 0

Longest streak: 3
```
