# Задание 21. Резерв воды

В баке изначально 100 литров воды. Резервный уровень — 20 литров.

Запросите количество дней. Для каждого дня запросите расход в литрах. После расхода обновите остаток. Как только он достигнет 20 литров или опустится ниже, завершите ввод с помощью `break`. Новые дни после этого не запрашивайте. В любом случае запросов расхода должно быть не больше указанного количества дней.

В конце выведите число учтённых дней `Days: <days>` и остаток `Water left: <left> l` с двумя знаками после точки. День достижения резерва тоже учитывается. При 0 дней вода остаётся нетронутой.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Day count: 5

Day 1 water use in liters: 30
Day 2 water use in liters: 50

Days: 2
Water left: 20.00 l
```
