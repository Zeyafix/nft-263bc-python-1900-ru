# Задание 22. Контроль нагрева

Аварийный порог — 80 °C. Запросите количество показаний, затем температуры по очереди.

При первой температуре не ниже 80 °C прекратите запросы с помощью `break` и выведите `Alarm at measurement: <count>`, где `<count>` — номер этого измерения, начиная с 1. Показания после аварийного не запрашивайте.

Если все запрошенные температуры ниже порога или количество равно 0, выведите `No alarm`. Выводится только одно из этих сообщений.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Measurement count: 5

Temperature in C: 20
Temperature in C: 79.5
Temperature in C: 80

Alarm at measurement: 3
```

## Ещё один пример

```text
Measurement count: 3

Temperature in C: -5
Temperature in C: 0
Temperature in C: 79.9

No alarm
```
