# Задание 23. Отбор посылок

Запросите количество посылок. Для каждой по порядку запросите вес в килограммах.

Принимаются посылки весом не больше 10 кг. Более тяжёлые пропускайте с помощью `continue`: для них не рассчитывайте и не выводите стоимость, но продолжайте обработку следующих посылок.

Тариф — 30 денежных единиц за килограмм, оплачивается фактический вес без округления до целого килограмма. Для каждой принятой посылки сразу выведите `Parcel <count>: <price>`, где `<count>` — её номер среди всех введённых посылок, начиная с 1, `<price>` — стоимость с двумя знаками после точки. Если подходящих посылок нет, строк результата не будет.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Parcel count: 4

Parcel 1 weight in kg: 2
Parcel 1: 60.00

Parcel 2 weight in kg: 12

Parcel 3 weight in kg: 10
Parcel 3: 300.00

Parcel 4 weight in kg: 0.5
Parcel 4: 15.00
```
