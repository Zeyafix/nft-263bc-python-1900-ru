# Задание 24. Средняя оценка сервиса

Запросите количество ответов, затем каждый ответ: оценку 1, 2, 3, 4 или 5 либо 0, означающий отказ от оценки. Других ответов не будет.

Пропускайте отказы с помощью `continue`. Найдите среднюю оценку только среди тех, кто поставил оценку. Выведите `Average: <average>` с двумя знаками после точки. Если оценок нет, выведите `No ratings`. Отказ не завершает опрос: запросите все ответы.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Response count: 4

Rating (1-5, or 0 to skip): 5
Rating (1-5, or 0 to skip): 0
Rating (1-5, or 0 to skip): 3
Rating (1-5, or 0 to skip): 0

Average: 4.00
```

## Ещё один пример

```text
Response count: 3

Rating (1-5, or 0 to skip): 0
Rating (1-5, or 0 to skip): 0
Rating (1-5, or 0 to skip): 0

No ratings
```
