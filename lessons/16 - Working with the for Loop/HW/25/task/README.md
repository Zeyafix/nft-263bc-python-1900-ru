# Задание 25. Инвентаризация склада

Запросите количество стеллажей, затем количество полок на каждом стеллаже.

Для каждого стеллажа по порядку запросите количество коробок на каждой его полке. Стеллажи и полки нумеруются с 1. Используйте вложенные циклы `for`: внешний для стеллажей, внутренний для полок.

После ввода всех полок одного стеллажа сразу выведите `Rack <номер>: <count>`, где `<count>` — итог по этому стеллажу, и только затем переходите к следующему. После всех стеллажей выведите общий итог `Total: <total>`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Rack count: 2
Shelves per rack: 2
Rack 1, shelf 1, box count: 3
Rack 1, shelf 2, box count: 4
Rack 1: 7
Rack 2, shelf 1, box count: 1
Rack 2, shelf 2, box count: 5
Rack 2: 6
Total: 13
```
