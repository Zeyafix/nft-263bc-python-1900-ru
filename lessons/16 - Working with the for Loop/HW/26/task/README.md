# Задание 26. Парные встречи

Запросите количество участников. Участники пронумерованы от 1 до этого количества включительно.

Составьте список встреч, в котором каждый встречается с каждым ровно один раз. Встреч с самим собой быть не должно, а `1 - 2` и `2 - 1` — одна и та же встреча.

Каждую встречу выведите на отдельной строке `A - B`, где A меньше B. Упорядочьте строки сначала по возрастанию A, а при одинаковом A — по возрастанию B. При одном участнике строк встреч не будет.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Participant count: 3
1 - 2
1 - 3
2 - 3
```
