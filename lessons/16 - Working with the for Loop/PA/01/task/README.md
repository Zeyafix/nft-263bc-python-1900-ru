# Задание 1. Повтор сообщения

Запросите сообщение с подсказкой `Message: `. Выведите его пять раз, каждый раз на новой строке. Сохраните регистр, пробелы и знаки препинания сообщения.

## Пример

После подсказок показан ввод пользователя.

```text
Message: Hello, Python!
Hello, Python!
Hello, Python!
Hello, Python!
Hello, Python!
Hello, Python!
```
