# Задание 3. Обе границы включены

Запросите границы с подсказками `Start: ` и `Stop: `. Обе границы задаются без дробной части, `start ≤ stop`, отрицательные значения допустимы. Выведите все числа от `start` до `stop` включительно по возрастанию, каждое на новой строке.

## Пример

После подсказок показан ввод пользователя.

```text
Start: 2
Stop: 5
2
3
4
5
```
