# Задание 7. Заданное количество запросов

Запросите количество людей с подсказкой `Count: `. Затем ровно столько раз запросите имя с подсказкой `Name: `. Сразу после каждого имени, до следующего запроса, выведите приветствие вида `Hello, Alice!`. При нулевом количестве имена не запрашивайте.

## Пример

После подсказок показан ввод пользователя.

```text
Count: 3

Name: Alice
Hello, Alice!

Name: Bob
Hello, Bob!

Name: Mary Jane
Hello, Mary Jane!
```
