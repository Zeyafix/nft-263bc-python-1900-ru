# Задание 8. Нумерация запросов

Запросите ровно пять имён с помощью цикла `for`. Номер текущего запроса показывайте в подсказках `Name 1: `, `Name 2: ` и так далее до `Name 5: `. После каждого имени сразу выведите приветствие вида `Hello, Alice!`.

## Пример

После подсказок показан ввод пользователя.

```text
Name 1: Alice
Hello, Alice!

Name 2: Bob
Hello, Bob!

Name 3: Sam
Hello, Sam!

Name 4: Kate
Hello, Kate!

Name 5: Mary Jane
Hello, Mary Jane!
```
