# Задание 9. Накопление суммы

Запросите количество чисел с подсказкой `Count: `. Каждое число запросите с подсказкой `Number: `. После всех запросов выведите сумму с подписью `Sum: `. Если чисел нет, сумма равна 0.

## Пример

После подсказок показан ввод пользователя.

```text
Count: 3

Number: 2.5
Number: -1
Number: 4

Sum: 5.5
```
