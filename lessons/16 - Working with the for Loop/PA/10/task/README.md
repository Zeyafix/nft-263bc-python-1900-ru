# Задание 10. Счётчик по условию

Запросите количество чисел с подсказкой `Count: `. Каждое число запросите с подсказкой `Number: `. Выведите количество отрицательных чисел с подписью `Negative: `. Ноль отрицательным не считается.

## Пример

После подсказок показан ввод пользователя.

```text
Count: 4

Number: -2
Number: 0
Number: 3
Number: -0.5

Negative: 2
```
