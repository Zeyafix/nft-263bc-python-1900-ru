# Задание 11. Остановка на числе

Перебирайте числа в цикле `for` от 1 до 20 включительно. Завершите цикл с помощью `break`, когда дойдёте до 7, до вывода этого числа. Предыдущие числа выведите каждое на новой строке. Запрашивать данные не нужно.

## Пример

После подсказок показан ввод пользователя.

```text
1
2
3
4
5
6
```
