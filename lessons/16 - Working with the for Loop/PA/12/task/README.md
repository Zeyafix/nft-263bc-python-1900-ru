# Задание 12. Досрочное завершение ввода

Запросите не более десяти чисел с подсказкой `Number: `. При вводе нуля сразу завершите цикл с помощью `break` и больше ничего не запрашивайте. Для каждого ненулевого числа сразу выведите строку вида `Accepted: 2.5`. Для нуля такую строку не выводите. После десяти ненулевых чисел программа тоже должна завершиться.

## Пример

После подсказок показан ввод пользователя.

```text
Number: 2.5
Accepted: 2.5

Number: -3
Accepted: -3

Number: 0
```
