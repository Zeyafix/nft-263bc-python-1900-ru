# Задание 14. Пропуск по условию

Запросите количество чисел с подсказкой `Count: `. Каждое число запросите с подсказкой `Number: `. Для положительного числа сразу выведите его квадрат с подписью `Square: `. Ноль и отрицательные числа пропускайте с помощью `continue`, ничего для них не выводя. Обработайте все запрошенные числа.

## Пример

После подсказок показан ввод пользователя.

```text
Count: 4

Number: -2

Number: 0

Number: 3
Square: 9

Number: 1.5
Square: 2.25
```
