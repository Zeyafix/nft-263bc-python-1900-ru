# Задание 15. Таблица цен

Запросите цену одной тетради с подсказкой `Price: `. Выведите стоимость покупки от 1 до 10 тетрадей с помощью цикла `for`: на каждой строке количество и стоимость в формате `1: 2.50`. Стоимость показывайте с двумя знаками после точки.

## Пример

После подсказок показан ввод пользователя.

```text
Price: 2.50
1: 2.50
2: 5.00
3: 7.50
4: 10.00
5: 12.50
6: 15.00
7: 17.50
8: 20.00
9: 22.50
10: 25.00
```
