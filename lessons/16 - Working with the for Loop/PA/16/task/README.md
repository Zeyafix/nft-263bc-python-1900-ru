# Задание 16. План тренировок

Запросите число повторений в первый день с подсказкой `First day: `, затем количество дней с подсказкой `Days: `. Каждый следующий день включает на два повторения больше предыдущего. Выведите план: номер дня с 1 и число повторений в формате `Day 1: 10`, по одному дню на строке.

## Пример

После подсказок показан ввод пользователя.

```text
First day: 10
Days: 3

Day 1: 10
Day 2: 12
Day 3: 14
```
