# Задание 17. Чек магазина

Запросите количество позиций с подсказкой `Items: `. Для каждой позиции запросите цену одной единицы с подсказкой `Price: `, затем количество товара с подсказкой `Quantity: `. Сразу выведите стоимость позиции в формате `Item 1: 7.50`, нумеруя позиции с 1. В конце выведите общую стоимость с подписью `Total: `. Все стоимости показывайте с двумя знаками после точки. Для чека без позиций итог равен `0.00`.

## Пример

После подсказок показан ввод пользователя.

```text
Items: 2

Price: 2.5
Quantity: 3
Item 1: 7.50

Price: 4
Quantity: 2
Item 2: 8.00

Total: 15.50
```
