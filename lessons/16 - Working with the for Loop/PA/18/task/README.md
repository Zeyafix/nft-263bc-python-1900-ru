# Задание 18. Учёт посещаемости

Запросите количество студентов с подсказкой `Students: `. Для каждого запросите отметку с подсказкой `Present (yes/no): `. Пользователь вводит только `yes`, если студент присутствует, или `no`, если отсутствует, именно в нижнем регистре. После всех отметок выведите число присутствующих с подписью `Present: `, затем число отсутствующих с подписью `Absent: `, на отдельных строках.

## Пример

После подсказок показан ввод пользователя.

```text
Students: 3

Present (yes/no): yes
Present (yes/no): no
Present (yes/no): yes

Present: 2
Absent: 1
```
