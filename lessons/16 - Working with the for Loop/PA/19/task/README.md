# Задание 19. Погода за дни

Запросите количество дней с подсказкой `Days: `. За каждый день запросите температуру в градусах Цельсия с подсказкой `Temperature: `. Выведите среднюю температуру с подписью `Average: ` и двумя знаками после точки. На следующей строке выведите количество дней с температурой строго ниже нуля с подписью `Below zero: `.

## Пример

После подсказок показан ввод пользователя.

```text
Days: 3

Temperature: -2.5
Temperature: 0
Temperature: 7

Average: 1.50
Below zero: 1
```
