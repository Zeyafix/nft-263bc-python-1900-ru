# Задание 20. Лучший результат

Запросите количество участников с подсказкой `Participants: `. Затем по порядку запросите время каждого участника в секундах с подсказкой `Time: `. Номера участников начинаются с 1. Выведите номер самого быстрого с подписью `Fastest: `. Самый быстрый имеет наименьшее время. Если оно одинаково у нескольких участников, выберите первого из них.

## Пример

После подсказок показан ввод пользователя.

```text
Participants: 3

Time: 14
Time: 10.5
Time: 12

Fastest: 2
```
