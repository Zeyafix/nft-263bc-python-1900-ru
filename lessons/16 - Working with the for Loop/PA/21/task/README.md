# Задание 21. Попытки входа

Дайте пользователю не более трёх попыток ввести учебный PIN-код `5869`. Каждая попытка начинается с подсказки `PIN: `. Совпадение должно быть точным. После правильного ввода выведите `Access granted` и сразу завершите цикл с помощью `break`. После неверного ввода переходите к следующей попытке без дополнительных сообщений. Если все три попытки неверны, выведите `Access denied` один раз. После успешного входа сообщение о провале не выводите.

## Пример

После подсказок показан ввод пользователя.

```text
PIN: 5869
Access granted
```
