# Задание 22. Цель накоплений

Запросите нужную сумму с подсказкой `Goal: `, затем количество дней с подсказкой `Days: `. Накопления изначально равны нулю. Каждый день запрашивайте неотрицательный взнос с подсказкой `Deposit: `. Как только накопления достигнут цели или превысят её, выведите номер дня в формате `Goal reached on day 3` и завершите цикл с помощью `break`. Номера дней начинаются с 1. Если за отведённые дни цель не достигнута, выведите `Goal not reached`.

## Пример

После подсказок показан ввод пользователя.

```text
Goal: 100
Days: 5

Deposit: 40
Deposit: 60

Goal reached on day 2
```
