# Задание 23. Отменённые заказы

Запросите количество заказов с подсказкой `Orders: `. Для каждого сначала запросите статус с подсказкой `Status: `. Пользователь вводит только `cancelled` или `active`. Отменённый заказ пропустите с помощью `continue`: его сумму спрашивать нельзя. Только для активного заказа запросите неотрицательную сумму с подсказкой `Amount: `. В конце выведите общую сумму активных заказов с подписью `Total: ` и двумя знаками после точки. Если учитывать нечего, итог равен `0.00`.

## Пример

После подсказок показан ввод пользователя.

```text
Orders: 4

Status: cancelled

Status: active
Amount: 12.5

Status: cancelled

Status: active
Amount: 7.25

Total: 19.75
```
