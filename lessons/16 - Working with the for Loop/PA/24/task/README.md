# Задание 24. Некорректные показания

Запросите количество измерений с подсказкой `Measurements: `. Каждое значение влажности в процентах запросите с подсказкой `Humidity: `. Показания меньше 0 или больше 100 пропускайте с помощью `continue`. Границы 0 и 100 считаются корректными. После всех запросов выведите среднее только корректных показаний с подписью `Average: ` и двумя знаками после точки. Если корректных показаний нет, выведите `No valid measurements`.

## Пример

После подсказок показан ввод пользователя.

```text
Measurements: 5

Humidity: -5
Humidity: 0
Humidity: 40
Humidity: 100
Humidity: 120

Average: 46.67
```
