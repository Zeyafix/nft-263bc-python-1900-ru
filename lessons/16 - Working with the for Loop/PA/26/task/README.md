# Задание 26. Выручка торговых точек

Запросите количество торговых точек с подсказкой `Branches: `. Для каждой точки отдельно запросите количество дней с подсказкой `Days: `. За каждый день этой точки запросите неотрицательную выручку с подсказкой `Revenue: `. Закончив ввод для точки, выведите её итог в формате `Branch 1: 125.50`, затем переходите к следующей точке. Номера точек начинаются с 1. В самом конце выведите выручку всей сети с подписью `Total: `. Все суммы показывайте с двумя знаками после точки. При отсутствии дней или точек соответствующая сумма равна `0.00`. Используйте вложенные циклы `for`.

## Пример

После подсказок показан ввод пользователя.

```text
Branches: 2

Days: 2
Revenue: 10
Revenue: 20.5
Branch 1: 30.50

Days: 1
Revenue: 7.25
Branch 2: 7.25

Total: 37.75
```
