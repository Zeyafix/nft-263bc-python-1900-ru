02 / Что такое метод и как его вызвать

Определение

Метод вызывается у значения

Метод похож на функцию (готовый алгоритм с именем), которая связана с определённым типом данных. У строк есть готовые методы для работы с текстом. Общая запись: text.method(arguments). Здесь text обозначает строку, method заменяют именем нужного метода, а arguments обозначает передаваемые ему данные. Это схема, а не готовая команда.

Сначала пишут строку или имя переменной, затем точку, имя метода и круглые скобки. Например, text.lower() возвращает текст со строчными буквами. Скобки нужны даже тогда, когда внутри ничего нет. Запись text.lower без скобок только обращается к методу, но не запускает его.

Функция и метод
text = "Python"
print(len(text))
print(text.lower())
print("HELLO".lower())
Консоль
6
python
hello

В len(text) строка передаётся аргументом отдельной функции. В text.lower() строка уже указана перед точкой. Метод lower() не требует дополнительных аргументов. У text.replace("P", "J") их два: что искать и на что заменить. Аргументы разделяют запятыми.

Возвращаемое значение можно вывести через print(), сохранить в переменную или использовать в условии. Сам вызов метода в файле программы не печатает результат. Строка неизменяема: методы обработки текста возвращают результат, но не переписывают исходное значение.

Сохранение результата
text = "HELLO"
text.lower()
print(text)
normalized = text.lower()
print(normalized)
text = text.lower()
print(text)
Консоль
HELLO
hello
hello

После text = text.lower() имя text связано с результатом обработки. Это новое присваивание, а не изменение символов старой строки.

Что могут возвращать методы строк
ВызовРезультатТип
"Hi".lower()"hi"str
"banana".count("a")3int
"Hi".startswith("H")Truebool
"red blue".split()["red", "blue"]list

Список пока можно понимать как несколько значений в определённом порядке. В разделе о split() разберём, как читать его элементы. Не нужно запоминать все методы сразу: выбирайте их по задаче и проверяйте тип результата.

03 / Изменение регистра

Регистр определяет, большая буква или маленькая. Это полезно, когда пользователь вводит команду разными способами: "HELP", "Help" или "help". Приведение к одному регистру упрощает сравнение.

Четыре способа изменить регистр
МетодЧто делает
lower()Переводит буквы в нижний регистр.
upper()Переводит буквы в верхний регистр.
capitalize()Первый символ делает заглавным, если это буква; остальные буквы переводит в нижний регистр.
title()Делает заглавной первую букву каждой группы букв, остальные буквы группы переводит в нижний регистр.
Один текст, четыре результата
text = "hELLO pYTHON"
print(text.lower())
print(text.upper())
print(text.capitalize())
print(text.title())
print(text)
Консоль
hello python
HELLO PYTHON
Hello python
Hello Python
hELLO pYTHON

Пробелы, цифры и знаки препинания эти методы не удаляют. capitalize() работает именно с первым символом: если строка начинается с пробела, метод не перескакивает к первой букве. title() использует простые границы групп букв, а не правила языка.

Пробел и апостроф
print(" hello WORLD".capitalize())
print("they're ready".title())
Консоль
 hello world
They'Re Ready
Совет

Выбирайте обработку под задачу

Для знакомых команд на английском обычно достаточно lower(). Для оформления заголовка можно попробовать title(), но результат для имён и слов с апострофом нужно проверять. Автоматическая смена регистра не исправляет опечатки.

04 / Очистка краёв строки

При вводе или копировании текста по краям часто остаются пробелы. Метод strip() без аргументов убирает пробельные символы с обоих краёв: обычные пробелы, табуляции и переводы строк. lstrip() очищает только левый край, rstrip() только правый. Внутри строки пробелы остаются.

Границы результата видны по скобкам
text = "  red  blue  "
print("[" + text.strip() + "]")
print("[" + text.lstrip() + "]")
print("[" + text.rstrip() + "]")
print("[" + "\t hello \n".strip() + "]")
Консоль
[red  blue]
[red  blue  ]
[  red  blue]
[hello]

Квадратные скобки здесь добавлены только для вывода, чтобы увидеть оставшиеся пробелы. Между red и blue по-прежнему два пробела. Если вся строка состоит из пробельных символов, strip() вернёт пустую строку.

Важно

Аргумент задаёт набор символов

В strip("ab") буквы a и b удаляются по краям в любом порядке и количестве. Обработка каждого края останавливается на первом символе вне этого набора. Целое слово "ab" метод не ищет. Если аргумент указан, пробел не удалится автоматически: его тоже нужно включить в набор.

Набор, а не фрагмент
print("abbaHello ba".strip("ab"))
print("***hello***".strip("*"))
print("  ***hello***  ".strip("*"))
print("  ***hello***  ".strip(" *"))
Консоль
Hello 
hello
  ***hello***  
hello

В первом результате справа сохранился пробел: его нет в наборе "ab". В третьем результате крайние пробелы не дают добраться до звёздочек. Для удаления конкретного начала или конца строки ниже познакомимся с removeprefix() и removesuffix().

05 / Проверка начала и конца

startswith(prefix) проверяет, начинается ли строка указанным фрагментом. endswith(suffix) проверяет конец. Оба метода возвращают bool: True или False. Исходный текст они не меняют, регистр и пробелы учитываются.

Команда должна начинаться с префикса
command = "/help"
print(command.startswith("/"))
print(command.startswith("help"))
print("/" in "help / later")
print("help / later".startswith("/"))
Консоль
True
False
True
False

Оператор in отвечает на вопрос «есть ли фрагмент где-нибудь?». Если команда должна начинаться с косой черты, наличие черты в середине недостаточно. Проверка startswith() выражает требование точнее.

Расширение в конце имени
filename = "report.txt.backup"
print(".txt" in filename)
print(filename.endswith(".txt"))
print("report.txt".endswith(".txt"))
print("REPORT.TXT".endswith(".txt"))
Консоль
True
False
True
False

Так можно проверить написание имени файла, но нельзя определить его настоящее содержимое. Для сравнения расширений без учёта регистра сначала приведите имя к нижнему регистру. Цепочки методов разберём ближе к концу урока.

06 / Поиск позиции и подсчёт вхождений

Когда нужен индекс найденного фрагмента, используйте find() или index(). Оба ищут первое вхождение слева и возвращают индекс его начала, считая от нуля. Различие проявляется, если фрагмента нет.

Поиск первого вхождения
text = "banana"
print(text.find("na"))
print(text.index("na"))
print(text.find("ba"))
print(text.find("x"))
Консоль
2
2
0
-1
Если фрагмент отсутствует
ВызовПоведение
"banana".find("x")Возвращает число -1. Программа продолжает работу.
"banana".index("x")Вызывает ValueError. Без обработки ошибки выполнение программы остановится.
"banana".count("x")Возвращает 0: вхождений нет.

Попробуйте "banana".index("x") отдельно в консоли. ValueError сообщает, что значение аргумента не позволило выполнить поиск с обязательным результатом. Обработку исключений изучим позже. Пока выбирайте find(), если отсутствие фрагмента ожидаемо.

Важно

Почему нельзя проверять просто if text.find(...)

В условии число 0 считается ложным, а -1 истинным. Поэтому найденный в самом начале фрагмент не запустит ветку if, а отсутствующий запустит. Результат find() является индексом, а не готовым ответом «найдено».

Проверка, которая даёт обратный смысл
text = "Python"
if text.find("Py"):
    print("Found at the start")
if text.find("Java"):
    print("This branch runs, but Java is absent")
Консоль
This branch runs, but Java is absent

Правильнее будет проверять на -1. Если поиск не вернул -1, значит элемент найден.

Явно проверяем результат поиска
text = "Python"
position = text.find("Py")
if position != -1:
    print("Found at index", position)
if "Py" in text:
    print("Fragment exists")
Консоль
Found at index 0
Fragment exists

Если нужен только факт наличия, выбирайте in. Если дальше потребуется позиция, сохраните результат find() и сравните его с -1. Не используйте -1 как индекс найденного фрагмента: text[-1] просто прочитает последний символ строки.

Подсчёт без перекрытий
print("banana".count("a"))
print("banana".count("ana"))
print("aaaa".count("aa"))
print("banana".count("x"))
Консоль
3
1
2
0

Метод count() считает неперекрывающиеся вхождения. В banana фрагмент ana встречается с индексов 1 и 3, но эти фрагменты используют общую букву a. После учёта первого фрагмента поиск продолжается за ним, поэтому результат равен 1. В aaaa помещаются два отдельных фрагмента aa.

07 / Замена и удаление фрагментов

replace(old, new) возвращает строку, в которой все вхождения old заменены на new. Третий аргумент ограничивает число замен, начиная слева. Метод учитывает регистр. Если old не найден, содержимое результата совпадёт с исходным текстом.

Все замены или только первые
text = "red red red"
print(text.replace("red", "blue"))
print(text.replace("red", "blue", 2))
print(text.replace("red", "blue", 0))
print(text)
Консоль
blue blue blue
blue blue red
red red red
red red red

Чтобы удалить найденный фрагмент, замените его на пустую строку "". Например, "12-34-56".replace("-", "") вернёт "123456". Удаление затронет все вхождения, включая середину строки.

Если нужно удалить только конкретное начало, используйте removeprefix(), только конкретный конец, removesuffix(). Они доступны с Python 3.9. При отсутствии нужного фрагмента содержимое остаётся прежним. За один вызов удаляется один совпавший префикс или суффикс.

Удаление точного фрагмента
print("unhappy".removeprefix("un"))
print("sunny".removeprefix("un"))
print("report.txt".removesuffix(".txt"))
print("report.txt.backup".removesuffix(".txt"))
print("prepretext".removeprefix("pre"))
Консоль
happy
sunny
report
report.txt.backup
pretext
Важно

Не удаляйте расширение набором символов

strip() и removesuffix() решают разные задачи
filename = "text.txt"
print(filename.strip(".txt"))
print(filename.removesuffix(".txt"))
Консоль
e
text

strip(".txt") удаляет с обоих краёв любые точки, буквы t и x, пока не дойдёт до другого символа. Поэтому от text.txt остаётся только e. removesuffix(".txt") удаляет точное расширение один раз справа.

08 / Проверка содержимого строки

Методы этой группы возвращают bool и проверяют всю строку. Им не передают аргументы. Для перечисленных ниже методов нужны хотя бы один символ и выполнение условия для каждого символа. Поэтому пустая строка даёт False во всех этих проверках.

09 / Разбиение строки на части

Метод split() возвращает список строк. Список хранит несколько элементов в определённом порядке. В записи ["red", "blue"] квадратные скобки ограничивают список, а запятая разделяет элементы. Здесь два элемента, и каждый из них является целой строкой.

Список, индексы и знакомый цикл
text = "red green blue"
parts = text.split()
print(parts)
print(len(parts))
print(parts[0])
print(parts[-1])
for part in parts:
    print(part)
Консоль
['red', 'green', 'blue']
3
red
blue
red
green
blue

Индексы списка начинаются с нуля. parts[0] возвращает первое слово, а text[0] вернуло бы первую букву исходной строки. В цикле part по очереди получает целый элемент списка. Обращение к отсутствующему индексу списка также вызывает IndexError.

Без аргументов split() считает разделителем последовательность пробельных символов. Несколько пробелов подряд работают как один разделитель. Пробелы по краям не создают пустых элементов. Табуляция и перевод строки тоже разделяют текст.

split() и split(" ")
text = " red  blue "
print(text.split())
print(text.split(" "))
print("red\tblue\ngreen".split())
print("".split())
print("".split(" "))
Консоль
['red', 'blue']
['', 'red', '', 'blue', '']
['red', 'blue', 'green']
[]
['']

Явный разделитель " " обозначает один конкретный пробел. Между соседними разделителями и по краям появляются пустые строки. Табуляция при таком вызове не является разделителем. Пустой список [] и список с одной пустой строкой [""] отличаются: у первого длина 0, у второго 1.

Разделитель и ограничение разбиений
print("red,green,,blue".split(","))
print("red<>green<>blue".split("<>"))
print("name=Alex=admin".split("=", 1))
print("red green blue".split(maxsplit=1))
Консоль
['red', 'green', '', 'blue']
['red', 'green', 'blue']
['name', 'Alex=admin']
['red', 'green blue']

maxsplit ограничивает число разбиений, а не количество элементов. После одного разбиения остаток строки попадает в последний элемент целиком. В split("=", 1) ограничение передано вторым аргументом. Запись split(maxsplit=1) задаёт его по имени и сохраняет обычное разбиение по пробельным символам.

Важно

Пустой разделитель недопустим

text.split("") вызывает ValueError. Если нужно пройти по отдельным символам строки, используйте уже знакомый for char in text. Если разделитель вообще не встретился, split() с явным разделителем вернёт список из исходной строки.

10 / Сборка строки из частей

separator.join(parts) соединяет строки из parts, вставляя между ними separator. Метод вызывают у строки-разделителя. Список частей передают внутрь скобок. Разделитель добавляется только между элементами, без добавления в начало и конец.

Разные разделители
parts = ["red", "green", "blue"]
print(", ".join(parts))
print("-".join(parts))
print("".join(parts))
print("-".join(["red"]))
print("[" + "-".join([]) + "]")
Консоль
red, green, blue
red-green-blue
redgreenblue
red
[]

Пустой разделитель допустим для join(): части просто склеиваются. Для пустого списка результатом будет пустая строка. В последней строке вывода скобки добавлены вручную, чтобы её показать.

Важно

Все элементы должны быть строками

"-".join(["item", 7]) вызывает TypeError: число 7 не является строкой. join() не вызывает str() за вас. Нужна запись "-".join(["item", str(7)]), которая даст "item-7". Запись parts.join("-") также неверна: в этой задаче join() вызывается у разделителя, а не у списка.

Разбить и собрать с другим разделителем
text = "red,green,blue"
parts = text.split(",")
result = " / ".join(parts)
print(parts)
print(result)
Консоль
['red', 'green', 'blue']
red / green / blue

split() превратил одну строку в список частей, затем join() создал из этих частей строку с другим разделителем. Эти операции не всегда точно восстанавливают исходный текст: split() без аргументов теряет сведения о количестве и виде пробелов.

11 / Несколько методов в одной задаче

Пользователь может ввести команду с лишними пробелами и в разном регистре. Нормализация приводит допустимые варианты ввода к единому виду. Сначала отделим этапы обработки, чтобы было видно назначение каждого шага.

Сначала промежуточные переменные
raw_command = "  HeLP  "
trimmed_command = raw_command.strip()
command = trimmed_command.lower()
print("[" + raw_command + "]")
print("[" + trimmed_command + "]")
print(command)
Консоль
[  HeLP  ]
[HeLP]
help

Первый шаг удаляет пробелы по краям, второй меняет регистр. Оба метода возвращают строки, поэтому второй можно вызвать прямо у результата первого. Так получается цепочка вызовов, которая читается слева направо.

Та же обработка коротко
raw_command = "  HeLP  "
command = raw_command.strip().lower()
print(command)
Консоль
help

Подключим input() и выберем действие через if. В показанном запуске пользователь ввёл два пробела, HeLP и ещё два пробела. В строке консоли после приглашения отображён этот ввод.

Нормализация введённой команды
raw_command = input("Command: ")
command = raw_command.strip().lower()
if command == "help":
    print("Available commands: help, exit")
elif command == "exit":
    print("Goodbye!")
else:
    print("Unknown command")
Консоль
Command:   HeLP  
Available commands: help, exit

Сначала input() возвращает строку. Затем strip() убирает края, lower() приводит буквы к нижнему регистру, и только после этого if сравнивает команду с ожидаемым текстом. Попробуйте ввод "EXIT", "unknown" и строку из пробелов. Последняя станет пустой и попадёт в else. Пробел внутри "he lp" не исчезнет: такая команда тоже неизвестна.

Совет

Следите за типом результата

Цепочка работает, пока следующий метод подходит результату предыдущего. text.strip().lower() допустимо: strip() возвращает строку. Но text.isdigit().lower() вызовет AttributeError, потому что isdigit() возвращает bool, у которого нет строкового метода lower(). Результат split() является списком, поэтому join() вызывают отдельно у разделителя.

Убираем лишние пробелы между словами
text = "  red   green\tblue  "
parts = text.split()
normalized = " ".join(parts)
print(normalized)
print(" ".join(text.split()))
Консоль
red green blue
red green blue

Здесь split() выделяет слова, а join() вставляет между ними ровно один пробел. Используйте такую обработку, только если количество исходных пробелов не нужно сохранять. Когда цепочка становится трудной для чтения, вернитесь к промежуточным переменным.
