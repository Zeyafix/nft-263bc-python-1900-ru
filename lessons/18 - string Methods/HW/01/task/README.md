# Задание 01. Положительные индексы

Запросите текст длиной не менее пяти символов. Получите первый, третий и пятый символы с помощью положительных индексов и индекса ноль. Выведите их с подписями `First`, `Third`, `Fifth` в квадратных скобках.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text (at least five characters): ABCDE

First: [A]
Third: [C]
Fifth: [E]
```
