# Задание 02. Отрицательные индексы

Запросите текст длиной не менее трёх символов. Через отрицательные индексы получите последний, предпоследний и третий с конца символы. Подписи: `Last`, `Previous`, `Third from end`; символы заключите в квадратные скобки.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text (at least three characters): ABC

Last: [C]
Previous: [B]
Third from end: [A]
```
