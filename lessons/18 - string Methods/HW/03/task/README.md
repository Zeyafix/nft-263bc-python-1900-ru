# Задание 03. Границы индекса

Запросите текст, затем индекс без дробной части, например `0`, `3` или `-2`. Текст может быть пустым. Если такой индекс существует, выведите `Character: [символ]`, иначе — `Result: out of range`. Индексы от начала считаются с нуля, от конца — с -1. Программа не должна завершаться с ошибкой из-за отсутствующей позиции.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: Cat
Index: 0

Character: [C]
```
