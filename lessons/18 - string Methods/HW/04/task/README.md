# Задание 04. Срез середины

Запросите текст и с помощью среза получите его без первого и последнего символов. Для текста короче трёх символов результат пустой. Выведите `Middle: [результат]`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: Python

Middle: [ytho]
```
