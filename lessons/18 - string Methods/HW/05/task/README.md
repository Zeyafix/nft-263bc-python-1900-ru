# Задание 05. Срезы с шагом

Запросите текст. С помощью срезов с шагом отдельно выведите символы на чётных индексах (`Even`) и нечётных (`Odd`), сохраняя порядок. Индексы начинаются с нуля. Результаты заключите в квадратные скобки. Пустой текст допустим.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: abcdef

Even: [ace]
Odd: [bdf]
```
