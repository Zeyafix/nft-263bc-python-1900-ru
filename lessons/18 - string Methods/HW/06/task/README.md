# Задание 06. Обратный срез

Запросите текст. С помощью обратных срезов выведите весь текст с конца к началу (`Reverse`), затем каждый второй символ с конца, начиная с последнего (`Every second`). Оба результата заключите в квадратные скобки. Пустой текст допустим.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: abcdef

Reverse: [fedcba]
Every second: [fdb]
```
