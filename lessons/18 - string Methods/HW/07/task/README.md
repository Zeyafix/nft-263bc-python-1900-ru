# Задание 07. Проход по символам

Запросите текст. Пройдите циклом по его символам и подсчитайте английские гласные `a`, `e`, `i`, `o`, `u` независимо от регистра. Буква `y` и остальные символы не считаются гласными. Выведите `Vowels: количество`. Пустой текст допустим.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: A quiet DAY

Vowels: 5
```
