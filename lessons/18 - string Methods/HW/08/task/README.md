# Задание 08. Проход по индексам

Запросите текст. Пройдите циклом по индексам и найдите позиции символов, равных соседнему слева с учётом регистра. Выводите индекс правого символа каждой пары, начиная с нуля, по возрастанию: `Positions: 1 2`. Если совпадений нет — `Positions: none`. Пустой текст допустим; у первого символа нет соседа слева.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: bookkeeper

Positions: 2 4 6
```
