# Задание 09. Оператор in

Запросите текст, затем фрагмент. Через оператор `in` проверьте наличие фрагмента: сначала с учётом регистра, затем без него. Выведите `Sensitive: True/False` и `Insensitive: True/False`. Используйте только английские буквы, цифры, пробелы и знаки ASCII. Пустые текст и фрагмент допустимы; пустой фрагмент присутствует в любом тексте.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: Hello World

Fragment: WORLD
Sensitive: False
Insensitive: True
```
