# Задание 10. Все индексы символа

Запросите текст, затем ровно один искомый символ. Найдите все его позиции с учётом регистра, включая первое и последнее места в тексте. Индексы начинаются с нуля. Выведите их по возрастанию через пробел с подписью `Positions`; если совпадений нет — `Positions: none`. Пустой текст допустим.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: abaca
Character: a

Positions: 0 2 4
```
