# Задание 11. Все индексы подстроки

Запросите текст, затем непустой фрагмент. Найдите начала всех вхождений с учётом регистра, включая перекрывающиеся: у `ana` в `banana` это 1 и 3. Индексы начинаются с нуля. Выведите позиции по возрастанию через пробел с подписью `Positions`; без совпадений — `Positions: none`. Текст может быть пустым, а фрагмент — длиннее текста.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: banana
Nonempty fragment: ana

Positions: 1 3
```
