# Задание 12. Изменение регистра

Запросите текст из английских букв, цифр, пробелов и знаков ASCII. Примените к исходному тексту отдельно `lower()`, `upper()`, `capitalize()` и `title()`. Выведите результаты в квадратных скобках с подписями `Lower`, `Upper`, `Capitalize`, `Title`. Пустой текст допустим. Сравните строки результата: начало всего текста и начало каждого слова обрабатываются по-разному.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: hELLO wORLD

Lower: [hello world]
Upper: [HELLO WORLD]
Capitalize: [Hello world]
Title: [Hello World]
```
