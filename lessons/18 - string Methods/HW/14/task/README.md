# Задание 14. Начало и конец

Запросите текст, префикс и суффикс в этом порядке. Проверьте начало через `startswith()`, конец через `endswith()`, учитывая регистр. Выведите `Prefix: True/False` и `Suffix: True/False`. Все три записи могут быть пустыми: пустая граница подходит к любой строке.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: report.txt
Prefix: report
Suffix: .txt

Prefix: True
Suffix: True
```
