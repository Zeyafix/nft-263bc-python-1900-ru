# Задание 15. Поиск позиции

Запросите текст и непустой фрагмент. Сначала выведите результат `find()` с подписью `Find`, затем результат `index()` с подписью `Index`. Используйте исходный регистр. Если фрагмент отсутствует, первая строка должна показать -1, а вызов `index()` должен завершить этот запуск ошибкой `ValueError`; строка `Index` тогда не выводится. Перехватывать ошибку не требуется.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: banana
Nonempty fragment: ban

Find: 0
Index: 0
```

Пример отдельного запуска без совпадения (служебные строки traceback сокращены):

```text
Text: banana
Nonempty fragment: BAN

Find: -1
ValueError: substring not found
```
