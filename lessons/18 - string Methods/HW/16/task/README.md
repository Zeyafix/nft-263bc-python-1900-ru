# Задание 16. Подсчёт вхождений

Запросите текст и непустой фрагмент. Выведите `Count` — результат `count()`, затем `Positions` — все начальные индексы, включая перекрытия, и `All matches` — число этих позиций. Позиции считаются с нуля и выводятся по возрастанию через пробел; без совпадений используйте `none`. Сравните результаты на `aaaa` и `aa`: неперекрывающихся совпадений 2, а всех позиций 3. Поиск учитывает регистр. Пустой текст допустим.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: aaaa
Nonempty fragment: aa

Count: 2
Positions: 0 1 2
All matches: 3
```
