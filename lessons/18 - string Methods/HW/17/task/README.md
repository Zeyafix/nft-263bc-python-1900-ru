# Задание 17. Замена фрагментов

Запросите текст, непустой старый фрагмент и новый фрагмент, который может быть пустым. Через `replace()` получите три независимых результата из исходного текста: полную замену (`All`), замену только первых двух вхождений (`First two`) и удаление всех вхождений старого фрагмента (`Removed`). Результаты заключите в квадратные скобки. Поиск учитывает регистр; замены идут слева направо без перекрытий. Пустой текст допустим.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: red red red
Nonempty old fragment: red
New fragment: blue

All: [blue blue blue]
First two: [blue blue red]
Removed: [  ]
```
