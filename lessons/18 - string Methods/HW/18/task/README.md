# Задание 18. Удаление точных границ

Запросите текст, непустой префикс и непустой суффикс. Сначала примените `removeprefix()`, затем к результату — `removesuffix()`. Удалите каждую точную границу не более одного раза; регистр важен. Такие же фрагменты внутри оставьте. Выведите `Result: [результат]`. Отсутствующая граница не меняет текст; пустой текст допустим.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: pre_mid_pre_tail_end
Nonempty prefix: pre_
Nonempty suffix: _end

Result: [mid_pre_tail]
```
