# Задание 19. Проверки содержимого

Запросите текст. Выведите результаты `isalpha()`, `isdecimal()`, `isdigit()`, `isalnum()` и `isspace()` с подписями `Alpha`, `Decimal`, `Digit`, `Alnum`, `Space`. Для каждой проверки выводите `True` или `False`. Текст может быть пустым.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: Hello

Alpha: True
Decimal: False
Digit: False
Alnum: True
Space: False
```
