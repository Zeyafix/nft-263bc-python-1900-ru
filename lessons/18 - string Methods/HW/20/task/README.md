# Задание 20. Разбиение и сборка

Запросите текст одной строкой. Сравните `split()` и `split(" ")`, затем примените `split(maxsplit=1)` и соберите части первого результата через `join()` с разделителем `-`. Выведите первые три результата как последовательности в квадратных скобках с кавычками вокруг каждой части, как в примере; подписи `Words`, `Spaces`, `Limited`. Для сборки используйте `Joined: [результат]`. Содержимое частей и пустые части нужно сохранить. Текст может быть пустым, содержать пробелы и табуляции.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text:   red  blue green  

Words: ['red', 'blue', 'green']
Spaces: ['', '', 'red', '', 'blue', 'green', '', '']
Limited: ['red', 'blue green  ']
Joined: [red-blue-green]
```
