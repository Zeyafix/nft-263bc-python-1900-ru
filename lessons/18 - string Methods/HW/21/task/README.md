# Задание 21. Маска карты

Запросите учебный номер карты: ровно 16 цифр от 0 до 9 без разделителей. Оставьте видимыми последние четыре цифры, а каждую из остальных замените звёздочкой. Выведите `Masked: результат`. Ведущие нули должны сохраниться. Используйте вымышленные номера, как в примере.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Fictional card number (16 digits): 1234567812345678

Masked: ************5678
```
