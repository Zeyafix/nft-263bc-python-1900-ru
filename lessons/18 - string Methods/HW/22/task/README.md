# Задание 22. Краткое уведомление

Запросите сообщение, затем предельную длину без дробной части, не меньше 3. Если сообщение длиннее предела, сократите его начало так, чтобы вместе с тремя точками `...` длина результата равнялась пределу. Сообщение, которое уже помещается, сохраните целиком. Пробелы тоже занимают место; не удаляйте их. Пустое сообщение допустимо. Выведите `Result: [результат]`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Message: Hello world
Maximum length (at least 3): 8

Result: [Hello...]
```
