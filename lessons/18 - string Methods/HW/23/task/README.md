# Задание 23. Проверка палиндрома

Запросите английскую фразу, состоящую только из букв A–Z, a–z и обычных пробелов. Определите, одинаково ли она читается в обе стороны, игнорируя пробелы и регистр. Выведите `Palindrome: True` или `Palindrome: False`. Пустая фраза и фраза только из пробелов считаются палиндромами.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
English phrase: Never odd or even

Palindrome: True
```
