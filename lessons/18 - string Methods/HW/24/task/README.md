# Задание 24. Инициалы автора

Запросите имя и фамилию одной строкой: ровно два непустых слова из английских букв. Между словами и по краям может быть несколько обычных пробелов. Получите первые буквы имени и фамилии в верхнем регистре. Формат: `Initials: A.B.` — без пробела между инициалами.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
First name and last name: ada lovelace

Initials: A.L.
```
