# Задание 25. Адрес статьи

Запросите английский заголовок из букв A–Z, a–z и обычных пробелов. Сделайте все буквы строчными, а слова соедините одиночными дефисами. Дефисов по краям быть не должно. Пустой заголовок и одни пробелы дают пустой результат. Выведите `Slug: [результат]`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
English title: Learn Python Today

Slug: [learn-python-today]
```
