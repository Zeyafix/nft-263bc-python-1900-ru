# Задание 26. Нормализация телефона

Запросите телефонную запись. Она содержит хотя бы одну цифру от 0 до 9, а также может содержать обычные пробелы, дефисы, круглые скобки и один плюс. Если плюс есть, он находится в самом начале введённой записи. Удалите пробелы, дефисы и скобки, сохранив все цифры в прежнем порядке и начальный плюс. Проверять длину номера не нужно. Выведите `Phone: результат`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Phone number: +1 (202) 555-0100

Phone: +12025550100
```
