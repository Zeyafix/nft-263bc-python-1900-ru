# Задание 27. Проверка промокода

Запросите промокод. Подходит только запись из точного префикса `SALE-` и ровно четырёх цифр ASCII от 0 до 9, например `SALE-2026`. Регистр, длина и отсутствие пробелов обязательны. Цифры других алфавитов и специальные цифровые символы не подходят. Выведите `Valid: True` или `Valid: False`. Пустой ввод не подходит.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Promo code: SALE-2026

Valid: True
```
