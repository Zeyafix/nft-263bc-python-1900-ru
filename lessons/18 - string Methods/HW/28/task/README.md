# Задание 28. Имя файла без расширения

Запросите простое имя файла без пути. В нём есть хотя бы одна точка, а части до и после последней точки непустые. Отделите расширение после последней точки. Выведите имя без этого расширения как `Name: [имя]`, а расширение без точки как `Extension: [расширение]`. Более ранние точки и регистр сохраните.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
File name with extension: notes.txt

Name: [notes]
Extension: [txt]
```
