# Задание 29. Разбор адреса почты

Запросите запись адреса почты без пробелов: ровно один `@`, а с обеих сторон есть хотя бы один символ. Выделите имя пользователя и домен. Регистр имени пользователя сохраните, домен приведите к нижнему регистру. Выведите `User: имя` и `Domain: домен`. Полную проверку правил электронной почты выполнять не нужно; в записи используются символы ASCII.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Email address: Alice.Smith@EXAMPLE.COM

User: Alice.Smith
Domain: example.com
```
