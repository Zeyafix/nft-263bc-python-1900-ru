# Задание 30. Поиск упоминаний

Запросите сообщение. В этой задаче каждый символ `@` считается отдельным упоминанием, даже в почтовом адресе или рядом с другим `@`. Выведите все его индексы с нуля по возрастанию через пробел с подписью `Positions`, затем общее число с подписью `Mentions`. Без совпадений выводите `Positions: none`. Пустое сообщение допустимо.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Message: @Ann hi @Bob@

Positions: 0 8 12
Mentions: 3
```
