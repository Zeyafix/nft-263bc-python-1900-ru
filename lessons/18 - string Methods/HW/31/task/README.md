# Задание 31. Поиск мотива

Запросите последовательность из заглавных букв `A`, `C`, `G`, `T`, затем непустой мотив из этих же букв. Найдите все начала мотива, включая перекрытия. Индексы начинаются с нуля. Выведите их по возрастанию через пробел с подписью `Positions`; если совпадений нет — `Positions: none`. Последовательность может быть пустой; мотив может быть длиннее неё.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Sequence (A, C, G, T): ATATAT
Nonempty motif: ATAT

Positions: 0 2
```
