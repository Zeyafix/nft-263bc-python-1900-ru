# Задание 32. Настройка приложения

Запросите запись настройки. Первый знак `=` отделяет непустое имя от значения. Остальные знаки равенства относятся к значению; оно может быть пустым. Выведите `Name: [имя]` и `Value: [значение]`, сохранив регистр и все пробелы. В записи гарантирован хотя бы один знак `=`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Setting (name=value): theme=dark=custom

Name: [theme]
Value: [dark=custom]
```
