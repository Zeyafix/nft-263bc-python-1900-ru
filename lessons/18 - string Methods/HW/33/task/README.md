# Задание 33. Очистка заметки

Запросите количество строк заметки от 0 до 20, затем сами строки по порядку, включая пустые. Каждая введённая строка — отдельная строка заметки. Между словами могут повторяться обычные пробелы, табуляции и переводы строк. Получите одну строку: между словами ровно один обычный пробел, по краям пробелов нет. Порядок слов и регистр сохраните. Пустая заметка даёт пустой результат. Выведите `Note: [результат]`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Number of note lines (0-20): 3
Note line 1:   Buy   milk
Note line 2: 
Note line 3: and bread  

Note: [Buy milk and bread]
```
