# Задание 34. Редактирование объявления

Запросите текст объявления, старое непустое название товара, затем новое непустое название. Замените только первое вхождение старого названия новым. Поиск учитывает регистр и допускает совпадение внутри слова. Остальные упоминания и пробелы сохраняются. Если совпадений нет, оставьте объявление целиком. Пустое объявление допустимо. Выведите `Announcement: [результат]`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Announcement: Tea sale! Tea today.
Nonempty old product name: Tea
Nonempty new product name: Coffee

Announcement: [Coffee sale! Tea today.]
```
