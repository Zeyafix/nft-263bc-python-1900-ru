# Задание 35. Маска кода заказа

Запросите непустой код заказа из английских букв, цифр от 0 до 9 и дефисов, например `AB-123456-CD`. Замените каждую цифру звёздочкой; буквы, их регистр и дефисы оставьте на местах. Количество и расположение цифр могут отличаться от примера. Выведите `Masked: результат`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Order code: AB-123456-CD

Masked: AB-******-CD
```
