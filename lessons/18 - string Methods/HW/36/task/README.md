# Задание 36. Проверка логина

Запросите логин. Его длина должна быть от 4 до 16 символов включительно. Первый символ — английская буква A–Z или a–z. Остальные — английские буквы, цифры от 0 до 9 или подчёркивание. Пробелы, дефисы, буквы других алфавитов и специальные цифровые символы запрещены. Ничего не исправляйте автоматически. Выведите `Valid: True` или `Valid: False`. Пустой ввод не подходит.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Login: A_09

Valid: True
```
