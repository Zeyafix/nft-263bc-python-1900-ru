# Задание 37. Статистика отзыва

Запросите отзыв одной строкой. Подсчитайте слова, английские гласные и знаки окончания предложений. Слово — любая непустая часть между пробелами или табуляциями; знаки препинания внутри такой части отдельно словом не становятся. Гласные — `a`, `e`, `i`, `o`, `u` в любом регистре. Каждый символ `.`, `!`, `?` считается отдельно: `?!` даёт 2. Выведите `Words`, `Vowels`, `End marks` с соответствующими количествами. Пустой отзыв допустим.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Review: Great app! Easy to use.

Words: 5
Vowels: 8
End marks: 2
```
