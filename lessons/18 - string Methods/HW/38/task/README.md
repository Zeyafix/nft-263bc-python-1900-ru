# Задание 38. Повторы при наборе

Запросите текст из английских букв, цифр, пробелов и знаков ASCII. Найдите все позиции, где английская буква совпадает с соседней слева без учёта регистра. Выводите индекс правой буквы пары, начиная с нуля. Повторяющиеся пробелы, цифры и знаки не считаются. Индексы должны относиться к исходному тексту. Выведите их по возрастанию через пробел с подписью `Positions`; если таких букв нет — `Positions: none`. Пустой текст допустим.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Text: aAAbB

Positions: 1 2 4
```
