# Задание 39. Очистка метки экспорта

Запросите метку экспорта. Удалите ровно один точный префикс `draft_`, если он есть, затем ровно один точный суффикс `_backup`, если он есть у полученного результата. Вхождения внутри и повторные границы сохраните. Регистр важен; частичные совпадения не удаляются. Пустая метка допустима. Выведите `Label: [результат]`.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Export label: draft_report_backup

Label: [report]
```
