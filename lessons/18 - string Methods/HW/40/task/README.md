# Задание 40. Разбор строки журнала

Запросите строку журнала вида `2026-09-25|ERROR|Connection failed`. Первые два знака `|` отделяют дату и уровень от сообщения. Дата записана как YYYY-MM-DD, уровень непустой; проверять календарную корректность не нужно. Сообщение может быть пустым и содержать дополнительные `|`. Выведите `Date: дата` и `Level: уровень`. Только если уровень точно равен `ERROR`, выведите ещё `Message: [сообщение]`. Сохраните регистр и пробелы; для любого другого уровня строки `Message` быть не должно.

## Пример диалога

После подсказок показаны ответы пользователя.

```text
Log record (date|level|message): 2026-09-25|ERROR|Connection failed

Date: 2026-09-25
Level: ERROR
Message: [Connection failed]
```
