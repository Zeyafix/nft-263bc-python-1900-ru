# Задание 1. Крайние символы

Прочитайте непустую строку. Получите её первый и последний символы сначала неотрицательными индексами, затем отрицательными. Выведите четыре строки в таком порядке: первый символ с начала, последний с начала, первый с конца, последний с конца. Для строки из одного символа все четыре результата совпадут.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
Python

P
n
P
n
```
