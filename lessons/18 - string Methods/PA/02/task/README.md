# Задание 2. Символ по индексу

Прочитайте непустую строку, затем допустимый индекс при отсчёте с начала: от 0 до длины строки минус один. Выведите выбранный символ, а на следующей строке — отрицательный индекс того же символа. Последний символ имеет индекс -1.

## Пример

Первые две строки — ввод, далее — вывод программы.

```text
Python
2

t
-4
```
