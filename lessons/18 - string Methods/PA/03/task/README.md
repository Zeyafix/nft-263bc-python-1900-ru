# Задание 3. Начало и конец строки

Прочитайте строку и с помощью срезов выведите первые три символа, затем последние три — каждый результат на отдельной строке. Если символов меньше трёх, каждый результат содержит всю строку. Пустая строка допустима: в этом случае выведите две пустые строки.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
Python

Pyt
hon
```
