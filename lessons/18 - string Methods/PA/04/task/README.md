# Задание 4. Границы среза

Прочитайте строку, затем начало и конец фрагмента на отдельных строках. Границы — от 0 до длины строки включительно; начало не больше конца. Срезом выделите символы от начала включительно до конца не включительно и выведите результат в квадратных скобках. На следующей строке так же выведите срез от того же начала до границы, равной длине строки плюс 10. Вторая операция показывает, что происходит с концом среза за пределами строки.

## Пример

Первые три строки — ввод, далее — вывод программы.

```text
Python
1
4

[yth]
[ython]
```
