# Задание 5. Каждый третий символ

Прочитайте строку. Срезом с шагом 3 получите символы, начиная со второго символа: с индексами 1, 4, 7 и далее. Выведите результат одной строкой. Если второго символа нет, выведите пустую строку.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
abcdefghij

beh
```
