# Задание 6. Разворот строки

Прочитайте строку. Выведите исходный текст, затем на следующей строке — все его символы в обратном порядке. Для разворота используйте срез с отрицательным шагом. Пробелы сохраняются; пустая строка допустима.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
Python

Python
nohtyP
```
