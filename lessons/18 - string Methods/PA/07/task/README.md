# Задание 7. Проход по символам

Прочитайте строку. Пройдите циклом непосредственно по её символам и выведите каждый на отдельной строке в квадратных скобках. Во время этого прохода подсчитайте обычные пробелы и после всех символов выведите `Spaces: N`, где `N` — их количество. Для пустого текста выведите только `Spaces: 0`.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
A B

[A]
[ ]
[B]
Spaces: 1
```
