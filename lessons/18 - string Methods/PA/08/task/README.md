# Задание 8. Проход по индексам

Прочитайте строку. Пройдите циклом по её индексам от 0 до последнего и на каждой строке выведите пару в формате `0: [P]`: индекс, двоеточие, пробел и символ в квадратных скобках. Получайте символ по текущему индексу. Пустой текст не должен давать ни одной строки результата.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
Cat

0: [C]
1: [a]
2: [t]
```
