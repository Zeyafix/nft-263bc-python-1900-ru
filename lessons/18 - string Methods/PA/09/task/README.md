# Задание 9. Принадлежность

Прочитайте строку, затем один искомый символ и непустой фрагмент на отдельных строках. С учётом регистра выведите четыре результата `True` или `False`: есть ли символ, отсутствует ли символ, есть ли весь фрагмент подряд, отсутствует ли весь фрагмент. Каждый результат выведите отдельно. Для положительных проверок используйте `in`, для отрицательных — `not in`.

## Пример

Первые три строки — ввод, далее — вывод программы.

```text
Python
P
tho

True
False
True
False
```
