# Задание 10. Поиск всех позиций

Прочитайте непустое английское слово, затем одну английскую букву. Выведите все индексы этой буквы по возрастанию, каждый на отдельной строке. Отсчёт начинается с 0, регистр учитывается. Если совпадений нет, выведите одну строку `Not found`.

## Пример

Первые две строки — ввод, далее — вывод программы.

```text
banana
a

1
3
5
```
