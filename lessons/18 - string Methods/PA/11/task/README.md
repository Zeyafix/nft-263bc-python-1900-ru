# Задание 11. Поиск всех начал

Прочитайте строку, затем непустую подстроку. Выведите индексы начала всех её вхождений по возрастанию, каждый отдельно. Учитывайте регистр и перекрытия: для `aa` в `aaaa` нужны 0, 1 и 2. При отсутствии совпадений выведите только `Not found`. Исходная строка может быть пустой.

## Пример

Первые две строки — ввод, далее — вывод программы.

```text
aaaa
aa

0
1
2
```
