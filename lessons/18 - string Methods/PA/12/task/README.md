# Задание 12. Регистр букв

Прочитайте английскую фразу. На четырёх отдельных строках выведите результаты `lower()`, `upper()`, `capitalize()` и `title()` именно в этом порядке. Каждый метод применяйте к исходной фразе. Пустой текст и пробелы по краям допустимы.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
hELLO wORLD

hello world
HELLO WORLD
Hello world
Hello World
```
