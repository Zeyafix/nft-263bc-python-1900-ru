# Задание 13. Пробелы по краям

Прочитайте строку. На трёх отдельных строках покажите результаты `strip()`, `lstrip()` и `rstrip()` без аргументов в этом порядке. Каждый метод применяйте к исходному тексту; каждый результат заключайте в квадратные скобки, чтобы было видно оставшиеся пробельные символы. Внутренние пробелы сохраняются. Пустая строка допустима.

## Пример

Первая строка — ввод, далее — вывод программы. Во вводимой строке по два пробела в начале, между словами и в конце.

```text
  red  blue  
  
[red  blue]
[red  blue  ]
[  red  blue]
```
