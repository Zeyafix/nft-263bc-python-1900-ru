# Задание 14. Префикс и суффикс

Прочитайте строку, затем непустой предполагаемый префикс и непустой предполагаемый суффикс на отдельных строках. Выведите четыре результата `True` или `False`: префикс где-нибудь в строке через `in`, префикс в начале через `startswith()`, суффикс где-нибудь через `in`, суффикс в конце через `endswith()`. Регистр учитывается; каждый результат занимает отдельную строку.

## Пример

Первые три строки — ввод, далее — вывод программы.

```text
pre-file.txt
pre-
.txt

True
True
True
True
```
