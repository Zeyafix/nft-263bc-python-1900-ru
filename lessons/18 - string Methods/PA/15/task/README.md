# Задание 15. Первая позиция

Прочитайте строку, затем три непустых фрагмента на отдельных строках. Первый гарантированно начинается с индекса 0. Первое вхождение второго гарантированно начинается после индекса 0 и заканчивается раньше конца строки. Третий гарантированно отсутствует. Выведите результаты `find()` для этих трёх фрагментов, затем результат `index()` для второго. Каждый результат занимает отдельную строку. Поиск учитывает регистр.

## Пример

Первые четыре строки — ввод, далее — вывод программы.

```text
sun moon sky
sun
moon
star

0
4
-1
4
```
