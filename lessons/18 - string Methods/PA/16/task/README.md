# Задание 16. Число совпадений

Прочитайте строку, один символ и непустую подстроку — по одному значению на строке. С помощью `count()` выведите количество вхождений символа, затем подстроки. Учитывайте регистр. Для подстроки считаются неперекрывающиеся вхождения: в `aaaa` подстрока `aa` встречается по этому правилу дважды. Пустая исходная строка допустима.

## Пример

Первые три строки — ввод, далее — вывод программы.

```text
aaaa
a
aa

4
2
```
