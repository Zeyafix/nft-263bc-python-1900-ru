# Задание 17. Новая строка после замены

Прочитайте исходный текст, непустой заменяемый фрагмент и новый фрагмент на отдельных строках. Новый фрагмент может быть пустым. С помощью `replace()` выведите сначала результат замены всех вхождений, затем только первого вхождения. Оба результата получайте из исходного текста. На третьей строке выведите исходный текст без изменений. Регистр учитывается.

## Пример

Первые три строки — ввод, далее — вывод программы.

```text
red red red
red
blue

blue blue blue
blue red red
red red red
```
