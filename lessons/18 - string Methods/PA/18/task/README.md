# Задание 18. Точная граница и набор символов

Прочитайте строку, затем непустой фрагмент границы. На трёх отдельных строках выведите результаты `removeprefix()`, `removesuffix()` и `strip()` с этим фрагментом как аргументом. Каждый метод примените к исходной строке, результаты заключите в квадратные скобки. Первый и второй удаляют одно точное совпадение на соответствующем краю, третий работает с набором символов. Проверьте случай `ababXbaba` с фрагментом `ab`.

## Пример

Первые две строки — ввод, далее — вывод программы.

```text
ababXbaba
ab

[abXbaba]
[ababXbaba]
[X]
```
