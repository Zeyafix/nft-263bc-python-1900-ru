# Задание 19. Категории символов

Прочитайте количество проверяемых строк (от 1 до 10), затем столько же строк, каждая не длиннее 20 символов. Для каждой строки выведите на одной строке пять результатов через один пробел: `isalpha()`, `isdecimal()`, `isdigit()`, `isalnum()`, `isspace()`. Порядок сохраняйте. Пустая строка — полноценный проверяемый пример. Среди примеров проверьте английские буквы, цифры, смесь букв и цифр, пробелы, пустую строку и символ `²`: он считается цифрой для `isdigit()`, но не для `isdecimal()`.

## Пример

Сначала вводится количество строк — 6. Затем после каждой введённой строки показан результат её проверки. Четвёртая проверяемая строка содержит три пробела, пятая — пустая: для неё нужно только нажать Enter.

```text
6

Hello
True False False True False

2048
False True True True False

A2
False False False True False

   
False False False False True


False False False False False

²
False False True True False
```
