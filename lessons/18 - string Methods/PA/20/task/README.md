# Задание 20. Части строки

Прочитайте строку с разделителями-пробелами или табуляцией, затем отдельную запись с запятыми. С помощью `split()` и `join()` выведите четыре результата, каждый в квадратных скобках на своей строке. Сначала разделите первую строку по пробельным символам и соедините части через ` / `. Затем разделите вторую по каждой запятой и соедините через ` | `. Далее разделите вторую только по первой запятой и соедините через ` | `. Наконец разделите первую по пробельным символам не более одного раза и соедините через ` / `. При явном разделителе пустые части сохраняются; пробелы внутри частей второй записи не удаляйте. Обе строки могут быть пустыми.

## Пример

Первые две строки — ввод, далее — вывод программы. В первой вводимой строке два пробела в начале, между red и blue и в конце; между blue и green — один.

```text
  red  blue green  
A,,B,

[red / blue / green]
[A |  | B | ]
[A | ,B,]
[red / blue green  ]
```
