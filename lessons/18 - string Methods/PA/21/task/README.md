# Задание 21. Бейдж участника

Прочитайте имя участника, которое содержит хотя бы одну английскую букву. Уберите пробельные символы по краям и выведите имя в верхнем регистре одной строкой. Пробелы внутри имени сохраните.

## Пример

Первая строка — ввод, далее — вывод программы. Во вводимой строке по два пробела в начале и в конце.

```text
  Tom  

TOM
```
