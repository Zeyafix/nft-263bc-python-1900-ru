# Задание 22. Команда меню

Прочитайте одну команду меню. Распознайте `start`, `help` и `exit`, не учитывая регистр английских букв и пробельные символы по краям. Выведите соответственно `Starting`, `Help` или `Goodbye`. Для любой другой записи, включая пустую, выведите `Unknown command`. Пробелы внутри команды значимы. Обработайте ровно одну команду.

## Пример

Первая строка — ввод, далее — вывод программы. Во вводимой строке по два пробела в начале и в конце.

```text
  StArT  

Starting
```
