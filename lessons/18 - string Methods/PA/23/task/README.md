# Задание 23. Заголовок карточки

Прочитайте непустое английское название карточки. Оно состоит из английских букв и обычных пробелов и содержит хотя бы одно слово. Выведите название, в котором каждое слово начинается с заглавной буквы, а остальные буквы слова строчные. Количество и расположение пробелов сохраните.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
the GREAT adventure

The Great Adventure
```
