# Задание 24. Проверка фотографии

Прочитайте имя файла. Выведите `Photo`, если оно заканчивается на `.jpg` или `.png` без учёта регистра английских букв. Иначе выведите `Not a photo`. Проверяется только окончание имени; имя может быть пустым. Пробелы являются частью имени и не удаляются.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
Holiday.JPG

Photo
```
