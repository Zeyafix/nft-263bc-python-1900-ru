# Задание 25. Метка срочного сообщения

Прочитайте сообщение. Если оно начинается с точной метки `[URGENT]`, выведите `Urgent`, иначе `Regular`. На следующей строке выведите сообщение без одной начальной метки, если она была. Весь остальной текст, включая пробел сразу после метки, сохраните. Метка в середине, метка другого регистра и метка после начального пробела не считаются начальной. Пустое сообщение допустимо.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
[URGENT] Call Tom

Urgent
 Call Tom
```
