# Задание 26. Короткий код билета

Прочитайте код билета вида `FL-2048`: ровно две заглавные английские буквы, дефис и четыре цифры от 0 до 9. Корректный формат гарантирован. Выведите отдельно две буквы рейса, затем на следующей строке четыре цифры номера. Нули в начале номера сохраните.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
FL-2048

FL
2048
```
