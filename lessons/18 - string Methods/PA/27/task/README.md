# Задание 27. Ценник

Прочитайте запись цены. Если она заканчивается точным суффиксом ` USD`, удалите одно такое окончание. Выведите оставшийся текст без любых других изменений. Если окончания нет, выведите исходную запись. Регистр и каждый пробел значимы; пустая запись допустима.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
19.90 USD

19.90
```
