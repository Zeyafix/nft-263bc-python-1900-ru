# Задание 28. Поиск в описании товара

Прочитайте описание товара, затем непустой поисковый фрагмент. Буквы в данных английские; цифры, пробелы и знаки препинания также допустимы. Выведите `Found`, если весь фрагмент встречается подряд без учёта регистра, иначе `Not found`. Пробелы остаются значимыми. Описание может быть пустым.

## Пример

Первые две строки — ввод, далее — вывод программы.

```text
Wireless Mouse
LESS mo

Found
```
