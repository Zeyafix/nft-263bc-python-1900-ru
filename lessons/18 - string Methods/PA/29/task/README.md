# Задание 29. Счётчик реакций

Прочитайте сообщение. Выведите количество восклицательных знаков с подписью `Exclamations: N`, а на следующей строке количество вопросительных с подписью `Questions: N`. Каждый знак учитывается отдельно, в том числе в сочетании `?!`. Пустое сообщение допустимо.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
Wow!! Really?!

Exclamations: 3
Questions: 1
```
