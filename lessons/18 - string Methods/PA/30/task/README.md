# Задание 30. Ошибки в адресе страницы

Прочитайте запись адреса страницы. Выведите все индексы обычных пробелов по возрастанию, каждый на отдельной строке. Отсчёт начинается с 0. Если пробелов нет, выведите `No spaces`. Не исправляйте запись перед поиском: пробелы по краям тоже нужны. Здесь проверяются только обычные пробелы, а не корректность адреса в целом; пустая запись допустима.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
a b c

1
3
```
