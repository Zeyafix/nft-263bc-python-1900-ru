# Задание 31. Поиск метки на ленте

Прочитайте строку сигнала. Найдите все начала точной метки `SOS`, включая перекрытия. Выведите индексы по возрастанию, каждый на отдельной строке; отсчёт начинается с 0. Например, `SOSOS` содержит начала 0 и 2. Если меток нет, выведите `Not found`. Регистр учитывается, пустой сигнал допустим.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
SOSOS

0
2
```
