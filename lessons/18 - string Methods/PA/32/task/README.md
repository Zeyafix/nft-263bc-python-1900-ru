# Задание 32. Одноразовый код

Прочитайте одноразовый код. Выведите `Valid`, если в записи ровно шесть символов и каждый — одна из цифр `0123456789`. Иначе выведите `Invalid`. Нули в начале допустимы. Пробелы, знаки, буквы, пустая запись и другие цифровые символы (например, `²`) недопустимы. Запись перед проверкой не изменяйте.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
123456

Valid
```
