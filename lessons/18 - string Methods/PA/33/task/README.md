# Задание 33. Пустой комментарий

Прочитайте комментарий. Выведите `Has text`, если в нём есть хотя бы один непробельный символ, иначе `Empty`. Пустая запись, одни пробелы, одна табуляция или их смесь считаются пустым комментарием. Цифры и знаки препинания тоже считаются текстом.

## Пример

Первая строка — ввод, далее — вывод программы. Во вводимой строке по два пробела в начале и в конце.

```text
  Hello  

Has text
```
