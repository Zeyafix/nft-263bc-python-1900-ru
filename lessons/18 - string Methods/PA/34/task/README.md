# Задание 34. Список покупок

Прочитайте непустую запись товаров, разделённых запятыми. Каждая часть содержит непустое название товара; запятых внутри названия нет. Выведите товары в прежнем порядке, каждый на отдельной строке, убрав пробельные символы по краям названий. Пробелы внутри названия сохраните. Товар может быть один.

## Пример

Первая строка — ввод, далее — вывод программы. Во вводимой строке по одному пробелу в начале и в конце; пробелы рядом с запятыми тоже входят в данные.

```text
 milk, bread , green tea 

milk
bread
green tea
```
