# Задание 35. Маршрут доставки

Прочитайте маршрут: одно или несколько непустых названий пунктов через запятую, без пробелов по краям названий. Выведите названия в прежнем порядке, разделив соседние пункты точной последовательностью ` -> `. До первого и после последнего пункта стрелки нет. Например, `Office,Warehouse,Shop` превращается в `Office -> Warehouse -> Shop`.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
Office,Warehouse,Shop

Office -> Warehouse -> Shop
```
