# Задание 36. Исправление объявления

Прочитайте объявление. Замените все точные вхождения ошибочного слова `teh` на `the` и выведите исправленный текст. Гарантируется, что последовательность `teh` встречается только как отдельное слово, в том числе рядом со знаками препинания. Регистр учитывается: `Teh` и `TEH` оставьте как есть. Остальной текст и пробелы сохраните; пустая запись допустима.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
teh shop has teh book

the shop has the book
```
