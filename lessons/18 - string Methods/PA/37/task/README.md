# Задание 37. Имя и сообщение

Прочитайте запись вида `Tom: Meet at 18:30`. До первого двоеточия находится непустое имя без двоеточий, после него — сообщение, которое может быть пустым. Выведите имя, затем на следующей строке сообщение, убрав пробельные символы по краям каждой части. Все двоеточия и пробелы внутри сообщения сохраните. В записи гарантированно есть хотя бы одно двоеточие.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
Tom: Meet at 18:30

Tom
Meet at 18:30
```
