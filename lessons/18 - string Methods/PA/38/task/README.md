# Задание 38. Длина ответа

Прочитайте ответ. Подсчитайте количество символов без пробельных символов по краям, сохраняя при подсчёте все внутренние пробелы и знаки. Выведите `Length: N`, затем на следующей строке `Fits`, если длина не превышает 100 символов, иначе `Too long`. Пустой или полностью пробельный ответ имеет длину 0 и укладывается в лимит.

## Пример

Первая строка — ввод, далее — вывод программы. Во вводимой строке по два пробела в начале и в конце.

```text
  Hello world  

Length: 11
Fits
```
