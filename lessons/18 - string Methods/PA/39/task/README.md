# Задание 39. Шифр с чередованием

Прочитайте зашифрованную запись. После каждого полезного символа добавлен ровно один лишний: полезные символы находятся на индексах 0, 2, 4 и далее. Длина записи всегда чётная, в том числе может быть нулевой. Выведите восстановленное сообщение одной строкой. Полезным символом может быть и пробел; сохраняйте его.

## Пример

Первая строка — ввод, далее — вывод программы.

```text
Hxeqlzlpo!

Hello
```
