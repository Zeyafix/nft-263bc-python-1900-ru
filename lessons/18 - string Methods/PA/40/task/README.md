# Задание 40. Сравнение кодовых фраз

Прочитайте две кодовые фразы на отдельных строках. Они состоят из английских букв, обычных пробелов и знаков препинания. Выведите `Match`, если фразы совпадают без учёта регистра, пробелов по краям и количества пробелов между словами. Иначе выведите `Different`. Границы слов и знаки препинания значимы: `ab c` и `a bc` различаются. Пустые фразы и фразы из одних пробелов считаются одинаковыми.

## Пример

Первые две строки — ввод, далее — вывод программы. В первой вводимой строке два пробела в начале, три между Open и THE и один в конце; во второй — два между the и GATE.

```text
  Open   THE gate 
open the  GATE

Match
```
