Вопрос

Что такое индекс?

Выберите определение индекса элемента последовательности.

При отсчёте слева первый элемент имеет индекс 0. Отрицательные индексы отсчитывают позиции с конца.

Имя переменной и индекс выполняют разные роли: text[2] использует имя text и индекс 2.

02 / Зачем нужен список

Представьте, что программа хранит оценки студента. Пока оценок три, можно завести три переменные. Но для четвёртой придётся добавить ещё одно имя, а для расчёта суммы постоянно переписывать выражение.

Отдельные переменные
score_1 = 8
score_2 = 10
score_3 = 8
print(score_1 + score_2 + score_3)
Консоль
26

Список объединяет значения. Имя scores обозначает всю последовательность, а квадратные скобки и запятые задают её элементы. Одинаковые оценки не пропадают: каждая занимает свою позицию.

Одна переменная со списком
scores = [8, 10, 8]
print(scores)
print(len(scores))
Консоль
[8, 10, 8]
3
Определение

Список: тип list

Список представляет собой изменяемую последовательность элементов. Порядок сохраняется, пока вы сами его не измените. Значения могут повторяться. Можно заменять элементы, добавлять новые и удалять существующие, поэтому длина списка может меняться.

Оценки, имена и разные типы
scores = [8, 10, 8]
names = ["Ann", "Bob", "Sam"]
profile = ["Ann", 18, True]
print(scores)
print(names)
print(profile)
Консоль
[8, 10, 8]
['Ann', 'Bob', 'Sam']
['Ann', 18, True]

Разные типы в одном списке допустимы. Но для общей обработки удобнее собирать данные одного назначения и совместимых типов: оценки складывать, имена приводить к одному регистру. Смешанный profile нельзя целиком сложить как оценки.

Полезная модель памяти: переменная names ссылается на объект списка, а его позиции содержат ссылки на объекты строк. При обращении по индексу Python находит позицию и получает соответствующий объект. Такая модель объясняет, почему в списке могут соседствовать разные типы. На схеме адреса вида 0xA100 условные, запоминать их не нужно.

03 / Создание списка

Самый прямой способ создать список: перечислить значения внутри []. Такая запись называется литералом. Запятые отделяют элементы друг от друга. Пустые скобки создают список без элементов, а [123] содержит один элемент, число 123.

Литералы списков
scores = [10, 20, 30]
empty = []
single = [123]
names = [
    "Ann",
    "Bob",
    "Sam",
]
print(scores)
print(empty)
print(single)
print(names)
print(type(scores))
Консоль
[10, 20, 30]
[]
[123]
['Ann', 'Bob', 'Sam']
<class 'list'>

В многострочной записи запятая после последнего элемента разрешена. Она удобна, когда добавляете следующую строку. print() показывает содержимое списка, а type() подтверждает тип всего объекта.

Создание через list()
empty = list()
numbers = list(range(5))
letters = list("cat")
words = "cat dog".split()
print(empty)
print(numbers)
print(letters)
print(words)
Консоль
[]
[0, 1, 2, 3, 4]
['c', 'a', 't']
['cat', 'dog']

list() без аргумента создаёт пустой список. С аргументом он собирает элементы того, что можно перебрать: range(5) отдаёт числа от 0 до 4, строка отдаёт отдельные символы. Поэтому list("cat") даёт список символов, а "cat dog".split() даёт список слов.

Число не является последовательностью
numbers = list(123)
Последняя строка сообщения об ошибке
TypeError: 'int' object is not iterable

В числе 123 нельзя таким способом перебрать элементы. Для списка с одним числом нужны квадратные скобки: [123]. Для списка символов числового текста подошло бы list("123"), но его элементы были бы строками.

После split() каждая часть остаётся строкой. Кавычки в выводе списка помогают это заметить. Чтобы получить числа, создадим пустой список, пройдём по частям циклом и применим int() к каждой части. Метод append() добавляет один элемент в конец списка; подробно разберём его в разделе 07.

Преобразование частей через for
text = "8 10 12"
parts = text.split()
scores = []
for part in parts:
    score = int(part)
    scores.append(score)
print(parts)
print(scores)
print(type(parts[0]))
print(type(scores[0]))
Консоль
['8', '10', '12']
[8, 10, 12]
<class 'str'>
<class 'int'>
Как растёт scores
Часть partРезультат int(part)scores после добавления
"8"8[8]
"10"10[8, 10]
"12"12[8, 10, 12]

Переменная parts продолжает хранить строки. Мы создали отдельный список scores и добавили в него результаты преобразования. Здесь исходный текст содержит только корректные записи целых чисел.

04 / Длина и индексы

Длина отвечает на вопрос «сколько элементов?», индекс отвечает на вопрос «на какой позиции?». В списке [8, 10, 12] три элемента. Оценка 10 стоит второй для человека, но имеет индекс 1. Само значение 10 не является её индексом.

Позиции в scores = [8, 10, 12]

Длина и доступ к элементу
scores = [8, 10, 12]

Для непустого списка длины n неотрицательные индексы идут от 0 до n - 1, отрицательные от -n до -1. Индекс -1 всегда означает последний элемент. У пустого списка допустимых индексов нет.

Индекс за правой границей
scores = [8, 10, 12]
print(scores[3])
Последняя строка сообщения об ошибке
IndexError: list index out of range
Доступ к пустому списку
scores = []
print(scores[0])
Последняя строка сообщения об ошибке
IndexError: list index out of range

Такая же ошибка возникнет при scores[-4] для списка из трёх элементов. Если человек вводит номер, сначала проверяйте диапазон от 1 до длины, затем вычитайте единицу. Номер 0 недопустим: без проверки он превратится в индекс -1 и ошибочно выберет последний элемент.

Проверка номера
scores = [8, 10, 12]
number = 2
if 1 <= number <= len(scores):
    index = number - 1
    print(scores[index])
else:
    print("Invalid number")
Консоль
10
Проверка непустого списка
scores = []
if scores:
    print(scores[-1])
else:
    print("No scores")
Консоль
No scores

В условии пустой список считается ложным, а непустой истинным. Даже [0] непустой: проверяется наличие элементов, а не значение каждого из них.

05 / Срезы списка

Срез выбирает часть списка и возвращает список. В записи scores[start:stop:step] начало start включается, граница stop исключается, а step задаёт шаг. Для положительного шага движение идёт слева направо. Если шаг не указан, он равен 1.

Срезы на одном списке
scores = [4, 6, 8, 10, 12]
print(scores[1:4])
print(scores[:3])
print(scores[2:])
print(scores[-3:-1])
print(scores[::2])
print(scores[::-1])
print(scores[4:1:-1])
print(scores[:])
Консоль
[6, 8, 10]
[4, 6, 8]
[8, 10, 12]
[8, 10]
[4, 8, 12]
[12, 10, 8, 6, 4]
[12, 10, 8]
[4, 6, 8, 10, 12]
Как читать границы и шаг
СрезЧто выбирается
[1:4]Индексы 1, 2, 3. Элемент под индексом 4 не включён.
[:3]От начала до индекса 3, не включая его.
[2:]От индекса 2 до конца.
[-3:-1]От третьего с конца до последнего, не включая последний.
[::2]Индексы 0, 2, 4: каждый второй элемент с первого.
[::-1]От последнего к первому. При отрицательном шаге пропущенные границы задают движение с конца.
[4:1:-1]Индексы 4, 3, 2: шаг отрицательный, граница 1 исключена.
Пустые срезы и далёкие границы
scores = [4, 6, 8, 10, 12]

print(scores[-100:100])

При положительном шаге нельзя дойти от индекса 3 к границе 1, поэтому результат пустой. Одинаковые границы тоже дают пустой срез. Далёкие границы среза ограничиваются длиной списка: scores[20:30] допустим, хотя обращение scores[20] вызовет IndexError.

Шаг не может быть нулём
scores = [4, 6, 8]
print(scores[::0])
Последняя строка сообщения об ошибке
ValueError: slice step cannot be zero

Срез списка создаёт новый список.

Замена в результате среза
scores = [4, 6, 8, 10]
selected = scores[1:3]
print(selected)
selected[0] = 12
print(selected)
print(scores)
Консоль
[6, 8]
[12, 8]

Сначала selected содержит [6, 8]. Присваивание заменяет элемент только в новом списке. В исходном scores число 6 остаётся на месте. Срез создаёт новый внешний список, но не копирует рекурсивно вложенные объекты. Вложенные списки и общие ссылки подробно изучим в следующей теме; здесь работаем с числами.

06 / Изменение элементов

У списка можно заменить элемент на существующей позиции. В scores[1] = 12 сначала выбирается позиция с индексом 1, затем в неё записывается новое значение. Остальные элементы не сдвигаются, длина не меняется.

Исправление одной оценки
scores = [8, 10, 9]
print(scores)
scores[1] = 12
print(scores)
print(len(scores))
Консоль
[8, 10, 9]
[8, 12, 9]
3

Ниже пример того, как мы можем использовать изменение элемента списка по введённым пользователем данным.

Номер человека превращается в индекс
scores = [8, 10, 9]
number = int(input("Score number: "))
if 1 <= number <= len(scores):
    new_score = int(input("New score (1-12): "))
    if 1 <= new_score <= 12:
        scores[number - 1] = new_score
    else:
        print("Invalid score")
else:
    print("Invalid number")
print(scores)
Пример сеанса
Score number: 2
New score (1-12): 12
[8, 12, 9]

Если ввести номер 0 или 4, программа напечатает Invalid number и оставит список прежним. Новая оценка запрашивается только после проверки номера.

07 / Добавление элементов

Добавление увеличивает длину списка. Выбор метода зависит от того, нужно ли добавить один объект, вставить его в середину или присоединить несколько элементов.

Разберём метод append.

Добавить оценку в конец
scores = [8, 10]
scores.append(12)
print(scores)
Консоль
[8, 10, 12]

Метод получает одно значение. Старые элементы сохраняют свои позиции, новый занимает следующую свободную позицию. У пустого списка первый добавленный элемент получит индекс 0.

Метод insert позволяет вставлять элементы по индексу.

Вставить оценку в середину
scores = [8, 10]
scores.insert(1, 12)
print(scores)
Консоль
[8, 12, 10]

Число 12 вставлено перед прежним элементом с индексом 1. Число 10 сдвинулось вправо. Это отличается от scores[1] = 12: при замене 10 исчезло бы из этой позиции, а длина осталась бы 2. insert(0, value) вставляет в начало. Слишком большой индекс вставляет в конец, слишком маленький отрицательный в начало, без IndexError.

Метод extend позволяет разом добавить несколько элементов в конец списка.

Присоединить несколько оценок
scores = [8, 10]
scores.extend([11, 12])
print(scores)
Консоль
[8, 10, 11, 12]

Метод принимает переданную последовательность, перебирает её и добавляет каждый её элемент в конец исходного списка. Порядок добавляемых элементов сохраняется.

Есть разница между использованием append и extend.

Список как элемент или элементы списка
items = [1, 2]
items.append([3, 4])
print(items)
print(len(items))

items = [1, 2]
items.extend([3, 4])
print(items)
print(len(items))
Консоль
[1, 2, [3, 4]]
3
[1, 2, 3, 4]
4

В первом случае [3, 4] стал одним элементом внутри другого списка. Это вложенный список, поэтому внешняя длина равна 3. Во втором случае добавлены два отдельных числа. Вложенность подробно разберём в следующей теме.

Строка целиком и по символам
items = []
items.append("cat")
print(items)

items = []
items.extend("cat")
print(items)
Консоль
['cat']
['c', 'a', 't']

Строку можно перебирать по символам. Поэтому extend("cat") добавляет три символа, а append("cat") один объект строки.

Важно

Изменение списка и результат вызова

append(), insert() и extend() меняют существующий список и возвращают None. Это специальное значение обозначает отсутствие содержательного результата. Вызывайте метод отдельной строкой, затем используйте изменённый список.

Список изменился, результат равен None
items = [1, 2]
result = items.append(3)
print(items)
print(result)
Консоль
[1, 2, 3]
None

Поэтому для работы этих методов достаточно просто вызывать их, без присваивания к result и другим подобным переменным.

08 / Удаление элементов

Для удаления сначала определите, что вам известно: значение элемента или его позиция. В списке [8, 10, 8, 12] значение 8 встречается дважды, поэтому удаление по значению и удаление по индексу могут затронуть разные элементы.

Если требуется удалить элемент по значению, то выбираем remove.

remove(): первое равное значение
scores = [8, 10, 8, 12]
result = scores.remove(8)
print(scores)
print(result)
Консоль
[10, 8, 12]
None

remove(8) ищет значение 8 слева направо и удаляет только первое совпадение. Второе остаётся. Элементы справа сдвигаются влево, поэтому их индексы меняются.

Если требуется удалить элемент по индексу и этот удалённый элемент сохранить в переменной для дальнейшего использования, то выбираем pop.

pop(): удалить и получить значение
scores = [8, 10, 8, 12]
removed = scores.pop()
print(removed)
print(scores)
removed = scores.pop(1)
print(removed)
print(scores)
Консоль
12
[8, 10, 8]
10
[8, 8]

Без аргумента pop() выбирает последний элемент. С аргументом pop(1) выбирает индекс 1, а не значение 1. Возвращённое значение можно сохранить в переменной и, например, сообщить, какую оценку удалили.

Если требуется только удаление по индексу, то можно использовать оператор del.

del и clear()
scores = [8, 10, 8, 12]
del scores[2]
print(scores)
result = scores.clear()
print(scores)

11 / Сортировка и обратный порядок

Сортировка располагает значения по порядку сравнения: например, числа от меньшего к большему. Выберите, нужно ли менять существующий список или получить отдельный результат.

sort() меняет исходный список
scores = [8, 12, 6, 10]
result = scores.sort()
print(scores)
print(result)
scores.sort(reverse=True)
print(scores)
Консоль
[6, 8, 10, 12]
None
[12, 10, 8, 6]

sort() является методом списка, поэтому записывается после точки. Как видно, метод sort возвращает None, поэтому результат работы scores.sort() не требуется присваивать переменной.

Существует отдельная функция sorted, которая возвращает отсортированный результат, при этом не меняет порядок в исходном объекте.

sorted() возвращает новый список
scores = [8, 12, 6, 10]
ordered = sorted(scores)
descending = sorted(scores, reverse=True)
print(ordered)
print(descending)
print(scores)
Консоль
[6, 8, 10, 12]
[12, 10, 8, 6]
[8, 12, 6, 10]

Оба способа по умолчанию сортируют по возрастанию, а reverse=True задаёт убывание. Для сортировки элементы должны поддерживать сравнение друг с другом: смесь чисел и строк, например [8, "Ann"], так отсортировать нельзя.

Сравним получение обратного списка с помощью среза, сортировку с помощью sorted и метод reverse.

Разворот и сортировка на неупорядоченных данных
scores = [8, 12, 6, 10]
backward = scores[::-1]
descending = sorted(scores, reverse=True)
print(backward)
print(descending)
print(scores)
result = scores.reverse()
print(scores)
print(result)
Консоль
[10, 6, 12, 8]
[12, 10, 8, 6]
[8, 12, 6, 10]
[10, 6, 12, 8]
None

scores[::-1] создаст новый обратный список. sorted(scores, reverse=True) вернёт новый список, отсортированный по убыванию. reverse() изменит порядок элементов в существующем списке.

Записи scores = scores.sort() и scores = scores.reverse() оставят в переменной None, что не имеет смысла. Поэтому если метод изменяет порядок, вызывайте метод отдельной строкой. Для методов, которые что-то явно возвращают, создавайте переменные, чтобы хранить и дальше использовать результат работы метода. Например, ordered = sorted(scores).

12 / Список и текст

Текст удобен для ввода и вывода, а список для обработки отдельных значений. split() разбивает текст на части. Строковый метод join() соединяет части через выбранный разделитель.

От текста к словам и обратно
text = "Ann Bob Sam"
parts = text.split()
separator = ", "
result = separator.join(parts)
print(parts)
print(result)
Консоль
['Ann', 'Bob', 'Sam']
Ann, Bob, Sam

Разделитель добавляется только между элементами, а не в начале или конце. join() вызывается у строки separator, не у списка. Все соединяемые элементы должны быть строками. Выражение ", ".join([8, 10]) вызовет TypeError: метод не преобразует числа автоматически. Ниже разберём несколько примеров.

Договоримся о корректном формате: целые числа разделены пробелами; например, 8 10 12. В этом примере не вводим буквы, запятые или десятичные дроби. Пустая строка допустима и даст пустой список. split() без аргументов также обработает несколько пробелов подряд.

Ввод, разделение, преобразование
text = input("Scores: ")
parts = text.split()
scores = []
for part in parts:
    scores.append(int(part))
print(scores)
Пример сеанса
Scores: 8 10 12
[8, 10, 12]

input() возвращает одну строку. Затем split() создаёт список строк. Цикл берёт каждую часть, int() преобразует её в целое число, append() добавляет это число. Например, на второй итерации часть "10" превращается в число 10.

Другой пример. Допустим у нас уже есть список чисел, который мы хотим показать через запятую.

Подготовить строки для join()
scores = [8, 10, 12]
parts = []
for score in scores:
    parts.append(str(score))
text = ", ".join(parts)
print(parts)
print(text)
print(scores)
Консоль
['8', '10', '12']
8, 10, 12
[8, 10, 12]

Исходный список остаётся числовым. Отдельный список parts нужен только для представления результата текстом. Если он пустой, join() вернёт пустую строку; print() выведет пустую строку консоли.
