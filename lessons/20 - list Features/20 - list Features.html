02 / Переменная и объект списка

Представьте журнал оценок. Запись scores = [8, 10, 12] создаёт список и связывает с ним имя scores. Переменная позволяет найти объект по имени. Сам список существует отдельно от имени, которым мы к нему обращаемся.

Определение

Имя ссылается на объект

Ссылка позволяет обратиться к уже существующему объекту. В записи backup = scores Python сначала находит объект по имени scores, затем связывает с тем же объектом имя backup. Слово backup само по себе не означает, что создана резервная копия.

Два имени, один список
scores = [8, 10, 12]
backup = scores

scores.append(9)
print(scores)
print(backup)

backup[0] = 11
print(scores)
print(backup)
Консоль
[8, 10, 12, 9]
[8, 10, 12, 9]
[11, 10, 12, 9]
[11, 10, 12, 9]
  1. scores = [8, 10, 12] создаёт один объект списка. Назовём его A.
  2. backup = scores добавляет второе имя для A. Копирования элементов нет.
  3. scores.append(9) меняет A. Обращение через backup показывает уже изменённый A.
  4. backup[0] = 11 заменяет элемент того же A. Поэтому изменение видно и через scores.
Схема общей ссылки
ИмяОбъект после всех изменений
scoresA: [11, 10, 12, 9]
backupТот же A: [11, 10, 12, 9]

Элементы списка тоже являются ссылками на объекты. В упрощённой схеме памяти scores указывает на объект списка, а его позиции ссылаются на числа 8, 10 и 12. Область памяти с объектами часто называют heap, или кучей. Для работы со списками не нужно вычислять адреса: важно видеть, какие имена и позиции ведут к одному объекту.

Переприсваивание меняет связь имени.

Новое значение переменной backup
scores = [8, 10, 12]
backup = scores
backup = [1, 2]
backup.append(3)

print(scores)
print(backup)
Консоль
[8, 10, 12]
[1, 2, 3]

Правая часть [1, 2] создаёт новый список B. Присваивание связывает backup с B, а scores продолжает ссылаться на A. Последующий append меняет только B. Здесь не было команды, которая меняла бы элементы A.

Изменение объекта и переприсваивание
ЗаписьЧто происходит

backup = [1, 2]Имя backup связывается с новым списком. Старый список этой командой не меняется.

Определение

== и is

Для списков == сравнивает длину и соответствующие элементы в их порядке. is проверяет, один ли это объект, без сравнения его содержимого. Поэтому для сравнения значений используйте ==. В этом уроке is помогает исследовать общие ссылки.

Обозначим объект scores и backup буквой A, а объект other буквой B. До изменения A и B имеют одинаковое содержимое. После изменения A отличается от B, но сами связи имён с A и B остаются прежними. Смена оценки не создаёт новый внешний список.

04 / Копирование обычного списка

Если нужно поэкспериментировать с оценками и сохранить исходный список, второго имени недостаточно. Нужен отдельный список. Для этого есть метод copy(), полный срез [:] и вызов list() с исходным списком.

Способы получить backup из scores
ЗаписьНовый внешний список?backup is scores
backup = scoresНет, остаётся общая ссылка.True
backup = scores.copy()Да, поверхностная копия.False
backup = scores[:]Да, полный срез создаёт поверхностную копию.False
backup = list(scores)Да, новый список из элементов scores.False

Срез [:] берёт все позиции от начала до конца, а list(scores) собирает новый список из элементов исходного. Во всех трёх вариантах содержимое сначала равно исходному.

Три изменения в копии
scores = [8, 10, 12]
backup = scores.copy()

backup[0] = 7
print(backup)
backup.append(9)
print(backup)
backup.pop(1)
print(backup)

print(scores)
print(backup)
print(backup is scores)
Консоль
[7, 10, 12]
[7, 10, 12, 9]
[7, 12, 9]
[8, 10, 12]
[7, 12, 9]
False
  1. Замена backup[0] = 7 меняет позицию 0 только в новом списке.
  2. append(9) создаёт дополнительную позицию в backup.
  3. pop(1) удаляет из backup элемент с индексом 1, то есть число 10. Результат метода здесь не сохраняется.
  4. Позиции списка scores не менялись. Его содержимое осталось [8, 10, 12].
Определение

Поверхностная копия

Поверхностное копирование создаёт новый внешний список, но переносит в него ссылки на те же элементы. Сами объекты элементов не копируются рекурсивно. Так работают copy(), [:] и list(scores) для исходного списка.

Числа неизменяемы: команда backup[0] = 7 не превращает объект числа 8 в число 7. Она заменяет ссылку в одной позиции backup. Поэтому общие ссылки на числа не мешают независимому изменению двух списков чисел. Но если элемент сам является изменяемым списком, изменение внутри него может оказаться общим. Следующие разделы объяснят этот случай.

05 / Вложенные списки

Для нескольких студентов удобно хранить отдельный список оценок каждого студента. Эти списки можно собрать в один общий. Получится список списков: его элементами будут не числа, а другие списки.

Внешний список может содержать вложенные списки разной длины. Пустой список [] означает, что для студента ещё нет оценок.

При указании двух индексов интерпретатор читает их слева направо.

  1. В grades[0][1] сначала вычисляется grades[0]. Получаем внутренний список [8, 10, 12].
  2. Затем к полученному списку применяется [1]. Получаем число 10.
  3. Тот же доступ можно разложить: row = grades[0], затем row[1]. Переменная row ссылается на существующий вложенный список, а не копирует его.

Перед изменением найдите объект, к которому относится операция. В grades[0].append(10) сначала выбирается вложенный список, а затем меняется именно он. В grades.append([7, 8]) метод вызывается у внешнего списка и добавляет целый вложенный список.

При использовании оператора in работа со вложенными списками остаётся прежней.

07 / Перебор вложенных списков

Один цикл по grades выдаёт вложенные списки целиком. Для действий с каждой оценкой внутри него нужен второй цикл. Он проходит текущий вложенный список до конца, и только после этого внешний цикл выбирает следующего студента.

Сначала вложенный список, затем его оценки
grades = [[8, 10], [], [12]]

for row in grades:
    for score in row:
        print(score)
Консоль

10

Ход вложенных циклов
Шаг внешнего циклаrowШаги внутреннего циклаВывод
1[8, 10]score сначала равен 8, затем 10.8, затем 10 на новой строке.
2[]Элементов нет, тело внутреннего цикла не выполняется.Нет вывода.
3[12]score равен 12.12.

Отступы задают вложенность. print находится внутри обоих циклов. Второй вложенный список журнала пуст, но это не ошибка: внешний цикл выбирает его, а внутреннему просто нечего перебирать.

Чтобы заменить оценку в журнале, нужно присваивание в позицию списка. Запись score = score + 1 внутри перебора чисел меняла бы только переменную score. Она не записывает новое число обратно во вложенный список.

Повышаем каждую оценку на один балл
grades = [[8, 10], [], [12]]

for student_index in range(len(grades)):
    for grade_index in range(len(grades[student_index])):
        if grades[student_index][grade_index] < 12:
            grades[student_index][grade_index] += 1

print(grades)
Консоль
[[9, 11], [], [12]]

Внешний индекс выбирает студента, внутренний индекс выбирает оценку. range(len(grades[student_index])) использует длину текущего вложенного списка. Поэтому код подходит и для двух оценок, и для одной, и для пустого вложенного списка. Проверка < 12 сохраняет верхнюю границу принятой здесь шкалы. Длина списков во время этого прохода не меняется.

Таким образом, можно составить программу статистики по всем студентам.

Суммы, количество и средние
grades = [[8, 10], [], [12]]
total = 0
count = 0

for student_index in range(len(grades)):
    row = grades[student_index]
    row_total = 0
    for score in row:
        row_total += score

    print("Student", student_index + 1, "sum:", row_total)
    if len(row) > 0:
        print("Average:", row_total / len(row))
    else:
        print("No grades")

    total += row_total
    count += len(row)

print("Total:", total)
print("Count:", count)
if count > 0:
    print("Overall average:", total / count)
else:
    print("No overall average")
Консоль

Student 2 sum: 0

Average: 12.0

Count: 3

  1. total и count создаются до внешнего цикла: они накапливают результат по всему журналу.
  2. row_total обнуляется для каждого студента, затем внутренний цикл складывает его оценки.
  3. Среднее студента вычисляется только при непустом вложенном списке. Сумма пустого вложенного списка равна 0, но среднего у него нет.
  4. После обработки вложенного списка его сумма добавляется в total, а длина в count. Деление total / count выполняется после всех вложенных списков и только при count > 0.

08 / Где поверхностной копии недостаточно

Вернёмся к резервной копии журнала. Метод copy() создаёт новые позиции только во внешнем списке. Если в этих позициях лежат ссылки на внутренние списки, копия получает ссылки на те же вложенные списки.

09 / Независимая копия вложенных данных

Для журнала, где каждый вложенный список содержит только числа, достаточно отдельно скопировать внешний список и каждый вложенный список. Сначала создадим пустой backup, затем пройдём grades и добавим копию каждого вложенного списка.

Копируем вложенные списки обычным циклом
grades = [[8, 10], [], [12]]
backup = []
for row in grades:
    backup.append(row.copy())

print(backup == grades)
print(backup is grades)
print(backup[0] is grades[0])
print(backup[1] is grades[1])

backup[0][0] = 7
backup[1].append(9)
print(grades)
print(backup)
Консоль
True
False
False
False

Схема до изменения копии
Исходный путьПуть в копииСвязь

A[0] → R0: [8, 10]B[0] → S0: [8, 10]R0 и S0 различны, числа в них равны.
A[1] → R1: []B[1] → S1: []Даже пустой вложенный список скопирован в отдельный объект.
A[2] → R2: [12]B[2] → S2: [12]Замена позиций S2 не затронет R2.

Каждый вызов row.copy() создаёт отдельный список. append сохраняет его во внешнем backup. Числа остаются общими объектами, но они неизменяемы. Замена чисел, добавление и удаление оценок теперь затрагивают только вложенные списки выбранного журнала.

Ещё один вложенный список остаётся общим
grades = [[[8, 10]], [[12]]]

Вложенным списком здесь является [[8, 10]], а его элементом является ещё один список [8, 10]. Метод row.copy() копирует вложенный список, но переносит ссылку на его вложенный элемент. Значит, самый глубокий список всё ещё общий. Для такой структуры прежнего цикла недостаточно.

В Python есть готовый инструмент deepcopy из модуля copy. Модуль можно понимать как набор готовых инструментов. Строка from copy import deepcopy делает имя deepcopy доступным в нашей программе.

Определение

Глубокая копия

Для рассматриваемых вложенных списков deepcopy() создаёт новый внешний список и рекурсивно копирует вложенные списки. Рекурсивно значит, что та же операция продолжается на следующих уровнях вложенности. Копии изменяемых списков отделяются от оригинала. Неизменяемые значения, например числа, могут оставаться теми же объектами.

Глубокая копия трёх уровней
from copy import deepcopy

print(backup[0] is grades[0])
print(backup[0][0] is grades[0][0])

backup[0][0][0] = 7
print(grades)
print(backup)

Если исходный список содержал копии два одинаковых списка, то deepcopy это скопирует в новый список точно так же.

Один общий вложенный список остаётся общим внутри копии
from copy import deepcopy

Оригинал защищён от изменения копии, но вложенные списки внутри backup не стали независимыми друг от друга. Это сохранение структуры ссылок, а не ошибка.

10 / Повторение элементов и общие вложенные списки

Оператор + объединяет элементы списков, а * повторяет их заданное число раз. Оба создают новый внешний список. Они переносят ссылки на элементы, поэтому не заменяют глубокое копирование.

Объединение и повторение чисел
first = [8, 10]

print(first)

Объединение не копирует внутренние списки

second = [[12]]

Разберём, почему [0] * 3 удобно, а [[0] * 3] * 2 требует внимания.

Обычный ряд из нулей
row = [0] * 3
row[0] = 1
print(row)
Консоль
[1, 0, 0]

Список содержит три ссылки на число 0. Но числа неизменяемы: row[0] = 1 заменяет только ссылку в первой позиции. Остальные позиции продолжают указывать на 0.

Ошибка

Повторилась ссылка на вложенный список

Две позиции ведут к одному вложенному списку
grid = [[0] * 3] * 2

grid[0][0] = 1
print(grid)
Консоль
[[0, 0, 0], [0, 0, 0]]
True
[[1, 0, 0], [1, 0, 0]]

Сначала [0] * 3 создаёт один вложенный список. Квадратные скобки вокруг него создают список с одной ссылкой на этот вложенный список. Умножение на 2 повторяет ссылку. Поэтому grid[0] и grid[1] ведут к одному изменяемому списку.

Верный подход

Создавайте вложенный список заново на каждой итерации

Независимые вложенные списки сетки
grid = []
for row_index in range(2):
    grid.append([0] * 3)

grid[0][0] = 1
print(grid)
print(grid[0] is grid[1])
Консоль
[[1, 0, 0], [0, 0, 0]]
False

Выражение [0] * 3 выполняется два раза. Каждый раз возникает новый список. Теперь у двух вложенных списков отдельные позиции для оценок или других значений.

Та же ошибка через append
grid = []
row = [0] * 3
for row_index in range(2):
    grid.append(row)

grid[0][1] = 5
print(grid)
print(grid[0] is grid[1])
Консоль
[[0, 5, 0], [0, 5, 0]]
True

Сам append ничего не копирует: он добавляет переданный объект. Здесь row создан только один раз до цикла. Чтобы использовать отдельную переменную, перенесите row = [0] * 3 внутрь цикла перед grid.append(row). Тогда на каждом шаге будет создан новый вложенный список.

11 / Изменение списка во время перебора

12 / Самопроверка

Вопрос

Что означает поверхностное копирование списка?

Отметьте верные варианты.

Копируются позиции внешнего списка. Вложенные изменяемые объекты могут остаться общими.

Это обычное присваивание backup = scores. При копировании внешний объект новый.

Поверхностная копия обрабатывает только внешний уровень.

Слово «поверхностная» относится к глубине, а не к количеству элементов.

Вопрос

Что означает глубокое копирование вложенных списков?

Отметьте верные варианты.

deepcopy отделяет вложенные списки от оригинала. Повторные ссылки внутри структуры при этом могут сохраниться.

Так работает присваивание =, а не deepcopy.

Такой границей ограничена поверхностная копия.

deepcopy запоминает уже скопированные объекты и сохраняет повторные ссылки внутри копии.

Вопрос

Что делает backup = scores, если scores уже ссылается на список?

Отметьте верные варианты.

Правая часть находит существующий объект; новое имя получает ссылку на него.

Присваивание само по себе список не копирует.

Для этого нужен отдельный вызов deepcopy.

Имя scores продолжает ссылаться на тот же объект.

Вопрос

Что делает backup = scores.copy()?

Отметьте верные варианты.

Это поверхностная копия: backup is scores даст False.

copy() возвращает новый объект списка.

Содержимое scores не меняется.

Вложенные списки остаются общими, если они есть.

Вопрос

Что делает backup = scores[:]?

Отметьте верные варианты.

Правая часть [:] берёт все элементы в новый внешний список.

Полный срез списка создаёт отдельный список.

Здесь срез читается. Он не стоит слева от присваивания и не удаляется через del.

Полный срез означает все позиции, а не все уровни вложенности.

Вопрос

Что делает backup = list(scores) для списка scores?

Отметьте верные варианты.

Для исходного списка это ещё один способ поверхностного копирования.

Создаётся новый внешний список, даже если scores уже имеет тип list.

list() собирает элементы без такого преобразования.

Объекты элементов не копируются рекурсивно.

Вопрос

Что выведет программа с общей ссылкой?

Предскажите вывод: присваивание
scores = [8, 10, 12]
backup = scores
backup[0] = 7
print(scores)
Отметьте верные варианты.

backup и scores ведут к одному объекту. Первая позиция этого объекта заменена.

Исходное содержимое сохранилось бы при отдельной копии внешнего списка.

Заменена одна позиция; остальные элементы не удаляются.

Индекс 0 существует, а список допускает замену элемента.

Вопрос

Что выведет программа с копией списка чисел?

Предскажите вывод: copy()
scores = [8, 10, 12]
backup = scores.copy()
backup[0] = 7
print(scores)
Отметьте верные варианты.

Первая позиция заменена только в новом внешнем списке backup.

Так было бы при backup = scores. Здесь вызван copy().

scores вообще не менялся. Кроме того, индекс 0 обозначает первую позицию.

Копирование и замена в backup не очищают scores.

Вопрос

Как проверить равенство содержимого двух списков?

Отметьте верные варианты.

== сравнивает длину и соответствующие элементы списков.

is проверяет, один ли это объект, а не равенство двух разных списков.

Это присваивание, а не проверка.

in ищет элемент, равный scores, среди элементов backup.

Вопрос

Как проверить, ведут ли два имени к одному объекту списка?

Отметьте верные варианты.

is проверяет идентичность объектов, на которые ссылаются имена.

Разные списки с одинаковыми элементами тоже дадут True.

Совпадение длины ничего не говорит об общей ссылке.

Это проверка неравенства содержимого.

Вопрос

Как обратиться к оценке 11 в этом журнале?

Журнал для поиска индексов
grades = [[8, 10], [7, 9, 11]]
Отметьте верные варианты.

Индекс 1 выбирает второй вложенный список [7, 9, 11], индекс 2 выбирает его третий элемент.

Внешнего индекса 2 нет: в журнале два вложенных списка.

Эта запись вернёт 9, второй элемент второго вложенного списка.

В первом вложенном списке два элемента, поэтому внутренний индекс 2 вне границ.

Вопрос

Какие связи создаёт copy() в этом примере?

Связи после copy()
grades = [[8, 10], [12]]
backup = grades.copy()
Отметьте верные варианты.

backup is grades даст False, а backup[0] is grades[0] даст True.

copy() создаёт именно новый внешний список.

copy() не копирует внутренние списки.

Внешний объект backup новый, хотя его элементы общие.

Вопрос

Какие связи создаёт deepcopy() в этом примере?

Связи после deepcopy()
from copy import deepcopy

Отметьте верные варианты.

Все три списка скопированы. Изменение вложенного списка backup не затронет вложенный список grades.

deepcopy продолжает копирование и во вложенных списках.

Это было бы верно для простого присваивания.

Копирование не удаляет исходные данные.

Вопрос

Что выведет изменение внутри поверхностной копии?

Предскажите вывод: вложенная поверхностная копия
grades = [[8, 10], [12]]
backup = grades.copy()
backup[0][0] = 7

Отметьте верные варианты.

backup[0] и grades[0] ведут к одному вложенному списку. Изменён его элемент 0.

Исходный вложенный список сохранился бы при отдельной копии вложенного списка или deepcopy.

Заменена одна оценка. Остальные элементы вложенного списка сохранились.

Первый индекс 0 выбирает первый вложенный список, а не второй.

Вопрос

Что выведет изменение внутри глубокой копии?

Предскажите вывод: глубокая копия
from copy import deepcopy

grades = [[8, 10], [12]]
backup = deepcopy(grades)
backup[0][0] = 7
print(grades)
Отметьте верные варианты.

Вложенный список backup отделён от исходного вложенного списка grades.

Так было бы при поверхностной копии внешнего списка.

Меняется только первый вложенный список копии, а grades не меняется вообще.

deepcopy импортирован, все индексы существуют, замена элемента допустима.
