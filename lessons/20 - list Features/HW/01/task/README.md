# Задание 1. Два способа адресации

Создайте программу `main.py`.

Исходные данные:

```python
colors = ["red", "green", "blue", "yellow", "white"]
```

Выведите третий элемент дважды: сначала получите его положительным индексом, затем отрицательным. Каждый результат выведите на отдельной строке.

## Пример

```text
blue
blue
```
