# Задание 2. Допустимый индекс

Создайте программу `main.py`.

Сначала введите числа без дробной части через пробел. Пустая строка означает пустой список. Затем введите индекс: он может быть положительным, нулевым или отрицательным. Если такой элемент существует, выведите его. Иначе — `Invalid index`. Для пустого списка любой индекс недопустим.

## Пример

```text
Enter numbers separated by spaces (empty for none): 10 20 30
Enter an index: -3
10
```

## Ещё один пример

```text
Enter numbers separated by spaces (empty for none): 
Enter an index: 0
Invalid index
```
