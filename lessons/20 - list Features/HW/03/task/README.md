# Задание 3. Проход по элементам

Создайте программу `main.py`.

Сначала введите числа без дробной части через пробел. Пустая строка означает пустой список. Пройдите по элементам и подсчитайте положительные, отрицательные и нулевые значения. Выведите три строки с подписями `Positive:`, `Negative:` и `Zero:`. Для пустого списка все количества равны нулю.

## Пример

```text
Enter numbers separated by spaces (empty for none): 4 -2 0 7 -1 0
Positive: 2
Negative: 2
Zero: 2
```
