# Задание 4. Проход по индексам

Создайте программу `main.py`.

Сначала введите числа без дробной части через пробел. Пустая строка означает пустой список. Затем введите искомое число. Пройдите по индексам списка и выведите все индексы совпадений по возрастанию, каждый на отдельной строке. Отсчёт начинается с нуля. Если совпадений нет, выведите `Not found`.

## Пример

```text
Enter numbers separated by spaces (empty for none): 7 2 7 7
Enter the target number: 7
0
2
3
```
