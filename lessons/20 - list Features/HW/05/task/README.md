# Задание 5. Проверка через in

Создайте программу `main.py`.

Сначала введите числа без дробной части через пробел. Пустая строка означает пустой список. Введите искомое число. Проверьте его наличие оператором `in`. Выведите `Found` или `Not found`. Пустой список не содержит ни одного значения.

## Пример

```text
Enter numbers separated by spaces (empty for none): 12 3 12
Enter the target number: 12
Found
```

## Ещё один пример

```text
Enter numbers separated by spaces (empty for none): 12 3
Enter the target number: 2
Not found
```
