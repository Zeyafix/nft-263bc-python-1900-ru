# Задание 6. Добавление через append()

Создайте программу `main.py`.

Сначала введите числа без дробной части через пробел. Пустая строка означает пустой список. Введите количество новых значений (от 0), затем каждое новое число отдельно. Добавьте их в конец через `append()` в порядке ввода. Выведите итоговый список.

## Пример

```text
Enter numbers separated by spaces (empty for none): 1 2
Enter the number of new values: 3
Enter a new number: 8
Enter a new number: -1
Enter a new number: 8
[1, 2, 8, -1, 8]
```
