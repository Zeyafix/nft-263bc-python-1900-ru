# Задание 7. Вставка через insert()

Создайте программу `main.py`.

Исходные данные:

```python
colors = ["red", "blue"]
```

Введите три названия цвета, каждое на отдельной строке. Через `insert()` вставьте первое перед `red`, второе между `red` и `blue`, третье после `blue`. Выведите итоговый список. Названия непустые, регистр сохраняется.

## Пример

```text
Enter the first color: white
Enter the middle color: green
Enter the last color: black
['white', 'red', 'green', 'blue', 'black']
```
