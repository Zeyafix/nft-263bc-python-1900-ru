# Задание 8. Удаление через remove()

Создайте программу `main.py`.

Сначала введите числа без дробной части через пробел. Пустая строка означает пустой список. Введите число для удаления. Заранее проверьте его наличие. Если оно есть, удалите через `remove()` только первое вхождение и выведите `Removed`. Иначе выведите `Not found`. Затем в любом случае выведите список.

## Пример

```text
Enter numbers separated by spaces (empty for none): 4 2 4 4
Enter the number to remove: 4
Removed
[2, 4, 4]
```

## Ещё один пример

```text
Enter numbers separated by spaces (empty for none): 1 2
Enter the number to remove: 3
Not found
[1, 2]
```
