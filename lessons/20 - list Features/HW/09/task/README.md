# Задание 9. Извлечение через pop(index)

Создайте программу `main.py`.

Сначала введите числа без дробной части через пробел. Пустая строка означает пустой список. Введите индекс без дробной части, в том числе отрицательный. Проверьте его допустимость. Для допустимого индекса извлеките элемент через `pop(index)` и выведите его с подписью `Removed:`. Иначе выведите `Invalid index`. Затем выведите оставшийся список.

## Пример

```text
Enter numbers separated by spaces (empty for none): 4 8 2
Enter an index to remove: -1
Removed: 2
[4, 8]
```

## Ещё один пример

```text
Enter numbers separated by spaces (empty for none): 4 8 2
Enter an index to remove: -3
Removed: 4
[8, 2]
```
