# Задание 10. Извлечение через pop()

Создайте программу `main.py`.

Сначала введите числа без дробной части через пробел. Пустая строка означает пустой список. Последовательно извлеките все элементы с конца через `pop()` без аргумента. Каждый извлечённый элемент выведите отдельной строкой с подписью `Removed:`. После завершения выведите пустой список. Для исходно пустого списка выведите только `[]`.

## Пример

```text
Enter numbers separated by spaces (empty for none): 5 2 5 8
Removed: 8
Removed: 5
Removed: 2
Removed: 5
[]
```

## Ещё один пример

```text
Enter numbers separated by spaces (empty for none): 
[]
```
