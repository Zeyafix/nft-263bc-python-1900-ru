# Задание 11. Удаление через del

Создайте программу `main.py`.

Исходные данные:

```python
letters = ["A", "B", "C", "D", "E"]
```

Введите два разных индекса исходного списка, каждый от 0 до 4. Удалите через `del` именно те элементы, которые находились на этих позициях до любых удалений. Порядок ввода индексов произвольный. Сохраните порядок остальных и выведите список. Индексы гарантированно допустимы и различны.

## Пример

```text
Enter the first original index (0-4): 1
Enter the second original index (0-4): 3
['A', 'C', 'E']
```
