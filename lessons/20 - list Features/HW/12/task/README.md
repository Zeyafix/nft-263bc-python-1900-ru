# Задание 12. Замена по индексу

Создайте программу `main.py`.

Сначала введите числа без дробной части через пробел. Пустая строка означает пустой список. Пройдите по индексам и замените в этом же списке каждое отрицательное число нулём. Сохраните порядок и остальные значения. Выведите список.

## Пример

```text
Enter numbers separated by spaces (empty for none): -2 -3 0 4 -1
[0, 0, 0, 4, 0]
```
