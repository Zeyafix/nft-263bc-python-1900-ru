# Задание 13. Обмен элементов

Создайте программу `main.py`.

Сначала введите числа без дробной части через пробел. Список должен содержать хотя бы один элемент. Введите два допустимых индекса, каждый отдельно; отрицательные индексы разрешены. Поменяйте выбранные элементы местами и выведите список. Индексы могут указывать на один элемент: тогда данные не изменяются. Проверять допустимость ввода не нужно.

## Пример

```text
Enter at least one number, separated by spaces: 1 2 3
Enter the first index: 0
Enter the second index: -1
[3, 2, 1]
```
