# Задание 14. Копирование через copy()

Создайте программу `main.py`.

Исходные данные:

```python
numbers = [10, 20, 30, 40]
```

Создайте поверхностную копию через `copy()`. Введите индекс от 0 до 3, новое значение для этой позиции в копии и ещё одно значение для добавления в конец копии. Каждое число вводится отдельно, без дробной части. Выведите исходный список с подписью `Original:`, затем копию с подписью `Copy:`. Исходный список должен остаться прежним.

## Пример

```text
Enter an index (0-3): 1
Enter the replacement number: 99
Enter the number to append: 5

Original: [10, 20, 30, 40]
Copy: [10, 99, 30, 40, 5]
```
