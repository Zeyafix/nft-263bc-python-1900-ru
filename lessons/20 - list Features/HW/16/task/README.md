# Задание 16. Перебор вложенных списков

Создайте программу `main.py`.

Исходные данные:

```python
rows = [[4, -1, 3], [], [2], [0, 0], [-2, -3]]
```

Пройдите по вложенным спискам. Выведите сумму чисел в каждом вложенном списке отдельно: `Row 1: ...`, `Row 2: ...` и так далее. Для пустого списка сумма равна нулю. Сохраните порядок строк.

## Пример

```text
Row 1: 6
Row 2: 0
Row 3: 2
Row 4: 0
Row 5: -5
```
