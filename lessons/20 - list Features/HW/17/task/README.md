# Задание 17. Изменение вложенных данных

Создайте программу `main.py`.

Исходные данные:

```python
rows = [[-1, -2, 3], [], [-4], [0, 5], [6, -7, 0, -8]]
```

Пройдите по индексам строк и элементов внутри каждой строки. В этих же вложенных списках замените отрицательные числа нулями. Длины строк могут различаться, пустые строки сохраните. Выведите весь вложенный список одной строкой.

## Пример

```text
[[0, 0, 3], [], [0], [0, 5], [6, 0, 0, 0]]
```
