# Задание 19. Домашние расходы

Создайте программу `main.py`.

Введите траты за дни через пробел: каждое значение — сумма в целых денежных единицах, от 0. Пустая строка означает, что данных пока нет. Посчитайте общую сумму и количество дней с нулевыми тратами. Выведите `Total:` и `Days without expenses:` на двух строках. При отсутствии данных оба результата равны нулю.

## Пример

```text
Enter daily expenses separated by spaces (empty for none): 20 0 35 0 5

Total: 60
Days without expenses: 2
```
