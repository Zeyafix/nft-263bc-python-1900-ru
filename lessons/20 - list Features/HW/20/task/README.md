# Задание 20. Контроль температуры

Создайте программу `main.py`.

Введите измерения температуры в градусах без дробной части через пробел. Пустая строка означает отсутствие измерений. Затем введите порог. Выведите номера всех измерений строго выше порога, каждый на отдельной строке в исходном порядке. Нумерация с 1. Если превышений нет, выведите `No alerts`.

## Пример

```text
Enter temperatures separated by spaces (empty for none): 18 25 25 19 30
Enter the temperature threshold: 19

2
3
5
```
