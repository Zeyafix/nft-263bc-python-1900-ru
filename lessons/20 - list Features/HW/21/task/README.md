# Задание 21. Гостевой список

Создайте программу `main.py`.

Исходные данные:

```python
guests = ["Anna", "Ben", "Chris"]
```

Введите непустое имя гостя. Регистр имеет значение: `Anna` и `anna` — разные имена. Если имя уже есть, выведите `Already invited`. Иначе добавьте гостя в конец и выведите `Guest added`. После сообщения выведите гостевой список.

## Пример

```text
Enter the guest name: Mia

Guest added
['Anna', 'Ben', 'Chris', 'Mia']
```
