# Задание 22. История тренировок

Создайте программу `main.py`.

Исходные данные:

```python
history = [10, 12]
```

В списке записано количество повторений на прошлых тренировках. Введите количество новых тренировок (от 0). Затем для каждой введите результат — количество повторений от 0. После каждого добавления в конец выведите всю текущую историю. Если новых тренировок нет, один раз выведите прежнюю историю.

## Пример

```text
Enter the number of new workouts: 3

Enter the repetition count: 15
[10, 12, 15]

Enter the repetition count: 0
[10, 12, 15, 0]

Enter the repetition count: 15
[10, 12, 15, 0, 15]
```

## Ещё один пример

```text
Enter the number of new workouts: 0
[10, 12]
```
