# Задание 23. План путешествия

Создайте программу `main.py`.

Исходные данные:

```python
route = ["Baku", "Tbilisi", "Istanbul", "Rome"]
```

Введите название дополнительного города, затем его желаемый номер в обновлённом маршруте. Название непустое. Допустимы номера от 1 до 5: 1 означает начало, 5 — конец. Для допустимого номера вставьте город, сохранив все прежние города и их порядок. Иначе выведите `Invalid position`. В конце в любом случае выведите маршрут.

## Пример

```text
Enter the additional city: Prague
Enter the new city position: 3

['Baku', 'Tbilisi', 'Prague', 'Istanbul', 'Rome']
```
