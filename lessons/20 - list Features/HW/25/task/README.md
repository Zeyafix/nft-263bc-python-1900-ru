# Задание 25. Выдача посылки

Создайте программу `main.py`.

Исходные данные:

```python
parcels = ["AX-14", "BX-08", "CX-21", "DX-05"]
```

Введите номер посылки в очереди без дробной части. Нумерация начинается с 1. Если номер допустим, удалите посылку и выведите её код с подписью `Parcel:`. Иначе выведите `Invalid number`. Затем покажите очередь.

## Пример

```text
Enter the parcel number: 2

Parcel: BX-08
['AX-14', 'CX-21', 'DX-05']
```
