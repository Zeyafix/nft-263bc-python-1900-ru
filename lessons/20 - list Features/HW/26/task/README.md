Создайте программу `main.py`.

Исходные данные:

```python
playlist = ["Intro", "Rain", "Rain", "Dawn", "Night", "Outro"]
```

Введите два различных номера записей исходного плейлиста, каждый от 1 до 6. Порядок ввода произвольный, номера гарантированно допустимы и различны. Удалите именно эти две записи; одинаковые названия на других позициях сохраните. Выведите плейлист, сохранив порядок остальных записей.

## Пример
