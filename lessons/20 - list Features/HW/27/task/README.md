# Задание 27. Исправление показания

Создайте программу `main.py`.

Исходные данные:

```python
readings = [100, 112, 999, 140, 155]
```

В списке показания счётчика по дням. Введите номер дня без дробной части, затем правильное показание в целых единицах, от 0. Нумерация дней с 1. Если день существует, замените его показание. Иначе выведите `Invalid day`. Затем выведите список показаний. Проверять возрастание показаний не требуется.

## Пример

```text
Enter the day number: 3
Enter the corrected meter reading: 125
```
