# Задание 29. Пробный бюджет

Создайте программу `main.py`.

Исходные данные:

```python
expenses = [300, 120, 80, 50]
```

Расходы по категориям записаны в целых денежных единицах. Создайте отдельную копию списка. Введите номер категории от 1 до 4 и новую сумму от 0 для неё. Измените только копию. Выведите четыре строки: исходные расходы с `Original:`, пробные с `Trial:`, затем их суммы с `Original total:` и `Trial total:`. Исходные расходы должны сохраниться.

## Пример

```text
Enter the category number (1-4): 2
Enter the trial amount: 100

Original: [300, 120, 80, 50]
Trial: [300, 100, 80, 50]

Original total: 550
Trial total: 530
```
