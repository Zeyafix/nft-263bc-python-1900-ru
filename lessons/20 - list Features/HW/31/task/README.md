# Задание 31. Успеваемость группы

Создайте программу `main.py`.

Исходные данные:

```python
grades = [[8, 10, 9], [], [7], [10, 10, 8], [4, 8], []]
```

Каждый вложенный список — оценки одного студента. Выведите среднюю оценку каждого студента с двумя знаками после точки: `Student 1: 9.00` и так далее. Нумерация с 1. Для студента без оценок вместо среднего выведите `No grades`. Сохраните исходный порядок, учитывайте все оценки.

## Пример

```text
Student 1: 9.00
Student 2: No grades
Student 3: 7.00
Student 4: 9.33
Student 5: 6.00
Student 6: No grades
```
