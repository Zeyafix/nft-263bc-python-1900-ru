# Задание 32. Бронирование в зале

Создайте программу `main.py`.

Исходные данные:

```python
hall = [
    ['_', '_', '_', '_', '_', '_', '_', '_', '_', '_'],
    ['_', '_', '_', '_', '_', '_', '_', '_', '_', '_'],
    ['_', '_', '_', '_', '_', '_', 'X', '_', '_', '_'],
    ['_', '_', '_', '_', '_', '_', '_', '_', '_', '_'],
    ['_', '_', '_', '_', '_', '_', '_', '_', '_', '_'],
    ['_', '_', '_', '_', '_', '_', '_', '_', '_', '_'],
    ['_', '_', '_', '_', '_', '_', '_', '_', '_', '_'],
    ['_', '_', '_', '_', '_', '_', '_', '_', '_', '_'],
    ['_', '_', '_', '_', '_', '_', '_', '_', '_', '_'],
    ['_', '_', '_', '_', '_', '_', '_', '_', '_', '_'],
]
```

В зале 10 рядов по 10 мест. `_` означает свободное место, `X` — занятое. Изначально занято только место 7 в ряду 3. Введите номер ряда, затем номер места без дробной части; нумерация с 1. Для номеров вне диапазона 1–10 выведите `Invalid seat`. Если место уже занято, выведите `Already booked`. Иначе отметьте выбранное место как занятое и выведите `Booked`. Затем в любом случае покажите весь зал: 10 строк по 10 символов, разделённых одиночными пробелами, без скобок и кавычек. Меняется только выбранное свободное место. За запуск обрабатывается одно бронирование.
