# Задание 1. Положительные индексы

Создайте программу `main.py`. Используйте такие исходные данные:

```python
numbers = [12, 7, 25, 9, 31, 4]
```

Выведите первый, третий и пятый элементы списка, каждый на отдельной строке. Обратитесь к ним по индексам от начала списка: отсчёт начинается с нуля.

## Пример

Программа показывает:

```text
12
25
31
```
