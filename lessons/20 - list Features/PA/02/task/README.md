# Задание 2. Отрицательные индексы

Создайте программу `main.py`. Используйте такие исходные данные:

```python
colors = ["red", "green", "blue", "yellow"]
```

Выведите последний и предпоследний элементы, каждый на отдельной строке. Используйте отрицательные индексы.

## Пример

Программа показывает:

```text
yellow
blue
```
