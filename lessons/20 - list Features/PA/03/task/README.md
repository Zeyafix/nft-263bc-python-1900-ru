# Задание 3. Проход по элементам

Создайте программу `main.py`. Используйте такие исходные данные:

```python
numbers = [8, -3, 0, 12, -5]
```

Пройдите циклом по элементам списка. Выведите каждое число на отдельной строке, а после всех чисел — их общую сумму с подписью `Total: `.

## Пример

Программа показывает:

```text
8
-3
0
12
-5
Total: 12
```
