# Задание 4. Проход по индексам

Создайте программу `main.py`. Используйте такие исходные данные:

```python
animals = ["cat", "dog", "fox", "owl"]
```

Пройдите циклом по индексам списка. Для каждого элемента выведите его индекс и значение в формате `0 - cat`. Отсчёт индексов начинается с нуля.

## Пример

Программа показывает:

```text
0 - cat
1 - dog
2 - fox
3 - owl
```
