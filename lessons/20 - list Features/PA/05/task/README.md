# Задание 5. Принадлежность

Создайте программу `main.py`. Используйте такие исходные данные:

```python
fruits = ["apple", "pear", "plum"]
```

Прочитайте название фрукта. Сначала выведите результат проверки наличия этого значения через `in`, затем результат проверки его отсутствия через `not in`. Каждый результат выведите на отдельной строке как `True` или `False`. Регистр букв имеет значение.

## Пример

Пользователь вводит:

```text
pear
```

Программа показывает:

```text
True
False
```
