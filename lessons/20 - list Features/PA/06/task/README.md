# Задание 6. Добавление в конец

Создайте программу `main.py`. Используйте такие исходные данные:

```python
numbers = [4, 8, 15]
```

Выведите исходный список с подписью `Before: `. Добавьте число 16 в конец через `append()` и выведите изменённый список с подписью `After: `.

## Пример

Программа показывает:

```text
Before: [4, 8, 15]
After: [4, 8, 15, 16]
```
