# Задание 7. Вставка по индексу

Создайте программу `main.py`. Используйте такие исходные данные:

```python
letters = ["A", "C", "D"]
```

Прочитайте индекс существующего элемента от 0 до 2. Через `insert()` добавьте `"B"` перед элементом с этим индексом. Выведите изменённый список.

## Пример

Пользователь вводит:

```text
1
```

Программа показывает:

```text
['A', 'B', 'C', 'D']
```
