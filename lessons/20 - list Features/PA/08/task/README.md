# Задание 8. Удаление по значению

Создайте программу `main.py`. Используйте такие исходные данные:

```python
numbers = [7, 2, 7, 9, 7]
```

Через `remove()` удалите первое вхождение числа 7. Выведите изменённый список. Остальные вхождения числа 7 должны остаться на своих местах относительно других элементов.

## Пример

Программа показывает:

```text
[2, 7, 9, 7]
```
