# Задание 9. Безопасное удаление

Создайте программу `main.py`. Используйте такие исходные данные:

```python
colors = ["red", "blue", "red"]
```

Прочитайте цвет. Проверьте его наличие через `in` перед вызовом `remove()`. Если цвет есть, удалите первое вхождение и выведите `Removed`. Если его нет, выведите `Not found`. Затем в обоих случаях выведите список. Регистр букв имеет значение.

## Пример

Пользователь вводит:

```text
red
```

Программа показывает:

```text
Removed
['blue', 'red']
```

Если цвета нет:

Пользователь вводит:

```text
green
```

Программа показывает:

```text
Not found
['red', 'blue', 'red']
```
