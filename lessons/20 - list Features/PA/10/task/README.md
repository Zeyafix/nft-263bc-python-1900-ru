# Задание 10. Удаление с результатом

Создайте программу `main.py`. Используйте такие исходные данные:

```python
cities = ["Oslo", "Rome", "Lima", "Baku"]
```

Прочитайте индекс от 0 до 3. Через `pop(index)` удалите выбранный элемент. Выведите возвращённое удалённое значение с подписью `Removed: `, затем оставшийся список.

## Пример

Пользователь вводит:

```text
1
```

Программа показывает:

```text
Removed: Rome
['Oslo', 'Lima', 'Baku']
```
