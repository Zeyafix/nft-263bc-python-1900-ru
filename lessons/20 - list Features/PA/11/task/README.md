# Задание 11. Последний элемент

Создайте программу `main.py`. Используйте такие исходные данные:

```python
numbers = [10, 20, 30, 40]
```

Удалите последний элемент через `pop()` без аргумента. Выведите возвращённое значение с подписью `Removed: `, затем оставшийся список.

## Пример

Программа показывает:

```text
Removed: 40
[10, 20, 30]
```
