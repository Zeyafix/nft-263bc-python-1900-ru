# Задание 12. Оператор del

Создайте программу `main.py`. Используйте такие исходные данные:

```python
letters = ["A", "B", "C", "D"]
```

Прочитайте индекс от 0 до 3. Удалите элемент по этому индексу оператором `del`. Выведите изменённый список.

## Пример

Пользователь вводит:

```text
1
```

Программа показывает:

```text
['A', 'C', 'D']
```
