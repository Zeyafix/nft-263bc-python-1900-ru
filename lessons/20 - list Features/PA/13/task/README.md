# Задание 13. Замена элемента

Создайте программу `main.py`. Используйте такие исходные данные:

```python
scores = [5, 7, 9, 6]
```

Прочитайте индекс от 0 до 3, затем новую оценку от 1 до 12, каждое значение на отдельной строке. Запишите новую оценку по заданному индексу. Выведите изменённый список.


## Пример

Пользователь вводит:

```text
1
12
```

Программа показывает:

```text
[5, 12, 9, 6]
```
