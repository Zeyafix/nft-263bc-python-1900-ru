# Задание 14. Изменение в цикле

Создайте программу `main.py`. Используйте такие исходные данные:

```python
numbers = [-2, 0, 5, 5]
```

Пройдите циклом по индексам и увеличьте каждый элемент исходного списка на единицу. Выведите изменённый список.

## Пример

Программа показывает:

```text
[-1, 1, 6, 6]
```
