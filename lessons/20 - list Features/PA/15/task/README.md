# Задание 15. Поверхностная копия

Создайте программу `main.py`. Используйте такие исходные данные:

```python
numbers = [3, 6, 9]
```

Создайте поверхностную копию списка через `copy()`. Замените её первый элемент на 100. Выведите исходный список с подписью `Original: `, затем копию с подписью `Copy: `. Исходный список должен сохранить свои значения.

## Пример

Программа показывает:

```text
Original: [3, 6, 9]
Copy: [100, 6, 9]
```
