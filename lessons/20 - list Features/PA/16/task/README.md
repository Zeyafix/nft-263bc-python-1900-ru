# Задание 16. Двойной индекс

Создайте программу `main.py`. Используйте такие исходные данные:

```python
table = [[11, 12, 13], [21, 22, 23], [31, 32, 33]]
```

Прочитайте индекс строки от 0 до 2, затем индекс столбца от 0 до 2, каждое значение на отдельной строке. Прочитайте выбранную ячейку по двум индексам и выведите её значение.

## Пример

Пользователь вводит:

```text
1
2
```

Программа показывает:

```text
23
```
