# Задание 17. Чтение строк

Создайте программу `main.py`. Используйте такие исходные данные:

```python
rows = [[2, 4, 6], [8], [10, 12]]
```

Пройдите по вложенным спискам и выведите элементы каждой строки в исходном порядке. Элементы одной строки разделяйте одним пробелом, каждую строку выводите с новой строки. Учитывайте, что длины строк различаются. Пробелов в конце строк быть не должно.

## Пример

Программа показывает:

```text
2 4 6
8
10 12
```
