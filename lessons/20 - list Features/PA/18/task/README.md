# Задание 18. Замена в строке

Создайте программу `main.py`. Используйте такие исходные данные:

```python
table = [[1, 2, 3], [4, 5, 6]]
```

Прочитайте индекс строки от 0 до 1, индекс столбца от 0 до 2 и новое значение, каждое на отдельной строке. Измените только выбранную ячейку по двум индексам. Выведите всю таблицу одним вложенным списком.


## Пример

Пользователь вводит:

```text
1
1
50
```

Программа показывает:

```text
[[1, 2, 3], [4, 50, 6]]
```
