# Задание 19. Первый и последний урок

Создайте программу `main.py`. Используйте такие исходные данные:

```python
schedule = ["Math", "English", "Art", "Python"]
```

Покажите первый и последний предметы этого непустого расписания. Выведите их на отдельных строках с подписями `First: ` и `Last: ` соответственно.

## Пример

Программа показывает:

```text
First: Math
Last: Python
```
