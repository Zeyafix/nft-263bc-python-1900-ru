# Задание 20. Выбор напитка

Создайте программу `main.py`. Используйте такие исходные данные:

```python
drinks = ["Water", "Tea", "Coffee", "Juice"]
```

В меню напитки пронумерованы от 1 до 4 в порядке списка. Прочитайте выбранный номер и выведите только название соответствующего напитка.

## Пример

Пользователь вводит:

```text
2
```

Программа показывает:

```text
Tea
```
