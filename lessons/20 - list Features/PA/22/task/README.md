# Задание 22. Нумерация книг

Создайте программу `main.py`. Используйте такие исходные данные:

```python
books = ["The Hobbit", "Dune", "Treasure Island"]
```

Выведите названия книг в порядке списка, пронумеровав их с единицы. Каждая книга занимает отдельную строку в формате `1. The Hobbit`.

## Пример
