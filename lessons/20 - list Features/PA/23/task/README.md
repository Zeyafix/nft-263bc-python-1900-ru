# Задание 23. Проверка приглашения

Создайте программу `main.py`. Используйте такие исходные данные:

```python
guests = ["Alice", "Ben", "Clara"]
```

Прочитайте имя посетителя. Если оно есть в списке приглашённых, выведите `Welcome`, иначе — `Not invited`. Имя должно совпадать целиком, с учётом регистра.

## Пример

Пользователь вводит:

```text
Ben
```

Программа показывает:

```text
Welcome
```
