# Задание 24. Список покупок

Создайте программу `main.py`. Используйте такие исходные данные:

```python
shopping = ["bread", "milk", "eggs"]
```

Прочитайте непустое название товара и добавьте его в конец списка покупок. Название может содержать пробелы. Уже имеющийся товар тоже добавляется как отдельная покупка. Выведите получившийся список.

## Пример

Пользователь вводит:

```text
apples
```

Программа показывает:

```text
['bread', 'milk', 'eggs', 'apples']
```
