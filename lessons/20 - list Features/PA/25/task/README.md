# Задание 25. Срочная задача

Создайте программу `main.py`. Используйте такие исходные данные:

```python
plan = ["Read mail", "Study Python", "Walk"]
```

Прочитайте непустое описание срочной задачи. Поставьте её первой в плане на день, сохранив все прежние задачи и их взаимный порядок. Выведите обновлённый план одним списком.

## Пример

Пользователь вводит:

```text
Call doctor
```

Программа показывает:

```text
['Call doctor', 'Read mail', 'Study Python', 'Walk']
```
