# Задание 26. Перерыв в расписании

Создайте программу `main.py`. Используйте такие исходные данные:

```python
schedule = ["Math", "English", "Python", "Art"]
```

Занятия пронумерованы от 1 до 4. Прочитайте номер занятия, перед которым нужен перерыв. Добавьте запись `"Break"` перед этим занятием, сохранив все занятия и их порядок. Выведите обновлённое расписание одним списком.

## Пример

Пользователь вводит:

```text
3
```

Программа показывает:

```text
['Math', 'English', 'Break', 'Python', 'Art']
```
