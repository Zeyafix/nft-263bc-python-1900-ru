# Задание 27. Купленный товар

Создайте программу `main.py`. Используйте такие исходные данные:

```python
shopping = ["milk", "bread", "milk", "eggs"]
```

Прочитайте название купленного товара. Уберите первое вхождение этого названия из списка и выведите `Purchased`. Если товара нет, выведите `Not on the list` и сохраните список. После сообщения выведите оставшийся список покупок. Сравнивайте названия целиком с учётом регистра.

## Пример

Пользователь вводит:

```text
milk
```

Программа показывает:

```text
Purchased
['bread', 'milk', 'eggs']
```
