# Задание 28. Следующий посетитель

Создайте программу `main.py`. Используйте такие исходные данные:

```python
queue = ["Emma", "Oliver", "Sophia"]
```

Пригласите первого человека из этой непустой очереди и уберите его из неё. Выведите его имя с подписью `Invited: `, затем оставшуюся очередь одним списком.

## Пример

Программа показывает:

```text
Invited: Emma
['Oliver', 'Sophia']
```
