# Задание 29. Отмена последнего действия

Создайте программу `main.py`. Используйте такие исходные данные:

```python
history = ["Open file", "Type title", "Save file"]
```

Отмените последнее действие из этой непустой истории: удалите последнюю запись и покажите её с подписью `Undone: `. Затем выведите оставшуюся историю одним списком.

## Пример

Программа показывает:

```text
Undone: Save file
['Open file', 'Type title']
```
