# Задание 30. Удаление слайда

Создайте программу `main.py`. Используйте такие исходные данные:

```python
slides = ["Title", "Problem", "Solution", "Demo", "Conclusion"]
```

Слайды пронумерованы от 1 до 5. Прочитайте номер ненужного слайда, уберите его и выведите оставшийся план презентации одним списком в прежнем порядке.

## Пример

Пользователь вводит:

```text
3
```

Программа показывает:

```text
['Title', 'Problem', 'Demo', 'Conclusion']
```
