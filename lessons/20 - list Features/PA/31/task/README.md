# Задание 31. Исправление имени

Создайте программу `main.py`. Используйте такие исходные данные:

```python
participants = ["Mia", "Jon", "Ava", "Liam"]
```

Участники пронумерованы от 1 до 4. Прочитайте номер участника, затем на следующей строке его исправленное непустое имя. Имя может содержать пробелы. Замените только выбранное имя и выведите список участников.

## Пример

Пользователь вводит:

```text
2
John
```

Программа показывает:

```text
['Mia', 'John', 'Ava', 'Liam']
```
