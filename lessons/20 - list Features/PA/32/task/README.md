# Задание 32. Начисление бонуса

Создайте программу `main.py`. Используйте такие исходные данные:

```python
scores = [0, 12, 7, 12]
```

Прочитайте размер бонуса. Увеличьте баллы каждого игрока на эту величину. Выведите обновлённый список, сохранив порядок игроков.

## Пример

Пользователь вводит:

```text
5
```

Программа показывает:

```text
[5, 17, 12, 17]
```
