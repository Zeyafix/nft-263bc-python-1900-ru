# Задание 33. Черновик плейлиста

Создайте программу `main.py`. Используйте такие исходные данные:

```python
playlist = ["Morning Light", "Blue Sky", "Night Walk"]
```

Создайте отдельную копию плейлиста для пробы. Прочитайте непустое название песни и добавьте его в конец копии, даже если такая песня уже есть. Исходный плейлист должен сохранить свои значения. Выведите исходный список с подписью `Original: `, затем пробный вариант с подписью `Draft: `.

## Пример

Пользователь вводит:

```text
Summer Rain
```

Программа показывает:

```text
Original: ['Morning Light', 'Blue Sky', 'Night Walk']
Draft: ['Morning Light', 'Blue Sky', 'Night Walk', 'Summer Rain']
```
