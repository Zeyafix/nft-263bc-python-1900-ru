# Задание 34. Оценка за работу

Создайте программу `main.py`. Используйте такие исходные данные:

```python
grades = [[8, 10, 12], [7, 9, 11], [6, 8, 10], [12, 11, 9]]
```

Каждый вложенный список хранит оценки одного студента за три работы. Студенты пронумерованы от 1 до 4, работы — от 1 до 3. Прочитайте номер студента, затем номер работы на следующей строке. Выведите выбранную оценку с подписью `Grade: `.

## Пример

Пользователь вводит:

```text
2
3
```

Программа показывает:

```text
Grade: 11
```
