# Задание 35. Расписание по дням

Создайте программу `main.py`. Используйте такие исходные данные:

```python
days = [["Math", "English"], [], ["Python"], ["Art", "Music", "Sport"], []]
```

Каждый вложенный список содержит занятия одного дня. Выведите для каждого дня заголовок `Day 1:`, `Day 2:` и так далее, начиная с единицы. После заголовка выведите каждое занятие на отдельной строке в исходном порядке. Для пустого дня вместо занятий выведите `No classes`. Пустые строки между днями не добавляйте.

## Пример

Программа показывает:

```text
Day 1:
Math
English

Day 2:
No classes

Day 3:
Python

Day 4:
Art
Music
Sport

Day 5:
No classes
```
