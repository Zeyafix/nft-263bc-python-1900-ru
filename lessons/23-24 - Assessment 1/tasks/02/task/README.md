# Задание 02. Скидка в интернет-магазине

Создайте программу `main.py`.

Запросите сумму покупки, статус клиента (`new`, `regular` или `vip`), затем промокод. Сумма неотрицательна, статус вводится из указанного списка.
Покупка от 500 включительно даёт 5%. Статус `new` даёт 2%, `regular` — 3%, `vip` — 8%. Промокод `5869` даёт ещё 7%. Другой код или пустой ввод не даёт скидки за промокод.
Все подходящие проценты складываются и применяются один раз к исходной сумме. Выведите `Discount: <процент>%`, затем `Payment: <сумма>` с двумя знаками после точки.

## Пример

Пример диалога: после подсказок показаны ответы пользователя.

```text
Purchase amount: 1000
Status (new/regular/vip): vip
Promo code: 5869

Discount: 20%
Payment: 800.00
```
