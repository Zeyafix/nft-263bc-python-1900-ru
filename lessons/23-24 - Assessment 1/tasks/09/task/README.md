# Задание 09. Индексы и символы строки

Создайте программу `main.py`.

Запросите одну строку. Дважды покажите каждый её символ вместе с индексом: сначала выполните обход с помощью `for`, затем отдельный обход с помощью `while`. Каждый обход должен самостоятельно получать символы исходной строки.

В обоих обходах двигайтесь от начала строки к концу. Индексы начинаются с 0. Каждую пару выводите на отдельной строке: сначала индекс, затем символ в двойных кавычках. Строка может быть пустой: в этом случае покажите только заголовки двух обходов.

## Пример

```text
Enter text: A b

For loop - index and character:
0: "A"
1: " "
2: "b"

While loop - index and character:
0: "A"
1: " "
2: "b"
```

## Пустая строка

Пользователь сразу нажимает Enter:

```text
Enter text:
For loop - index and character:
While loop - index and character:
```
