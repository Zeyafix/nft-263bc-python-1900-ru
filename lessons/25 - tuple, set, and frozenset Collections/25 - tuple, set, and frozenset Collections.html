02 / Зачем нужен кортеж

Определение

Кортеж: значения с фиксированными позициями

tuple (кортеж) является неизменяемой последовательностью. Порядок элементов сохраняется, индексы доступны, значения могут повторяться и иметь разные типы. После создания нельзя заменить, добавить или удалить элемент самого кортежа.

Представьте точку на экране. У неё есть две связанные координаты: сначала x, затем y. Их удобно передавать и читать вместе. Если взять запись студента, то первая позиция может означать ID, а вторая имя. Кортеж хранит значения, но смысл позиций задаёте вы.

Координаты и запись студента
point = (10, 20)
student = (101, "Alice")
print(point)
print(point[0], point[1])
print(student[0], student[1])
print((10, 10, "start"))
Консоль
(10, 20)
10 20
101 Alice
(10, 10, 'start')

У point[0] значение 10, у point[1] значение 20. В student соседствуют число и строка. Повтор числа 10 в последнем кортеже допустим. Как и в списке, отсчёт индексов начинается с нуля.

Сравним две модели одной точки. Если программа передвигает точку и постоянно заменяет отдельные координаты, список позволяет менять их на месте. Если запись должна описывать выбранное положение целиком, кортеж подчёркивает фиксированную структуру: для другого положения создают другую запись.

Одна задача, две модели
moving_point = [10, 20]
moving_point[0] = 15
saved_point = (10, 20)
new_point = (15, saved_point[1])
print(moving_point)
print(saved_point)
print(new_point)
Консоль
[15, 20]
(10, 20)
(15, 20)

Выбирайте коллекцию по смыслу данных и нужным действиям. Кортеж не является «всегда более быстрым» или «лучшим» списком. Для постоянно изменяемого журнала удобен список. Для пары координат с неизменяемыми данными удобен кортеж.

03 / Создание кортежа

Чтобы собрать значения в кортеж, перечислите их через запятую. Скобки помогают увидеть границы записи. Пустой кортеж записывают как () или получают вызовом tuple() без аргументов.

Пустые и заполненные кортежи
empty = ()
also_empty = tuple()
colors = ("red", "green", "blue")
print(empty)
print(also_empty)
print(colors)
Консоль
()
()
('red', 'green', 'blue')

У tuple(iterable) один аргумент: объект, из которого нужно взять элементы. Итерируемым называют объект, элементы которого можно по очереди получать в цикле for. Вы уже знаете список и строку. Конструктор tuple() собирает их элементы в кортеж в порядке перебора.

Преобразование знакомых коллекций
scores = [8, 10, 8]
saved_scores = tuple(scores)
letters = tuple("cat")
word = ("cat",)
print(saved_scores)
print(letters)
print(word)
Консоль
(8, 10, 8)
('c', 'a', 't')
('cat',)

Строка при переборе отдаёт символы, поэтому tuple("cat") содержит три элемента. В ("cat",) перечислен один готовый элемент: строка целиком. Преобразование списка не убирает повторяющиеся оценки.

Скобки сами по себе могут только группировать выражение. Для непустого кортежа решающую роль играет запятая. Посмотрим на значение и тип трёх почти одинаковых записей.

Число или кортеж
number = (5)
single = (5,)
without_brackets = 5,
print(type(number), number)
print(type(single), single)
print(type(without_brackets), without_brackets)
Консоль
<class 'int'> 5
<class 'tuple'> (5,)
<class 'tuple'> (5,)

В первом случае получился int. Во втором и третьем получился tuple длины один. Запись со скобками (5,) обычно легче заметить и прочитать. Если хотели один элемент, но написали (5), добавьте запятую.

04 / Чтение и операции с кортежем

Пусть нужно прочитать сохранённые результаты. Индекс выбирает один элемент, срез values[start:stop:step] выбирает часть последовательности, не включая границу stop. Отрицательный индекс отсчитывается с конца, а пропущенные границы среза означают начало или конец.

Индексы, срезы и длина
scores = (8, 10, 8, 12)
print(scores[0])
print(scores[-1])
print(scores[1:3])
print(scores[::2])
print(scores[::-1])
print(len(scores))
print(10 in scores)
print(7 not in scores)
for score in scores:
    print(score)
Консоль
8
12
(10, 8)
(8, 8)
(12, 8, 10, 8)
4
True
True
8
10
8
12

Срезы тоже возвращают кортежи. scores[1:3] берёт индексы 1 и 2, scores[::2] берёт каждый второй элемент с начала, а шаг -1 читает с конца. len() возвращает длину, in и not in проверяют наличие значения. Цикл выводит элементы в их исходном порядке.

Ошибка

Индекс за границей

Индекс за границей
point = (10, 20)
print(point[2])
Последняя строка сообщения об ошибке
IndexError: tuple index out of range

У двух элементов есть индексы 0 и 1. Индекс 2 уже за границей.

Срезы могут выходить за границы.

Срезы за границей
point = (10, 20)
print(point[:100])
print(point[100:])
Консоль
(10, 20)
()

Срез берёт только доступную часть. Если в выбранной области нет элементов, он возвращает пустой кортеж.

Метод count(value) считает вхождения, а index(value) возвращает индекс первого совпадения. Это удобно, если нужно узнать, сколько раз встретилась оценка и где она встретилась впервые.

Количество и первая позиция
scores = (8, 10, 8, 12)
print(scores.count(8))
print(scores.count(7))
print(scores.index(8))
target = 7
if target in scores:
    print(scores.index(target))
else:
    print("Not found")
Консоль
2
0
0
Not found

Ноль от count() означает отсутствие значения. Для index() отсутствие является ошибкой, поэтому проверка in должна стоять до вызова метода.

Ошибка

Поиск отсутствующего значения

Поиск отсутствующего значения
scores = (8, 10, 8, 12)
print(scores.index(7))
Последняя строка сообщения об ошибке
ValueError: tuple.index(x): x not in tuple

Метод существует, но подходящего значения нет. Используйте проверку target in scores, как в рабочем примере выше.

Кортежи можно комбинировать и повторять.

Объединение, повторение и равенство
first = (10, 20)
combined = first + (30,)
repeated = first * 2
print(combined)
print(repeated)
print(first)
print((10, 20) == (20, 10))
print((10, 20) == (10, 20))
Консоль
(10, 20, 30)
(10, 20, 10, 20)
(10, 20)
False
True

Оператор + соединяет кортежи, а * с целым числом повторяет последовательность. Оба выражения формируют результат и оставляют first прежним. При равенстве сравниваются соответствующие позиции: одинакового набора значений в другом порядке недостаточно.

05 / Неизменяемость кортежа

Ошибка

Нельзя заменить ячейку кортежа

Нельзя заменить ячейку кортежа
point = (10, 20)
point[0] = 15
Последняя строка сообщения об ошибке
TypeError: 'tuple' object does not support item assignment

Этот тип не поддерживает присваивание по индексу. Вместо этого создайте point = (15, point[1]) или используйте список, если нужны частые замены.

Ошибка

Нельзя дописать элемент методом append

Нельзя дописать элемент методом append
point = (10, 20)
point.append(30)
Последняя строка сообщения об ошибке
AttributeError: 'tuple' object has no attribute 'append'

У tuple нет append(). Можно получить новый кортеж через point + (30,).

Ошибка

Нельзя удалить элемент методом remove

Нельзя удалить элемент методом remove
point = (10, 20)
point.remove(20)
Последняя строка сообщения об ошибке
AttributeError: 'tuple' object has no attribute 'remove'

У tuple нет remove(). Если требуется менять состав, преобразуйте кортеж в список и удалите элемент у списка.

Если требуется изменить элемент кортежа, то можно конвертировать кортеж в список, затем проводить изменения.

Изменяемый рабочий список
values = (10, 20)
editable = list(values)
editable.remove(20)
editable.append(30)
print(editable)
print(values)
Консоль
[10, 30]
(10, 20)

Имя переменной можно связать с другим объектом. Это не меняет прежний объект. Сохраним ссылку на старый кортеж, чтобы увидеть различие.

Переприсваивание имени
point = (10, 20)
old_point = point
point = point + (30,)
print(point)
print(old_point)
Консоль
(10, 20, 30)
(10, 20)

Сначала вычисляется правая часть: получается (10, 20, 30). Затем point начинает обозначать этот результат. old_point продолжает обозначать прежний (10, 20).

Кортеж хранит ссылки на свои элементы. Если элемент сам является изменяемым объектом, его содержимое можно менять. Например, имя и список оценок составляют запись студента: позиции записи фиксированы, а список оценок растёт.

Меняется вложенный список
record = ("Alice", [8, 10])
print(record)
record[1].append(12)
print(record)
Консоль
('Alice', [8, 10])
('Alice', [8, 10, 12])

Выражение record[1] сначала получает список. Затем append(12) меняет именно его. Вторая позиция кортежа по-прежнему ссылается на тот же список, поэтому правило неизменяемости кортежа не нарушено.

Ошибка

Замена вложенного объекта запрещена

Замена вложенного объекта запрещена
record = ("Alice", [8, 10])
record[1] = [8, 10, 12]
Последняя строка сообщения об ошибке
TypeError: 'tuple' object does not support item assignment

Здесь заменяется сама ссылка в позиции 1. Чтобы добавить оценку в существующий список, вызовите record[1].append(12). Чтобы заменить запись целиком, создайте новый кортеж.

06 / Упаковка и распаковка

Упаковка собирает несколько значений в один кортеж. Распаковка распределяет элементы итерируемого объекта по отдельным переменным. Это позволяет читать координаты через понятные имена вместо повторяющихся индексов.

Из координат в отдельные переменные
point = 10, 20
x, y = point
print(point)
print(x)
print(y)
Консоль
(10, 20)
10
20

Справа от первого = числа упаковываются в кортеж. Во второй строке первый элемент попадает в x, второй в y. В обычной распаковке каждому имени нужен ровно один элемент.

Распаковка списка и строки
width, height = [80, 25]
first_letter, second_letter = "OK"
print(width, height)
print(first_letter, second_letter)
Консоль
80 25
O K

Распаковка не является отдельным методом кортежа: она работает и со знакомыми списками и строками. Слева перечисляют имена через запятую, справа помещают итерируемый объект.

Ошибка

Значений слишком мало

Значений слишком мало
x, y = (10,)
Последняя строка сообщения об ошибке
ValueError: not enough values to unpack (expected 2, got 1)

Слева два имени, справа один элемент. Передайте два значения или оставьте одно имя со структурой x, = (10,).

Ошибка

Значений слишком много

Значений слишком много
x, y = (10, 20, 30)
Последняя строка сообщения об ошибке
ValueError: too many values to unpack (expected 2, got 3)

Для трёх элементов нужны три обычных имени, например x, y, z. Если часть значений нужно собрать вместе, используйте распаковку с остатком из следующего раздела.

Используя распаковку и упаковку можно решать разные задачи, например, обмен значений. В left, right = right, left Python сначала вычисляет всю правую часть, используя прежние значения, и только затем присваивает результаты слева.

Поменять местами
left = "red"
right = "blue"
left, right = right, left
print(left, right)
Консоль
blue red

Правая часть содержит сначала "blue", затем "red". Поэтому left получает "blue", а right получает "red". Последовательные строки left = right и right = left дали бы другой результат: оба имени обозначали бы "blue".

Если результаты хранятся в списке кортежей, каждую запись можно распаковать. Сначала прочитаем одну запись, затем применим ту же запись имён в заголовке цикла.

Одна запись и весь список
results = [("Alice", 10), ("Bob", 8)]
name, score = results[0]
print(name, score)
for name, score in results:
    print(f"{name}: {score}")
Консоль
Alice 10
Alice: 10
Bob: 8

Каждая итерация получает очередной кортеж и распаковывает его в name и score. Все записи в этом примере содержат по два элемента. Первая Alice в выводе относится к отдельной распаковке. Следующие строки относятся к циклу.

07 / Распаковка с остатком

Иногда число элементов заранее неизвестно. Чтобы взять первый результат, а остальные сохранить вместе, поставьте * перед одним именем слева от =. В этом месте звёздочка означает сбор остатка, а не умножение.

Первый и остальные
values = (10, 20, 30, 40)
first, *rest = values
print(first)
print(rest)
print(type(rest))
Консоль
10
[20, 30, 40]
<class 'list'>

first получает 10, а rest получает список [20, 30, 40]. Даже если справа кортеж, звёздочка собирает именно список.

Чтобы отдельно получить последний элемент, перенесите звёздочку к первому имени. Обычные имена справа от неё забирают элементы с конца.

Начало и последний
values = (10, 20, 30, 40)
*start, last = values
print(start)
print(last)
Консоль
[10, 20, 30]
40

Звёздочку можно поставить и между обычными именами. Например, отделить крайние измерения от промежуточных.

Края и середина
values = (10, 20, 30, 40)
first, *middle, last = values
print(first)
print(middle)
print(last)
Консоль
10
[20, 30]
40

Минимальное число элементов равно числу имён без звёздочки: каждому из них нужен свой элемент. Для first, *rest нужен хотя бы один; для first, *middle, last нужны хотя бы два. Сам остаток может быть пустым.

Минимум элементов
first, *rest = (10,)
print(first, rest)
*start, last = (40,)
print(start, last)
first, *middle, last = (10, 40)
print(first, middle, last)
Консоль
10 []
[] 40
10 [] 40
Ошибка

Не хватает значений для краёв

Не хватает значений для краёв
first, *middle, last = (10,)
Последняя строка сообщения об ошибке
ValueError: not enough values to unpack (expected at least 2, got 1)

Звёздочка не создаёт недостающие значения. Здесь нужны минимум два элемента, например (10, 40), либо нужно убрать одно обычное имя.

Ошибка

Два остатка на одном уровне

Два остатка на одном уровне
first, *middle, *rest = (10, 20, 30)
Последняя строка сообщения об ошибке
SyntaxError: multiple starred expressions in assignment (<lesson>, line 1)

На одном уровне допускается одна цель со звёздочкой. Иначе непонятно, как разделить остаток. Используйте first, *rest = (10, 20, 30).

08 / Зачем нужно множество

В список участников иногда попадают повторные регистрации. Если нужно узнать уникальные имена, последовательность всех заявок уже не подходит: нам важен состав. Для этого есть множество set.

Определение

Множество: уникальные элементы

set хранит уникальные хешируемые элементы. Хешируемость разберём в следующем разделе. Множество можно изменять, но у него нет индексов и срезов, и оно не гарантирует сохранение порядка вставки.

Уникальные имена

print(len(participants))
print(sorted(participants))

Четыре регистрации содержат три разных имени. set(names) оставляет уникальные значения. Здесь уникальность именно по имени: два разных человека с одинаковым именем тоже превратятся в один элемент. В законченной программе ниже будем использовать ID.

sorted(participants) возвращает новый отсортированный список, чтобы вывод был воспроизводимым. Само множество упорядоченным от этого не становится. Сортируйте значения, которые можно сравнивать между собой, например только имена или только целые числа. Смешанные числа и строки так сортировать нельзя.

09 / Какие значения можно хранить во множестве

Множество должно быстро находить уже добавленные элементы. Для поиска Python использует хеш: целое число, связанное с объектом. Его можно получить через hash(value), если объект поддерживает такую операцию. Само значение хеша не является ID человека или постоянным кодом для хранения в файле.

Определение

Хешируемость

У хешируемого объекта хеш остаётся стабильным в течение его жизни. Равные объекты должны иметь равные хеши. Обратное не обязательно: совпадение хешей ещё не доказывает равенство. При поиске Python учитывает и равенство элементов.

У знакомых встроенных типов числа и строки хешируемы. Кортеж тоже подходит, если каждый его элемент хешируем. Например, множество координат может хранить пары чисел.

Допустимые элементы
values = {10, 2.5, "Alice", (1, 2)}
print(len(values))
print("Alice" in values)
print((1, 2) in values)
point = (1, 2)
print(hash(point) == hash((1, 2)))
Консоль
4
True
True
True

Здесь четыре различных элемента разных типов. Мы не сортируем их вместе. Хеши равных кортежей совпадают, поэтому последний вывод True. Численные хеши специально не запоминаем: например, хеш строки может отличаться между запусками Python.

Последняя строка сообщения об ошибке

set не хешируем.

Ошибка

Кортеж со списком тоже не подходит

Кортеж со списком тоже не подходит

Внешний кортеж неизменяем, но содержит нехешируемый список.

Неизменяемость и хешируемость не являются синонимами. Мы только что увидели неизменяемый кортеж, который нельзя поместить во множество из-за его содержимого.

Ниже пример того, как Python рассматривает объекты.

Равенство числовых значений

Для Python эти значения равны и имеют равные хеши, поэтому множество считает их одним элементом. Проверяйте размер, а не конкретный вид оставшегося представителя. Уникальность определяется равенством значений, а не только названием их типа.

11 / Операции над множествами

В кружок Python записались Alice и Bob, в кружок дизайна Bob и Clara. Нам нужно отвечать на разные вопросы о составах. Возьмём first = {"Alice", "Bob"} и second = {"Bob", "Clara"}. На схемах слева только Alice, в пересечении Bob, справа только Clara. Цветом отмечен результат операции.

Для задачи объединения используйте оператор |: слева и справа от него стоят множества. Та же операция доступна как метод union().

Объединение: кто есть хотя бы в одном кружке
first = {"Alice", "Bob"}
second = {"Bob", "Clara"}
result = first | second
print(sorted(result))
print(sorted(first.union(second)))
print(sorted(first))
Консоль
['Alice', 'Bob', 'Clara']
['Alice', 'Bob', 'Clara']
['Alice', 'Bob']

Объединение берёт все элементы обоих множеств без повторов. Bob включён один раз. Последняя строка показывает, что исходное ,first осталось прежним: результат нужно сохранить отдельно, если он понадобится дальше.

Для задачи пересечения используйте оператор &: слева и справа от него стоят множества. Та же операция доступна как метод intersection().

Пересечение: кто посещает оба кружка
first = {"Alice", "Bob"}
second = {"Bob", "Clara"}
result = first & second
print(sorted(result))
print(sorted(first.intersection(second)))
print(sorted(first))
Консоль
['Bob']
['Bob']
['Alice', 'Bob']

Пересечение оставляет только элементы, которые есть одновременно слева и справа. Последняя строка показывает, что исходное first осталось прежним: результат нужно сохранить отдельно, если он понадобится дальше.

Для задачи разности используйте оператор -: слева и справа от него стоят множества. Та же операция доступна как метод difference().

Разность: кто есть только в первом кружке
first = {"Alice", "Bob"}
second = {"Bob", "Clara"}
result = first - second
print(sorted(result))
print(sorted(first.difference(second)))
print(sorted(first))
Консоль
['Alice']
['Alice']
['Alice', 'Bob']

Разность берёт элементы слева и исключает всё, что есть справа. Направление здесь важно. Последняя строка показывает, что исходное first осталось прежним: результат нужно сохранить отдельно, если он понадобится дальше.

Для задачи симметрической разности используйте оператор ^: слева и справа от него стоят множества. Та же операция доступна как метод symmetric_difference().

Симметрическая разность: кто посещает ровно один кружок
first = {"Alice", "Bob"}
second = {"Bob", "Clara"}
result = first ^ second
print(sorted(result))
print(sorted(first.symmetric_difference(second)))
print(sorted(first))
Консоль
['Alice', 'Clara']
['Alice', 'Clara']
['Alice', 'Bob']

Симметрическая разность исключает общих участников, но оставляет участников любой из двух сторон. Последняя строка показывает, что исходное first осталось прежним: результат нужно сохранить отдельно, если он понадобится дальше.

Разность в двух направлениях
first = {"Alice", "Bob"}
second = {"Bob", "Clara"}
print(sorted(first - second))
print(sorted(second - first))
Консоль
['Alice']
['Clara']

first - second даёт Alice, а second - first даёт Clara. Для объединения, пересечения и симметрической разности перестановка этих двух наборов не меняет состав результата.

Операторы |, &, -, ^ требуют множества: set или frozenset. Соответствующие методы могут принимать и другие итерируемые объекты, например список. Это удобно, если новые регистрации ещё хранятся в списке.

Методы принимают список

12 / Сравнение множеств, ссылки и безопасный перебор

Допустим, для задания нужны Python и Git. Множество required является подмножеством available, если каждый требуемый навык есть в имеющемся наборе. Это проверка включения, а не сравнение размеров.

Подмножество и надмножество
required = {"python", "git"}
available = {"python", "git", "sql"}
print(required <= available)
print(required < available)
print(available >= required)
print(available > required)
print(required <= required)
print(required < required)
print({"java"} <= available)
Консоль
True
True
True
True
True
False
False

<= допускает равенство составов. < требует строгое включение: все элементы слева есть справа, и справа есть ещё хотя бы один. >= и > смотрят в обратном направлении и проверяют надмножество. Набор из одного "java" меньше по длине, но не является подмножеством available.

Те же проверки методами
required = {"python", "git"}
available = {"python", "git", "sql"}
print(required.issubset(available))
print(available.issuperset(required))
print(required.isdisjoint({"design", "music"}))
print(required.isdisjoint({"git", "design"}))
Консоль
True
True
True
False

issubset() соответствует <=, issuperset() соответствует >=. isdisjoint() отвечает, нет ли ни одного общего элемента: для дизайна и музыки вернётся True, при общем Git вернётся False.

Напомним, что присваивание backup = tags не создаёт копию. Оба имени ссылаются на одно множество. Если нужна отдельная версия состава, вызовите tags.copy().

Общая ссылка
tags = {"python"}
backup = tags
tags.add("git")
print(sorted(tags))
print(sorted(backup))
Консоль
['git', 'python']
['git', 'python']
Отдельное множество
tags = {"python"}
backup = tags.copy()
tags.add("git")
print(sorted(tags))
print(sorted(backup))
Консоль
['git', 'python']
['python']

В первом случае добавленный Git виден через оба имени. Во втором меняется только tags. Метод copy() создаёт новое внешнее множество. Это поверхностная копия, без создания новых копий каждого элемента.

Ошибка

Удаление из перебираемого множества

Удаление из перебираемого множества
scores = {8, 10, 12}
for score in scores:
    if score < 10:
        scores.remove(score)
Последняя строка сообщения об ошибке
RuntimeError: Set changed size during iteration

Изменение размера множества во время перебора нарушает обход. Добавление или удаление элементов в том же множестве не используйте как способ фильтрации. Соберите подходящие элементы в отдельное множество.

Пусть нужно оставить оценки не ниже 10. Цикл читает исходный набор, а add() меняет отдельный результат. После завершения обхода можно связать исходное имя с новым набором.

Безопасная фильтрация
scores = {8, 10, 12}
passed = set()
for score in scores:
    if score >= 10:
        passed.add(score)
print(sorted(scores))
scores = passed
print(sorted(scores))
Консоль
[8, 10, 12]
[10, 12]

До переприсваивания scores содержит все три оценки. После него имя обозначает результат из двух оценок. Исходный объект не менялся в процессе перебора.

13 / Неизменяемое множество frozenset

Определение

Фиксированный состав

frozenset является неизменяемым множеством уникальных хешируемых элементов. Оно поддерживает чтение и операции над множествами, но не добавление и удаление элементов на месте. У него нет индексов и гарантированного порядка вставки.

Например, набор разрешённых команд фиксируется при запуске программы. Для пустого набора вызовите frozenset(), для набора из готовых значений передайте итерируемый объект в frozenset(iterable). Отдельного литерала с фигурными скобками у этого типа нет.

Разрешённые команды
empty = frozenset()
allowed_commands = frozenset(["help", "start", "stop", "help"])
print(len(empty))
print(len(allowed_commands))
command = "start"
if command in allowed_commands:
    print("Allowed")
print("delete" not in allowed_commands)
for command in sorted(allowed_commands):
    print(command)

Повторный help не добавляет элемент. Как и у set, принадлежность проверяет in, а длину возвращает len(). Прямой for command in allowed_commands тоже допустим, но для определённого порядка вывода нужен sorted().

print(first.issuperset(["git"]))
print(first.isdisjoint(second))

Проверки включения и методы issubset(), issuperset(), isdisjoint() имеют тот же смысл. Для получения результата доступны union(), intersection(), difference() и symmetric_difference(). При операциях над этими двумя объектами результат тоже frozenset.

frozenset хешируем, поэтому его можно поместить во множество. Это полезно для подсчёта разных наборов выбранных тегов: порядок выбора внутри набора нам не нужен, зато разные составы нужно отличать.

Уникальные наборы тегов
selections = {
    frozenset(["python", "git"]),
    frozenset(["git", "python"]),
    frozenset(["web"]),
}

print(frozenset(["git", "python"]) in selections)

Ошибка

Обычный set не хешируем. Исправьте добавление на selections.add(frozenset(["python", "git"])).

Обычного set достаточно, когда список разрешённых команд должен расширяться во время работы и достаточно проверки принадлежности. frozenset полезен, когда состав должен оставаться фиксированным или целый набор должен стать элементом другого множества. Это выбор модели данных, а не дополнительная защита от переприсваивания переменной.

14 / Разбор законченной программы

Сравним участников кружков Python и дизайна. Запись (student_id, name) содержит ID и имя. В наших исходных данных одному ID соответствует одно имя. Разные люди могут иметь одинаковые имена, поэтому уникальность определяем по ID. Повтор одной записи не должен увеличивать число участников.

На первом этапе требуется получить ID из записей. Списки сохраняют записи и их порядок, кортеж объединяет поля записи, а множество собирает уникальные ID. При каждой итерации распаковываем запись и добавляем только её числовой идентификатор.

Один кружок
python_club = [(101, "Alice"), (102, "Bob"), (101, "Alice")]
python_ids = set()
for student_id, name in python_club:
    python_ids.add(student_id)
print(sorted(python_ids))
Консоль
[101, 102]

Имя name получает второе поле, но для сравнения составов оно не нужно. Повтор ID 101 не увеличил множество. Код предполагает согласованные записи; проверка противоречащих друг другу имён одного ID была бы отдельной задачей.

На втором этапе требуется ответить на вопросы о составах.

15 / Как выбрать коллекцию

Сначала сформулируйте, что важно сохранить: позиции, повторения или только состав. Затем решите, должен ли сам объект меняться. У этих коллекций разные задачи, поэтому универсального победителя нет.

Сравнение коллекций
ТипПорядокИндексыПовторыИзменяемостьЭлементыПример задачи
listСохраняетсяЕстьДопустимыДаЛюбые объектыПополняемые покупки, в том числе повторные
tupleСохраняетсяЕстьДопустимыНет; вложенные объекты могут менятьсяЛюбые объектыКоординаты точки с фиксированными позициями
setНет гарантии порядка вставкиНетРавные значения объединяютсяДаТолько хешируемыеУникальные ID посетителей за день
frozensetНет гарантии порядка вставкиНетРавные значения объединяютсяНетТолько хешируемыеФиксированные разрешённые значения

Конструкторы list(), tuple(), set() и frozenset() берут элементы из переданного итерируемого объекта. Требования целевого типа продолжают действовать: превращение списка списков в множество не сделает внутренние списки хешируемыми.

От последовательности к составу
values = [30, 10, 30, 20]
saved = tuple(values)
unique = set(saved)
fixed = frozenset(unique)
editable = set(fixed)
ordered = sorted(editable)
restored = list(saved)
print(saved)
print(ordered)
print(tuple(ordered))
print(restored)
print(len(list(fixed)))
Консоль
(30, 10, 30, 20)
[10, 20, 30]
(10, 20, 30)
[30, 10, 30, 20]
3

Переход list → tuple → list сохранил порядок и повторы исходных элементов. После перехода к set повтор 30 потерян, а исходный порядок больше не гарантируется. list(fixed) и tuple(unique) возможны, но берут порядок перебора множества, а прежнюю последовательность они не восстанавливают. sorted() создаёт новый порядок по возрастанию, а не возвращает старый.

Выбор по смыслу

visitors.add(103)

Покупки допускают повтор и дописываются. Координаты сохраняют роли x и y. Посетитель с тем же ID не увеличивает множество. Набор размеров используется для проверки допустимого значения и не изменяется на месте.
