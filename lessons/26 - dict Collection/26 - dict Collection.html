Вопрос

Постоянство хеша позволяет использовать объект в хеш-таблице.

Объекты, равные по ==, должны иметь одинаковый хеш.

У разных значений бывают одинаковые хеши. Такие совпадения называют коллизиями.

Кортеж со списком внутри неизменяем, но не хешируем.

Какие коллекции используют хешируемость?

Элементы множества должны быть хешируемыми.

У неизменяемого множества то же требование к элементам.

В списке могут находиться другие списки.

Кортеж может содержать список. Сам такой кортеж будет нехешируемым.

Вопрос

Какие значения хешируемы?

Какие значения можно поместить в множество? Выберите все подходящие варианты.

Целое число и строка хешируемы.

Оба элемента кортежа хешируемы.

Список не хешируем.

Изменяемое множество set не хешируемо.

Список внутри делает весь кортеж нехешируемым.

02 / Зачем нужен словарь

Представьте журнал: у каждого студента есть уникальный ID и оценка. Нужно узнать оценку студента 102. В списке пар придётся проверять записи, пока не встретится нужный ID. Кортеж в каждой записи содержит сначала ID, затем оценку; цикл распаковывает его в две переменные.

Поиск оценки в списке записей
records = [(101, 10), (102, 8), (103, 12)]
target_id = 102
for student_id, score in records:
    if student_id == target_id:
        print(score)
        break
Консоль
8

Если обращение по ID требуется постоянно, удобно сразу связать ID с оценкой. У словаря мы указываем известный ключ в квадратных скобках. Писать собственный цикл поиска для этого не нужно.

Поиск оценки по ключу
scores = {101: 10, 102: 8}
print(scores[102])
Консоль
8
Определение

Словарь dict

Словарь dict является изменяемой коллекцией пар «ключ: значение». Ключ помогает найти запись. Значение хранит связанные с ключом данные. Пара объединяет конкретный ключ и его значение.

В scores = {101: 10, 102: 8} ключ 101 обозначает ID студента, значение 10 обозначает его оценку, а 101: 10 является одной парой. Переменная scores ссылается на весь словарь.

Словарь scores как таблица
Ключ: ID студентаЗначение: оценка
10110
1028

Квадратные скобки знакомы по спискам, но их смысл зависит от коллекции. У списка внутри находится индекс, у словаря ключ. Даже числовой ключ не становится индексом.

Позиция списка и ключ словаря
items = [10, 8]
scores = {101: 10, 102: 8}
print(items[0])
print(scores[101])
Консоль
10
10

Оба выражения дали 10, но нашли его по разным правилам. items[0] берёт элемент на первой позиции. scores[101] ищет ключ 101. Выражение scores[0] не означает «первая оценка»: оно потребует отдельную запись с ключом 0.

03 / Создание словаря и основные свойства

Чтобы начать пустой журнал и добавлять записи позже, создайте {} или вызовите dict() без аргументов. Если данные известны заранее, используйте литерал: фигурные скобки с парами. Двоеточие соединяет ключ с его значением, запятая отделяет одну пару от другой.

Пустой словарь и готовые записи
empty_scores = {}
empty_profile = dict()
student = {"name": "Alice", "age": 18}
print(empty_scores)
print(empty_profile)
print(student)
Консоль
{}
{}
{'name': 'Alice', 'age': 18}

Список пар из предыдущего раздела можно преобразовать через dict(pairs). Каждый элемент должен содержать ровно две части: ключ и значение. Это та же структура кортежа, которую мы распаковывали в student_id, score. Сам вызов dict() выполняет построение словаря за нас.

Из списка кортежей в словарь
pairs = [(101, 10), (102, 8)]
student_id, score = pairs[0]
scores = dict(pairs)
print(student_id, score)
print(scores)
Консоль
101 10
{101: 10, 102: 8}

Для строковых ключей, которые можно записать как имена аргументов, есть короткая форма dict(name="Alice", age=18). Здесь слева от = стоят имена аргументов, а не переменные, которые нужно заранее создать. В словаре они становятся строками "name" и "age". Для числовых ключей или ключа с пробелом удобнее литерал.

Строковые ключи из имён аргументов
student = dict(name="Alice", age=18)
print(student)
Консоль
{'name': 'Alice', 'age': 18}

У каждого ключа в словаре только одно текущее значение. Если равный ключ указан повторно, последнее значение заменяет предыдущее. Значения разных ключей могут совпадать: два студента вполне могут получить одинаковую оценку.

Повтор ключа и повтор значения
scores = {101: 10, 102: 8, 101: 12, 103: 8}
print(scores)
print(len(scores))
Консоль
{101: 12, 102: 8, 103: 8}
3

Запись 101 теперь содержит 12. Ключей три, поэтому len(scores) возвращает 3: длина словаря равна количеству пар. Два значения 8 у разных ключей не мешают друг другу. Условие if data проверяет, есть ли в словаре хотя бы одна пара, независимо от истинности её значения.

Ниже приведён пример того, как можно проверять на пустые словари.

Есть ли записи в журнале
data = {101: 0}
if data:
    print("Records:", len(data))
else:
    print("No records")

data = {}
if data:
    print("Records:", len(data))
else:
    print("No records")
Консоль
Records: 1
No records

Словарь сохраняет порядок добавления ключей. Этот порядок виден при печати и переборе. Обновление значения оставляет ключ на прежнем месте, а удаление ключа и последующее добавление помещают его в конец. Ни сортировка, ни доступ по позиции из этого не следуют.

Порядок вставки
data = {102: 8, 101: 10}
data[102] = 9
print(data)
del data[102]
data[102] = 12
print(data)
Консоль
{102: 9, 101: 10}
{101: 10, 102: 12}

В строке data[102] = 9 мы записали новое значение по прежнему ключу. Команда del data[102] удалила пару целиком, поэтому следующая запись того же ключа стала новым добавлением. Подробно разберём эти операции в разделах 07 и 09.

04 / Какие значения подходят для ключей

Словарь использует хешируемость для поиска по ключу. Ключ должен иметь неизменный хеш, а равные ключи должны иметь равные хеши. Значение словаря таким ограничением не связано: в качестве значения можно сохранить список, множество или другой словарь.

Строка, число, кортеж и frozenset как ключи
data = {
    "name": "Alice",
    101: [8, 10],
    (2, 3): "desk",
    frozenset({"read", "write"}): "editor",
}
print(data["name"])
print(data[101])
print(data[(2, 3)])
print(data[frozenset({"write", "read"})])
Консоль
Alice
[8, 10]
desk
editor

Кортеж (2, 3) подходит, потому что оба его элемента хешируемы. frozenset тоже хешируем: он неизменяем и состоит из хешируемых элементов. Порядок элементов множества не важен, поэтому оба набора прав из примера дают один и тот же ключ. В значении ключа 101 свободно хранится изменяемый список.

Ошибка

Список нельзя использовать как ключ

Ошибка: ключ-список
data = {[2, 3]: "desk"}
Ошибка (последняя строка)
TypeError: cannot use 'list' as a dict key (unhashable type: 'list')

Список не хешируем. Для пары координат используйте кортеж (2, 3): data = {(2, 3): "desk"}.

Ошибка

Множество нельзя использовать как ключ

Ошибка: ключ-множество
data = {{"read", "write"}: "editor"}
Ошибка (последняя строка)
TypeError: cannot use 'set' as a dict key (unhashable type: 'set')

Здесь внутренние фигурные скобки создают set. Для набора прав используйте frozenset({"read", "write"}), как в рабочем примере выше.

Ошибка

Неизменяемость не гарантирует хешируемость

Ошибка: список внутри кортежа
data = {(2, [3]): "desk"}
Ошибка (последняя строка)
TypeError: cannot use 'tuple' as a dict key (unhashable type: 'list')

Сам кортеж менять нельзя, но его элемент является списком. Вложенный список делает кортеж нехешируемым. Если по смыслу нужны вложенные координаты, замените список кортежем: (2, (3,)).

Здесь показаны сообщения Python 3.14. В других версиях формулировка может быть короче, например TypeError: unhashable type: 'list'. Причина та же: ключ или один из его элементов не хешируем.

Тип ключа имеет значение. Строка "101" не равна числу 101, поэтому эти ключи создают разные записи. Это особенно важно после input(), который возвращает строку: для поиска по числовому ID сначала требуется int() при корректном числовом вводе.

Строковый и числовой ID
data = {"101": "text ID", 101: "numeric ID"}
print(len(data))
print(data["101"])
print(data[101])
Консоль
2
text ID
numeric ID

Но разные типы не всегда означают разные ключи. Числа 1 и 1.0, а также логическое значение True равны друг другу и имеют одинаковый хеш. Словарь считает их одним ключом.

Равные числовые ключи
data = {1: "integer", 1.0: "float", True: "boolean"}
print(len(data))
print(data[1])
print(data[1.0])
print(data[True])
Консоль
1
boolean
boolean
boolean

05 / Чтение значения и проверка наличия ключа

Чтобы показать имя из профиля, напишите имя словаря и ключ в квадратных скобках: student["name"]. Python находит пару с таким ключом и возвращает её значение. Строковый ключ нужно заключить в кавычки. Без кавычек name означало бы отдельную переменную.

Чтение имени
student = {"name": "Alice", "age": 18}
print(student["name"])
Консоль
Alice
Ошибка

Запрошенной записи нет

Ошибка: отсутствующий город
student = {"name": "Alice", "age": 18}
print(student["city"])
Ошибка (последняя строка)
KeyError: 'city'

Ошибка KeyError сообщает об отсутствии запрошенного ключа. При обычном запуске программа остановится на этой строке. Исправление зависит от задачи: добавить обязательную запись или заранее проверить наличие необязательной.

Выражение key in data проверяет наличие ключа, а key not in data его отсутствие. Проверка не читает значение и не меняет словарь. Метод values() даёт доступ к значениям: чтобы искать среди них, пишут value in data.values().

Где именно ищет in
student = {"name": "Alice", "age": 18}
print("name" in student)
print("city" not in student)
print("Alice" in student)
print("Alice" in student.values())
Консоль
True
True
False
True

Alice есть среди значений, но ключа "Alice" нет. Поэтому третья строка вывода содержит False, а четвёртая True. Для необязательного поля можно сначала проверить ключ и только затем читать его значение. В следующем примере цикл позволяет проверить сразу оба случая.

Отдельные ветки для найденного и отсутствующего ключа
student = {"name": "Alice", "age": 18}
for key in ["name", "city"]:
    if key in student:
        print(key, student[key])
    else:
        print(key, "not found")
Консоль
name Alice
city not found
Ошибка

Истинность значения не проверяет наличие ключа

Логическая ошибка: нулевая оценка
scores = {101: 0}
if scores[101]:
    print("Record exists")
else:
    print("No record")
Консоль
No record

Ключ 101 существует, но scores[101] вернул 0. Условие посчитало ноль ложным и выбрало неверное сообщение. То же происходит со значениями False и "". При отсутствующем ключе чтение вообще вызовет KeyError ещё до выбора ветки.

Верно

Проверяем наличие ключа

Проверка наличия ключа
scores = {101: 0}
if 101 in scores:
    print("Record exists:", scores[101])
else:
    print("No record")
Консоль
Record exists: 0

Разделяйте вопросы «существует ли запись?» и «истинно ли её значение?». Для первого используйте in. Для второго читайте значение, когда наличие ключа уже известно.

06 / Безопасное чтение через get()

Город в профиле может быть не заполнен. Если в этом случае достаточно показать запасной текст, удобно вызвать student.get("city", "Unknown"). Первый аргумент является ключом, второй значением по умолчанию. Метод возвращает найденное значение; запасной вариант используется только при отсутствии ключа.

Получаем обязательное и необязательное поле
student = {"name": "Alice"}
print(student.get("name"))
print(student.get("city"))
print(student.get("city", "Unknown"))
print(student)
Консоль
Alice
None
Unknown
{'name': 'Alice'}

Без второго аргумента значение по умолчанию равно None. Здесь None означает, что метод не нашёл запись. Последняя строка показывает: get() ничего не добавил в профиль. Безопасность относится к отсутствию ключа. Переданный ключ всё равно должен быть хешируемым.

Существующие ложные значения сохраняются
data = {"score": 0, "active": False, "city": "", "phone": None}
print(data.get("score", 100))
print(data.get("active", True))
print("[" + data.get("city", "Unknown") + "]")
print(data.get("phone", "Unknown"))
Консоль
0
False
[]
None

Каждый ключ существует, поэтому ни один запасной вариант не использован. Скобки в выводе [] помогают увидеть пустую строку между ними. get() не проверяет, насколько значение полезно для нашей задачи: если нужно заменить пустой текст, это отдельное правило программы.

Решим одну задачу этими способами. Для профиля с обязательным городом можно сразу использовать скобки. Для необязательного города проверка in позволит, например, отдельно сообщить об отсутствии. get() сократит код, когда требуется просто напечатать текст.

Одна задача, три способа чтения
student = {"name": "Alice", "city": "Baku"}
print(student["city"])

if "city" in student:
    print(student["city"])
else:
    print("Unknown")

print(student.get("city", "Unknown"))
Консоль
Baku
Baku
Baku

Один результат None не доказывает отсутствие ключа: такое значение могло быть сохранено намеренно. Чтобы отличить «телефон ещё не указан» от «поля телефона вообще нет», дополнительно проверьте in.

Сохранённый None и отсутствующая запись
student = {"phone": None}
print(student.get("phone"))
print(student.get("city"))
print("phone" in student)
print("city" in student)
Консоль
None
None
True
False
Верный подход

Разбор: необязательный город

Нужно вывести город из каждого профиля. Если ключа нет, выводим Unknown. Если сохранена пустая строка, оставляем её пустой. Сначала предскажите результат для трёх профилей, затем запустите пример.

Город есть, отсутствует или пуст
profiles = [
    {"name": "Alice", "city": "Baku"},
    {"name": "Bob"},
    {"name": "Carol", "city": ""},
]
for profile in profiles:
    city = profile.get("city", "Unknown")
    print(profile["name"], "[" + city + "]")
Консоль
Alice [Baku]
Bob [Unknown]
Carol []

У Alice найден Baku. У Bob нет ключа, поэтому получен Unknown. У Carol ключ есть, поэтому возвращена пустая строка. Имя читаем через [], поскольку оно задано в каждом профиле.

07 / Добавление и изменение записей

Чтобы записать оценку, используйте data[key] = value. Python сначала вычисляет правую часть, затем сохраняет значение по ключу. Если ключа не было, появится новая пара и длина увеличится. Если ключ уже был, изменится только его значение.

Обновляем оценку и добавляем студента
scores = {101: 10, 102: 8}
scores[102] = 9
print(scores, len(scores))
scores[103] = 12
print(scores, len(scores))
Консоль
{101: 10, 102: 9} 2
{101: 10, 102: 9, 103: 12} 3
До и после записи по ключу
ШагСодержимое scoresДлина
До изменения{101: 10, 102: 8}2
scores[102] = 9{101: 10, 102: 9}2: заменили значение
scores[103] = 12{101: 10, 102: 9, 103: 12}3: добавили пару

Если количество товара нужно увеличить, а не заменить заранее известным числом, используйте сокращённое присваивание. stock["pen"] += 1 сначала читает старое значение, прибавляет единицу и записывает результат по тому же ключу.

Увеличиваем количество товара
stock = {"pen": 4}
stock["pen"] += 1
print(stock)
Консоль
{'pen': 5}
Ошибка

Для += запись должна существовать

Ошибка: увеличение отсутствующего счётчика
stock = {}
stock["pen"] += 1
Ошибка (последняя строка)
KeyError: 'pen'

Читать старое значение пока неоткуда. Сначала создайте stock["pen"] = 0 или используйте stock["pen"] = stock.get("pen", 0) + 1. Во втором варианте отсутствующий счётчик начинается с нуля.

Словарь изменяем, поэтому важно помнить о ссылках. Присваивание alias = scores не копирует пары. Обе переменные получают доступ к одному объекту, как это было со списками.

Два имени одного словаря
scores = {101: 10}
alias = scores
alias[101] = 12
print(scores)
print(alias is scores)
Консоль
{101: 12}
True
Обратите внимание

У dict нет метода set()

Для записи используйте data[key] = value. Вызова data.set(key, value) у словаря нет. Метод словаря setdefault() решает другую задачу: добавляет значение только при отсутствии ключа. Его разберём дальше.

08 / Обновление через update() и значение через setdefault()

10 / Перебор keys(), values() и items()

Для печати всех ID достаточно обычного цикла for student_id in scores. Перебор самого словаря даёт ключи, по одному на каждом шаге. Форма for student_id in scores.keys() делает тот же выбор явным: метод keys() предоставляет представление ключей.

11 / Порядок, сравнение и безопасный перебор

В журнале записи могут появляться в любом порядке ID. Обычный цикл сохранит порядок вставки. Для отчёта по возрастанию ID используйте sorted(scores): функция собирает ключи в новый отсортированный список, а словарь не меняет.

Порядок вставки и сортировка ключей
scores = {103: 12, 101: 10, 102: 8}
print("Insertion order:")
for student_id in scores:
    print(student_id, scores[student_id])
print("Sorted order:")
for student_id in sorted(scores):
    print(student_id, scores[student_id])
print(list(scores))
Консоль

101 10
102 8
Sorted order:

102 8
103 12
[103, 101, 102]

В примере все ключи являются числами. Для обычной сортировки выбирайте однородные сравнимые ключи: например, только целые числа или только строки. Смешанные ключи вроде 101 и "name" нельзя автоматически упорядочить таким же способом. Последняя строка подтверждает, что порядок самого словаря остался прежним.

У словарей оператор == сравнивает соответствие ключей и значений независимо от порядка вставки. Оператор is отвечает на другой вопрос: являются ли две ссылки одним и тем же объектом.

Равные данные и общий объект

print(first is alias)

False
True

first и second содержат одинаковые пары, поэтому равны. Они созданы отдельно, поэтому не являются одним объектом. alias и first ссылаются на один словарь. Для сравнения содержимого используйте ==.

Решим задачу удаления товаров с нулевым остатком в два этапа. Сначала обойдём пары и соберём названия ненужных товаров в список. Затем пройдём по этому списку и удалим записи из словаря.

Безопасное удаление отдельным циклом
stock = {"pen": 0, "book": 3, "pencil": 0}
to_remove = []
for product, quantity in stock.items():
    if quantity == 0:
        to_remove.append(product)

for product in to_remove:
    del stock[product]
print(stock)
Консоль
{'book': 3}

Первый цикл не меняет состав stock. Во втором источником перебора служит отдельный список to_remove, поэтому удаление из stock не нарушает этот обход. Менять значение уже существующего ключа при переборе допустимо: набор ключей при этом остаётся прежним. Но добавление и удаление записей выносите в отдельный этап.

Ошибка

Не удаляйте ключи во время перебора этого словаря

Ошибка: размер словаря изменился
stock = {"pen": 0, "book": 3}

        del stock[product]
Ошибка (последняя строка)

Цикл начал обход одного набора ключей, но внутри него этот набор изменился. Добавление новых ключей создаёт ту же проблему. Не полагайтесь на конкретный момент появления ошибки: отделяйте отбор от изменения состава словаря.

12 / Копирование и первое знакомство с вложенными данными

Перед изменением профиля может понадобиться сохранить исходные данные. Присваивание backup = student создаёт только ещё одну ссылку. Методы student.copy() и вызов dict(student) создают новые словари, копируя пары на верхнем уровне.

Общая ссылка и две поверхностные копии

Поверхностная копия не копирует вложенные объекты. Новый словарь получает ссылки на те же значения. Если значение является изменяемым списком, оба словаря пока ссылаются на один список. Новым стал только внешний контейнер.

13 / Разбор программы подсчёта слов

Задача: посчитать, сколько раз встретилось каждое слово в строке "Red blue red green blue red". Слова разделены пробелами, пунктуации нет. Регистр не должен создавать разные счётчики: Red и red считаем одним словом.

Сначала lower() переводит буквы в нижний регистр. Затем split() без аргументов разделяет строку по пробельным символам и возвращает список слов. Пустая строка или строка из пробелов даст пустой список.

Подготовка слов
text = "Red blue red green blue red"
words = text.lower().split()
print(words)
print("".lower().split())
Консоль

[]

Ключом словаря counts будет слово, значением целое число его повторений. Начинаем с пустого словаря. Для первого появления слова создаём счётчик 1. Для каждого следующего появления увеличиваем уже существующий счётчик на 1.

Полная программа с проверкой in
text = "Red blue red green blue red"
words = text.lower().split()
counts = {}

for word in words:
    if word in counts:
        counts[word] += 1
    else:
        counts[word] = 1

if counts:
    for word, count in counts.items():
        print(word, count)
else:
    print("No words")

green 1

2blueКлюча нет: записать 1{"red": 1, "blue": 1}

4greenКлюча нет: записать 1{"red": 2, "blue": 1, "green": 1}
5blueКлюч есть: 1 + 1{"red": 2, "blue": 2, "green": 1}
6redКлюч есть: 2 + 1{"red": 3, "blue": 2, "green": 1}

Вместо двух веток можно прочитать прежний счётчик через get() с нулём по умолчанию. Выражение counts.get(word, 0) + 1 сначала берёт текущее количество или 0, затем прибавляет 1. Левая часть counts[word] = ... сохраняет результат. Сам get() по-прежнему ничего не добавляет.

Та же программа с get()
text = "Red blue red green blue red"
words = text.lower().split()
counts = {}

for word in words:
    counts[word] = counts.get(word, 0) + 1

if counts:
    for word, count in counts.items():
        print(word, count)
else:
    print("No words")
Консоль
red 3
blue 2
green 1

Оба решения выводят слова в порядке первого появления: red, blue, green. Частота не влияет на порядок ключей.

14 / Разбор программы учёта товаров

Задача: хранить остатки товаров, добавлять новые позиции, пополнять количество и списывать товар при достаточном остатке. Используем плоский словарь stock: английское название товара служит ключом, неотрицательное целое количество значением. Например, {"pen": 5, "book": 0} означает пять ручек и известную позицию book с нулевым остатком.

В примерах названия являются непустыми строками в нижнем регистре, а количество операции целым числом больше нуля.

Первое действие: зарегистрировать новый товар с количеством 0. Сначала проверим отсутствие ключа, чтобы случайно не обнулить уже существующий остаток. Затем можно сделать первую поставку.

Добавляем товар без потери старого остатка
stock = {"pen": 5}
product = "pencil"
if product not in stock:
    stock[product] = 0
print(stock)
Консоль
{'pen': 5, 'pencil': 0}

Для пополнения известного товара читаем его количество и прибавляем поставку. Проверка in устанавливает наличие записи, после неё [] безопасно читает старый остаток. Неизвестную позицию этот фрагмент не создаёт автоматически.

Пополняем количество
stock = {"pen": 5}
product = "pen"
quantity = 3
if quantity <= 0:
    print("Quantity must be positive")
elif product in stock:
    stock[product] += quantity
    print(product, stock[product])
else:
    print("Unknown product")
Консоль
pen 8

Для справочного вывода можно использовать stock.get(product, 0): он покажет ноль, если товара нет. Но такой результат объединяет два разных случая. Для регистрации товара и продажи нужно различать отсутствие позиции и нулевой остаток, поэтому там выбираем in.

Неизвестный товар и известный товар с нулевым остатком
stock = {"pen": 5, "book": 0}
for product in ["book", "eraser"]:
    print(product, product in stock, stock.get(product, 0))
Консоль
book True 0
eraser False 0

Списание требует последовательных проверок. Сначала количество должно быть положительным, затем товар должен существовать. Только после этого читаем остаток. При нуле сообщаем об отсутствии на складе, при недостатке не меняем словарь, а при достаточном количестве вычитаем продажу.

Одна успешная продажа
stock = {"pen": 5}
product = "pen"
quantity = 2
if quantity <= 0:
    print("Quantity must be positive")
elif product not in stock:
    print("Unknown product")
elif stock[product] == 0:
    print("Out of stock")
elif quantity > stock[product]:
    print("Not enough stock")
else:
    stock[product] -= quantity
    print("Sold:", product, quantity)
print(stock)
Консоль
Sold: pen 2
{'pen': 3}

Полная программа ниже объединяет регистрацию, пополнение и несколько заявок на продажу. Каждая заявка представлена знакомым кортежем (product, quantity), а цикл распаковывает его. Все количества целые, проверка положительности остаётся частью обработки операции.

Полная программа учёта товаров
stock = {"pen": 5, "book": 0}

new_product = "pencil"
if new_product not in stock:
    stock[new_product] = 0
print("Added:", new_product, stock[new_product])

delivery_product = "pen"
delivery_quantity = 3
if delivery_quantity <= 0:
    print("Quantity must be positive")
elif delivery_product in stock:
    stock[delivery_product] += delivery_quantity
    print("Restocked:", delivery_product, stock[delivery_product])
else:
    print("Unknown product:", delivery_product)

requests = [("eraser", 1), ("book", 1), ("pen", 9), ("pen", 2)]
for product, quantity in requests:
    if quantity <= 0:
        print("Quantity must be positive")
    elif product not in stock:
        print("Unknown product:", product)
    elif stock[product] == 0:
        print("Out of stock:", product)
    elif quantity > stock[product]:
        print("Not enough stock:", product, stock[product])
    else:
        stock[product] -= quantity
        print("Sold:", product, quantity)

print("Final stock:")
for product, quantity in stock.items():
    print(product, quantity)
Консоль

Restocked: pen 8
Unknown product: eraser
Out of stock: book

Sold: pen 2
Final stock:
pen 6
book 0
pencil 0

15 / Сравнение коллекций

Коллекцию выбирают по тому, как программа будет использовать данные. Нужно ли сохранять порядок и повторы? Менять содержимое? Искать по позиции или по смысловому ключу? Ответы помогают выбрать подходящий тип.

Какая коллекция подходит задаче
ТипКороткая задачаПочему подходитОграничение
strХранить имя товара "pen"Текст, поиск подстрок и строковые методы.Строка неизменяема, а изменение создаёт новую строку.
listХранить последовательность заявок на продажуСохраняет порядок и повторы, позволяет добавлять и менять элементы.Доступ по позиции, но поиск нужной записи может требовать перебора.
tupleПередать пару ("pen", 2)Фиксированная структура, удобная распаковка.Элементы самого кортежа заменить нельзя, но вложенный список может меняться.
setСобрать уникальные названия купленных товаровУбирает повторы, даёт проверку принадлежности и операции множеств.Нет индексов и гарантированного порядка вставки, а элементы хешируемы.

Не пытайтесь заменить все коллекции словарём. Тексту нужен str, очереди действий обычно подходит list, фиксированной паре tuple, уникальным элементам set или frozenset. dict выбирайте, когда задача формулируется как «получить значение по известному ключу».
