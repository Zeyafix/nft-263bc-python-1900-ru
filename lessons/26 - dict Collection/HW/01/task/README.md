# Задание 01. Элемент по индексу

Создайте программу `main.py`. Используйте исходные данные:

```python
places = ("harbor", "museum", "park", "library", "station")
```

Запросите индекс от 1 до 4 включительно. Получите соответствующий элемент кортежа положительным индексом и выведите его. Индекс 1 означает второй элемент.

## Пример 1

```text
Enter an index from 1 to 4: 1
Place: museum
```

## Пример 2

```text
Enter an index from 1 to 4: 4
Place: station
```
