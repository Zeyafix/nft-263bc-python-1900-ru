# Задание 02. Обмен двух элементов

Создайте программу `main.py`. Используйте исходные данные:

```python
tools = ("brush", "pencil", "ruler", "eraser")
```

Запросите два индекса от 0 до 3 включительно. Преобразуйте кортеж в list, поменяйте элементы с этими индексами местами и преобразуйте результат обратно в tuple. Выведите исходный и новый кортежи целиком. Одинаковые индексы допустимы: данные сохраняются.

## Пример 1

```text
Enter the first index: 0
Enter the second index: 3

Original: ('brush', 'pencil', 'ruler', 'eraser')
Updated: ('eraser', 'pencil', 'ruler', 'brush')
```

## Пример 2

```text
Enter the first index: 1
```
