# Задание 03. Знаки показаний

Создайте программу `main.py`. Используйте исходные данные:

```python
readings = (0, -3, 7, 7, -1, 0, 2, -3)
```

Пройдите по кортежу и подсчитайте отдельно положительные, отрицательные и нулевые значения. Выведите три количества в этом порядке. Повторяющиеся показания учитывайте каждый раз.

## Пример 1

```text
Positive: 3
Negative: 3
Zero: 2
```
