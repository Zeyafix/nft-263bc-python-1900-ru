# Задание 05. Участники клуба

Создайте программу `main.py`. Используйте исходные данные:

```python
members = {"Liam", "Emma", "Olivia"}
```

Запросите имя: непустое английское слово с учётом регистра. Проверьте его через in и not in. Выведите два ответа True/False: присутствует ли имя и отсутствует ли оно. Затем выведите каждого участника отдельной строкой в любом порядке.

## Пример 1

```text
Enter a name: Emma

Present: True
Absent: False

Member: Emma
Member: Liam
Member: Olivia
```
