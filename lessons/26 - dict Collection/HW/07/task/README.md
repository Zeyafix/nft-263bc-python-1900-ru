# Задание 07. Два направления разности

Создайте программу `main.py`. Используйте исходные данные:

```python
first = {"tea", "milk", "bread"}
second = {"milk", "eggs", "rice"}
```

Получите через - элементы только first, затем только second. Выведите две коллекции в этом порядке. Порядок внутри каждой свободный.

## Пример 1

```text
Only first: ['bread', 'tea']
Only second: ['eggs', 'rice']
```
