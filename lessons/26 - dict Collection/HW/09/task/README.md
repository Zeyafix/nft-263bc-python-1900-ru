# Задание 09. Значения выше порога

Создайте программу `main.py`. Используйте исходные данные:

```python
values = frozenset((-4, 0, 3, 6, 9))
```

Запросите порог: число без дробной части. Пройдите по frozenset и найдите сумму и количество только тех элементов, которые строго больше порога. Выведите сумму, затем количество. Если подходящих значений нет, оба результата равны 0.

## Пример 1

```text
Enter a threshold: 3

Sum above threshold: 15
Count above threshold: 2
```

## Пример 2

```text
Enter a threshold: 9

Sum above threshold: 0
Count above threshold: 0
```
