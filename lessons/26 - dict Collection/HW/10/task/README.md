# Задание 10. Ключ не равен позиции

Создайте программу `main.py`. 

Создайте dict: ключу 104 соответствует "camera", ключу 207 — "tripod", ключу 315 — "lamp" именно в таком порядке. Запросите один из этих трёх номеров и получите название через data[key]. Выведите найденное название. Имя переменной словаря можно выбрать другое.

## Пример 1

```text
Enter an equipment number: 104
Equipment: camera
```

## Пример 2

```text
Enter an equipment number: 207
Equipment: tripod
```
