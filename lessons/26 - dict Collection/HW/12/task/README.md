# Задание 12. Отдельный список ключей

Создайте программу `main.py`. Используйте исходные данные:

```python
data = {"west": 4, "east": 2, "north": 4}
```

Получите ключи через keys(), сохраните их в отдельный список и выведите его целиком в порядке записей исходного словаря.

## Пример 1

```text
Keys: ['west', 'east', 'north']
```
