# Задание 13. Значения с повторами

Создайте программу `main.py`. Используйте исходные данные:

```python
data = {"west": 4, "east": 0, "north": 4, "south": 9}
```

Получите значения через values(), сохраните их в отдельный список и выведите его целиком в порядке записей словаря. Повторяющиеся значения разных ключей должны остаться.

## Пример 1

```text
Values: [4, 0, 4, 9]
```
