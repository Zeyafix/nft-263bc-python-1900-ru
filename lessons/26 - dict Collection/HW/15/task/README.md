# Задание 15. Ключи выше порога

Создайте программу `main.py`. Используйте исходные данные:

```python
data = {"oak": 6, "pine": 3, "birch": 6, "maple": 0}
```

Запросите порог: число без дробной части. Переберите словарь и выведите отдельными строками ключи, чьи значения строго больше порога, в порядке записей. Если таких ключей нет, сообщите об этом. Имена переменных можно выбрать другие.

## Пример 1

```text
Enter a threshold: 3

Key: oak
Key: birch
```

## Пример 2

```text
Enter a threshold: 6

No matching keys
```
