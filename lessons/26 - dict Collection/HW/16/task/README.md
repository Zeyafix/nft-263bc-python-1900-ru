# Задание 16. Сумма и нули

Создайте программу `main.py`. Используйте исходные данные:

```python
batches = [{"a": 0, "b": 5, "c": -2, "d": 0}, {}, {"x": 0}]
```

Для каждого словаря из batches пройдите по значениям, найдите сумму значений и число нулей. Выведите два числа на одной строке для каждого словаря, сохраняя порядок batches. Для пустого словаря оба результата равны 0.

## Пример 1

```text
Total and zeros: 3 2
Total and zeros: 0 0
Total and zeros: 0 1
```
