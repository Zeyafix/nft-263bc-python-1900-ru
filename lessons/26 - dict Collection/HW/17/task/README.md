# Задание 17. Отчёт с удвоением

Создайте программу `main.py`. Используйте исходные данные:

```python
data = {"first": 3, "second": 0, "third": -4}
```

Пройдите по парам словаря. Для каждой записи выведите на одной строке ключ, исходное значение и удвоенное значение. Соблюдайте порядок записей. Словарь не изменяйте. После отчёта выведите его целиком.

## Пример 1

```text
Entry: first 3 6
Entry: second 0 0
Entry: third -4 -8
Original: {'first': 3, 'second': 0, 'third': -4}
```
