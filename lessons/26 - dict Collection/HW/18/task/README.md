# Задание 18. Добавить без перезаписи

Создайте программу `main.py`. Используйте исходные данные:

```python
prices = {"tea": 0, "cake": 7}
```

Запросите товар (непустое английское слово), затем цену от 0 без дробной части. Если ключа ещё нет, добавьте запись присваиванием по ключу. Если есть — сохраните прежнее значение. Сообщите результат действия и выведите весь словарь в порядке записей. Новая запись идёт в конце.

## Пример 1

```text
Enter a product: milk
Enter a price: 4
Product added

Prices: {'tea': 0, 'cake': 7, 'milk': 4}
```

## Пример 2

```text
Enter a product: tea
Enter a price: 5
Product already exists

Prices: {'tea': 0, 'cake': 7}
```
