# Задание 19. Изменить существующую запись

Создайте программу `main.py`. Используйте исходные данные:

```python
prices = {"tea": 0, "cake": 7}
```

Запросите название товара, затем новую цену от 0 без дробной части. Замените значение только существующего ключа. При отсутствии ключа сообщите об этом и ничего не добавляйте. При успехе также сообщите результат. Выведите весь словарь в исходном порядке записей.

## Пример 1

```text
Enter a product: tea
Enter a new price: 5
Price updated

Prices: {'tea': 5, 'cake': 7}
```

## Пример 2

```text
Enter a product: milk
Enter a new price: 3
Product not found

Prices: {'tea': 0, 'cake': 7}
```
