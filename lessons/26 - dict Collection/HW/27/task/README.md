# Задание 27. Бюджет по категориям

Создайте программу `main.py`. Используйте исходные данные:

```python
expenses = {"food": 120, "travel": 40, "books": 40, "games": 0}
```

Запросите лимит: сумму от 0 без дробной части. Покажите одной коллекцией категории, затем одной коллекцией все суммы в порядке записей, включая повторы и нули. Выведите общий расход и коллекцию категорий, расход по которым строго выше лимита, в порядке записей. Если превышений нет, последняя коллекция пуста.
