# Задание 28. Склад после продажи

Создайте программу `main.py`. Используйте исходные данные:

```python
stock = {"pen": 8, "book": 3, "ruler": 0}
```

Запросите товар, затем количество для продажи: от 1 без дробной части. Если товар есть и остатка достаточно, уменьшите его на проданное количество и сообщите об успехе. При нехватке или отсутствии товара сообщите конкретную причину, не меняя склад. Выведите весь склад в порядке записей. Товар с нулевым остатком остаётся в каталоге.

## Пример 1

```text
Enter a product: pen
Enter a sale quantity: 2
Sale completed

Stock: {'pen': 6, 'book': 3, 'ruler': 0}
```

## Пример 2

```text
Enter a product: book
Enter a sale quantity: 3
Sale completed

Stock: {'pen': 8, 'book': 0, 'ruler': 0}
```
