# Задание 30. Частота слов

Создайте программу `main.py`. 

Запросите строку английских слов в нижнем регистре без пунктуации. Слова разделены одним или несколькими пробелами. Пробелы по краям и пустая строка допустимы. Составьте словарь числа вхождений каждого слова. Покажите словарь целиком, затем каждое слово и его количество отдельной строкой в порядке первого появления. Для пустого ввода покажите пустой словарь и сообщение об отсутствии слов.

## Пример 1

```text
Enter words:  red  blue red green red 

Counts: {'red': 3, 'blue': 1, 'green': 1}
Word: red 3
Word: blue 1
Word: green 1
```

## Пример 2

```text
Enter words: 

Counts: {}
No words
```
