# Задание 31. Итоги голосования

Создайте программу `main.py`. 

Запросите имена выбранных кандидатов одной строкой через пробел. Каждое имя — одно английское слово, регистр значим. Каждое появление имени — отдельный голос. Пустая строка означает отсутствие голосов. Составьте и покажите словарь количества голосов в порядке первого появления имён. Затем покажите максимальное число голосов и всех победителей одной коллекцией в том же порядке. При отсутствии голосов максимум равен 0, коллекция победителей пуста.

## Пример 1

```text
Enter votes: Emma Liam Olivia Liam Emma

Votes: {'Emma': 2, 'Liam': 2, 'Olivia': 1}
Maximum: 2
Winners: ['Emma', 'Liam']
```

## Пример 2

```text
Enter votes: 

Votes: {}
Maximum: 0
Winners: []
```
