# Задание 32. Стоимость корзины

Создайте программу `main.py`. Используйте исходные данные:

```python
prices = {"tea": 2.50, "bread": 1.20, "sample": 0.00}
cart = {"tea": 3, "rice": 2, "bread": 2, "sample": 1}
```

Для каждого товара корзины с известной ценой выведите название и стоимость позиции (цена за единицу × количество), в порядке корзины. Если цены нет, сообщите название неизвестного товара вместо стоимости и не включайте его в итог. В конце покажите общую стоимость известных позиций. Все денежные результаты — с двумя знаками после точки. Нулевая цена считается известной. Исходные данные не изменяйте.

## Пример 1

```text
Item cost: tea 7.50
Price not found: rice
Item cost: bread 2.40
Item cost: sample 0.00
Total: 9.90
```
