# Задание 33. Остаток бюджета

Создайте программу `main.py`. Используйте исходные данные:

```python
planned = {"food": 100, "travel": 50, "books": 0, "games": 20}
actual = {"food": 120, "travel": 50, "books": 0, "gifts": 30}
```

Покажите остаток для каждой категории, которая встречается хотя бы в одном словаре: запланированная сумма минус фактическая. Если суммы нет, считайте её равной нулю. Сначала идут категории planned в исходном порядке, затем новые категории actual в его порядке. Каждую категорию и остаток выведите отдельной строкой. Отрицательный остаток означает перерасход. Исходные данные не изменяйте.

## Пример 1

```text
Balance: food -20
Balance: travel 0
Balance: books 0
Balance: games 20
Balance: gifts -30
```
