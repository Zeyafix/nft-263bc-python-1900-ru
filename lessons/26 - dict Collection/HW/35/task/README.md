# Задание 35. Посещаемость

Создайте программу `main.py`. 

Запросите имена посетителей одной строкой через пробел, затем минимальное число визитов от 1 без дробной части. Каждое имя — английское слово, регистр значим. Пустая строка имён допустима. Составьте и покажите словарь количества визитов в порядке первого появления имён. Затем покажите одной коллекцией тех, кто пришёл не меньше указанного числа раз, в том же порядке. Если подходящих имён нет, коллекция пуста.

## Пример 1

```text
Enter visitor names: Emma Liam Emma Olivia Liam Liam
Enter a minimum visit count: 2

Visits: {'Emma': 2, 'Liam': 3, 'Olivia': 1}
Selected visitors: ['Emma', 'Liam']
```

## Пример 2

```text
Enter visitor names: Emma Liam
Enter a minimum visit count: 2

Visits: {'Emma': 1, 'Liam': 1}
Selected visitors: []
```
