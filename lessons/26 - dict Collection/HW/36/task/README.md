# Задание 36. Очистка каталога

Создайте программу `main.py`. Используйте исходные данные:

```python
catalogs = [{"pen": 0, "ruler": 0, "book": 5, "paper": 0}, {}, {"tea": 0}, {"milk": 2}]
```

Для каждого каталога из catalogs удалите записи с нулевым остатком. Покажите удалённые названия одной коллекцией в исходном порядке записей, затем очищенный каталог целиком в порядке оставшихся записей. Если удалений нет, коллекция названий пуста. Не меняйте размер словаря во время его непосредственного перебора.

## Пример 1

```text
Removed: ['pen', 'ruler', 'paper']
Catalog: {'book': 5}

Removed: []
Catalog: {}

Removed: ['tea']
Catalog: {}

Removed: []
Catalog: {'milk': 2}
```
