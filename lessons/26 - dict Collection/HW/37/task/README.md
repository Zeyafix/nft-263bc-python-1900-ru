# Задание 37. Поиск по номеру

Создайте программу `main.py`. Используйте исходные данные:

```python
contacts = {"Emma": "00123", "Liam": "00456", "Olivia": "00123", "Noah": "123"}
```

Запросите телефон: от 3 до 15 цифр, ведущие нули значимы. Покажите все имена с этим номером одной коллекцией в порядке записей телефонной книги. Если совпадений нет, покажите пустую коллекцию. Телефон должен совпадать полностью. Книгу не изменяйте.

## Пример 1

```text
Enter a phone number: 00123
Matching names: ['Emma', 'Olivia']
```

## Пример 2

```text
Enter a phone number: 999
Matching names: []
```
