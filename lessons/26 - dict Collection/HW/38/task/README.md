# Задание 38. Объединение поставок

Создайте программу `main.py`. Используйте исходные данные:

```python
first = {"paper": 10, "pens": 0, "folders": 4}
second = {"pens": 7, "paper": 3, "clips": 0, "tape": 2}
```

Соберите новый общий словарь поставок. Для совпадающих товаров сложите количества, для остальных сохраните единственное количество. Нулевые количества сохраняйте. Порядок: сначала товары first в исходном порядке, затем новые товары second в его порядке. Выведите общий словарь, затем оба исходных: они должны остаться неизменными.

## Пример 1

```text
Combined: {'paper': 13, 'pens': 7, 'folders': 4, 'clips': 0, 'tape': 2}
First: {'paper': 10, 'pens': 0, 'folders': 4}
Second: {'pens': 7, 'paper': 3, 'clips': 0, 'tape': 2}
```
