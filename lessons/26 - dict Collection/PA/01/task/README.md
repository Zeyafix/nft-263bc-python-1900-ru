# Задание 01. Индексы кортежа

Создайте программу `main.py`. Используйте исходные данные:

```python
colors = ("red", "green", "blue", "yellow", "white")
```

Выведите первый, третий и последний элементы кортежа, каждый на отдельной строке. Получите их по неотрицательным индексам (нулевой индекс также разрешён).

## Пример 1

```text
First: red
Third: blue
Last: white
```
