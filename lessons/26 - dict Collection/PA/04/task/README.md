# Задание 04. Добавление и удаление в множестве

Создайте программу `main.py`. Используйте исходные данные:

```python
colors = {"red", "green", "blue"}
```

Добавьте "yellow" через add(), удалите существующий "green" через remove(), затем попробуйте удалить отсутствующий "black" через discard(). Покажите оставшиеся элементы одной коллекцией. Порядок свободный.

## Пример 1

```text
Colors: ['blue', 'red', 'yellow']
```
