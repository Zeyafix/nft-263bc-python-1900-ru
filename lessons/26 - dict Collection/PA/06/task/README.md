# Задание 06. Общие элементы

Создайте программу `main.py`. Используйте исходные данные:

```python
first = {"music", "coding", "chess"}
second = {"sports", "coding", "chess"}
```

С помощью isdisjoint() определите, пересекаются ли два множества. Выведите True, если общие элементы есть, иначе False. Затем получите общие элементы через & и покажите их одной коллекцией в любом порядке.

## Пример 1

```text
Have common interests: True
Common interests: ['chess', 'coding']
```
