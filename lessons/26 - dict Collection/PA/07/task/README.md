# Задание 07. Только с одной стороны

Создайте программу `main.py`. Используйте исходные данные:

```python
first = {"music", "coding", "chess"}
second = {"sports", "coding", "art"}
```

Через - получите элементы только первого множества, затем только второго. Покажите две коллекции в этом порядке. Внутри каждой порядок свободный.

## Пример 1

```text
Only first: ['chess', 'music']
Only second: ['art', 'sports']
```
