# Задание 09. Перебор frozenset

Создайте программу `main.py`. Используйте исходные данные:

```python
commands = frozenset({"open", "save", "quit"})
```

Пройдите по неизменяемому множеству и выведите каждую команду на отдельной строке. Порядок свободный.

## Пример 1

```text
Command: open
Command: quit
Command: save
```
