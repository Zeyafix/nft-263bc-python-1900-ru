# Задание 11. Ключ или значение

Создайте программу `main.py`. Используйте исходные данные:

```python
data = {"name": "Mia", "city": "Baku", "course": "Python"}
```

Через in проверьте наличие ключа "city", затем ключа "Baku". Отдельно через in data.values() проверьте наличие значения "Baku", затем значения "city". Выведите четыре результата True или False в указанном порядке.

## Пример 1

```text
City key exists: True
Baku key exists: False
Baku value exists: True
City value exists: False
```
