# Задание 15. Перебор ключей

Создайте программу `main.py`. Используйте исходные данные:

```python
data = {"Mia": 3, "Noah": 1, "Ava": 2}
```

Выведите каждый ключ на отдельной строке сначала проходом for key in data, затем проходом for key in data.keys(). Разделите два прохода английскими пояснениями. В каждом проходе сохраните порядок записей. Имена переменных свободные.

## Пример 1

```text
Direct iteration:
Mia
Noah
Ava

Keys iteration:
Mia
Noah
Ava
```
