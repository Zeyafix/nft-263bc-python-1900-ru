# Задание 18. Новая запись

Создайте программу `main.py`. Используйте исходные данные:

```python
prices = {"tea": 4, "cake": 7}
```

Покажите исходный словарь целиком. Добавьте пару "juice" — 5 присваиванием по отсутствующему ключу и покажите словарь после добавления. Остальные записи и их порядок должны сохраниться. Новая запись идёт в конце.

## Пример 1

```text
Before: {'tea': 4, 'cake': 7}
After: {'tea': 4, 'cake': 7, 'juice': 5}
```
