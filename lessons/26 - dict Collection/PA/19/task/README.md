# Задание 19. Новое значение

Создайте программу `main.py`. Используйте исходные данные:

```python
prices = {"tea": 4, "cake": 7, "water": 2}
```

Покажите исходный словарь. Измените цену "tea" на 6 и покажите словарь после изменения. Число записей, остальные цены и порядок записей сохраняются.

## Пример 1

```text
Before: {'tea': 4, 'cake': 7, 'water': 2}
After: {'tea': 6, 'cake': 7, 'water': 2}
```
