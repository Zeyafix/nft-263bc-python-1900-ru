# Задание 20. Удаление по ключу

Создайте программу `main.py`. Используйте исходные данные:

```python
prices = {"tea": 4, "cake": 7, "water": 2, "juice": 5}
```

Покажите исходный словарь. Удалите "tea" через del, затем "cake" через pop(). Покажите извлечённую цену cake, затем оставшийся словарь. Остальные записи сохраняются.

## Пример 1

```text
Before: {'tea': 4, 'cake': 7, 'water': 2, 'juice': 5}
Removed price: 7
After: {'water': 2, 'juice': 5}
```
