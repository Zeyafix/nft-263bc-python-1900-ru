# Задание 21. Расписание дня

Создайте программу `main.py`. Используйте исходные данные:

```python
schedule = ("Python", "English", "Python", "Design")
```

Покажите первое и последнее занятия, затем всё расписание по одному занятию на строке в исходном порядке. Повторяющиеся занятия также нужны.

## Пример 1

```text
First lesson: Python
Last lesson: Design

Schedule:
Python
English
Python
Design
```
