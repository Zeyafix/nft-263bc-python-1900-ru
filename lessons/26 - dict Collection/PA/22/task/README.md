# Задание 22. Замена дежурного

Создайте программу `main.py`. Используйте исходные данные:

```python
duties = ("Mia", "Noah", "Ava", "Liam")
```

Запросите номер позиции от 1 до 4, затем новое непустое имя на английском. Замените дежурного на выбранной позиции через временный список и покажите новый кортеж целиком. Другие позиции и их порядок сохраняются. Номер всегда допустимый, совпадение нового имени со старым разрешено.

## Пример 1

```text
Enter a position from 1 to 4: 2
Enter the new name: Zoe

Duties: ('Mia', 'Zoe', 'Ava', 'Liam')
```

## Пример 2

```text
Enter a position from 1 to 4: 1
Enter the new name: Tom

Duties: ('Tom', 'Noah', 'Ava', 'Liam')
```
