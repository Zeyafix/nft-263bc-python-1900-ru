# Задание 24. Интересы двух студентов

Создайте программу `main.py`. Используйте исходные данные:

```python
mia = {"coding", "music", "chess"}
noah = {"coding", "sports", "art"}
```

Покажите True, если есть общие интересы, иначе False. Затем покажите тремя коллекциями: общие интересы, интересы только Mia, интересы только Noah. Внутри каждой порядок свободный.

## Пример 1

```text
Have common interests: True
Common: ['coding']
Only Mia: ['chess', 'music']
Only Noah: ['art', 'sports']
```
