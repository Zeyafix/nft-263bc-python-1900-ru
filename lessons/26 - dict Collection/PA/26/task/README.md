# Задание 26. Перевод слова

Создайте программу `main.py`. Используйте исходные данные:

```python
synonyms = {"quick": "fast", "small": "little", "happy": "glad"}
```

Найдите английский синоним: запросите одно непустое слово на английском. Если оно есть среди исходных слов, покажите его синоним. Иначе сообщите об отсутствии слова. Регистр учитывается. Обратный поиск по синонимам не нужен.

## Пример 1

```text
Enter a word: quick
Synonym: fast
```

## Пример 2

```text
Enter a word: slow
Word not found
```
