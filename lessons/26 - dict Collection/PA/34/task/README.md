# Задание 34. Изменение цены билета

Создайте программу `main.py`. Используйте исходные данные:

```python
prices = {"Airport": 4.0, "Center": 1.5, "Beach": 2.0}
```

Запросите название существующего маршрута, затем новую цену, не более двух знаков после точки. Покажите прежнюю и новую цены с двумя знаками после точки, затем весь обновлённый справочник. Маршрут гарантированно есть, остальные цены и порядок записей сохраняются. В справочнике запись чисел свободная, например 4 и 4.0 означают одну цену.

## Пример 1

```text
Enter the route: Airport
Enter the new price: 5.25

Old price: 4.00
New price: 5.25

Prices: {'Airport': 5.25, 'Center': 1.5, 'Beach': 2.0}
```

## Пример 2

```text
Enter the route: Center
Enter the new price: 0

Old price: 1.50
New price: 0.00

Prices: {'Airport': 4.0, 'Center': 0.0, 'Beach': 2.0}
```
