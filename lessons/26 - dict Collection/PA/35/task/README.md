# Задание 35. Отмена бронирования

Создайте программу `main.py`. Используйте исходные данные:

```python
bookings = {"A12": "Mia", "B07": "Noah", "C31": "Ava"}
```

Запросите непустой код брони. Если код известен, удалите бронь и покажите имя её владельца. Иначе сообщите, что бронь не найдена. Затем в любом случае покажите оставшиеся бронирования. Регистр учитывается, а остальные записи и их порядок сохраняются.

## Пример 1

```text
Enter the booking code: B07
Cancelled booking for: Noah

Bookings: {'A12': 'Mia', 'C31': 'Ava'}
```

## Пример 2

```text
Enter the booking code: X99
Booking not found

Bookings: {'A12': 'Mia', 'B07': 'Noah', 'C31': 'Ava'}
```
