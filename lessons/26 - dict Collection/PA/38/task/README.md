# Задание 38. Пополнение запаса

Создайте программу `main.py`. Используйте исходные данные:

```python
stock = {"paper": 12, "wood": 0, "paint": 5}
```

Запросите непустое английское название материала, затем количество поступивших единиц. У существующего материала увеличьте запас на это количество, новый материал добавьте с таким запасом, даже если поступило 0. Покажите весь склад. Регистр учитывается, остальные запасы и порядок сохраняются; новый материал идёт в конце.

## Пример 1

```text
Enter the material: paper
Enter the delivered quantity: 3

Stock: {'paper': 15, 'wood': 0, 'paint': 5}
```

## Пример 2

```text
Enter the material: metal
Enter the delivered quantity: 7

Stock: {'paper': 12, 'wood': 0, 'paint': 5, 'metal': 7}
```
