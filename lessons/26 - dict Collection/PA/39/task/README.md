# Задание 39. Чек покупки

Создайте программу `main.py`. Используйте исходные данные:

```python
prices = {"bread": 1.5, "milk": 2.25, "apple": 0.75}
purchases = ["milk", "bread", "milk", "apple"]
```

Для каждой покупки покажите название и цену отдельной строкой в порядке покупок, затем общую сумму чека. Все товары есть в каталоге. Каждый повтор означает ещё одну покупку и учитывается в сумме. Цены и итог в манатах показывайте с двумя знаками после точки.

## Пример 1

```text
Purchase: milk 2.25
Purchase: bread 1.50
Purchase: milk 2.25
Purchase: apple 0.75
Total: 6.75
```
