# Задание 40. Счётчик цветов

Создайте программу `main.py`. Используйте исходные данные:

```python
colors = ["red", "blue", "red", "green", "blue", "red", "Red"]
```

Подсчитайте, сколько раз встретился каждый цвет, и соберите словарь «цвет — количество». Выведите пары по одной на строке в порядке первого появления цвета, цвет перед количеством. Регистр учитывается: "red" и "Red" — разные названия.

## Пример 1

```text
Color: red 3
Color: blue 2
Color: green 1
Color: Red 1
```
