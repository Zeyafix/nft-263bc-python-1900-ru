# Задание 01. Журнал студентов

Создайте консольное приложение `main.py`, в котором преподаватель ведёт журнал: добавляет студентов, меняет их данные и оценки, смотрит статистику по всему журналу и по группам.

В стартовом [main.py](main.py) уже находятся десять студентов. Сохраните их ID, имена, группы, оценки и порядок оценок при запуске. Внутреннее устройство программы можно выбрать самостоятельно. Все изменения действуют до завершения программы. При новом запуске журнал снова содержит стартовые данные. Сохранение в файл не требуется.

## Диалог с пользователем

Программа запрашивает команду, выполняет её и снова ждёт команду, пока пользователь не введёт `exit`. Перед каждым запросом, в том числе при добавлении студента, показывайте подсказки. Сопровождайте данные подписями. После изменения журнала сообщайте об успехе, а при ошибке — о причине. Текст подсказок и подписей выбирайте самостоятельно: в примерах показан лишь один вариант.

Первое слово команды — её название, следующие слова — аргументы. Между словами может быть несколько пробелов. Пробелы по краям не мешают выполнению. Регистр учитывается. ID, имя и группа — непустые обозначения без пробелов, например `s21`, `Anna`, `Python263`. При добавлении запрашивайте их отдельными строками. Если значение пустое или содержит пробелы, сообщите об ошибке и вернитесь к запросу команды, не добавляя запись. ID вводит пользователь, он должен быть уникальным.

Неизвестная команда, неверное число аргументов, отсутствующий ID или недопустимое значение не должны завершать программу или менять журнал. Сообщите о проблеме, напомните о `help` и снова запросите команду. Не запрашивайте дополнительные аргументы для ошибочной команды. Отдельный диалог предусмотрен только для `st_add`.

## Команды журнала

| Команда | Что делает |
| --- | --- |
| `help` | Показывает все команды, их аргументы и краткие описания. |
| `exit` | Завершает программу. |
| `st` | Показывает всех студентов: `<ID> - <name> - <group> - <grades>`. |
| `st <ID>` | Показывает карточку студента: ID, имя, группу, оценки и среднюю оценку, каждое поле на отдельной строке с подписью. Порядок полей именно такой. |
| `st_add` | Запрашивает ID. Если он занят, сообщает об ошибке и возвращается к командам, не запрашивая имя и группу. Иначе запрашивает имя, затем группу и добавляет студента без оценок. |
| `st_rm <ID>` | Удаляет студента. Освободившийся ID можно использовать снова. |
| `st_set_name <ID> <name>` | Меняет имя студента. |
| `st_set_group <ID> <group>` | Переводит студента в другую группу. |
| `st_add_grade <ID> <grade>` | Добавляет оценку в конец оценок студента. Допустимы оценки от 1 до 12 без дробной части. |
| `st_rm_grade <ID> <position>` | Удаляет оценку по её порядковому номеру, начиная с 1. Остальные оценки сохраняют взаимный порядок. |
| `st_ch_grade <ID> <position> <grade>` | Заменяет оценку на указанном месте. Требования к оценке и номеру такие же, как выше. |

Номер оценки должен соответствовать существующей оценке: нельзя удалить или заменить нулевую, отрицательную или отсутствующую позицию. Оценки, позиции и количество студентов в рейтинге записываются десятичными цифрами, например `12`, `2`, `3`; запись `2.0` не подходит.

## Статистика и группы

Средняя оценка — сумма всех оценок студента, делённая на их количество. Показывайте её с двумя знаками после точки. Если оценок нет, показывайте `N/A`, а на месте самих оценок — `-`. В обычных списках и карточках такие студенты остаются, а в рейтинги лучших и худших не входят. Сравнивайте средние до округления.

| Команда | Что делает |
| --- | --- |
| `st_stats` | Показывает всех студентов: `<ID> - <name> - <group> - <average>`. |
| `st_stats_best` | Показывает одного студента с наибольшей средней оценкой. |
| `st_stats_best <num>` | Показывает до `<num>` лучших студентов по убыванию средней оценки. |
| `st_stats_worst` | Показывает одного студента с наименьшей средней оценкой. |
| `st_stats_worst <num>` | Показывает до `<num>` худших студентов по возрастанию средней оценки. |
| `st_group` | Для каждой группы показывает её название отдельной строкой с подписью, а под ним — всех студентов этой группы. |
| `st_group_best` | Для каждой группы показывает её название и одного лучшего студента этой группы. |
| `st_group_best <num>` | Для каждой группы показывает её название и до `<num>` лучших студентов по убыванию средней оценки. |
| `st_group_worst` | Для каждой группы показывает её название и одного худшего студента этой группы. |
| `st_group_worst <num>` | Для каждой группы показывает её название и до `<num>` худших студентов по возрастанию средней оценки. |

Строка общего рейтинга имеет вид `<ID> - <name> - <group> - <average> - <grades>`. Строка под названием группы во всех групповых командах имеет вид `<ID> - <name> - <average> - <grades>`. В поле `<grades>` оценки разделяются пробелами. Символы `<...>` обозначают места для данных и не выводятся.

Количество `<num>` должно быть не меньше 1. Если запрошено больше студентов, чем имеют оценки, покажите всех подходящих студентов. Для групповых рейтингов этот предел применяется отдельно к каждой группе. При равных средних допустим любой взаимный порядок; если на границе рейтинга несколько равных результатов, можно выбрать любой из них. Порядок групп, обычных списков и строк `st_stats` свободный.

Если журнал пуст, сообщите об этом. Если для рейтинга нет студентов с оценками, выведите пояснение вместо строк рейтинга. В групповом рейтинге сохраняйте заголовки существующих групп без оценок и под каждым таким заголовком сообщайте об отсутствии оценок. Группу, из которой удалили или перевели последнего студента, больше не показывайте.

Grade added.

Group: Python263
Grades: 12 8
Average grade: 10.00
