Требуется создать журнал студентов в виде консольного приложения.

Студент это словарь вида:
{"name": str, "group": str, "grades": list[int]}

У каждого студента есть ID, который он получает при создании студента. Все студенты хранятся в словаре вида:
{"<ID>": <студент>}

Тестовые данные:

```python
students = {
    {"s01": {"name": "Teston", "group": "Python263", "grades": [12, 12, 12]}},
    {"s19": {"name": "Kate", "group": "Python263", "grades": []}},
    {"s05": {"name": "Tom", "group": "CSharp263", "grades": [11]}},
    {"s09": {"name": "Bob", "group": "CSharp263", "grades": [7, 2]}},
    {"s12": {"name": "Arthur", "group": "Python263", "grades": []}},
    {"s09": {"name": "Jane", "group": "CSharp263", "grades": [12, 11, 12]}},
    {"s09": {"name": "Sam", "group": "Python263", "grades": [9, 8, 9]}},
    {"s09": {"name": "Todd", "group": "Python263", "grades": [9, 8, 9]}},
    {"s09": {"name": "Rick", "group": "Python262", "grades": [12, 12, 12, 11, 12]}},
    {"s09": {"name": "Alice", "group": "CSharp263", "grades": [4, 3, 5]}}
}
```

Программа всегда запрашивает команду. При старте доступны следующие команды:

- help - показывает доступные команды.
- exit - завершает программу.
- st - показывает всех студентов в консоли в формате "<ID> - <name> - <group> - <grade> <grade> <grade> ...".
- st <ID> - показывает данные студента с <ID> в формате "ID: <ID>\nName: <name>\nGroup: <group>\nGrades: <grade> <grade> <grade>\nAverage grade: <average_grade>"
- st_add - запускает процесс добавления студента. Запрашивает ID. Если ID уже существует, то оповещает. Иначе запрашивает имя и группу, создаёт студента. Список оценок изначально пустой.
- st_rm <ID> - удаляет студента по <ID> из students.
- st_set_name <ID> <name> - изменяет студенту с <ID> имя на <name>.
- st_set_group <ID> <group> - изменяет студенту с <ID> группу на <group>.
- st_add_grade <ID> <grade> - добавляет студенту с <ID> оценку <grade>. Оценка может быть целое число от 1 до 12 включительно.
- st_rm_grade <ID> <position> - удаляет у студента с <ID> оценку по порядковому номеру <position>.
- st_ch_grade <ID> <position> <grade> - изменяет студенту с <ID> оценку по порядковому номеру <position> на оценку <grade>. Оценка может быть целое число от 1 до 12 включительно.
- st_stats - показывает всех студентов в консоли в формате "<ID> - <name> - <group> - <average_grade>".
- st_stats_best - показывает данные одного студента в формате "<ID> - <name> - <group> - <average_grade> - <grade> <grade> <grade>", у которого самая высокая средняя оценка.
- st_stats_best <num> - показывает указанное <num> студентов в формате "<ID> - <name> - <group> - <average_grade> - <grade> <grade> <grade>", у которых самая высокая средняя оценка. Требуется показывать в отсортированном виде по убыванию <average_grade>. Если <num> превышает количество студентов, то показываются все.
- st_stats_worst - показывает данные одного студента в формате "<ID> - <name> - <group> - <average_grade> - <grade> <grade> <grade>", у которого самая низкая средняя оценка.
- st_stats_worst <num> - показывает указанное <num> студентов в формате "<ID> - <name> - <group> - <average_grade> - <grade> <grade> <grade>", у которых самая низкая средняя оценка. Требуется показывать в отсортированном виде по возрастанию <average_grade>. Если <num> превышает количество студентов, то показываются все.
- st_group - показывает всех студентов, где сперва указана <group>, а затем под ним данные всех студентов в формате "<ID> - <name> - <average_grade> - <grade> <grade> <grade>"
- st_group_best - показывает студента, где сперва указана <group>, а затем под ним данные одного студента в формате "<ID> - <name> - <average_grade> - <grade> <grade> <grade>", у которого самая высокая средняя оценка.
- st_group_best <num> - показывает указанное <num> студентов, где сперва указана <group>, а затем под ним данные <num> студентов в формате "<ID> - <name> - <average_grade> - <grade> <grade> <grade>", у которых самая высокая средняя оценка. Требуется показывать в отсортированном виде по убыванию <average_grade>. Если <num> превышает количество студентов в группе, то показываются все.
- st_group_worst - показывает студента, где сперва указана <group>, а затем под ним данные одного студента в формате "<ID> - <name> - <average_grade> - <grade> <grade> <grade>", у которого самая низкая средняя оценка.
- st_group_worst <num> - показывает указанное <num> студентов, где сперва указана <group>, а затем под ним данные <num> студентов в формате "<ID> - <name> - <average_grade> - <grade> <grade> <grade>", у которых самая низкая средняя оценка. Требуется показывать в отсортированном виде по возрастанию <average_grade>. Если <num> превышает количество студентов в группе, то показываются все. 

При вводе неверной команды показывается оповещение, а также подсказка о доступных командах. Для упрощения, введённый текст в качестве команды до первого пробела считается командой, а все последующие через пробел аргументами этой команды.
